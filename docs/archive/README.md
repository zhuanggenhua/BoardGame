# 历史归档

[`docs/archive/`](README.md) 只保留从根目录或旧入口迁走、仍可能需要人工回查的历史材料。这里的内容不是当前任务入口，也不承载 AI 执行规范。

| 目录 | 用途 |
| --- | --- |
| [`session-state/`](session-state/README.md) | 旧会话计划、进度和发现记录；仅作历史回查 |
| [`kiro/`](kiro/README.md) | 旧 Kiro 自动恢复与窗口监控方案；已退役，仅作经验回查 |
| [`reports/`](reports/README.md) | 旧修复报告、审查报告和方案分析；不是当前入口 |
| [`testing/`](testing/README.md) | 旧测试设计提案；只作历史回查 |
