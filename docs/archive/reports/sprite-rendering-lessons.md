# 精灵图渲染经验归档

本文是 Summoner Wars 卡牌精灵图裁切问题的历史摘要。

## 当时问题

横向多帧精灵图渲染时出现黑色区域。单纯用 `<img>` 位移、`margin-left`、`background-position` 或 `object-fit` 都没有稳定解决。

## 保留结论

- 精灵图不能只按等分宽高裁切；要记录真实内容区域。
- 最终采用类似 `CardAtlasConfig` 的精确帧配置：图集总宽高、列 / 行数量、每列起点与宽度、每行起点与高度。
- 关键点是把行高设为真实内容高度，而不是图集总高度，从而裁掉底部填充区。

## 当前使用口径

新图集问题优先回到当前图集配置、裁图脚本和资源验收流程；本文只提示不要重复尝试已证明不稳定的裁切方式。
