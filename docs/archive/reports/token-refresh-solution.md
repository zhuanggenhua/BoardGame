# WebSocket 自动重连方案归档

本文是旧自动重连方案摘要，不作为当前传输层合同。

## 当时问题

- 浏览器后台会节流或冻结计时器。
- socket.io 心跳超时后，自动重连可能不能及时执行。
- 仅靠 `visibilitychange` 不能覆盖“页面仍可见但浏览器在后台”的场景。

## 当时方案

- 增加统一健康检查，每 30 秒检查连接状态并主动 `connect()`。
- 页面恢复可见时立即重连并重新同步。
- 对局内同步请求增加超时重试，降低长时间失焦后的状态落后风险。
- 覆盖 LobbySocket、SocialSocket、MatchSocket 和 GameTransportClient。
