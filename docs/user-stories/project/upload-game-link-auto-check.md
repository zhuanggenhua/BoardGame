# 游戏链接自动检测防止基本错误

## 用户原始要求

2026-10-12，用户明确说明：

> 用户故事加一下，游戏链接可以自动检测防止404等基本错误

## 覆盖范围

- 上传工坊里「游戏链接」字段：上传新游戏、编辑已提交游戏。
- 粘贴或改写链接后自动检测，不要求玩家先点保存才知道坏链。
- 基本错误至少包括：空链接、不是网页地址、链接格式不对、页面不存在（404）。

## 项目级裁定

- 链接输入框下方常驻检测结果，状态为待填写、正在检测、可以打开、打不开。
- 打不开或格式不对时，保存资料和提交审核不得当成成功。
- Open Design 先把检测结果画在上传页上；落地 `src/` 时对真实地址做请求检测。

## 验收标准

1. 上传页已有链接时，玩家能看见「可以打开」或等价通过文案。
2. 空链接时，玩家能看见会自动检测的提示。
3. 格式不对或页面不存在时，玩家能看见失败文案，且不能靠提交混过去。

## 不覆盖范围

- 不检测玩法能否运行、封面是否匹配、规则是否完整。
- 不在本条改发现页或收藏库的外链打开方式。
