# 图片优先真相源规则

## 用户原始要求

2026-05-12，用户明确说明：

> 图片是唯一标准。
> 图片优先于 wiki，除非明确在用户故事说明，规范没说就加一下。

## 项目级裁定

- 清晰图片、截图、扫描件覆盖当前字段时，图片是主真相源。
- Wiki、社区资料、抓取脚本结果只能作为对照源。
- 只有用户故事、需求单或当轮用户明确说明需要偏离图片时，才允许覆盖图片口径。
- 偏离图片的需求必须在本目录和对应游戏规则/evidence 文档中留档。

## 不覆盖范围

- 图片没有覆盖、看不清或字段无法从图片唯一读出时，仍按项目数据录入规范继续查规则书、官方资料、既有规则文档或请求用户裁定。
- 该规则不授权凭记忆补全图片外信息。
