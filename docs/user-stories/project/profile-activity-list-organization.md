## 项目级裁定

从点名 `个人主页.png` 迁出的组织不变量：

1. 两列：左主列是身份 + 最新动态横条列表，右列是侧栏。
2. 身份：大方头像 + 名字。
3. 「编辑个人资料」在右侧栏。
4. 主列有「最新动态」标题，标题右侧写这段时间的游玩时长。
5. 每条动态是横版胶囊：左横图、中游戏名、右时长 / 上次游玩。
6. 收藏在侧栏写成数量。
7. 左右两侧留给资料背景，中间才是内容井；内容井不得拉满整宽。

从 BGG 公开截图迁出的分数语义（`refs/bgg-rank-display/`）：

- 排行只属于游戏：列表最左列是游戏位次，排行种类页全是游戏榜。用户资料没有玩家排行。
- 用于排名的分是列表里的 Geek Rating（三位小数）。Average / Avg. Rating 是原始均分。彩色格 / My rating 才是玩家给这款游戏打的 1 到 10 分。
- 本产品「分数」对齐用于排名的那一列，标签写「分数」，不写「评分」。
- 局数对齐 Plays。
- 个人页没有「当前正在游戏」。

本产品字段：侧栏只有游玩时长、局数、收藏。排行和分数只出现在游戏动态行，表示该游戏的位次和排名分。不搬等级、成就、徽章、经验、当前正在游戏、对局分数、玩家评分。

「当前正在游戏」出现在 Steam 资料页右侧栏和第一条动态上，属于 Steam 在线状态壳，不进本产品字段。

## 验收标准

1. 个人主页主内容是动态横条列表，左右露出资料背景。
2. 右侧能看见编辑个人资料、游玩时长、局数、收藏数量。没有排行，没有评分。
3. 动态行能看见该游戏的局数、排行位次、分数（排名分，三位小数）。
4. 没有当前正在游戏、没有对局分数、没有成就、没有等级。
5. 截图对照的是 `个人主页.png` 的组织和留白；排行和分数对照 BGG 游戏榜，不对照玩家资料。

## 不覆盖范围

- 不复制 Steam 深色皮肤、等级、徽章、成就进度条、展柜。
- 不复制 BGG 紫顶栏、星星控件或数据库整表。
- 不把个人主页做成收藏库封面墙。
