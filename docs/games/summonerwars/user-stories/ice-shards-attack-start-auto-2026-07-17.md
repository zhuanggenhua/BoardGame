# 召唤师战争 - 寒冰碎屑攻击阶段自动结算

## 用户原始要求

- 「寒冰碎屑」不是一个玩家选择交互，不应该出现确认、跳过或是否执行选择。
- 正确触发时机是攻击阶段开始时。
- 触发后应对每个与友方建筑相邻的敌方单位造成伤害；结果必须可见，不能只证明提示出现。

## 覆盖对象和字段

- 游戏：召唤师战争。
- 对象：贾穆德「寒冰碎屑」（`ice_shards`）。
- 覆盖字段：
  - 触发时机：攻击阶段开始。
  - 可选性：强制自动结算，不提供确认/跳过 UI。
  - 资源消耗：触发时消耗 1 点充能。
  - 结果：每个与友方建筑相邻的敌方单位受到 1 点伤害，多建筑相邻不重复伤害。

## 覆盖原因

- 当前反馈命中的是线上可见行为：旧实现出现确认/跳过提示，且用户反馈有人在魔力阶段看到触发、没有实际效果。
- 旧 E2E 只证明“提示存在”和“未确认不推进”，没有证明寒冰碎屑真实伤害结果，验收口径错误。
- 本用户故事覆盖旧的“建造阶段结束 / 可选择确认或跳过”证据口径。历史证据可保留为旧实现背景，但不得再作为当前规则真相。

## 验收标准

- 从建造阶段点击结束阶段进入攻击阶段时，寒冰碎屑自动结算。
- 页面不得出现寒冰碎屑确认按钮、跳过按钮或是否执行提示。
- 结算后仍处于攻击阶段。
- 贾穆德充能减少 1。
- 每个与友方建筑相邻的敌方单位受到 1 点伤害。
- E2E 必须同时断言“没有选择 UI”和“伤害/充能结果已经落位”。

## 不覆盖范围

- 不改变其它真正可选阶段技能，例如喂养巨食兽、寄生、呼叫守卫。
- 不改变寒冰碎屑伤害执行器的目标去重逻辑。
- 不把该单卡规则升格成所有阶段开始技能都自动结算；是否可选仍以具体规则文本和用户故事为准。
