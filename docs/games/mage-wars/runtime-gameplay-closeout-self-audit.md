## 证据边界

- `e2e/mage-wars/online-runtime.e2e.ts` 是本次正式玩法 E2E；它创建正式双人房间、双方占座 / 加入并通过页面点击推进。
- `e2e/mage-wars/foundation-board-runtime.e2e.ts` 是基础牌桌和布局覆盖；它能证明素材、桌面 / 移动横屏基础布局和攻击结算视觉，但不能替代正式双人联机玩法链。
- 这次装备 / 结界显示问题的现实原因不是缺少“装备不是随从”的新规范；规则合同和设计文档已有附件表达要求。失败发生在实现层把所有 `fieldObjects` 复用同一个场上单位卡片组件，以及验收层只检查状态附着，没有断言 UI 附件语义。
- 后续凡证明附着物流程，必须同时检查状态关系和可见表达：装备 / 结界附件要出现在宿主附件槽，且不得作为 `mage-wars-zone-field-card` 这类主场上单位卡片出现。
- 状态注入布局类 E2E 只能证明布局回归，不再作为玩法完成证据。
- 曾临时新增的 `e2e/mage-wars/runtime-gameplay.e2e.ts` 是单页本地辅助入口，会和双方 ready 规则冲突；本次已从交付中移除，避免误伤 closeout。
- `_shared/online-runtime.e2e` 下的旧截图是早期归档路径错误的历史证据，不作为本文件依据。
- 墙体 / 墙壁类必须作为独立后续切片处理；它们需要自己的运行对象、区域边界目标、视线 / 通行规则、浏览器 E2E 和截图证据，不能被现有代表链吞掉。
- 本文件不是 Mage Wars 整体完成宣告；后续应继续围绕墙体 / 墙壁类、全量法术、自由构筑、更多法师、教程、完整 AI、行动日志 UI 和撤回 UI 分 change 推进。
