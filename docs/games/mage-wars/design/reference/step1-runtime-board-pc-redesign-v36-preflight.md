## 外部范式回代

| 来源 | 采用结论 | v36 设计动作 |
| --- | --- | --- |
| BGA Studio Guidelines | 主游戏区域居中，桌游适配应让玩家不用重新学习实体桌面，交互对象不应过小 | 只展示当前可交互的 2x3 学徒半场，并把六格放大为主棋盘 |
| BGA UX Guidelines | 当前玩家本回合所需信息优先，次要信息滚动 / 次级化 | 法术书完整浏览不在结算态展开；只保留入口和数量 |
| Magic Online card zoom update | 卡牌游戏读卡需要稳定大图 / 放大机制 | 当前火球术在右下作为大卡工作台，不再依赖底部缩略 |
| Apple HIG Game Controls | 不相关或不可用控制应隐藏以减少遮挡 | 无常驻确认 / 取消；不可用候选不占主 UI |
| Microsoft HUD guidance | HUD 应让玩家不离开主玩法视线理解状态 | 骰子和伤害仍贴 B2 目标，但改成轻量上层，不再把所有结果堆在目标卡旁 |

## 空间预算

| 区域 | 最大可见对象 | 最小可读尺寸 / 策略 | 让位顺序 |
| --- | ---: | --- | --- |
| 学徒半场主棋盘 | 4 张场上卡 + 1 组轻量结算 + 1 个目标高亮 | 六格各约 `320x320`；场上卡约 `112x157`；骰带与状态贴附不压目标卡 | 未用半场退场；先删路径线、再删重复标签、再拆散结果团块 |
| 当前工作台 | 当前火球术 + 另一张已计划 + 法术书入口 + 弃牌堆入口 | 当前火球术约 `268x378`；入口只显示数量 / 顶牌 | 当前已计划优先，完整法术书候选让位到浏览态 |
| 结算浮层 | 3 颗攻击骰 + 1 颗效果骰 + 2 个结果 token | 骰带贴 B2 上沿，伤害 / 燃烧贴目标右侧，结果文字退到工作台摘要 | 若拥挤，缩小或分散结算元素，不移动到侧栏 |
| 法师 HUD | 双方法师牌 + 生命 / 法力 / 聚魔 + 行动 / 守卫 token | 法师牌在昵称上方；血条蓝条贴法师，不复现状态板 | 不抢主棋盘，不进入法术工作台 |
| 归档入口 | 法术书、弃牌堆、对手已计划和弃牌 | 只显示卡背 / 顶牌 / 数量 | 永远让位给当前来源和当前目标 |

## 前置硬失败禁止清单

- 不得出现规则不存在的手牌 / hand / opponent-hand。
- 不得保留底部不可读混合牌区。
- 不得用远处重复大图替代当前工作台。
- 不得让未用半场占据主画布。
- 不得把骰子、伤害或燃烧移到侧栏。
- 不得让目标、骰子、伤害、燃烧和标签在 B2 形成单个注意力团块。
- 不得出现常驻确认 / 取消 / 提交 / 下一步。
- 用户批准前不得进入真实 Board/UI、真实页面 E2E 或移动端。
