# Mage Wars v58 法术书密度与稳定选中态前置回执

> 状态：`preflight-ready / open-design-artifact-only / media-generate-forbidden / human-review-not-allowed-until-ai-pass`。本文件只服务 v58 Open Design artifact 设计稿；不批准真实 Board/UI 实现、真实运行页 E2E 或移动端适配。

## 本轮问题本质

v57 撤销通过不是因为某个坐标微调，而是三条设计前提失败：

- **法术书容量失真**：规则合同锁定学徒法术书为兽王 33 张，女祭司 / 邪术师 / 巫师各 30 张。一页 4 张意味着 30 张约 8 页，玩家需要频繁翻页，不能代表真实法术书浏览体验。
- **已计划牌归属错误**：已计划法术最多 2 张，语义上属于当前行动 / 回合推进相关操作区；它应贴近 `回合结束` 上方，不应占中下主空间。
- **选中态改变布局**：左右特大牌让选中 / 焦点 / 来源状态看起来像额外实体。选中态只能改变高亮、层级、短状态和临时 inspect，不得改变常驻布局占位。

## 规则到画面结论

| 规则 / 数据结论 | 影响主体 | v58 设计决策 / 禁止项 |
| --- | --- | --- |
| 法术书总量为 30/33 张 | 法术书浏览器 | 每页至少 8 张，建议 10 张；页码必须按真实容量显示为 `1 / 3` 或 `1 / 4`，不得继续一页 4 张 |
| 已计划法术最多 2 张 | 已计划区、回合结束按钮 | 已计划牌放到 `回合结束` 上方，形成当前行动 / 结束回合操作带；两张紧凑横排或轻叠，不能占中下大区 |
| 选中 / 焦点 / 来源态不是新实体 | 法术书卡、已计划卡、场上目标 | 卡牌常驻同尺寸；通过金色描边、轻微抬升、短状态贴附和 inspect 图标表达，不允许常驻特大牌改变布局 |
| 读完整卡面需要，但不是常驻主态 | 法术书与已计划法术 | 完整读卡进入 hover / focus / inspect 临时层；主态只显示真实卡面缩略和稳定密度，不外部复写卡名 / 费用 / 射程 / 目标 |
| 当前目标选择仍在棋盘本体完成 | B2 目标、骰子、token | 保留 B2 高亮、骰子和伤害 / 燃烧 token；法术书和计划区不得遮挡当前目标、场上卡或 token 宿主 |
| 弃牌堆是公开归档入口 | 弃牌堆 | 只显示卡背堆 + 数量；不得用弃牌堆正面牌或大区域抢当前决策空间 |

## v58 空间预算

| 层级 | 对象 | 预算 / 要求 |
| --- | --- | --- |
| 主舞台 | 学徒 `2x3` 竞技场 | 保持第一视觉；底图是最低层，可被低权重 overlay 覆盖，但格子语义、场上卡、目标、骰子和 token 必须可读 |
| 法术书 | 当前玩家法术书 | 底部开放书页 / 牌轨，宽度服务 8-10 张卡；卡间可轻微叠压，但不能让一页少于 8 张 |
| 已计划法术 | 己方 2 张已计划 | 贴在右下 `回合结束` 上方；常驻卡宽约 `94-112px`，来源态不通过放大改变布局 |
| 当前选择反馈 | 法术书当前焦点、已计划来源、B2 目标 | 同尺寸高亮、角标、短状态、目标高亮；不出现左右特大牌或第二工作台 |
| 检视层 | hover / focus / inspect | 可以大图读卡，但属于临时层；本张常驻饱和主态不展开 inspect |
| 归档入口 | 弃牌堆 | 右下边缘紧凑入口，不与已计划牌或回合结束按钮抢空间 |

## v58 出图硬禁止

- 禁止可见文字 `手牌`。
- 禁止卡外重复显示卡名、费用、射程、目标、类型、等级或正文。
- 禁止法术书一页少于 8 张。
- 禁止页码与 30/33 张容量不匹配，例如一页 4 张却显示 `1 / 5`。
- 禁止已计划牌远离 `回合结束` 按钮或占据中下大主区。
- 禁止通过左右特大牌、第二卡面、第二工作台表达选中 / 焦点 / 来源态。
- 禁止删除骰子、效果骰、伤害 token、燃烧 token、守卫 token、行动 / 快速施法 token、法术书、已计划法术、弃牌堆和对手已计划卡背。
- 禁止为了显示法术书遮挡 A3 / B3 场上卡、B2 目标、骰子、token 或区域归属。

## v58 AI 核验门

- v58 必须导出 1920x1080 PNG 后再审图。
- PASS 最低条件：法术书一页卡数 `>= 8`；页码与真实容量一致；已计划牌在回合结束上方；选中态不改变常驻布局占位；无可见 `手牌 / 确认 / 执行 / 取消`；用户点名的骰子、token、计划区、法术书、弃牌堆、对手计划卡背仍可见。
- AI 图面核验 PASS 后才允许打开给用户人工验收；未 PASS 只记录为失败候选，不打开。
