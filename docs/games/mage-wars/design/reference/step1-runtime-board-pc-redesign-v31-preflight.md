## 外部范式回代

| 范式结论 | v31 设计决策 |
| --- | --- |
| 当前可支配卡牌必须可读 | 当前已计划火球术放大为底部来源卡，并在右下提供大焦点预览 |
| 小候选必须有焦点预览 / 抽屉 | 法术书候选只显示 3 张较大候选，完整浏览交给分页；右下承担焦点详情职责 |
| 主舞台不能被所有对象同时挤占 | 中央隐藏路径线，骰子从 6 颗降噪到 3 颗代表 + 效果骰，token 贴目标下方 |
| 空白必须有职责 | 右下角改为当前法术详情与费用 / 目标状态，不再留空 |
| 规则术语必须真实 | 继续只使用法术书、已计划法术、弃牌堆、目标和结算；不出现手牌 |

## 空间预算

| 区域 | 最大可见对象 | 最小可读尺寸 / 策略 | 让位顺序 |
| --- | ---: | --- | --- |
| 竞技场主舞台 | 4 张场上卡 + 目标高亮 + 1 组结算 | 场上卡保持 `94x132`，目标和骰子不互相覆盖 | 先删路径线，再收结算装饰，再收候选牌 |
| 当前来源 | 2 张已计划法术 | 当前火球术 `118x166`，同屏右下 `164x231` 焦点预览 | 保留当前来源，压缩非当前已计划 |
| 法术书浏览 | 3 张候选 + 分类 + 分页 | 候选 `92x130`；完整浏览靠分页 / 抽屉 | 收掉第 4/5 张候选，不硬塞 |
| 右下焦点 | 1 张大卡 + 费用 / 目标短状态 | 右下必须承担焦点预览，不得空置 | 若中央拥挤，右下承接详情 |
| 归档入口 | 双方弃牌堆小入口 | 只显示顶牌 / 数量，不进中央 | 永远让位给当前来源和结算 |

## 前置硬失败禁止清单

- 底部牌区变成不可读小牌墙。
- 右下角空置，同时当前来源或候选不可读。
- 中央目标、骰子、路径线、token 和牌区 overlay 挤成一团。
- 规则不存在的手牌 / hand / opponent-hand。
- 常驻确认 / 取消 / 提交 / 下一步。
- 用户批准前进入真实 Board/UI、真实页面 E2E 或移动端。
