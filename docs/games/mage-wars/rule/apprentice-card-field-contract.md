## 字段说明

- `费用`：左上角主法力费用；若卡面存在额外费用或 X 费用，在效果字段另列。
- `类型 / 学派`：右上角卡牌类型和学派 / 元素文字。
- `等级`：右侧圆形等级数字。
- `攻击条`：只记录会影响结算的骰数、效果骰、关键特性和规则文字；图标语义无法逐字确认时保留中文可读结果。
- `正文原文`：只录入卡面中具有规则效果的正文。单纯风味引文不作为基础版执行字段锁定。
- `生物 / 魔物字段`：记录费用、类型 / 子类、学派 / 元素、等级、射程 / 召唤目标、生命、护甲、攻击条、特性和规则正文；攻击名称只在卡面可读时写入。
