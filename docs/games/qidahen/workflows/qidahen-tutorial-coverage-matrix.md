## 当前结论

### 已经证明的部分

- 当前教程不是空白壳。
- 当前目录真实可见 6 个主章节，不再只是计划态。
- 基础回合、轮盘代价、轮盘发展分支、军备、事件、野战、撤退、攻城、外交、跨年、朝鲜朝贡/耗损、地图特例，都至少有一条真实截图链或隐藏续章承接。

### 还不能宣称完成的部分

- 基础章已收掉“首个主操作跳过轮盘真实选择”的错误，并补成真实手牌上限弃牌、轮盘推进、一次手牌行动和轮盘结果提示链；但正式局完整手牌一级入口仍受 2.4 缺口限制。
- 当前教程里能示范 `升级军备 / 事件行动`，不等于正式局已经具备规则书级真实手牌入口。
- 战斗章还没真正教满战术、水路、中立、避战、劫掠这些关键规则。
- 轮盘发展章虽然已有 `wheel-reclaim / wheel-military-farm / wheel-recruit-train` 等隐藏续章证据，但主章节与续章的玩家心智连续性还没被重新审清。
- 年序章与地图特例章虽然已分开命名，也已补到朝鲜朝贡/耗损摘要链，但部分证据仍偏摘要态，没有把关键规则真正教透。
