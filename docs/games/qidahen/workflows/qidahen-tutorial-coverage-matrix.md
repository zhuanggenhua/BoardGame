# 七大恨教程覆盖矩阵

> 目的：把“规则条目 -> 教程章节 -> 证据截图/用例”先锁清，再继续扩教程实现。

## 当前章节设计

1. `basic-opening`
   - 目标：从真实开局主入口走完一次手牌行动和一次轮盘行动。
2. `wheel-shared-cost`
   - 目标：看懂轮盘走 3 格时，两家对手如何抽牌，以及轮盘如何把当前回合推进到进攻调度。
3. `armament-upgrade`
   - 目标：从真实手牌行动入口升级一次军备，看到弃牌与军备等级变化。
4. `diplomacy-and-hire`
   - 目标：从真实轮盘外交/雇佣入口进入，完成一次外交、雇佣与结果收口。
5. `attack-and-battle`
   - 目标：从真实进攻调度入口进入，接一次野战结算与战后处理。
6. `retreat-and-rout`
   - 目标：从真实野战待结算入口进入，看懂断后和溃退的代价差异。
7. `siege-and-occupation`
   - 目标：看懂城战胜利后，占领与围城的差别。
8. `year-and-characters`
   - 目标：看懂年中判定、新年维护、纪年卡争分与跨年后的顺位变化。
9. `korea-and-special-map-rules`
   - 目标：看懂朝鲜、汉城、水路和山海关这些会直接改玩法的地图特例。

## 审计结论

- 当前 9 章**不是空白教程**，但也**还不能算完成**。
- 已经有真实截图和真实交互证据的部分，主要集中在：
  - 基础回合里的一次势力行动支付
  - 一次从真实轮盘入口进入的“走 3 格 -> 两家对手抽牌 -> 进攻调度”链
  - 一次从真实进攻调度入口进入的野战链
  - 一次从真实野战待结算入口进入的撤退惩罚链
  - 一次从真实城战待结算入口进入的围城选择
  - 一次外交与雇佣结算
  - 年中 / 新年结算入口
- 仍然存在三类问题：
  - **口径错误**：有些句子把规则顺序讲反了，或把“提到过”误当成“真的教会了”。
  - **部分覆盖**：有些规则只在说明里提到，但没有真实操作或结果证据。
  - **完全缺失**：还有几条核心规则链根本没进当前教程体系。

## 当前主要问题

1. **基础回合口径有冲突**
   - 当前文案把“先转动公共轮盘”写成硬顺序，但当前基础章真实流程是先做一次势力行动、再做轮盘推进。
   - 下一版必须先裁清：到底要按规则改教程顺序，还是按当前实现改文案；两者不能继续并存。

2. **当前矩阵把“提到过”误当成“已教会”**
   - 例如事件牌、战术牌、纪年卡、人物判定，都只是文案提到或摘要提到，不等于玩家已经通过真实局面学会。

3. **战斗教程虽然进了真实入口，但规则面还没教满**
   - 现在已经有“真实进攻调度 -> 野战 -> 战后处理”和“真实城战待结算 -> 围城选择”两条链。
   - 但移动距离、水路、中立守军、战术阶段、撤退惩罚、守城时机这些关键规则还缺真实操作证据。

## 下一版章节建议

> 这不是最终文案，只是下一轮重写时建议采用的章节骨架。

1. `basic-opening`
   - 讲赢法、手牌四种类型、一条真实势力行动支付、共享轮盘的基本推进。
2. `attack-and-battle`
   - 从真实进攻调度入口进入，教部队移动、边界 / 水路 / 中立入侵，然后打一场完整野战。
3. `siege-and-occupation`
   - 在上一章之后单独讲城战、守城、围城、占领差异。
4. `diplomacy-and-hire`
   - 讲友好 / 附庸 / 控制区，以及雇佣军落点和控制关系。
5. `year-and-characters`
   - 把年中 / 新年 / 人物判定 / 纪年卡 / 顺位刷新放成同一章，不再只讲维护。
6. `korea-and-special-map-rules`
   - 单独讲朝鲜、汉城 VP、水路、山海关这类地图特例。

## 当前缺口策略

1. 不再做“单条超长教程覆盖一切”。
2. 刷新会丢教程进度，因此优先保留短章节。
3. 新增章节必须满足：
   - 从该规则段真实入口进入。
   - 至少有一次真实结果反馈。
   - 至少有一张能指认“下一步点哪里”的截图。
