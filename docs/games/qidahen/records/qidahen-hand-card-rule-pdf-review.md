## 可用信息

规则 PDF 能确认普通手牌的顶层分类与入口规则：

- 军备牌：作为手牌行动，打出军备牌之后再弃 1 张手牌，打出的军备牌会留在己方场上永久提升军队素质。
- 事件牌：作为手牌行动打出时，执行牌上行动内容。
- 战术牌：在战斗中打出，影响战斗进行；每次战斗中只能打出 1 张战术牌。
- 银两牌：无特殊效果，只能弃牌作为资源使用。
- 玩家行动流程包含：检查手牌上限、转动轮盘、执行一次手牌行动及轮盘行动，顺序由玩家自行决定。
- 手牌行动包含：执行事件、升级军备、势力行动。

## 不可用信息

规则 PDF 当前没有提供 OpenSpec `2.4` 所需的逐牌真相源：

- 没有普通事件牌的逐张中文牌名。
- 没有普通军备牌的逐张中文牌名和对应军备目标。
- 没有普通战术牌的逐张中文牌名与效果。
- 没有银两牌的逐张身份或牌面数量。
- 没有能映射到运行时 `cardKind / cardDefId / armamentId` 的逐牌表。

## 当前结论

- 规则 PDF 可以作为“手牌行动一级入口语义”的规则依据。
- 规则 PDF 不能作为普通事件、军备、战术、银两的逐牌规则映射依据。
- 因此它能支撑 2.4 的目标定义，但不能关闭 2.4。
- OpenSpec `2.4` 和 `4.5` 必须继续保持未完成，直到找到逐牌牌表、可靠 OCR 后人工确认，或完成可审计人工录入。
