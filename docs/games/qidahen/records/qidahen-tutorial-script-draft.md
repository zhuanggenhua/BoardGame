# 七大恨玩家教程脚本

> 本文只记录生产玩家看到的连续入门课，不替代规则书。规则句使用对应规则内容的简体中文译文；其他句子只指导当前真实操作或承接已经发生的结果。

## 玩家入口和流程

玩家目录只有一条「七大恨入门」，进入后从正式开局开始。首个决策同时开放手牌行动和轮盘行动，规则允许玩家自行决定顺序；轮盘每回合只选 1、2、3 格中的一种。征兵训练只在玩家实际选择 3 格后出现。

| 节点 | 玩家看到的内容 | 操作与承接 |
|---|---|---|
| `welcome` | 七大恨有三种胜利条件：新年控制 16 个区域、攻下对手首都、或先取得 3 点威望。 | 地图中央无锚点阅读；避开玩家状态、轮盘、行动区、手牌和年卡 |
| `choose-opening-action` | 本回合各进行一次手牌行动和轮盘行动，先后由你决定。现在选一个先做：右侧的“征召军队”，或轮盘走法。 | 不高亮单一控件；玩家可在两类真实操作之间选择。此时不讲弃牌成本或轮盘费用、落点 |
| `pay-recruit` | 征召军队需弃 1 张手牌。选牌前可点“看”查看牌面，移动端长按；选 1 张并确认支付。 | 在真实弃牌窗口检视手牌；关闭检视后仍留在原支付窗口，再选择并支付 |
| `choose-recruit-target` | 点击高亮的宣府。正规军必须在本土（深色）区域建立。 | 点击真实地图区域 |
| `choose-recruit-formation` | 右侧列出这次可选的建军方式。选择 6 支等级 2 正规军，建立在宣府。 | 选择当前真实候选；显示实际建军结果 |
| `action-result` | 征召军队已结算，右侧显示实际建军结果。轮盘行动还未执行；接下来选择一种走法。 | 继续到公共轮盘 |
| `wheel-move` | 轮盘标记由所有玩家共用。本回合每位玩家只选一种走法；费用和落点效果见各格提示。选择 1、2、3 格之一。 | 三个选项都保持真实可操作；按选择结算 |
| `wheel-move-opponent` | 所选对手抽 2 张牌。选择后金。 | 只在选择 2 格并出现真实对手弹窗后显示；点击后金后结算 |
| 1 格落点 | 不另加说明卡。 | 开垦结算后宣府人口增加 1；显示轮盘结果 |
| 2 格落点 | 点击轮盘 2 格并指定一个对手。 | 大明和该对手各抽 2 张，宣府建立 1 支等级 2 正规军；显示轮盘结果 |
| 3 格落点：支付 | 征兵训练先弃 1 张手牌。选择 1 张并确认。 | 支付后进入真实征兵训练选择 |
| 3 格落点：选择行动 | - 征兵行动：直接建立 1 个等级 2 的正规军部队。<br>- 训练行动：将部队向上转 1 级，在一回合中每个部队只能各提升 1 级。<br><br>选择征兵或训练。 | 两条规则对应同时可选的行动；玩家先选真实行动 |
| 3 格落点：征兵目标 | 正规军必须在本土（深色）区域建立。右侧列出可选区域。 | 只在选择征兵后出现；点击真实候选区域 |
| 3 格落点：训练目标 | 右侧候选项显示部队当前等级和目标等级；候选较多时，列表提示可滚动查看，末行不被右下弃牌堆遮挡。 | 只在选择训练或完成额外训练支付后出现；需要时滚动列表并点击真实可训练部队 |
| 3 格落点：继续 | 首次出现续选窗口时说明：每额外弃 1 张手牌，可再训练 1 支部队；右侧显示刚才的结果。 | 在额外训练按钮可见且仍有手牌时，先理解费用和效果，再选择额外训练、其它行动或结束；后续不重复讲 |
| `wheel-result`（共同终点） | 右侧结果显示刚才行动的实际变化。本回合的两种行动都已完成。 | 两条顺序分支都到达同一终点；关闭教程提示，留在同一局继续对战 |

玩家若先执行轮盘行动，会在该行动实际结算后看到“还剩一次手牌行动”，再进入征召支付；其余节点按同一规则和当前局面继续。三格分支只讲当前真实窗口需要的内容：初始支付时讲弃牌，行动选择时展示征兵和训练两条当前选项；选定后将对应目标规则、真实候选和操作合并在一张卡上。额外训练在第一次成为可选动作时先说明费用和效果，进入支付窗口后只指导选牌确认，不重复规则，也不提前讲其它未触发限制。开局手牌上限 15 张未在本局触发；本主线不声称覆盖该规则。

## 参考资料与取舍

- 已检查 [BGA 教程指南](https://jsrpg.boardgamearena.com/tutorialfaq) 和 [教程检查表](https://en.doc.boardgamearena.com/Tutorials_checklist)。借鉴情境先行、让玩家亲自输入、并紧邻操作检查结果的组织方式，对应本课的征召、轮盘选择和征兵训练分支。
- 已检查 Dean Ray Johnson 的 [《Every Board Game Rulebook Is Awful》](https://boardgametextbook.com/EBGRIA.pdf) 中对 Wingspan 数字教程的分析。借鉴逐步展开复杂操作和首轮结束后继续同局的做法，对应三格条件分支与教程结束后的真实轮盘操作。
- 已检查本仓当前工作区的 DiceThrone revision 19 教程实现与覆盖文档。它把主线不会触发的手牌上限留在独立练习；本次借鉴“规则在真实决策时讲”，移除七大恨开局未触发的上限提示，并把牌面检视说明移到实际弃牌窗口。
- 已亲自核对七大恨规则 PDF 第 2、3、5、9 页、当前运行时代码和界面；没有亲自操作 BGA 上的其他游戏。参考资料用于教程组织，不替代七大恨规则证据。

## 文案边界

1. 玩家首次需要作出决策时，展示此决策所需的规则译文；不要先念完整规则段。
2. 把规则说明、当前点击要求、结算结果分开；结果只描述已经发生的变化。
3. 不制造超限弃牌，不把未选择的轮盘路线写成必经步骤，不把互斥选择串成同一回合连续操作。
4. 不将 E2E 专项预设局面描述为玩家章节或正式开局的连续后续。
5. 修改脚本时同步源码、双语文案、Vitest、真实 E2E、截图索引和覆盖矩阵。
