# 七大恨入门教程脚本（当前实现索引）

本文件不再维护第二份玩家文案或行动步骤。当前正常对局行动链、规则取舍、节点用途和来源记录见 [教程覆盖矩阵](qidahen-tutorial-coverage-matrix.md)。实际展示文字以 `public/locales/zh-CN/game-qidahen.json` 为准；节点、命令与推进条件以 `src/games/qidahen/tutorial.ts` 为准。

旧稿按机制排列的「先征召军队、再分别演示轮盘 1 / 2 / 3 格」不是当前教程。它让玩家为了教学而行动，且把互斥走法拼成课程。当前入门从大明正式开局，固定一条有局面用途的合法路线：军屯辽东，突袭叶赫部，打出鸳鸯阵，处理战斗并占领，然后留在同一局继续对局。其它合法轮盘走法和征兵训练由正式对局与专项回归覆盖，不冒充本课已经教过。

修改文案前，先更新覆盖矩阵中的无教学话术行动记录并用正式状态转移复演，再落实到玩家提示。通用顺序见 [教程标准](../../../../.spec/knowledge/standards/tutorial-design.md)与 [教程工作流](../../../../.spec/skills/tutorial-workflow/SKILL.md)。
