# 七大恨 PC 战斗 UI：逐阶段参考与验收账

环境：PC 真实年度教程，普通对局复用同一战斗状态与操作。上一版 [11 月 1 日审计](qidahen-pc-open-battle-review-20261101.md) 只有 Armello 战斗画面；不能凭该画面认可地图叠层、选兵、战术和战后全链。

来源：Strategy Game Studio 的 [《SGS Afrika Korps》官方手册](https://strategygamestudio.com/pdf/afrika-korps/eng/SGS-Afrika-Korps-Rules_English.pdf)（按 PDF 文件页码）。它是按地区摆放多兵堆、使用牌和分段处理战斗的电子兵棋。子代理逐张实读 70 以后相关的 10 页原图。Game UI Database 旧 Armello 参考仅保留对读投掷归属，本轮未拿到适配多兵选兵或战后操作的数据库图。正式玩法由 `gameasset/七大恨 中文mod/七大恨规则.pdf` Ver 1.3 第 4–6 页及 `turnResolutionChoices.ts`、`pendingBattleFlow.ts`、`postBattleDecisionResolution.ts` 交叉核对。

本轮判退基线：`20261118-fixed-hud-battle-r10b` 的 02 有遮补色块，00/02/04 的复位与聊天相叠，15/18 辽北多兵疏密仍不均；`annual-failure.png` 在出兵来源，提示距目标边缘约 80 px 并与正式行动面板重复。该跑没有抵达战斗，不能视为验收通过。

验收时按上表真实运行：覆盖输入、可选性、前后状态及战果的测试单独记录；子代理逐图核对改到的阶段能否独立读懂，写明文件和判退原因；保留整条 PC 教程和改前改后对照。移动端在 PC 人审后开展。
