## 收窄原则

优先级只用于安排人工核读顺序，不代表牌类结论：

1. 先看“既有 OCR 普通关键词待人工确认”：文本只命中少量普通手牌关键词，且没有命中人物、年度、贝勒、朝鲜等非普通线索。
2. 再看“既有 OCR 低信息待人工确认”：文本不足以判断牌类，仍需要人工看小图或外部 OCR。
3. 暂缓“普通词与非普通线索混合”：这些行虽然出现“打出 / 科技”等词，但同时命中人物、年度、贝勒等线索，错判风险高。
4. 暂缓“偏非普通手牌”：这些行主要命中人物、下野、叛逃、贝勒、朝鲜或纪年线索。
