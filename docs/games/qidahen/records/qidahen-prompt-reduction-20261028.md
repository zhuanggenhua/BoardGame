## 规范裁决

全项目、多游戏教程的唯一主源仍为[教程设计标准](../../../../.spec/knowledge/standards/tutorial-design.md)。既有文本虽要求精简，但“当前结果”要求复述变化与前后值，没有先判断正式画面是否已经表达；这是可执行条款的缺口。本轮先修该条款，增加同屏删句核查，不在skill、验收报告或七大恨记录建立第二套规范。教程workflow已有到主源的引用，无需再复制正文。

实现边界是已有正式提示、结果呈现和入门步骤；不改地图mask、战斗规则、行动权限或支付数值。没有已获用户认可的历史提示方案，旧图只证明被退回的问题，不冒称正常基线。
