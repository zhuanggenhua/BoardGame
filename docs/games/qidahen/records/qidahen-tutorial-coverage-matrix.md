## 2. 连续主线流程

规则允许玩家自行决定轮盘行动和手牌行动的先后。首个决策节点同时开放征召军队和轮盘选择，不强制固定顺序。手牌上限 15 张没有在三张起手牌的局面触发，因此不在这里讲。选择弃牌时才教桌面“看”与移动端长按检视；关闭检视后仍留在原支付状态。每局轮盘只走 1、2、3 格中的一种，不连续串走。

| 顺序 / 步骤 | 当前局面与目标 | 玩家操作 | 实际结果与后续 |
|---|---|---|---|
| `welcome` | 正式开局；理解本局三种胜利条件 | 地图中央无锚点阅读 | 避开玩家状态、轮盘、行动区、手牌和年卡后进入首回合流程 |
| `choose-opening-action` | 首回合的手牌行动和轮盘行动都可执行；讲清两者各一次且顺序可选 | 选择右侧“征召军队”，或先选任意一种轮盘走法 | 不高亮单一控件；只讲当前顺序选择，不提前讲弃牌成本、轮盘费用和落点 |
| `pay-recruit` / `pay-recruit-after-wheel` | 征召的真实弃牌支付窗口 | 检视一张牌后关闭，再选 1 张并确认支付 | 桌面“看”和移动端长按都不提交支付；仍留在原窗口 |
| `choose-recruit-target` | 当前候选区域；解释征召需要本土区域 | 选择宣府 | 显示当前开局合法编制 |
| `choose-recruit-formation` | 真实编制候选 | 选择 6 支等级 2 正规军 | 部队建立，支付和编制均由局面验证 |
| `action-result` | 征召已结算，轮盘尚未行动 | 阅读当前结果 | 进入轮盘选择 |
| `wheel-move` | 共享轮盘标记；三种路线的费用 / 效果可从各自扇区提示查看 | 选择 1、2、3 格中的一种 | 1 / 3 格继续即时结算；2 格进入独立的对手选择教学 |
| `wheel-move-opponent` | 已选 2 格走法；真实对手选择弹窗已出现 | 按提示选择后金 | 弹窗消失并完成轮盘移动；不再显示选格提示 |
| 1 格分支 | 落到开垦 | 完成实际轮盘操作 | 宣府人口增加 1，进入共用的最终轮盘结果卡 |
| 2 格分支 | 落到军屯 | 选择对手并完成实际轮盘操作 | 双方各抽 2 张，宣府建立 1 支等级 2 正规军，进入最终结果卡 |
| 3 格分支：初始支付 | 落到征兵训练 | 选择并弃 1 张手牌 | 展示征兵 / 训练两条译文，进入当前可选行动 |
| 3 格分支：行动与目标 | 真实征兵 / 训练窗口 | 先比较征兵与训练；选定后只出现对应目标规则和真实候选，并在同一卡上完成选择 | 右侧结果反映已发生的征兵或升级；不会先看独立规则卡，再重复点击通用目标提示 |
| 3 格分支：额外训练 | 首次出现续选窗口时说明额外支付与训练效果 | 有可用额外训练时，规则先于按钮选择出现；支付后选可训练部队，也可改选其它动作或结束 | 不重复讲已知规则；无牌或无候选时不强行展示该选项 |
| `wheel-result` | 轮盘结果已结算；两种行动均已完成 | 查看实际摘要并结束教程提示 | 留在同一局；下一行动人仍可在真实棋盘继续操作 |

主线不强制 2 格作为“主路”。E2E 从独立正式开局分别走 1、2、3 格，验证三种互斥选择及后果；三格用例实际完成初始弃牌、征兵 / 训练目标、可支付的额外训练，并结束轮盘行动。三格路径的手牌预算按正式起手闭合：先支付征召 1 张，轮盘训练初始支付 1 张，最多还剩 1 张用于一次额外训练；没有剩余牌时仍可结束，不会被教程强迫执行无法支付的征召。

## 3. 规则与 UI 覆盖

| 规则 / 可见元素 | 教学位置 | 当前边界 | 验证证据 |
|---|---|---|---|
| 三种胜利条件 | `welcome` | 只给获胜目标，不提前讲完整战斗策略 | 入门 E2E 正文断言和截图 |
| 行动次数与先后顺序 | `choose-opening-action` | 每回合各进行一次手牌行动和轮盘行动，顺序由玩家选择；不把其中一项呈现为强制先做 | Vitest 步骤合同；桌面主线和轮盘先行 E2E |
| 手牌上限与超限弃牌 | 本次主线未覆盖 | 开局 3 张低于 15 张上限；没有真实超限弃牌决策，不在行动顺序节点插入该规则，也不声称本课覆盖 | Vitest 起手状态；E2E 断言没有弃牌选择状态 |
| 手牌检视 | `pay-recruit` 的弃牌选择窗口 | 在真实选择弃牌时说明：桌面点击“看”，移动端长按；关闭后支付仍未执行 | 桌面和移动端 Chromium E2E 实际检视并关闭，断言牌数、已选牌和行动状态不变 |
| 征召行动、支付、目标和编制 | 选择征召后至 `action-result`；轮盘先行则在 `wheel-result` 结束 | 弃牌成本只在支付窗口讲；目标和编制只在真实选择出现时讲；未选编制的规则留待对应机制出现 | Vitest 状态断言、手牌先行与轮盘先行 Chromium E2E |
| 轮盘共享标记和三种走法 | `wheel-move` 与真实扇区提示 | 三个候选始终可用；每局只选一个。费用 / 效果依 UI 实际提示核对 | 1 / 2 / 3 格独立 E2E |
| 两格目标选择 | `wheel-move-opponent` | 选格后才说明指定对手，并高亮真实弹窗 | Vitest 事件推进断言、桌面真实入口 E2E 与逐图视觉验收 |
| 开垦 | 1 格分支 | 实际结果是控制区人口增加 | E2E 前后状态对照 |
| 军屯 | 2 格分支 | 选择真实对手，验证双方摸牌及建军结果 | E2E 前后状态对照 |
| 征兵训练 | 3 格条件分支 | 规则译文按支付、行动选择、目标、额外训练四个当前原子呈现；目标说明与真实候选同屏，只显示当前所选的征兵或训练分支；训练候选较多时提示列表可滚动，并保证末项可到达、高亮贴合可见面板且不遮挡右下弃牌堆；不自动征兵或训练 | Vitest、3 格 Chromium E2E（检查面板边界、与弃牌堆不相交、滚动到末项和两种目标阶段）、截图 |
| 完成后继续 | `wheel-result` 后退出提示 | 验证同一局路由、下一行动人的真实轮盘操作及状态变化 | 主线、1 格、3 格 E2E |
| 战斗、攻城、年度和地图专项 | 本轮未纳入玩家教程；部分仅有 E2E 测试代表态 | 当前无游戏内规则帮助入口，不声称入门课已教会这些机制 | 专项 E2E 仅覆盖其声明的入口与状态，不证明玩家可在游戏内学习 |

## 4. 参考资料与设计决定

- 已检查 BGA 官方教程指南和检查表。采用了“在真实局面提出问题、玩家亲自输入、紧邻结果验证”的组织方式，对应征召支付、轮盘选择、3 格条件分支和同局续玩；没有把其它游戏案例当作七大恨规则证据。
- 已检查《Every Board Game Rulebook Is Awful》中对 Wingspan 数字教程的分析。借鉴逐步揭示复杂操作以及首轮后继续游戏的做法，对应征兵训练只在真实落点后展开、教程结束后保留对局。
- 已检查本仓当前工作区的 DiceThrone revision 19 教程实现与覆盖文档。它把主线不会触发的手牌上限留在独立练习；本次只借鉴“机制在产生真实决策时再讲”，不把 DiceThrone 当作七大恨规则来源。对应调整是移除首回合没有超限弃牌决策时的上限提示，并让首个行动节点保留手牌行动与轮盘行动两种可选操作，不指向无关标记。
- 已亲自核对七大恨规则 PDF 第 2、3、5、9 页以及运行时代码和界面。未亲自操作 BGA 上的其它游戏。

## 5. 验收与未覆盖边界

- 规则决策、实际按钮 / 卡牌 / 地图目标、关键结果和离开提示后的同局操作由 Vitest 与 Chromium E2E 验证；截图只证明对应状态的 UI 和交互可见性。
- 1 / 2 / 3 格分别从新局执行；不得用三张截图暗示一回合连续走三种步数。
- 专项预设状态不是正式新局；它们只证明专项运行时状态，不可外推为入门主线或完整游戏规则验收。
- 修改主线时同步源码、双语文案、步骤合同、E2E、截图清单和本文；不得把测试目录写成更多玩家章节。
