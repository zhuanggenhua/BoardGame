| 教程 ID | 目录状态 | 主要职责 |
|---|---|---|
| `basic-opening` | 唯一玩家入口 | 正式起手、完成一次手牌行动、选择一种轮盘走法并处理实际落点；三格征兵训练是条件分支 |
| 其余 16 个场景 ID | 仅 E2E 测试运行时注册 | 给对应机制的独立起始状态做专项回归；不进入生产玩家目录，不构成额外教程章节 |

## 2. 基础教程映射

`basic-opening` 是一条课程，按正式开局和运行时状态推进。胜利条件卡没有单一对应的 UI 对象，因此在地图中央无锚点显示，并避开年卡、玩家状态、手牌和行动区。首个行动节点不高亮任一控件，因为手牌行动和轮盘行动各一次且先后可选；它同时保留“征召军队”和三种轮盘走法供玩家选择。轮盘三种走法互斥，玩家每回合只能选其中一种：

```text
welcome
  -> choose-opening-action（不锁顺序、不高亮单一控件）
       ├─ 手牌先行：征召 -> 支付 -> 选择宣府 -> 选择编制 -> action-result
       │    -> wheel-move -> 选择 1 / 2 / 3 格之一 -> 落点结算 -> wheel-result
       └─ 轮盘先行：wheel-move -> 选择 1 / 2 / 3 格之一 -> 落点结算
            -> wheel-first-result -> 选择征召 -> 支付 -> 选择宣府 -> 选择编制
            -> wheel-result（两类行动完成后的共同终点）
  -> 关闭教程提示，留在同一局；玩家可从同一状态继续对局
```

承接规则：

- 正式开局为大明 3 张手牌、手牌上限 15 张；当前没有超限弃牌决策，因此 `handLimitDiscardSelection` 为空。手牌上限不进入本主线；只在真实超限状态或对应帮助入口教学。
- `choose-opening-action` 只说明本回合各有一次手牌行动和轮盘行动、顺序由玩家决定，并让两类实际操作同时可选；不展示弃牌成本、轮盘费用或落点效果。当前没有单一目标可指，因此不高亮某一方。
- 手牌检视操作放在首次真实弃牌选择中：桌面点击牌面的“看”，移动端长按；关闭检视后仍停在原支付步骤，不会提交弃牌或行动。
- 主线同时验证手牌先行和轮盘先行。轮盘先行分支在实际结算后再提示还有手牌行动；E2E 对该顺序使用免费的一格开垦，证明顺序可以由玩家选择。
- 征召军队真实支付 1 张，玩家选宣府和当前局面展示的建军方式。规则提示只在费用、区域、编制分别成为当前决策时出现。
- `wheel-move` 展示共享标记及互斥的 1 / 2 / 3 格选择；费用和即时收益从真实扇区提示读取。三种候选都保持可操作，教程不把一条路线标成唯一主路，也不禁用另外两项。选 2 格后，单独进入 `wheel-move-opponent`，讲解并高亮真实对手选择弹窗；不会在选择对手时继续显示选格提示。
- 1 / 2 / 3 格是独立分支，E2E 分别从全新正式开局实操；不可串成一个回合。1 格验证开垦人口，2 格验证指定对手抽牌和军屯结算，3 格进入真实的征兵训练支付 / 行动 / 目标链。
- 三格下初始支付后才展示征兵和训练规则；选定行动后，将对应地域 / 单位规则、真实候选和点击要求合并为一张可操作提示，不另插重复规则页或同时提两类目标。训练目标面板按视口限高、可滚动到末项、高亮贴合面板，并避开右下弃牌堆。额外训练只在真实选择提供且手牌足够时出现；手牌消耗完仍可主动结束，不会被强迫做无法支付的征召。
- 手牌先行的三格主线手牌预算：正式起手 3 张，征召行动支付 1 张，三格征兵训练初始支付 1 张，最多剩 1 张用于 1 次额外训练。运行时的行动次数和提前结束规则仍由真实状态决定；教程不虚构步骤来锁定玩家选择。
- `action-result` 只承接征召结果；`wheel-result` 是唯一共同终点，验证两类行动均完成后关闭提示，保持同一局可继续。

## 3. 专项 E2E 场景映射

| 专题 | 入口状态 | 主要结果 |
|---|---|---|
| `wheel-shared-cost` | 轮盘位于军屯，公共轮盘未使用 | 走 3 格后每名有效对手各补 2 张牌；展示弃 1 张手牌的规则译文并实际支付；退出教程后保留地图部队调度入口 |
| `wheel-reclaim` | 轮盘位于新年 | 开垦结算，己方控制区人口增加 |
| `wheel-military-farm` | 轮盘位于开垦 | 军屯结算，补牌并建立正规军 |
| `wheel-recruit-train` | 轮盘位于军屯 | 展示支付与对应行动规则；玩家弃牌、选择训练炮兵、选择本土征兵及目标，再实际执行一次额外训练并结束轮盘行动 |
| `armament-upgrade` | 正式手牌行动窗口 | 支付军备行动费用，火炮技术升到 2 级 |
| `event-action` | 正式手牌行动窗口 | 支付大汗令箭后进入共享征兵 / 训练流程，由玩家选择征兵并点选本土区域 |
| `attack-and-battle` | 突袭作战可选 | 进入野战并完成战后处理 |
| `retreat-and-rout` | 已进入战败处理 | 处理断后与溃退代价；溃退结果提示需避开聊天悬浮菜单，并由 E2E 几何断言验证 |
| `cavalry-evasion` | 待处理骑兵避战 | 骑兵避战并移动到相邻友方区域 |
| `cavalry-plunder` | 待处理骑兵劫掠 | 选择劫掠并写入结算摘要 |
| `neutral-invasion` | 中立入侵待结算 | 生成并结算中立守军 |
| `water-dispatch` | 水路调度窗口 | 锁定海岸水路限 2，排除水路后接陆路 |
| `diplomacy-and-hire` | 外交 / 雇佣窗口 | 友好标记、附庸 / 雇佣结果 |
| `year-and-characters` | 年中年度状态 | 年中、新年、纪年、顺位和人物刷新 |
| `korea-and-special-map-rules` | 新年朝贡状态 | 朝贡、汉城、水路、朝鲜耗损、山海关 |

## 4. 串联规则

这些场景只在 `__E2E_TEST_MODE__` 下注册，用于验证独立机制，不显示在生产玩家目录。它们不通过 `nextTutorialId` 自动串联，也不应被称为玩家课程章节。

玩家完成 `basic-opening` 后直接回到可继续对局的正常状态；测试场景 URL 只供 E2E 直接访问，不能从玩家课程跳转。

## 5. 代码与测试职责

- `src/games/qidahen/tutorial.ts`：唯一玩家课程及 E2E 专项场景的步骤、目标、允许命令和状态校验。
- `src/games/qidahen/tutorialSetup.ts`：E2E 专项场景预设局面；每个场景单独启动，不伪装成自然承接。
- `src/games/qidahen/__tests__/tutorialFlow.test.ts`：玩家课程目录边界、基础步骤合同和专题结果合同。
- `e2e/qidahen/qidahen-closeout.e2e.ts`：真实入口、玩家动作顺序、截图和关键结果断言。
- `public/locales/zh-CN/game-qidahen.json` / `public/locales/en/game-qidahen.json`：玩家可见文案；规则解释不能脱离规则源。
- 结果提示的落点必须避让当前行动区与会遮住教程控件的聊天悬浮菜单；战后占领 / 围城 / 撤回面板打开时收起右下弃牌堆，选项说明不得被列表压缩，不能盖住选项或确认按钮。E2E 对溃退结果与聊天菜单的相交、战后选项可读性、三种处理分支及占领确认控件做断言；撤回链截图覆盖选择前、确认前与结果后。

## 6. 维护红线

- 不在当前未超限的起手插入弃牌 / 手牌上限说明；不重复讲首次真实读牌时已经教过的手牌检视，也不重复讲轮盘规则。
- 不因为截图方便增加代操作、假确认、教程专属跳转或第二套状态。
- 不把单元测试、历史截图或旧 PASS 清单解释为当前完整 E2E 通过。
- 任一专题如果需要独立局面，必须保持独立入口、独立截图组和独立证据范围。
