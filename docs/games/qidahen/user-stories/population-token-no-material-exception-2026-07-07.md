# 七大恨人口数字标记不用素材例外

## 现实裁定

用户已明确裁定：七大恨地图上的人口可以不用图片素材表示。

这是一条只针对“人口数量状态”的专项例外，不是七大恨全局素材规则的放宽，也不是其他对象可以跳过素材的通用依据。

## 适用对象

- 七大恨地图区域里的“人口数量”。
- 运行时由人口数量生成的人口 token。
- 人口 token 的视觉表达方式，包括数字、圆形标记和数量展示。

## 规则解释

人口在当前七大恨实现里表示一个地区的数量状态。它不是玩家手牌、兵牌、控制标记、地区牌、人物、骰子，也不是需要单独查看正反面或被玩家直接操控的实体对象。

因此，人口可以用数字圆点或数字 token 表示。这样能直接表达数量，避免为了一个状态值伪造并不存在的图片素材。

## 实现要求

- 人口 token 必须直接显示人口数字。
- 人口 token 可以保持圆形数字标记样式。
- 即使运行时存在 `imageSrc`，人口 token 也不得渲染成图片素材。
- 不得新增 `populationMarkerImageSrc`、人口图片字段或人口专用素材配置来满足这类显示。

## 验收标准

- 地图上人口仍能被玩家看成明确的人口数量。
- 人口 token 不会因为存在图片字段而变成素材图。
- 代码或测试里能明确拦住“人口 token 走图片渲染”的回归。
- 本例外不会被解释成“所有七大恨对象都可以不用素材”。

## 不覆盖范围

- 兵牌、手牌、控制标记、地区、人物、骰子仍必须优先使用正式素材或已有正式组件。
- 兵牌仍需要遵守正反面展示规则，不能借用人口例外跳过素材。
- 控制标记仍可以使用素材和数值角标，不能借用人口例外退化成纯数字。
- 骰子不属于本例外。掷骰核心必须真实产生对应面数的结果；展示层只有在已有组件或素材能正确表达该面数时才能接入，不得用不支持多面骰的组件伪装支持。
