# 木乃伊横行联机黄金链覆盖矩阵

主用例为 [online-mummy-golden.e2e.ts](../../../../e2e/betrayal/online-mummy-golden.e2e.ts)。三名玩家在同一正式在线房间各自操作，使用房主席的浏览器上下文记录开局和终局，另保留第二席与叛徒席的操作证据。以服务端 `sys.gameover`、终局赢家和各席胜负报告共同确认结束。

下表规定新版通过所需的动作和结果。通过状态以同一跑次的服务器记录、浏览器测试报告和原图复核为准。

| 高频操作族 | 黄金链内的玩家操作及结果 |
| --- | --- |
| 开局、观察与移动 | 三席各自选角并确认剧本，房主点击三维棋子和门厅，右键检视本方棋子，其他席看到位置同步 |
| 探索、揭示、随机结算 | 玩家自行选门位、旋转并放置厨房、血腥房间和标本室，分别触发事件、物品、预兆。投掷事件骰并结算，确认急救包，圣符进入持有区后实际掷出 5+ 触发作祟 |
| 物品使用 | 急救包经回合交接后可用，点击同房受伤棋子并确认，验证物品消耗及目标恢复 |
| 交易和响应 | 发起席选择给出的地图及换回的兔脚，接收席在自己的页面确认，服务端核对双方库存变化 |
| 作祟和阶段交接 | 各席确认公开预兆结果，在各自页面读并关闭对应阵营的私有剧本。同一房间记录作祟前后及操作权 |
| 怪物、攻防和伤害 | 叛徒开启木乃伊回合、掷移动骰、选中怪物及攻击目标。由规则指定的席位各自在自己的页面确认投骰，叛徒选择造成伤害，受伤席按规则分配并确认 |
| 筹码转移、返棺与终局 | 从地面实际拾起女孩并交给木乃伊，再交出来源可追溯的圣符。叛徒点选携物木乃伊，真实选择石棺房，触发朗读并由三席各自打开胜负报告 |

## 注入和分段范围

- 此链为合法状态注入黄金链。提前排好原房间与原牌堆，准备可治疗同房局面、交易双方筹码、两张已发现预兆和作祟后同房攻防。使用正式随机序列控制骰面。逐次注入在原运行记录内标出断点、用途和跳过的准备。
- 低点作祟未触发、不同剧本触发源和旁观同步由 [作祟公开专题](../../../../e2e/betrayal/haunt-reveal-discovery-confirmation.e2e.ts) 覆盖。交易条件和多牌、狗远距路径由 [交易专题](../../../../e2e/betrayal/first-scenario-trade-interaction.e2e.ts) 覆盖。
- 木乃伊偷取、致死、保命和其它移动点数由 [木乃伊行动专题](../../../../e2e/betrayal/mummy-rampage-monster-actions.e2e.ts) 覆盖。英雄驱逐胜利属于另一条结束分支，见 [英雄终局专题](../../../../e2e/betrayal/first-scenario-core-interactions.e2e.ts)。
- 同房多牌 UI 容量由 [多牌交易](../../../../e2e/betrayal/trade-multi-give.e2e.ts) 验证。真实拒绝响应、不同角色、牌库全量、其它作祟、移动端整局和客户端人机模式不计入本链。现有移动端测试覆盖转桌、缩放、触屏和检视。
