# 小黑屋选角席位标记与剧本名（2026-10-02）

## 用户原始裁定

- 选中显示的不是名字，是 P1、P2。
- 右下角剧本描述：当前实现没有这么多字。点击才展开详情。常态只要名字。
- 密密麻麻的小字禁止。
- 该和现在一样的地方保持现页；不该一样的地方按本裁定改。
- 所有明确要求都要更新进用户故事。

## 覆盖范围

- 小黑屋（`betrayal`）开局选角页的选中标记、底部席位主标记、右下角局内剧本常态和点击后的详情。
- 不改角色板素材、左侧属性条、三列角色板和确认按钮的现有位置。

## 正式口径

1. 角色被某座位选中后，角色板上的占用标记和底部席位的主标记使用 `P1`、`P2`、`P3`。不用玩家昵称代替这个标记。
2. 席位下面可以保留玩家名和准备状态，但主标记仍是 `P1` / `P2`。
3. 右下角局内剧本的常态只显示剧本名字，例如 `木乃伊横行`。不常驻剧本正文、触发说明或一串状态小字。
4. 剧本详情只在玩家点击该入口后展开。展开后的正文必须好读，不能用密密麻麻的小字塞进窄格。
5. 角色属性、特性仍留在现页已经有的左侧详情里。本裁定不把它们收成角标，也不再复制到每张角色板下面。

## 覆盖原因

- 设计稿曾把选中标记改成玩家昵称，和用户明确要求的 `P1` / `P2` 相反。
- 设计稿曾把剧本正文常驻在右下角，和现页「常态只要名字、点击才展开」不一致。

## 验收标准

- 选角常态截图里，已选角色板角标是 `P1`，不是玩家昵称。
- 右下角常态能看到剧本名字，看不到剧本正文。
- 点击右下角入口后，详情里能读到该剧本的描述，且不是一小块密字。
- 未按本裁定改实现时，只算用户故事已留档，不算选角页已改完。
