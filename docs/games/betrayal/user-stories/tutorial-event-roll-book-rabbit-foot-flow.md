# 山屋惊魂教程：事件骰、书本与兔脚自然流程

> 状态：`locked-for-current-tutorial`
> 日期：2026-08-31
> 角色：`canonical-source`，记录本次山屋惊魂教程事件骰流程的产品裁定；跨游戏的教程判断以 `.spec/knowledge/standards/tutorial-design.md` 为唯一规范正文。

## 用户原始裁定

事件先触发，再由触发者点击“投掷事件”。书本只在事件骰已经出现时教学：先查看书本牌面，确认它能介入这次非战斗检定；关闭牌面后再使用书本本体，点击后立即扣除神志并改用知识投骰，不需要第二次确认。玩家已经经历公开可见的事件骰、书本改骰和兔脚重掷过程后，不需要每位玩家再确认事件结果，游戏应自动进入伤害分配。

基础教程按自然玩家流程合并教学；不能因为测试、截图或机制数量拆章节。只有叛徒视角或其它真实私密信息边界才单独成章。

主线合并的含义是把同一条玩家因果链放进一个可见教程容器，不是把多个中段测试快照首尾拼接。主线必须从恶兆前开始，玩家先通过真实探索获得预兆、完成作祟检定并看到作祟触发，之后才进入作祟目标教学；已作祟、已找真名或已学会驱逐法术的快照只能作为隐藏专题回归起点。

## 覆盖对象

| 对象 | 本轮裁定 |
| --- | --- |
| 事件投掷 | 事件牌翻出后保留“投掷事件”作为真实入口，触发者主动开始投掷。 |
| 书本 | 事件骰显示且书本可用时先高亮查看牌面入口；玩家读完牌面后再点击书本本体即刻生效，扣除 1 点神志并把本次非战斗检定改为知识。 |
| 兔脚 | 书本改骰后由玩家选择一颗骰子并确认使用兔脚，随后展示重掷后的结果。 |
| 事件结算 | 兔脚重掷后的事件骰不存在 `确认 1/3` 或等价的多人确认入口；没有后续玩家选择时自动进入伤害分配。 |
| 确认按钮 | 需要确认的物品命令和事件命令使用同一确认按钮组件与样式；是否出现确认由当前流程是否仍有玩家决策或共同等待理由决定。 |
| 教程目录 | 普通玩家主线合并为自然因果链；叛徒视角因私密信息另列章节。 |

## 验收标准

- 教程 E2E 从事件触发后的“投掷事件”按钮开始，不用测试夹具的即时投骰链代替。
- 截图链至少包含事件骰出现后的书本“可查看时机”、书本牌面查看、关闭牌面后使用书本、以及点击书本后的生效结果。
- 点击书本后验证神志减少 1、检定属性改为知识、书本已使用且事件骰仍在结算中。
- 兔脚重掷后验证事件确认按钮不存在，并且不模拟其它玩家操作即可进入伤害分配。
- 教程连续文案只讲当前新增信息，不复读前一步的完整机制说明。

## 不覆盖

- 仍需要其它玩家选择、响应或授权的发现 / 卡牌窗口，继续保留相应的共同确认。
- 不改变其他事件、预兆、房间效果或联机响应窗口的确认语义；它们必须按各自的公开展示和决策需要裁定。
- 不把本次教程事件链外推成所有随机结果一律自动结算。
