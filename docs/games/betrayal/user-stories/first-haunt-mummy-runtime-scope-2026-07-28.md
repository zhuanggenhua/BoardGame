## 用户原始裁定

用户明确指出：新规则下当前要实现的第一个剧本不是「杰克」，而是「木乃伊横行」。本轮继续处理剧本时，默认首个作祟必须切换到「木乃伊横行」，不要继续按「赤红杰克归来」推进。

## 本轮目标

- 默认候选剧本卡和首剧本配置指向「木乃伊横行」。
- 作祟触发后创建木乃伊、石棺、女孩位置和木乃伊目标进度。
- 英雄侧可完成三步闭环：寻找真名、学习驱逐法术、同房神志驱逐木乃伊。
- 建立最小可验证单测，证明首剧本不再默认进入杰克链路。

## 本轮不覆盖

- 不声明完整牌库、全部房间、全部作祟和全部能力已完成。
- 不删除「赤红杰克归来」旧合同或旧实现。
- 不把摘要文案冒充官方完整剧本原文。
- 不把木乃伊偷窃、携带女孩 / 圣符 / 指环返回石棺的完整叛徒胜利链冒充已全量实现；若未完成，必须继续标缺口。

## 验收标准

- 新游戏默认首个作祟卡显示 / 配置为「木乃伊横行」。
- 作祟 1 触发后，运行时状态存在木乃伊、石棺房间、女孩标记房间和知识标记进度。
- 木乃伊属性为速度 3、力量 8、神志 5。
- 英雄可在合法位置完成 6+ 知识检定取得第 1 枚知识标记。
- 持有书本的英雄可在第 1 枚标记后完成 6+ 知识检定取得第 2 枚知识标记。
- 持书英雄与木乃伊同房后，英雄可用神志驱逐木乃伊并进入英雄胜利结局。
