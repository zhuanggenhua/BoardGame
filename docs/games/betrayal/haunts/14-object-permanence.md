# 作祟 14 交互子账本：Object Permanence

> 状态：`contract-ready`。这是左侧玩家叛徒作祟，核心是咒书计数轨、活动家具替身和火焰房间毁书。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p22 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p13 |
| 剧本卡 / 触发预兆 | For Sale / Book |
| 叛徒 | 作祟揭秘者左侧玩家 |
| 类型 | 一名叛徒 + 咒书计数轨 + 怪物替身复活 |

## 2. 公开步骤

- 公开叛徒为作祟揭秘者左侧玩家。
- 公开 Book 是 Old Spellbook，是英雄施法目标，也是叛徒毁书目标。
- 公开数字轨代表施法进度；怪物回合后若活着的英雄持有 Book，会自动推进。

## 3. 私密可见性

- 英雄可见：持书加速施法、每轮最多一次加速、保护 Book。
- 叛徒可见：火焰房间毁书、活动家具替身复活、Book 转移给最近英雄。
- 叛徒死亡并借家具复活时必须公开，因为会改变地图和 Book 归属。

## 4. setup 队列

英雄侧：
1. 数字轨设为 4/4/5/5。
2. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 左侧玩家成为叛徒并保留探索者。
2. Monster Card 放在叛徒左侧，Animated Furniture 在叛徒后行动。
3. 叛徒治疗全部属性。
4. 找出 1/2/3/4 个 Animated Furniture；在每个有英雄的房间放置 1 个，不给持有 Book 的英雄所在房间放置；若同房间多个英雄，每名英雄对应 1 个。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 数字轨到 0，成功施放咒语 |
| 叛徒 | 在火焰房间毁掉 Book，或所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 加速咒语 | 持有 Book 的英雄 | 持有 Book；每轮英雄方最多一次 | 神志检定；5+ 数字轨 -1 并失去 1 神志，到 0 英雄胜利；0-4 失去 1 神志 | Book 卡动作 + 本轮次数锁 |
| 毁掉咒书 | 叛徒 | 叛徒在火焰房间并持有 Book | 直接毁书，叛徒胜利 | 火焰房间动作 + Book 状态 |

火焰房间：Kitchen、Furnace Room、Laboratory。

## 7. 持续 / 触发规则

- 一轮结束口径为怪物行动完成。
- 英雄方每轮只能执行一次“加速咒语”。
- 怪物回合后，若活着的英雄持有 Book，数字轨 -1；到 0 英雄胜利。
- 叛徒死亡时，若屋内仍有 Animated Furniture，叛徒治疗全部属性并放到任一 Animated Furniture 所在房间，移除该家具；若叛徒持有 Book，则交给最近英雄。
- 若没有 Animated Furniture，叛徒保持死亡。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 施法进度；到 0 英雄胜利 |
| Book | 1 | 当前持有人；是否被毁；是否活着英雄持有 |
| Animated Furniture | 1/2/3/4 | 房间、状态、是否可作为叛徒复活替身 |

Animated Furniture 属性：力量 6、速度 3、神志 4、知识 2。

## 9. UI 承接

- 主目标条显示施法进度条和 Book 当前持有人。
- Book 卡上显示“本轮是否已加速”，而不是全局特殊行动误判。
- 叛徒界面高亮火焰房间；死亡后若可复活，显示可选家具房间。
- 怪物回合后自动推进数字轨必须有日志和进度动画。

## 10. 验证

- 单测：数字轨初始值按人数；英雄每轮最多加速一次；怪物回合后活英雄持书推进；叛徒火焰房间毁书；叛徒死亡家具复活和 Book 转移。
- 页面测试：Book 持有人、火焰房间高亮、家具替身选择。
- E2E：覆盖英雄施法胜利和叛徒毁书胜利。
