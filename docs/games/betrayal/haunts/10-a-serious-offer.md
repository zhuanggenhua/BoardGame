# 作祟 10 交互子账本：A Serious Offer

> 状态：`contract-ready`。这是自由混战作祟，核心是宝藏搜索、倒计时献礼和最高分共享胜利。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | 无，叛徒书独占 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p8-p9 |
| 剧本卡 / 触发预兆 | For Sale / Armor |
| 叛徒 | 自由混战 |
| 类型 | 全员敌对 + 隐藏宝藏价值 + 倒计时计分 |

## 2. 公开步骤

- 公开这是自由混战：所有探索者互为障碍物，且可以互相攻击。
- 公开数字轨从 4 开始，每次作祟揭秘者回合结束下降。
- 公开数字轨到 0 时所有玩家公开报价并按宝藏价值决胜。

## 私密可见性

- 本作祟是自由混战；个人分数和已公开宝藏可见，未翻开的宝藏编号 / 价值保持隐藏。
- 倒计时和献礼结算是公开进度，不得只藏在日志。
- 尸体搜刮、宝藏拾取和攻击替代偷取必须按当前玩家视角展示合法候选。

## 3. setup 队列

1. 若 Vault 不在屋内，作祟揭秘者从房间堆搜索 Vault 并放在一楼，尽可能远离入口大厅。
2. 准备两套 1 到 2/3/4/5 的 Number token，代表宝藏。
3. 将最高编号之一放在 Vault。
4. 其余宝藏面朝下洗混，随机放在预兆符号房间，尽量均匀分布在各区域。
5. 数字轨设为 4。
6. 作祟后首回合由作祟揭秘者左侧玩家开始。

## 4. 目标模型

| 玩家 | 胜利条件 |
| --- | --- |
| 每名探索者 | 倒计时结束时献礼分最高；平手玩家共享胜利 |

## 5. 特殊行动 / 攻击替代

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 搜索宝藏 | 探索者 | 在有宝藏 token 的房间 | 知识检定；4+ 拿 1 个宝藏面朝下放角色板；1-3 查看该房间 1 个面朝下宝藏；0 无事 | 房间 token 动作 + 私密查看 |
| 抢宝藏 | 对其他探索者进行力量攻击的探索者 | 目标持有宝藏且攻击者获胜 | 可随机偷目标 1 个宝藏替代造成伤害；攻击者若失败照常受伤 | 攻击胜利后的随机偷取选择 |
| 献礼计分 | 系统 / 全体 | 数字轨到 0 | 每人合计宝藏值；在一楼楼梯额外 +2；最高分胜利，平手共享 | 终局计分面板 |

## 6. 持续 / 触发规则

- 宝藏 token 拿到后面朝下保留，持有人可随时查看。
- 宝藏可像物品 / 预兆一样从尸体搜刮，每具尸体每回合仍只能搜刮 1 个对象。
- 作祟揭秘者回合结束时数字轨 -1；到 0 后立即献礼。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 当前倒计时；到 0 触发计分 |
| 宝藏 Number token | 两套 1 到人数对应上限 | 价值、房间或持有人、面朝下、持有人私密可见 |
| Vault | 1 | 是否已在屋内；setup 搜索放置位置 |

## 8. UI 承接

- 主目标条显示倒计时和“带宝藏到一楼楼梯加 2 分”。
- 宝藏价值对持有人私密显示，对他人只显示数量。
- 献礼终局需要展示每个玩家宝藏合计、楼梯加值、平手共享胜利。

## 9. 验证

- 单测：Vault 搜索放置；宝藏数量按人数；最高宝藏在 Vault；倒计时归零计分；楼梯 +2；平手共享。
- 页面测试：面朝下宝藏私密查看、攻击随机偷宝藏、终局计分。
- E2E：覆盖倒计时归零后非击杀胜利。
