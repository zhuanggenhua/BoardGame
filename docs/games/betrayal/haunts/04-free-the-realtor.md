# 作祟 4 交互子账本：Free the Realtor

> 状态：`contract-ready`。这是无叛徒合作作祟，核心是知识、净化房间、护符和恶魔地产经纪人。

## 1. 源段锁定

| 类型 | 合作目标 + 怪物压力 + 区域净化加值 |

## 2. 公开步骤

- 公开本作祟没有叛徒，所有玩家同队。
- 公开恶魔地产经纪人位于入口大厅，并在作祟揭秘者之后行动。
- 公开净化房间、诅咒知识、保护结界都会影响最终仪式或战斗。

## 私密可见性

- 本作祟无叛徒；所有目标、怪物规则、token 归属和进度均对全体玩家公开。
- Knowledge token 和 Might token 是公开角色状态，不能只作为个人隐藏增益。
- 恶魔地产经纪人的移动、攻击范围和区域伤害必须在怪物回合前可预览。

## 3. setup 队列

1. 将 Demon token 放在入口大厅，代表恶魔地产经纪人。
2. Monster Card 放在作祟揭秘者左侧；怪物在其之后行动。
3. 找出 6 个 Fire token，按 3/4/5/6 人局分别在英雄所在房间放置 3/2/1/0 个，代表已净化房间；同一房间不能多于 1 个。
4. 剩余 Fire token、2 个 Might token、2 个 Knowledge token 备用。
5. 作祟后首回合由作祟揭秘者左侧玩家开始。

## 4. 目标模型

| 阵营 | 胜利条件 | 失败条件 |
| --- | --- | --- |
| 英雄 | 在恶魔地产经纪人所在房间成功完成仪式 | 全部英雄死亡 |

## 5. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 获得诅咒知识 | 英雄 | 在可研究房间 | 知识检定；5+ 自己获得 Knowledge token，若已有则给同房间没有 token 的探索者；0-4 无事 | 房间动作 + 同房间目标选择 |
| 净化房间 | 英雄 | 在事件符号房间，且该房间没有 Fire token | 速度检定；若有 Knowledge token +2；6+ 放 Fire token；0-5 无事 | 房间动作 + 净化 token 预览 |
| 准备结界 | 英雄 | 在结界房间 | 力量检定；若有 Knowledge token +2；6+ 获得 Might token；0-5 无事 | 房间动作 + 角色 token |
| 完成仪式 | 英雄 | 与恶魔地产经纪人同房间 | 神志检定；本区域每个 Fire token +1；在 Ritual Room 额外 +1；有 Knowledge token 额外 +2；13+ 英雄胜利，9-12 无事并结束回合，0-8 每名英雄失去 1 神志并结束回合 | 怪物对象动作 + 区域加值明细 |

可研究房间：Library、Chapel、Laboratory。结界房间：Nursery、Armory、Graveyard。

## 6. 持续 / 触发规则

- 恶魔地产经纪人向最近英雄移动，并在同房间时使用神志攻击。
- 对恶魔地产经纪人造成伤害时，不击晕；攻击者可按伤害点数移动她最多对应房间数。
- 英雄攻击或被恶魔地产经纪人攻击时，若有 Might token，额外掷 2 颗骰。
- 怪物回合结束时，与恶魔地产经纪人同区域的每名英雄受 1 骰精神伤害。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 恶魔地产经纪人 | 1 | 房间、怪物回合、不能击晕、被伤害后可被移动 |
| Fire token | 6 | 已净化房间位置；同房间唯一；区域加值来源 |
| Knowledge token | 2 | 诅咒知识持有人；不可重复持有 |
| Might token | 2 | 保护结界持有人；战斗额外骰来源 |

恶魔地产经纪人属性：力量 5、速度 3、神志 6、知识 4。

## 8. UI 承接

- 主目标条显示“积累知识 / 净化房间 / 同房间完成仪式”。
- 地图必须显示同区域 Fire token 对仪式的加值，不只显示总数。
- 恶魔地产经纪人被攻击成功后要弹出“移动她最多 N 格”的路径选择。
- 角色板显示 Knowledge token 和 Might token 的不同用途。

## 9. 验证

- 单测：人数决定初始 Fire token 数；Knowledge token 加值；仪式三类加值叠加；怪物不可击晕且可被伤害推动；区域精神伤害。
- 页面测试：研究、净化、准备结界、仪式动作都从房间或怪物本体触发。
- E2E：覆盖英雄仪式胜利，以及攻击恶魔后移动她改变区域伤害范围。
