# 作祟 13 交互子账本：Holy Ground

> 状态：`contract-ready`。这是作祟揭秘者叛徒作祟，核心是仪式知识、献祭尸体、邪教徒尸体和双向进度。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p21 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p12 |
| 剧本卡 / 触发预兆 | A Strange Disappearance / Holy Symbol |
| 叛徒 | 作祟揭秘者 |
| 类型 | 叛徒 + 怪物 + 计数轨献祭 / 打断 |

## 2. 公开步骤

- 公开叛徒为作祟揭秘者，叛徒仍在游戏中。
- 公开 Ritual Room 和 Chasm 可能需要从房间堆搜索放置到地下室。
- 公开 Cultist 可被杀死并变成可搬运尸体。

## 3. 私密可见性

- 英雄可见：研究仪式、扰乱仪式、杀死叛徒和所有 Cultist 的胜利路径。
- 叛徒可见：搬运尸体、在 Chasm 献祭、每回合英雄受伤、Cultist 属性和尸体规则。
- 当叛徒献祭或英雄扰乱仪式时，相关进度变化必须公开。

## 4. setup 队列

英雄侧：
1. 英雄无额外设置。
2. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 作祟揭秘者成为叛徒并保留探索者。
2. Monster Card 放在叛徒左侧，Cultist 在叛徒后行动。
3. 数字轨设为 3，代表仪式进度。
4. 若 Ritual Room 和 Chasm 未发现，从房间堆找出并按正常规则放到地下室。
5. 在 Ritual Room 放置 3/4/5/6 个 Cultist。
6. 叛徒治疗全部属性，并提升 1 力量和 1 速度。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 成功扰乱仪式，或叛徒和所有 Cultist 都死亡 |
| 叛徒 | 仪式进度降到 0，或所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 研究仪式 | 英雄 | 在可研究房间 | 知识检定；5+ 获得 Ritual Knowledge Rune token，不可交易；0-4 无事 | 房间动作 + 角色知识计数 |
| 扰乱仪式 | 英雄 | 在 Ritual Room | 神志检定；每个自己持有的 Ritual Knowledge +1；每个存活 Cultist -1；6+ 英雄胜利，4-5 受 1 精神伤害，0-3 受 2 精神伤害 | Ritual Room 动作 + 加减值明细 |
| 搬运尸体 | 叛徒 | 同房间有 Cultist 或探索者尸体 | 拾起 1 具尸体放在角色板；一次最多携带 1 具 | 尸体对象动作 + 携带状态 |
| 献给她 | 叛徒 | 在 Chasm 且携带尸体 | 神志检定；7+ 数字轨 -1，到 0 叛徒胜利；0-6 叛徒获得 2 神志 | Chasm 动作 + 进度条 |

可研究房间：Library、Chapel、Ritual Room。

## 7. 持续 / 触发规则

- 叛徒回合结束时，每名英雄受 1 点一般伤害。
- Cultist 在叛徒回合后行动。
- Cultist 被杀死而不是被击晕；翻到击晕面后成为尸体，可被献祭。
- 叛徒一次只能携带 1 具尸体。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 仪式进度，从 3 到 0 |
| Cultist | 3/4/5/6 | 房间、存活/尸体、是否被携带 |
| Ritual Knowledge | 8 | 英雄持有人，不可交易 |
| 尸体 | 可变 | 来源、房间或叛徒携带、是否已献祭 |

Cultist 属性：力量 5、速度 3、神志 3、知识 3。

## 9. UI 承接

- 主目标条必须同时显示“英雄扰乱仪式”和“叛徒献祭进度”。
- 数字轨用进度条表达，不只写日志。
- Cultist 死亡后应显示尸体状态和可被叛徒搬运。
- 扰乱仪式面板要显示 Ritual Knowledge 加值和存活 Cultist 减值。

## 10. 验证

- 单测：Ritual Room/Chasm 搜索放置；Cultist 人数；扰乱仪式加减值；献祭进度到 0；Cultist 死亡转尸体；叛徒每回合伤害。
- 页面测试：研究、扰乱、搬尸、献祭都从房间或对象触发。
- E2E：覆盖英雄扰乱胜利和叛徒献祭胜利两条路径。
