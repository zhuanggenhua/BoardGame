# 作祟 27 交互子账本：Words from the Stars

> 状态：`contract-ready`。这是外星文字扩散作祟，核心是英雄学习语言、文字障碍/伤害和叛徒移除骰子。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p35 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p30 |
| 剧本卡 / 触发预兆 | Cursed! / Mask |
| 叛徒 | 作祟揭秘者 |
| 类型 | 一名叛徒 + Rune token 扩散 + 攻击骰干扰 |

## 2. 公开步骤

- 公开 Alien Words 不能拾取或交易。
- 公开英雄离开有 Alien Word 的房间耗 2 点移动力。
- 公开叛徒和英雄各有独立 Alien Word token 池，叛徒放完自己的 Alien Words 也可胜利。

## 私密可见性

- 英雄可见：Alien Words 位置、自己是否学会语言、相邻文字伤害风险。
- 叛徒可见：文字扩散、移除英雄骰子的干扰能力和叛徒胜利进度。
- Rune / Alien Words token 是公开地图状态；语言知识是角色状态，必须可查。

## 3. setup 队列

英雄侧：
1. 英雄无额外 setup。
2. 按人数给英雄侧准备 3/4/4/5 个 Rune token 作为 Alien Words。
3. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者并治疗全部属性。
2. 按人数给叛徒侧准备 5/4/4/3 个 Rune token。
3. 在叛徒房间放置 1 个叛徒侧 Alien Word。

## 4. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 杀死叛徒 |
| 叛徒 | 放完叛徒侧全部 Alien Words，或所有英雄死亡 |

## 5. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 学习语言 | 英雄 | 在有语言笔记房间 | 知识检定；4+ 获得自己的 Hero token；0-3 从英雄侧 token 池放 1 个 Alien Word 到当前房间；若当前房间已有，则放到相邻房间 | 房间动作 + token 放置 |
| 传播文字 | 叛徒 | 在没有英雄且没有 Alien Word 的房间 | 知识检定；每个相邻 Alien Word +1；7+ 在当前房间放 1 个叛徒侧 Alien Word；0-6 叛徒获得 2 知识 | 叛徒房间动作 + 邻接加值 |

语言笔记房间：Library、Observatory、Tower、Laboratory、Specimen Room。

## 6. 持续 / 触发规则

- 英雄若拥有 Knowledge of Aliens，攻击叛徒时可重掷最多 2 个骰。
- 英雄攻击叛徒获胜时，可偷取叛徒的 Mask 替代造成伤害。
- 英雄回合结束时，若在 Alien Word 所在房间或相邻房间，受 1 精神伤害。
- 叛徒攻击或被攻击时，若叛徒所在房间有 Alien Word，叛徒在英雄掷骰并重掷后移除英雄 1 颗骰，该骰不计入结果。
- 叛徒回合结束时，若叛徒侧 Alien Words 全部在屋内，叛徒胜利。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |

| 叛徒侧 Alien Word | 5/4/4/3 | token 池、房间、叛徒胜利进度 |
| Knowledge of Aliens | 每名英雄 1 | 持有人、不可交易、攻击重掷权限 |
| Mask | 1 | 叛徒持有与否、可被偷取 |

## 8. UI 承接

- 地图上 Alien Word 要显示“离开耗 2”与“相邻精神伤害”范围。
- 英雄攻击叛徒时要显示可重掷骰和叛徒可能移除骰子的顺序。
- 主目标条显示叛徒 Alien Word 剩余数，不能只在日志里提示。

## 9. 验证

- 单测：英雄/叛徒 token 池人数规则；学习失败扩散；叛徒传播邻接加值；英雄回合末相邻伤害；重掷后移除骰；叛徒放完胜利。
- 页面测试：Alien Word 范围、攻击骰流程、知识 token 私有状态。
- E2E：覆盖叛徒放完文字胜利和英雄杀死叛徒胜利。
