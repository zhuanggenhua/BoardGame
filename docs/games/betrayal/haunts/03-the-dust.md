## 2. 公开步骤

- 公开该作祟为隐藏叛徒；所有探索者可互相攻击。
- 公开“离开有其他探索者的房间耗 2 点移动力”。
- 公开疾病 token 规则，但编号内容只对持有人自己可见。
- Monster Card 放在作祟揭秘者左侧；Feverish 在怪物回合行动。

## 3. 私密可见性

- 玩家可随时查看自己的疾病 token。
- 疾病 token 编号不可展示给他人，死亡时也不揭示。
- 玩家可以声称自己持有什么编号，但系统不能强制公开真实编号。
- 曾经获得编号 1 的玩家永久成为叛徒，即使后来失去该 token。

## 4. setup 队列

1. 为每名玩家准备 3 个疾病编号 token；3-5 人局只有 1 个编号 1，6 人局有 2 个编号 1。
2. 疾病 token 洗混后每名玩家秘密获得 3 个。
3. Monster Card 放到作祟揭秘者左侧。
4. 作祟揭秘者左侧玩家先行动。
5. 准备 8 个符文 token 作为研究 token。

实现状态：疾病 token 分发和首玩家解析已由作祟揭示落账；Monster Card 放在作祟揭秘者左侧、研究 token 池准备这两个灰尘 setup 人工确认项都已可通过正式命令写入队列状态，并在牌桌“开局承接”卡片提供短按钮确认；两个都确认后 setup 进度进入 resolved。

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 寻找治愈线索 | 任意探索者 | 在预兆符号房间，且该房间没有研究 token | 知识或神志检定；5+ 放 1 个研究 token；0-4 与左侧玩家随机交换 1 个疾病 token | 房间动作 + 随机交换确认 |

| 控制冲动 | 任意探索者 | 与另一探索者同房间 | 与目标玩家随机交换 1 个疾病 token，目标必须同意 | 同房间玩家选择 + 双方确认 |

可研究房间：实验室、手术室、观星台、厨房。

## 7. 持续 / 触发规则

- 回合结束时，若当前探索者与其他探索者同房间，必须逐个与同房间探索者随机交换 1 个疾病 token。
- 回合内若没有通过“控制冲动”或回合结束同房间规则交换过疾病 token，该探索者受 2 骰一般伤害。
- 任意时刻拿到编号 1 的探索者永久成为叛徒。
- 死亡时若该探索者是叛徒：掩埋其物品和预兆，用小怪物 token 替代成为 Feverish。
- 死亡时若该探索者不是叛徒：不执行灰尘专属掩埋和 Feverish 生成，其物品和预兆继续按通用尸体搜刮规则保留。
- 死亡时不能揭示疾病 token 编号。
- 已死亡叛徒在怪物回合作为 Feverish 行动，由已揭露且已死亡的叛徒控制。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 疾病编号 token | 每玩家 3 个 | 持有人、编号、是否曾持有 1、私密可见 |
| 研究 token | 8 | 房间位置；同一房间不可重复放 |
| Feverish | 死亡叛徒产生 | 原玩家、房间、怪物行动权 |

Feverish 属性：力量 6、速度 5、神志 3、知识 3；在作祟揭秘者之后的怪物回合行动。

- 主目标条不能显示谁是隐藏叛徒，只显示公开目标和感染压力。

- 研究 token 必须显示在地图房间上，并影响治愈加值。
