# 作祟 2 交互子账本：Friends Forever

> 状态：`contract-ready`。这是隐藏叛徒 + 时间循环作祟，不能用普通一对多作祟承接。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p6-p7 |
| 叛徒书 | 无，英雄书独占 |
| 剧本卡 / 触发预兆 | Cursed! / Ring |
| 叛徒 | 隐藏叛徒；编号 1 token 持有人 |
| 类型 | 隐藏身份 + 倒计时 + 登陆板返回 + 戒指毁灭 |

## 2. 公开步骤

- 公开这是隐藏叛徒作祟；叛徒开始时不公开。
- 公开所有探索者可以互相攻击。
- 公开有其他探索者的房间离开耗 2 点移动力；叛徒揭露后英雄之间不再互为障碍物，但叛徒仍与英雄互为障碍物。
- 公开数字轨代表时间循环倒计时，并会在作祟揭秘者回合结束时下降。

## 3. 私密可见性

- 每名玩家可随时查看自己的编号 token。
- 编号 token 不允许公开展示，除非规则要求；玩家可以口头声称任意编号。
- 编号 1 玩家为叛徒；叛徒可在他人成功毁戒指前揭露以触发规则。

## 4. setup 队列

1. 找出编号 1 到玩家人数对应上限的 Number token，面朝下洗混，每名玩家 1 个。
2. 每名玩家秘密查看自己的编号。
3. 编号 1 玩家成为隐藏叛徒。
4. 数字轨设置为 3/4/5/6 人对应 6/5/4/3。
5. 作祟后首回合由作祟揭秘者左侧玩家开始。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 毁掉戒指，或杀死叛徒 |
| 叛徒 | 所有英雄死亡，或数字轨到 0 |

毁戒指成功时若叛徒尚未死亡，叛徒必须立即揭露；若叛徒揭露导致毁戒指者被移回登陆板而不再满足结果条件，该次毁戒指可以失败。

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 毁掉戒指 | 持有戒指的探索者 | 持有 Ring | 速度或知识检定；每个在时间扰动房间的英雄 +1；7+ 毁戒指，若叛徒死则英雄胜利，否则叛徒揭露；0-6 受 6 点一般伤害并被放到任一登陆板 | 戒指卡动作 + 时间扰动加值条 + 登陆板选择 |

时间扰动房间：Panic Room、Furnace Room、Ballroom、Operating Theatre、Junk Room。

## 7. 持续 / 触发规则

- 作祟揭秘者回合结束时，数字轨下降 1。
- 数字轨下降后，每名英雄可以回到一个登陆板；未回到登陆板的英雄受 2 点精神伤害。
- 叛徒揭露时治疗全部属性并提升 1 点力量。
- 已揭露叛徒在作祟揭秘者回合结束时不因未返回登陆板受伤。
- 数字轨到 0 时叛徒胜利。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 编号 token | 每名玩家 1 个 | 编号、持有人、是否已公开、是否为叛徒 |
| 数字轨 | 1 | 当前倒计时；到 0 触发叛徒胜利 |
| Ring | 1 | 当前持有人；是否已毁灭 |

## 9. UI 承接

- 主目标条：公开显示“毁戒指 / 找出叛徒 / 倒计时”，但不泄露叛徒身份。
- 风险条：数字轨必须常驻显示，并在作祟揭秘者回合结束前提示即将下降。
- 私密面板：只显示自己的编号 token。
- 登陆板返回必须是玩家选择，不允许系统默认送回某个登陆板。

## 10. 验证

- 单测：编号 1 分配为隐藏叛徒；数字轨按人数初始值；作祟揭秘者回合结束降轨；未返回登陆板受伤；叛徒揭露治疗和力量提升。
- 页面测试：私密编号只对本人可见；毁戒指加值来自时间扰动房间；登陆板选择交互。
- E2E：覆盖叛徒未揭露时毁戒指、叛徒揭露打断毁戒指、数字轨归零叛徒胜利。
