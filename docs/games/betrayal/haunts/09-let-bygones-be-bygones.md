# 作祟 9 交互子账本：Let Bygones be Bygones

> 状态：`contract-ready`。这是自由混战作祟，核心是 Idol 持有人攻击加值、偷神像和击杀推进。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | 无，叛徒书独占 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p7 |
| 剧本卡 / 触发预兆 | A Mysterious Invitation / Idol |
| 叛徒 | 自由混战 |
| 类型 | 全员敌对 + Idol 争夺 + 物品掩埋攻击加值 |

## 2. 公开步骤

- 公开这是自由混战：所有探索者互为障碍物，且可以互相攻击。
- 公开数字轨从 1 开始，代表 Idol 持有者力量攻击加值。
- 作祟后首回合由作祟揭秘者左侧玩家开始。

## 私密可见性

- 本作祟是自由混战；没有阵营私密目标，所有玩家目标相同但互相敌对。
- Idol 持有人、击杀进度和掩埋物品获得的攻击加值必须公开显示。
- 玩家手牌 / 持有物仍按基础规则可见性处理；攻击替代偷取只在攻击胜利后进入选择。

## 3. setup 队列

1. 数字轨设置为 1。
2. 作祟后首回合由作祟揭秘者左侧玩家开始。
3. 触发预兆 Idol 保持当前持有人；若因异常不在任何人手中，必须通过当前持有物真相先恢复其位置，不能默认给揭秘者。

## 4. 目标模型

| 玩家 | 胜利条件 |
| --- | --- |
| 每名探索者 | 自己成为最后存活的探索者 |

## 5. 特殊行动 / 攻击替代

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 搜索架子 | 探索者 | 在物品符号房间 | 知识检定；5+ 抽物品牌堆顶；0-4 无事 | 房间动作 + 抽牌亮相 |
| 偷神像 | 对 Idol 持有人进行力量攻击的探索者 | 攻击目标持有 Idol，攻击者获胜 | 可选择偷 Idol 替代造成伤害；攻击者若失败照常受伤 | 攻击胜利后的替代结果选择 |
| 掩埋物品强化徒手攻击 | 探索者 | 进行无武器力量攻击 | 可掩埋任意数量持有物品，每掩埋 1 张本次攻击结果 +1 | 攻击声明面板 + 掩埋多选 |

## 6. 持续 / 触发规则

- Idol 持有人进行力量攻击时，加上数字轨当前值。
- Idol 持有人杀死另一名探索者时，数字轨 +1。
- 自由混战中所有探索者都是障碍物。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 当前 Idol 加值；击杀后递增 |
| Idol | 1 | 当前持有人；可被攻击胜利后偷取 |
| 物品牌堆 | 1 | 搜索架子抽取来源；被掩埋物品进入牌堆底或弃置规则需按通用物品掩埋承接 |

## 8. UI 承接

- 主目标条显示“最后生还者”，并显示 Idol 当前持有人。
- 攻击面板必须展示 Idol 加值和掩埋物品加值的来源明细。
- 偷 Idol 是攻击胜利后的选择，不应在攻击前自动决定。

## 9. 验证

- 单测：自由混战障碍物；Idol 持有人攻击加值；击杀后数字轨 +1；攻击 Idol 持有人可偷取替代伤害；掩埋多个物品加值。
- 页面测试：Idol 持有人高亮、攻击结果替代选择、物品掩埋多选。
- E2E：覆盖 Idol 换手后加值来源同步改变。
