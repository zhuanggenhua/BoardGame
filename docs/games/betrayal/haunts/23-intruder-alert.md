# 作祟 23 交互子账本：Intruder Alert

> 状态：`contract-ready`。这是机器人和电路作祟，核心是 ON/OFF token、翻面毁坏房间、蓝图移动和激光上传压力。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p31 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p25 |
| 剧本卡 / 触发预兆 | Cursed! / Idol |
| 叛徒 | 作祟揭秘者 |
| 类型 | 一名叛徒 + 机器开关 + 房间翻面 + 机器人怪物 |

## 2. 公开步骤

- 公开数字轨代表英雄还需要毁坏的房间数量。
- 公开 ON/OFF token 是机器电路；英雄需全部关掉并把数字轨降到 0。
- 公开 Wrecked 房间翻面后无符号无效果，四边都有门。

## 私密可见性

- 英雄可见：ON/OFF token、毁坏房间、上传数字轨和机器人位置。
- 叛徒可见：机器人行动、激光 / 上传压力和机器开关控制。
- 房间翻面和机器状态是公开地图状态，不得只用日志表示。

## 3. setup 队列

英雄侧：
1. 数字轨设为 2/3/4/5。
2. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者并治疗全部属性。
2. Monster Card 放在叛徒左侧，Robot Assistant 在叛徒后行动。
3. 在屋内均匀放置 2/3/4/5 个 ON token。
4. 每个 ON token 房间放 1 个 Robot Assistant。

## 4. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 全部 Machine token 变 OFF，且数字轨为 0 |
| 叛徒 | 所有英雄死亡 |

## 5. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 关闭机器 | 英雄 | 与 ON token 同房间 | 知识检定；5+ 翻为 OFF，并击晕同区域一个 Robot；0-4 无事 | ON token 动作 + 区域 Robot 选择 |
| 毁坏房间 | 英雄 | 在预兆符号房间 | 力量检定；4+ 房间翻面变 Wrecked，数字轨 -1；0-3 无事 | 房间动作 + 计数轨 |
| 移动蓝图 | 叛徒 | 选择有英雄的房间 | 将该房间移动到同区域其他位置，不能导致任意房间无法通过普通移动到达 | 叛徒动作 + 连通性预览 |
| 打开激光 | Robot | 选择视线内英雄 | 该英雄速度检定；5+ 放置自己到任一相邻房间；0-4 受 2 骰物理伤害 | 怪物动作 + 英雄位移选择 |

## 6. 持续 / 触发规则

- 英雄回合结束时若全部机器 OFF 且数字轨为 0，英雄胜利。
- Wrecked 房间无符号无效果，四边有门。
- Robot Assistant 受伤害时不会因此击晕；仍可被其他方式击晕。
- Robot 在叛徒回合后行动。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 待毁坏房间数；毁坏房间时下降 |
| ON/OFF token | 2/3/4/5 | 房间、开关状态、是否全部 OFF |
| Robot Assistant | 2/3/4/5 | 房间、状态、是否被非伤害方式击晕 |
| Wrecked 房间 | 可变 | 原房间、翻面、无符号、四边门 |

Robot 属性：力量 2、速度 6、神志 2、知识 2。

## 8. UI 承接

- 主目标条同时显示“机器关闭数”和“毁坏进度”。
- Wrecked 房间必须在地图视觉上变成翻面状态，并重算门位。
- 移动蓝图需要显示断连风险，禁止静默移动。

## 9. 验证

- 单测：ON token 分布和 Robot 数；关闭机器击晕同区域 Robot；Wrecked 房间规则；蓝图移动连通性校验；Robot 激光结果。
- 页面测试：机器开关、毁坏房间翻面、目标双进度。
- E2E：覆盖全 OFF + 数字轨 0 后英雄胜利。
