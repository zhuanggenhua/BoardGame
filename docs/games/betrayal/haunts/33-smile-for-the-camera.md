# 作祟 33 交互子账本：Smile for the Camera

> 状态：`contract-ready-needs-implementation-audit`。已有代表链不能等同于完整支持。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p41 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p38 |
| 剧本卡 / 触发预兆 | NONE / Say Cheese |
| 叛徒 | 见事件 |
| 类型 | 一名叛徒 + 相机 / Essence token + 远程怪物攻击 |

## 2. 公开步骤

- 公开魔法相机、幻影摄影师和英雄 Essence token 的存在。
- 英雄没有额外 setup；叛徒仍在游戏中。
- 叛徒 setup 会放置幻影摄影师，并确保魔法相机在叛徒面前。
- 作祟后首回合由叛徒左侧玩家开始。

## 3. 私密可见性

- 英雄可见：破坏魔法相机、击杀幻影摄影师、英雄胜利条件。
- 叛徒可见：拍照夺取 Essence、相机保护、持有 Essence 攻击加骰、摄影师回合和视线夺 Essence。
- Essence token 的当前归属是规则真相，不能只在叛徒描述里隐藏。

## 4. setup 队列

1. 叛徒保留探索者并成为叛徒。
2. 根据玩家人数放置 2/3/4/5 个小怪物 token 作为幻影摄影师，放在非登陆板房间，并尽量均匀分布在区域间。
3. 若魔法相机尚未发现，从物品牌堆搜索并面朝上放在叛徒面前。
4. 给每名英雄其对应 Hero token，代表该英雄的 Essence。
5. 作祟后首回合由叛徒左侧玩家开始。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 击杀所有幻影摄影师，并摧毁魔法相机 |
| 叛徒 | 所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 砸碎魔法相机 | 英雄 | 与叛徒同房间 | 神志检定；6+ 若叛徒持有魔法相机则将相机移出游戏；0-5 无事 | 叛徒对象动作 + 相机状态 |
| 拍照 | 叛徒 | 与目标英雄同房间；若有魔法相机则可选视线内英雄；目标仍有 Essence | 速度检定；6+ 拿走目标 Essence，并提升叛徒任一属性 1 步；0-5 无事 | 目标英雄选择 + 视线范围 + 属性提升选择 |

## 7. 持续 / 触发规则

- 幻影摄影师只能被力量攻击杀死；其他成功攻击只能击晕。
- 英雄回合结束时，若该英雄在任一幻影摄影师视线内且仍有 Essence，叛徒拿走该 Essence。
- 叛徒持有魔法相机时，其属性不能降到临界以下。
- 叛徒攻击某英雄时，若拥有该英雄 Essence，额外掷 2 颗骰。
- 叛徒回合后，幻影摄影师行动。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 幻影摄影师 | 2/3/4/5 | 房间、状态、是否被力量攻击杀死 |
| Essence token | 每名英雄 1 个 | 当前归属：英雄 / 叛徒；不能重复夺取 |
| 魔法相机 | 1 | 叛徒面前 / 被摧毁移出游戏；是否保护叛徒属性 |

幻影摄影师属性：力量 4、速度 1、神志 6、知识 2；使用神志攻击，可攻击视线内任意英雄；获胜造成精神伤害。

## 9. UI 承接

- 主目标条：英雄显示“杀死所有摄影师 + 砸相机”；叛徒显示“夺取 Essence 并杀死英雄”。
- 地图：幻影摄影师视线必须高亮；英雄回合结束前应能看见 Essence 被视线威胁。
- 英雄 token：Essence 当前是否仍在英雄手上必须可见给对应玩家；叛徒持有的 Essence 必须影响攻击面板。
- 相机：魔法相机被摧毁后，叛徒拍照范围和属性保护立即改变。

## 10. 验证

- 单测：人数决定摄影师数量；相机未发现时搜索给叛徒；拍照同房间 / 视线范围差异；Essence 攻击加骰；属性不能降到临界以下；摄影师只有力量攻击可杀。
- 页面测试：摄影师视线威胁、英雄砸相机、叛徒拍照选择属性提升。
- E2E：覆盖英雄摧毁相机 + 清除摄影师，以及叛徒通过 Essence 加骰击杀英雄。
