# 作祟 44 交互子账本：A Missing Seam

> 状态：`contract-ready`。这是纵火逃生作祟，核心是燃烧房间翻面、登陆板例外、火势按连续火区扩散、假人怪物和全屋燃烧胜利。

## 2. 公开步骤

- 公开燃烧房间正面翻到背面，不再有符号和效果，并视为四边都有门。
- 公开登陆板不会翻面；改用 Fire token 表示燃烧，并保留楼层连接。
- 公开英雄可主动纵火，怪物回合末火势扩散；全屋燃烧时英雄胜利。

## 3. 私密可见性

- 英雄可见：所有燃烧房间、Fire token、可纵火房间和火势扩散候选。
- 叛徒可见：假人数量、假人移动限制和自身塑料减伤。
- 火势是公开全局状态；不能只作为叛徒或英雄私密规则。

## 4. setup 队列

英雄侧：
1. 作祟揭秘者将自己所在房间翻面，并把棋子放回该房间；该房间成为燃烧。
2. 若只有 3 名玩家，也翻面另一名英雄所在房间，除非该英雄在登陆板。
3. 找出 5 个 Fire token 放旁边。
4. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 叛徒保留探索者并成为叛徒。
2. 叛徒治疗全部属性。
3. Monster Card 放在叛徒左侧；假人在叛徒回合后行动。
4. 在登陆板放置 1/2/3/4 个 Small Monster token，代表假人。

| 叛徒 | 所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 纵火 | 英雄 | 任意房间；每回合 1 次 | 神志检定；4+ 将当前房间翻面成为燃烧；若是登陆板则放 Fire token；0-3 无事 | 房间动作 + 火势预览 |
| 火势扩散 | 规则流程 | 怪物回合末 | 每片连续燃烧区作为 1 场火；每场火选择任一相邻房间，同时翻面成为燃烧；若没有可扩散房间，则在未燃烧登陆板放 Fire token | 火势扩散选择交互 |

火势扩散选择应由英雄阵营承接为显式交互；实现不能静默随机挑房间。

## 7. 持续 / 触发规则

- 英雄移动到燃烧房间时，受到 1 一般伤害。
- 叛徒和假人不会因进入燃烧房间受伤。
- 燃烧房间没有符号和效果，且四边都有门。
- Basement Landing、Ground Floor Landing / staircase、Upper Landing 的连通在燃烧后仍保留；Ground Floor Landing 对火势计为 1 个房间。
- 叛徒受到所有攻击伤害时，伤害减少 1。
- 假人若在英雄视线内开始自己的回合，只掷 2 骰决定移动，否则使用速度 6。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Burning tile | 可变 | 房间是否翻面、是否为登陆板例外、可通行门位 |
| Fire token | 最多 5 | 登陆板燃烧状态 |
| Mannequin | 1/2/3/4 | 房间、视线移动限制、怪物状态 |
| 火势连续区 | 派生 | 每片连续燃烧区及其扩散候选 |

假人属性：力量 7、速度 6 或视线内 2 骰移动、神志 4、知识 2。

## 9. UI 承接

- 地图必须用房间本体翻面 / 火焰覆盖表达燃烧，不能只用日志。
- 火势扩散阶段要高亮每片连续火区和可选扩散目标。
- 登陆板燃烧必须保留楼层连接提示，避免玩家误以为楼梯断开。

## 10. 验证

- 单测：初始燃烧房间；3 人额外燃烧；登陆板 Fire token 例外；燃烧房间四门；英雄受火伤而叛徒 / 假人免疫；连续火区扩散；无扩散时点燃登陆板；假人视线移动限制。
- 页面测试：火势地图、扩散选择、登陆板连接、叛徒减伤。
- E2E：覆盖英雄通过纵火和扩散使全屋燃烧胜利。
