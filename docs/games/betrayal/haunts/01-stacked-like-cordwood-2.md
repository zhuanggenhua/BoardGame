## 2. 公开步骤

- 作祟揭示层必须公开：作祟编号、标题、触发预兆、叛徒为作祟揭秘者、所需 token。

- 首个作祟后回合由叛徒左侧玩家开始。

## 3. 私密可见性

- 英雄可见：杰克知识、驱魔圈、释放杰克之灵、驱魔目标和英雄胜利条件。
- 叛徒可见：潜行猎物、叛徒死亡后杰克之灵、杰克之灵怪物规则、叛徒复活规则。
- 使用特殊行动或怪物公开互动时，对应行动结果必须可在日志/规则揭示里向所有玩家解释。

## 4. setup 队列

1. 设置阵营：作祟揭秘者成为叛徒。
2. 叛徒保留探索者，不离场。
3. 叛徒治疗所有属性，并按玩家人数获得物理属性提升：3/4 人 +1 力量和速度，5/6 人 +2 力量和速度。
4. Monster Card 放到叛徒左侧；杰克之灵只有在叛徒死亡后进入地图。
5. 准备 Jack’s Spirit 大怪物 token、2 个神志 token 作为驱魔圈、2 个力量 token 作为杰克知识。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 先杀死叛徒释放杰克之灵，再在杰克之灵所在房间成功驱魔 |

## 7. 持续 / 触发规则

- 有杰克知识的英雄攻击叛徒或被杰克之灵攻击时，掷骰结果 +2。
- 普通攻防造成非致死伤害时，受伤方必须按物理 / 精神伤害类型自行分配属性伤害；不能由攻击方自动代扣。当前已补英雄攻击叛徒、叛徒攻击英雄、杰克之灵攻击英雄的代表切片；兔脚重掷普通攻击投骰时，会回滚旧攻击伤害并按新差值生成或替换防守者待分配伤害。致死胜负仍需单独审计。
- 叛徒死亡时，在离叛徒尸体最远的预兆符号房间放置杰克之灵；每次叛徒死亡都重复这个流程。
- 若叛徒回合开始时叛徒已死亡，则本回合改为操作杰克之灵。
- 怪物回合开始时，若杰克之灵与叛徒尸体同房间，叛徒治疗所有属性、重新控制探索者，并移除杰克之灵。

## 10. 验证

- 单测：叛徒 setup 治疗与人数加成；杰克知识加值；驱魔圈区域加值；叛徒死亡生成最远预兆房间；杰克之灵复活叛徒。
- 已补代表单测：英雄用砍刀 / 匕首 / 指环攻击叛徒、叛徒 / 杰克之灵攻击英雄时，非致死伤害先进入“攻击”伤害分配，由受伤方确认后才扣对应属性；错误玩家不能代分配；兔脚攻击重掷会回滚旧反伤或未确认待分配伤害，并按新攻击结果替换为新的防守者待分配伤害。
