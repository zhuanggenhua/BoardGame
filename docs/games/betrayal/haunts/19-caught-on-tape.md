# 作祟 19 交互子账本：Caught on Tape

> 状态：`contract-ready`。这是录像带倒计时作祟，核心是录像带销毁、入口逃离和怨灵在录像带间移动。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p27 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p20 |
| 剧本卡 / 触发预兆 | Cursed! / Holy Symbol |
| 叛徒 | 作祟揭秘者 |
| 类型 | 倒计时 + token 清除 + 怪物传送 |

## 2. 公开步骤

- 公开数字轨代表午夜倒计时；叛徒回合结束下降。
- 公开英雄要销毁全部 Videotape，并至少 1 名英雄到 Entrance Hall。
- 公开 Vengeful Spirit 可在 Videotape token 间移动。

## 私密可见性

- 英雄可见：录像带位置、已销毁数量、入口逃离条件和数字轨倒计时。
- 叛徒可见：怨灵在录像带之间移动、远程攻击和倒计时胜利。
- 录像带状态是公开地图真相，不能只在叛徒剧本书里驱动怪物传送。

## 3. setup 队列

英雄侧：
1. 英雄无额外 setup。
2. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者，Monster Card 放在叛徒左侧。
2. 叛徒获得 1 神志。
3. 数字轨设为 6/4/3/2。
4. 在尽可能远离英雄的 5 个不同房间放置 5 个 Videotape token。
5. 在任一有 Videotape 的房间放置 Ghost token，代表 Vengeful Spirit。

## 4. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 销毁全部 Videotape，并在回合结束时至少 1 名英雄在 Entrance Hall |
| 叛徒 | 所有英雄死亡，或数字轨到 0 |

## 5. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 销毁录像带 | 英雄 | 在有 Videotape 的房间 | 力量检定；4+ 移除该 Videotape；0-3 无事 | token 动作 |
| 抵挡诅咒 | 英雄 | 与 Vengeful Spirit 同房间 | 掷 1 颗骰；2：数字轨 +1；1：数字轨 +1 并结束回合；0：结束回合 | 怪物对象动作 + 轨道变化 |

## 6. 持续 / 触发规则

- 英雄回合结束时，若全部 Videotape 已毁且至少 1 名英雄在 Entrance Hall，英雄胜利。
- 叛徒可选择用神志攻击；目标也用神志防御，败者受精神伤害。
- 叛徒回合结束时数字轨 -1；到 0 叛徒胜利。
- 叛徒回合后，Vengeful Spirit 行动。
- Vengeful Spirit 可把有 Videotape token 的房间视为彼此相邻。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 倒计时；可被抵挡诅咒增加，被叛徒回合减少 |
| Videotape | 5 | 房间、是否已毁；也是怨灵特殊相邻点 |
| Vengeful Spirit | 1 | 房间、特殊相邻、怪物回合 |

Vengeful Spirit 属性：力量 7、速度 3、神志 4、知识 3。

## 8. UI 承接

- 主目标条显示“录像带剩余 / 是否有人在入口大厅 / 倒计时”。
- 地图需要显示 Vengeful Spirit 可通过录像带传送的连接。
- “抵挡诅咒”结果可能结束回合，必须在按钮和结果里明确。

## 9. 验证

- 单测：数字轨人数初始值；录像带放置 5 个不同房间；销毁录像带；抵挡诅咒三结果；怨灵录像带相邻；入口大厅胜利条件。
- 页面测试：录像带剩余目标条、倒计时条、怨灵传送高亮。
- E2E：覆盖英雄销毁全录像带并到入口大厅胜利，以及数字轨归零叛徒胜利。
