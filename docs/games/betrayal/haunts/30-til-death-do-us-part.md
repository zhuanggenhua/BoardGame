# 作祟 30 交互子账本：'Til Death Do Us Part

> 状态：`contract-ready`。这是最低神志叛徒作祟，核心是预兆暗置、Ring 引诱、Altar 锁定和 Wedding Party。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p38 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p33 |
| 剧本卡 / 触发预兆 | A Strange Disappearance / Ring |
| 叛徒 | 最低神志，排除作祟揭秘者 |
| 类型 | 一名叛徒 + 面朝下预兆 + 祭坛终局 |

## 2. 公开步骤

- 公开叛徒是除作祟揭秘者外神志最低的探索者。
- 公开英雄要找 Ring、将 Altar 置入最后发现房间，并在 Altar 与叛徒同房间时完成 Ceremony。
- 公开叛徒目标是获得 Ring。

## 3. 私密可见性

- 英雄队伍分开后可自由交易预兆，但每名英雄的预兆必须面朝下放在自己面前。
- 英雄可随时查看自己的面朝下预兆。
- 使用或受益于某个面朝下预兆时，必须向叛徒揭示，然后再翻回面朝下。
- 新获得的预兆不公开。
- 英雄之间交易预兆时不需要公开内容。
- 叛徒可通过攻击英雄翻开其一个预兆；英雄死亡时其全部预兆翻开。

## 4. setup 队列

英雄侧：
1. 若 Secret Stairs 未发现，从房间堆搜索并按正常规则放入屋内。
2. 将房间堆顶 4/6/9/12 张留下，其余放回盒中；若牌堆不足则跳过。
3. 把叛徒持有的所有预兆交给作祟揭秘者。
4. 英雄可自由交易预兆；每名英雄将预兆面朝下放在自己面前。
5. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者，治疗全部属性，并放到 Entrance Hall。
2. Monster Card 放在叛徒左侧。
3. 在不同预兆符号房间放置 1/2/3/4 个 Wedding Party；预兆房间不足时剩余放 Ground Floor Staircase。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 在 Altar 房间且叛徒同房间时成功 Perform the Ceremony |
| 叛徒 | 获得 Ring |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 引诱幽灵 | 持有 Ring 的英雄 | 揭示 Ring | 知识检定；移动叛徒最多等于结果的房间数 | Ring 卡动作 + 叛徒路径选择 |
| 完成仪式 | 英雄 | 在 Altar 房间且叛徒同房间 | 神志检定；6+ 英雄胜利；0-5 无事 | Altar token 动作 |

## 7. 持续 / 触发规则

- 发现房间堆最后一张房间时，在该房间放置 Altar token。
- 叛徒攻击英雄时，可翻开该英雄一个预兆，该预兆本作祟保持公开。
- 英雄死亡时，翻开其全部预兆。
- 叛徒属性不能低于起始值。
- 叛徒一旦进入 Altar 房间，就不能离开；效果也不能使其离开。
- 叛徒回合后 Wedding Party 行动。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Altar | 0/1 | 最后一张房间发现时放置、房间 |
| Ring | 1 | 当前持有人、是否被英雄面朝下持有、是否被叛徒获得 |
| Wedding Party | 1/2/3/4 | 房间、怪物回合 |
| 面朝下预兆 | 可变 | 持有人、是否对叛徒公开 |

Wedding Party 属性：力量 5、速度 4、神志 2、知识 3。

## 9. UI 承接

- 英雄预兆区必须支持“自己可见、叛徒不可见、已公开”三种状态。
- 主目标条显示房间堆剩余数、Altar 是否已出现、Ring 当前公开/私密状态。
- 叛徒进入 Altar 后要显示锁定状态，移动按钮禁用。
