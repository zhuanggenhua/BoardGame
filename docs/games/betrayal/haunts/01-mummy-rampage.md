## 2. 公开步骤

- 作祟揭示层公开：1 号作祟标题为「木乃伊横行」，叛徒为作祟揭秘者。
- 叛徒仍继续使用原探索者。
- 放置木乃伊大怪物 token 和五角形物品 token；五角形物品 token 代表石棺。
- 「女孩」按旧版规则从持有者身上旁置，当前运行以 Openclipart 女孩 SVG token 在地图上表示；它不是当前 9 张预兆牌的新对象。
- **本轮视觉裁定（2026-08-25）**：女孩单位不再使用内联程序化几何 SVG；运行时使用 `betrayal/tokens/haunts/mummy-girl.svg`，SVG 本体承担主视觉和身份识别。禁止再用 CSS 圆球、渐变圆、通用徽章壳、普通文字 badge 或其它抽象几何图形包裹/替代 SVG 主体。
- 首个作祟后回合由叛徒左侧玩家开始。

## 3. 私密可见性

- 英雄可见：驱逐木乃伊目标、书本需求、真名 / 驱逐法术两枚知识标记、神志攻击驱逐条件。
- 叛徒可见：木乃伊与女孩结婚目标、圣符 / 指环需求、木乃伊移动和攻击规则。
- 木乃伊、石棺和女孩 token 是公开地图对象；不属于秘密状态。

## 4. setup 队列

1. 设置阵营：作祟揭秘者成为叛徒。
2. 叛徒保留探索者，不离场，不按杰克规则治疗或提升属性。
3. 在叛徒所在房间放置木乃伊大怪物 token 和石棺 token。
4. 将女孩预兆旁置并放置女孩 token：只能放在已发现房间；未翻开的房间不是合法房间，不能放置女孩 token。候选优先选择与木乃伊同楼层且至少相隔 5 个房间的已发现房间；若没有，放在同楼层最远已发现房间；若同楼层没有其它已发现房间，放到全图最远已发现房间。
5. 拿出 2 枚知识考验标记备用。
6. Monster Card 放到叛徒左侧。
7. 首个作祟后由叛徒左侧玩家开始。

## 7. 持续 / 触发规则

- 若书本尚未翻开，后续英雄探索新房间并需抽预兆时，应从预兆堆找出书本代替抽牌并洗牌。
- 若圣符和指环都尚未翻开，后续叛徒因探索新房间翻开预兆时，应从预兆堆找出圣符或指环并洗牌。
- 任何人物或木乃伊进入女孩标记所在房间，即可持有女孩；当前运行记录为剧本 token / 持有状态，旧版规则书称为「女孩预兆」。
- 叛徒持有女孩且与木乃伊同房时，可将女孩交给木乃伊。
- 木乃伊移动掷骰结果为 0 或 1 时，可瞬移到大宅任意已发现房间；未翻开的房间不存在于当前大宅地图，不能作为木乃伊移动目标。
- 木乃伊可携带物件、偷窃；物件不会改变木乃伊属性。
- 木乃伊与英雄同房时，可能的话必须攻击该英雄。
- 木乃伊只用力量攻击；英雄受伤先扣速度，速度到底后才扣力量。
- 木乃伊攻击本会造成 2 点或以上损伤时，可选择偷 1 件物品或预兆代替扣减能力，并可用此方式夺取女孩。
- 英雄不能用速度攻击木乃伊，包括手枪和炸药。
- 本源段未给出「木乃伊不能被击晕」例外；木乃伊受伤按通用怪物规则击晕。英雄胜利仍必须按英雄书的真名、驱逐法术和书本同房步骤完成最终神志驱逐。

- 主目标条：英雄显示“找真名 -> 学驱逐法术 -> 同房神志驱逐”；叛徒显示“让木乃伊带女孩和圣符 / 指环回石棺”。

- 状态区：用「知识标记」进度条显示 0/2、1/2、2/2。
- 怪物详情：地图上非目标选择态点击木乃伊可打开详情，显示木乃伊速度 3、力量 8、神志 5、默认力量攻击、速度攻击无效、0/1 瞬移、攻击本会造成 2 点或以上损伤时可偷取物品 / 预兆 / 女孩来代替扣减能力，以及英雄最终必须按英雄书步骤用神志攻击让木乃伊战败并驱逐。不得再把未证实的抗击晕例外或实现层分数比较阈值写成原文规则。
