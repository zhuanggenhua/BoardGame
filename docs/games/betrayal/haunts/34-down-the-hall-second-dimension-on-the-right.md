## 2. 公开步骤

- 公开所有房间都视为一楼；地下室和二楼区域不再存在。
- 公开原本连通的特殊房间仍连通，即使不相邻。
- 公开 Mystic Elevator 只在掷出 2 或 4 时移动。
- 公开只有英雄可探索新房间，叛徒不能探索。

## 私密可见性

- 英雄可见：Christina 是否找到 / 持有人、数字轨、Entrance Hall 逃离条件和单一区域地图。
- 叛徒可见：维度操纵次数、房间移动 / 伤害 / 属性提升三选一和复活规则。
- 空间重排是公开地图真相，不能只在叛徒操作后静默改变房间连接。

## 3. setup 队列

英雄侧：
1. 准备 Small Monster token 作为 Christina。
2. 事件牌堆移出游戏。
3. 数字轨设为 6/3/1/0。
4. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者并治疗全部属性。
2. 除 Landing 和有探索者的房间外，所有房间洗回房间堆。
3. 将剩余房间和 Landing 重新排列为相互接触且构成一个连续区域。

## 6. 持续 / 触发规则

- 英雄探索时总是放置房间堆顶房间，不看背面区域。
- 英雄探索新房间后不强制结束回合；若还有移动力可继续移动。
- 新房间事件符号无事；物品符号照常抽物品；预兆符号抽预兆并使数字轨 +1，最高 8。
- Christina 可按正常交易规则在英雄之间交易；英雄死亡时，其他英雄可从尸体取得 Christina；叛徒不能取得 Christina。
- 叛徒死亡时，在任意开放门位房间复活，治疗全部属性并正常行动。
