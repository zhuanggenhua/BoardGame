# 作祟 15 交互子账本：Of Monsters and Mayhem

> 状态：`contract-ready`。这是作祟揭秘者死亡后控怪的作祟，核心是随机怪物、指定武器和怪物各自特殊攻击。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p23 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p14-p15 |
| 剧本卡 / 触发预兆 | Paranormal Investigators / Dagger |
| 叛徒 | 作祟揭秘者 |
| 类型 | 叛徒已死 + 怪物替代回合 + 指定武器击杀 |

## 2. 公开步骤

- 公开作祟揭秘者的探索者已死亡，叛徒改为控制怪物。
- 公开 Ghost、Vampire、Werewolf 中按人数随机进入屋内，未选中的怪物移出本作祟。
- 公开英雄需要用对应武器真正杀死怪物：Holy Symbol 对 Ghost、Crossbow 对 Vampire、Dagger 对 Werewolf。

## 私密可见性

- 英雄可见：怪物种类、指定武器 / 击杀条件、每只怪物状态和叛徒已死亡事实。
- 叛徒可见：怪物行动顺序、怪物特殊攻击和替代回合控制权。
- 指定武器和怪物弱点是公开目标信息，不能只藏在英雄书截图或日志里。

## 3. setup 队列

1. 叛徒探索者死亡，叛徒控制怪物。
2. Monster Card 放在叛徒左侧；怪物回合替代叛徒回合。
3. 找出 Ghost、Vampire、Werewolf 大怪物 token，随机选择 1/2/2/3 个放在叛徒死亡房间，未选中 token 放回盒中。
4. 英雄没有额外 setup。
5. 作祟后首回合由叛徒左侧玩家开始。

## 4. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 击败屋内所有怪物 |
| 叛徒 | 所有英雄死亡 |

## 5. 特殊行动 / 武器规则

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 搜索武器 | 英雄 | 在物品或预兆符号房间 | 知识检定；4+ 查看对应牌堆顶 4 张，拿 1 张，其余放牌堆底；0-3 无事 | 房间动作 + 牌堆选择 |
| 击杀 Ghost | 持有 Holy Symbol 的英雄 | 攻击 Ghost | 可用 Holy Symbol 作武器，双方掷神志；英雄胜利则 Ghost 被摧毁，失败受精神伤害 | 攻击声明 + 指定武器提示 |
| 击杀 Vampire | 持有 Crossbow 的英雄 | 用 Crossbow 攻击 Vampire 并胜利 | Vampire 被摧毁 | 攻击声明 |
| 击杀 Werewolf | 持有 Dagger 的英雄 | 用 Dagger 攻击 Werewolf 并胜利 | Werewolf 被摧毁 | 攻击声明 |

## 6. 怪物行动合同

- 叛徒不执行探索者回合，而是让屋内每个怪物各行动一次。
- 怪物行动顺序由叛徒选择；每个怪物单独掷速度。
- Ghost 可穿过非门相邻房间，不能被击晕；可用“Boo!”进行神志攻击，然后按目标速度骰移动该英雄最多相应格数。
- Vampire 可用“Slurp!”力量攻击；每个 Blood token 让该攻击 +1，然后获得 1 个 Blood token；Blood token 不足时可用其他 token 替代。
- Werewolf 可用“Howl!”力量攻击；可对同房间每名英雄各重复一次。

## 6.1 持续 / 触发规则

- 叛徒探索者已死亡，不再执行普通探索者行动、交易、探索或持有物行动。
- 屋内所有入场怪物每轮各行动一次，行动顺序由叛徒选择。
- 怪物被非指定方式攻击成功时，只能按该怪物规则受伤 / 击晕，不能算作英雄胜利击杀。
- 未随机入场的怪物不属于本局目标，也不应出现在主目标条。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Ghost | 0/1 | 是否入场、房间、不能击晕、是否被 Holy Symbol 摧毁 |
| Vampire | 0/1 | 是否入场、房间、Blood token 数 |
| Werewolf | 0/1 | 是否入场、房间、同房间英雄列表 |
| Blood token | 3 起 | Vampire 加值；不足时替代 token |

怪物属性：Ghost 4/4/5/5，Vampire 5/4/5/5，Werewolf 6/4/4/4（力量/速度/神志/知识）。

## 8. UI 承接

- 主目标条显示当前入场怪物和对应所需武器，不显示未入场怪物为待完成目标。
- 攻击面板必须区分“普通击晕/伤害”和“指定武器摧毁”。
- 怪物回合面板允许叛徒选择怪物行动顺序。

## 9. 验证

- 单测：随机怪物数量按人数；搜索武器看 4 拿 1；指定武器击杀；Ghost 不可击晕；Vampire 血 token 加值；Werewolf 对同房间多人攻击。
- 页面测试：当前怪物目标清单、武器声明、怪物行动顺序选择。
- E2E：覆盖至少两个怪物入场时英雄逐个击杀胜利。
