# 作祟 6 交互子账本：Inheritance

> 状态：`contract-ready`。这是隐藏叛徒作祟，核心是证据配对、揭露最高未公开编号和强制作战压力。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p14-p15 |
| 叛徒书 | 无，英雄书独占 |
| 剧本卡 / 触发预兆 | A Mysterious Invitation / Dagger |
| 叛徒 | 隐藏叛徒；编号 1 token 持有人 |
| 类型 | 隐藏身份 + 证据 token + 强制攻击压力 |

## 2. 公开步骤

- 公开这是隐藏叛徒；所有探索者可以互相攻击。
- 公开离开有其他探索者的房间耗 2 点移动力；叛徒揭露后英雄之间不再互为障碍物。
- 公开证据 token 可以拾取、交易、死亡掉落，并用于揭露编号。

## 3. 私密可见性

- 每名玩家可查看自己的编号 token。
- 编号 token 不可随意公开，除非死亡、被规则揭露或叛徒主动揭露。
- 叛徒可在自己回合任意时刻揭露。

## 4. setup 队列

1. 作祟揭秘者把每种 Trait token 的两枚分别放在不同区域的不同房间，代表配对证据；同名 token 不能在同一区域。
2. 编号 1 到玩家人数对应上限的 Number token 洗混，每名玩家 1 个。
3. 玩家秘密查看编号，编号 1 成为隐藏叛徒。
4. 作祟后首回合由作祟揭秘者左侧玩家开始。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 杀死叛徒 |
| 叛徒 | 所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 揭开真相 | 持有证据的英雄 | 自己持有一枚证据，且在匹配证据所在房间或匹配证据持有人同房间 | 用该证据对应属性检定；5+ 最高编号且尚未揭露的玩家公开编号；0-4 无事 | 证据卡动作 + 匹配证据定位 + 被揭露玩家提示 |

## 7. 持续 / 触发规则

- 证据在房间时可被同房间探索者拾取，并放到角色板。
- 证据可在英雄之间按正常交易规则转移。
- 英雄死亡时，其证据掉落在死亡房间。
- 任意探索者死亡时，公开自己的编号 token。
- 回合结束时若本回合没有攻击，受 2 骰精神伤害。
- 叛徒揭露或被“揭开真相”揭露时，治疗全部属性并提升 1 力量。
- 若叛徒因回合末精神伤害会死亡，改为揭露叛徒、治疗全部属性并提升 1 力量。
- 叛徒揭露后不再因回合末未攻击而受精神伤害。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 编号 token | 每名玩家 1 个 | 编号、持有人、是否公开、是否为叛徒 |
| Trait token 证据 | 8 | trait 类型、房间或持有人、是否匹配、可交易/掉落 |

## 9. UI 承接

- 地图显示可拾取证据，但同名配对关系应在证据详情中表达。
- 私密面板显示自己的编号；公开编号应进入日志和角色状态。
- 回合结束前若未攻击，短提示“未攻击会受精神伤害”；这不是建议，而是强制触发规则。

## 10. 验证

- 单测：证据跨区域放置；揭开真相揭露最高未公开编号；叛徒揭露治疗加力；未攻击回合末伤害；叛徒因该伤害濒死时改为揭露。
- 页面测试：证据拾取/交易/掉落、私密编号、揭露日志。
- E2E：覆盖证据揭露叛徒后英雄击杀胜利。
