# 作祟 8 交互子账本：Housekeeping

> 状态：`contract-ready`。这是无叛徒合作作祟，核心是特定脏房间清洁和管家怪物压力。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p18-p19 |
| 叛徒书 | 无，英雄书独占 |
| 剧本卡 / 触发预兆 | A Mysterious Invitation / Dog |
| 叛徒 | 无叛徒 |
| 类型 | 合作清洁目标 + 怪物追击 + 全员回合末压力 |

## 2. 公开步骤

- 公开没有叛徒。
- 公开必须清洁 Bloody Room、Charred Room、Collapsed Room、Junk Room、Catacombs 五个房间。
- 公开 Housekeeper 在作祟揭秘者之后行动。

## 私密可见性

- 本作祟无叛徒；脏房间、已清洁状态、管家位置和全员回合末压力全部公开。
- 清洁目标不是个人隐藏任务；地图和主目标条必须显示剩余清洁数量。
- 管家行动和惩罚来源必须在结算前可追溯。

## 3. setup 队列

1. 若屋内事件符号房间少于 3/4/5/6 个，从房间堆抽取并放置直到达到该数量；这些新放房间不结算文字或符号效果。
2. 在不同事件符号房间放置 3/4/5/6 个 Housekeeper，尽量均匀分布在各区域。
3. 5 个 Rune token 放在一边，代表已清洁房间。
4. 作祟后首回合由作祟揭秘者左侧玩家开始。

## 4. 目标模型

| 阵营 | 胜利条件 | 失败条件 |
| --- | --- | --- |
| 英雄 | 五个指定房间全部放上 Rune token | 全部英雄死亡 |

## 5. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 清洁房间 | 英雄 | 位于可清洁房间，且该房间没有 Rune token | 速度或神志检定；5+ 放 Rune token；放下第 5 个 Rune token 时英雄胜利；0-4 无事 | 房间本体动作 + 五房间进度 |

可清洁房间：Bloody Room、Charred Room、Collapsed Room、Junk Room、Catacombs。

## 6. 持续 / 触发规则

- Housekeeper 在作祟揭秘者之后行动。
- Housekeeper 向最近英雄移动；距离平手时朝年龄最大的英雄移动。
- Housekeeper 使用力量攻击。
- 怪物回合结束时，每名探索者受 1 点一般伤害。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Housekeeper | 3/4/5/6 | 房间、最近英雄、平手目标、状态 |
| Rune token | 5 | 对应已清洁房间；同房间唯一 |

Housekeeper 属性：力量 5、速度 4、神志 5、知识 5。

## 8. UI 承接

- 主目标条显示 5 个指定房间清洁进度，不能只显示 Rune token 总数。
- 地图要高亮“可清洁但未清洁”的房间，以及缺失未发现的指定房间。
- setup 抽放事件房间时必须显示“仅补房间，不结算效果”的短提示。

## 9. 验证

- 单测：事件符号房间不足时补房但不结算；Housekeeper 数量按人数；第 5 个 Rune token 触发胜利；怪物回合结束全员伤害。
- 页面测试：五房间清单、清洁按钮、已清洁状态。
- E2E：覆盖清洁最后一个指定房间后立即胜利。
