# 作祟 36 交互子账本：Finding Peace

> 状态：`contract-ready`。这是最低神志叛徒作祟，核心是鬼魂调解、事件房间生成鬼、叛徒吃鬼启蒙和不可攻击鬼。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p45 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p41 |
| 剧本卡 / 触发预兆 | For Sale / Holy Symbol |
| 叛徒 | 最低神志 |
| 类型 | 一名叛徒 + Ghost token + 双方争夺鬼魂状态 |

## 2. 公开步骤

- 公开事件符号新房间不抽事件，改为放置 Ghost。
- 公开 Ghost 不能攻击也不能被攻击。
- 公开英雄需要让足够 Ghost 和解，叛徒则可吞噬 Ghost 达到最大神志启蒙。

## 私密可见性

- 英雄可见：Ghost token 位置、已调解 / 未调解状态和事件房间生成风险。
- 叛徒可见：吃鬼提升神志、神志最大值胜利和鬼魂争夺节奏。
- Ghost 状态是公开目标状态，不能只表现成普通不可攻击怪物。

## 3. setup 队列

英雄侧：
1. 英雄无额外 setup。
2. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者，Monster Card 放在叛徒左侧。
2. 每个事件符号房间放置 1 个 Ghost。

## 4. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 角色板上和解 Ghost 数达到 4/5/6/8 |
| 叛徒 | 神志达到最大值，或所有英雄死亡 |

## 5. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 寻找和解 | 英雄 | 与 Ghost 同房间 | 神志检定；5+ 移除该 Ghost 并放到英雄角色板；达到 4/5/6/8 时英雄胜利；0-4 无事 | Ghost token 动作 + 和解计数 |
| 吞噬 Ghost | 叛徒 | 与 Ghost 同房间 | 知识检定；4+ 移除 Ghost 并提升 1 神志；0-3 将该房间所有 Ghost 移到任意相邻房间，可无视墙 | Ghost token 动作 + 相邻移动 |

## 6. 持续 / 触发规则

- 英雄攻击叛徒获胜时，可拿走叛徒 1 张物品或预兆替代造成伤害。
- 叛徒被攻击造成伤害时，改为按伤害点数移动相应格数并提升 1 力量或知识；叛徒不按该攻击受伤。
- 新发现事件符号房间不抽事件，放置 Ghost。
- 英雄死亡时，在其死亡房间放置 Ghost，叛徒控制该 Ghost。
- 叛徒回合后 Ghost 行动；Ghost 不能攻击或被攻击。
- Ghost 回合结束时，与任意数量 Ghost 同房间的英雄各受 2 一般伤害。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Ghost | 可变 | 房间/英雄角色板、是否已和解、控制者 |
| 和解计数 | 1 | 英雄角色板上 Ghost 总数，目标 4/5/6/8 |
| 叛徒神志 | 1 | 是否达到最大值 |

Ghost 属性：力量 3、速度 3、神志 3、知识 4；不能攻击或被攻击。

## 8. UI 承接

- 主目标条显示和解 Ghost 数和叛徒神志启蒙风险。
- 事件房间探索提示应写“放置 Ghost，不抽事件”。
- Ghost token 的“和解 / 吞噬 / 移动”归属要清楚，不能混成普通怪物攻击。

## 9. 验证

- 单测：初始事件房间放 Ghost；事件探索放 Ghost；和解人数目标；叛徒吞噬提升神志；攻击叛徒改为移动和提升属性；Ghost 回合末伤害。
- 页面测试：Ghost token、和解进度、叛徒启蒙条。
- E2E：覆盖英雄和解足够 Ghost 胜利，以及叛徒达到最大神志胜利。
