# 作祟 37 交互子账本：Out of Body

> 状态：`contract-ready`。这是换身和 DNA 作祟，核心是角色板/物品分离、安全机器人、上传样本和逃离次数轨。

## 1. 源段锁定

| 项 | 内容 |

| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p46 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p42-p43 |
| 剧本卡 / 触发预兆 | A Mysterious Invitation / Armor |
| 叛徒 | 作祟揭秘者 |
| 类型 | 一名叛徒 + 身体交换 + DNA token + 机器人 |

## 2. 公开步骤

- 公开 Body Swap 时交换角色板，不交换物品或预兆；玩家控制自己面前角色板对应的立牌，回合顺序不变。
- 公开 DNA token 留在英雄角色板上，不可交易，只能被叛徒上传移除。
- 公开英雄必须先禁用全部 Security Robot，再从 Entrance Hall 逃离。

## 私密可见性

- 英雄可见：每个身体 / 角色板对应关系、DNA token、逃离次数和机器人位置。
- 叛徒可见：上传样本目标、安全机器人行动和换身后的攻击 / 移动限制。
- 身体交换是公开状态，必须同时影响角色板显示、持有物和地图 token。

## 3. setup 队列

英雄侧：
1. 每名英雄获得自己的 Hero token 放在角色板上，代表 DNA。
2. 数字轨设为 2/3/4/5。
3. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者；掩埋 Armor，并把叛徒所有属性设回起始值。
2. Monster Card 放在叛徒左侧。
3. 叛徒立牌放到 Entrance Hall，并同房间放 0/1/1/2 个 Security Robot。
4. 每名英雄在自己房间放 1 个 Security Robot。

## 4. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 禁用全部 Security Robot 后，在 Entrance Hall 将数字轨降到 0 |
| 叛徒 | 上传每名英雄的 DNA，或所有英雄死亡 |

## 5. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 干扰电路 | 英雄 | 在技术房间，同区域有 Security Robot | 用知识攻击本区域任一 Robot，不能用武器，算本回合攻击；胜利移除 Robot，失败受精神伤害 | 房间动作 + Robot 目标 |
| 尝试逃离 | 英雄 | 全部 Robot 已禁用，且在 Entrance Hall | 速度检定；4+ 数字轨 -1，到 0 英雄胜利；0-3 无事 | Entrance Hall 动作 + 轨道 |
| 变形主体 | 叛徒 | 与仍有 DNA 的英雄同房间 | 与该英雄交换角色板，不交换物品/预兆；治疗新角色板全部属性并立即结束回合 | 英雄目标 + 角色板交换 |
| 上传样本 | 叛徒 | 在预兆符号房间，当前角色板上有 DNA | 移除该 DNA；若已取得所有英雄 DNA，叛徒胜利 | 房间动作 + DNA 进度 |

技术房间：Observatory、Game Room、Laboratory、Panic Room。

## 6. 持续 / 触发规则

- 若某英雄当前角色板仍有 DNA，该角色板属性不能低于临界。
- 当前角色板没有 DNA 的英雄可正常死亡。
- 叛徒死亡时，将属性设为起始值，并把立牌放到任意 Landing。
- 叛徒回合后 Security Robot 行动。
- Robot 若可能，必须各自朝不同英雄移动。
- Robot 受任意伤害即死亡；Robot 攻击英雄时自身不受反伤。

## 7. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| DNA Hero token | 每名英雄 1 | 所在角色板、是否已上传、不可交易 |
| Security Robot | 英雄数 + 0/1/1/2 | 房间、状态、移动目标 |
| 数字轨 | 1 | 逃离锁数量，从 2/3/4/5 到 0 |
| 角色板绑定 | 可变 | 玩家、角色板、立牌、物品/预兆分离 |

Security Robot 属性：力量 6、速度 5、神志 5、知识 4。

## 8. UI 承接

- Body Swap 必须在 UI 上显示“玩家控制权 / 角色板 / 立牌 / 持有物”四者变化。
- DNA token 位置应在角色板上，而不是玩家身上。
- 尝试逃离按钮在 Robot 未清完前禁用，并显示原因。
