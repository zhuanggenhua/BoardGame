# 作祟 18 交互子账本：A Nice Ring to It

> 状态：`contract-ready`。这是幻象隐藏作祟，核心是编号 1 真身、驱散、召回幻象和幻象共享持有物。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p26 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p18-p19 |
| 剧本卡 / 触发预兆 | Paranormal Investigators / Ring |
| 叛徒 | 作祟揭秘者 |
| 类型 | 叛徒移出地图 + 幻象 token + 真身揭露 |

## 2. 公开步骤

- 公开叛徒隐藏在 Illusion 中，编号 1 是真身。
- 公开叛徒每回合只能作为幻象或真身行动，不能两者都行动。
- 公开英雄可驱散幻象以揭露叛徒。

## 3. 私密可见性

- Illusion token 面朝下；叛徒可随时查看编号。
- 英雄只在驱散或攻击成功时翻开对应 token。
- 编号 1 被揭示时叛徒真身才回到地图。

## 4. setup 队列

1. 叛徒探索者从屋内移除，叛徒治疗全部属性。
2. Monster Card 放在叛徒左侧，幻象行动替代叛徒或真身行动。
3. 找出编号 1 到 3/4/5/6 的 Number token 作为 Illusion；编号 1 是真身。
4. Illusion 面朝下洗混，1 个放在叛徒原房间，其余放在距离不超过叛徒速度值的房间；尽可能每房间 1 个。
5. 英雄无额外 setup，叛徒左侧玩家先行动。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 杀死叛徒 |
| 叛徒 | 所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 对峙幻象 | 英雄 | 与 Illusion 同房间 | 知识检定；若有 Mirror +2；5+ 驱散该幻象；0-4 受 1 骰精神伤害 | 幻象 token 动作 |
| 呼唤戒指 | 英雄 | 在 Vault | 神志检定；每个自己持有的预兆 +1；8+ 若叛徒已揭露则对其造成 1 骰精神伤害，否则驱散任意 Illusion，并结束回合；0-7 结束回合 | Vault 动作 + 幻象选择 |
| 召唤幻象 | 叛徒 | 叛徒角色板上有 Illusion token | 洗混角色板上全部 Illusion，按 setup 距离规则重新放置；移除叛徒探索者并结束回合，下回合幻象可移动攻击 | 叛徒动作 + 幻象布置 |

## 7. 持续 / 触发规则

- 英雄攻击 Illusion 并获胜时，驱散该 Illusion；若攻击揭露叛徒，该攻击不造成伤害。
- Illusion 被驱散后翻开并回到叛徒角色板。
- 若驱散的是编号 1，叛徒在该 token 所在房间放回探索者，屋内其他 Illusion 回到角色板，并移除最高编号 Illusion token 出游戏。
- Illusion 共享叛徒当前属性，移动格数等于叛徒速度，不掷移动骰。
- Illusion 可使用叛徒物品和预兆；Dagger、Creepy Doll 等负面仍影响叛徒。
- Illusion 不能交易、不能搜刮尸体、不能探索新房间、不能被击晕。

## 9. UI 承接

- 地图上的 Illusion 显示为未知编号；叛徒视角可看编号。
- 叛徒面板必须清楚当前行动体是“幻象”还是“真身”。
- 召唤幻象需要布置合法房间，不允许自动随机后不给确认。

## 10. 验证

- 单测：Illusion 数量按人数；编号 1 揭露流程；攻击揭露不造成伤害；幻象不能交易/搜刮/探索；召唤幻象移除真身并结束回合。
- 页面测试：英雄未知编号、叛徒私密编号、Vault 呼唤戒指。
- E2E：覆盖先驱散假幻象，再揭露编号 1 并击杀叛徒。
