# 作祟 43 交互子账本：Hide and Eat

> 状态：`contract-ready`。这是狼人作祟，核心是隐藏 token、黎明倒计时、未受伤加速、狼人不能攻击隐藏英雄和叛徒揭露隐藏。

## 1. 源段锁定

| 项 | 内容 |

| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p52 |
| 剧本卡 / 触发预兆 | A Strange Disappearance / Dog |
| 叛徒 | 持有预兆最多的探索者 |
| 类型 | 一名叛徒 + 狼人怪物 + 隐藏状态 + 黎明倒计时 |

## 2. 公开步骤

- 公开英雄可通过 Hide 获得 Hidden token；隐藏英雄不能被攻击。
- 公开隐藏会在移动时失效，并在怪物回合末统一清除。
- 公开怪物回合末数字轨下降，若本轮没有英雄受伤则额外下降；到 0 英雄胜利。

## 3. 私密可见性

- 英雄可见：隐藏点房间、当前隐藏英雄、黎明数字轨和狼人位置。
- 叛徒可见：揭露隐藏、诅咒视线内非隐藏英雄、驱使狼人攻击。
- Hidden token 是公开状态，不是秘密伏击；但被隐藏英雄的安全性必须在目标选择中生效。

## 4. setup 队列

英雄侧：
1. 数字轨设为 6/7/8/9。
2. 掩埋 Dog 预兆。
3. 在作祟揭秘者房间放 Werewolf token。
4. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 叛徒保留探索者并成为叛徒。
2. Monster Card 放在叛徒左侧；狼人会在叛徒回合后行动。

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 隐藏 | 英雄 | 狼人不在视线内；每回合 1 次 | 速度检定；若在隐藏点房间 +1；5+ 获得 Hidden token；0-4 无事 | 房间 / 角色动作 |
| 安抚野兽 | 英雄 | 与狼人同房间；每回合 1 次 | 神志检定；同房间每个未隐藏英雄 +1；8+ 击晕狼人；5-7 无事；0-4 自己受 1 物理伤害 | 狼人目标动作 |

| 与狼沟通 | 叛徒 | 与未击晕狼人同房间；每回合 1 次 | 移动狼人 1 个房间，然后用狼人发起力量攻击 | 狼人控制动作 |

隐藏点房间：Armory、Soundproofed Room、Catacombs、Winter Bedroom、Graveyard、Statuary Corridor。

## 7. 持续 / 触发规则

- 隐藏英雄不能被攻击，也不算障碍物。
- 狼人不能攻击隐藏英雄。
- 英雄移动时弃掉 Hidden token，立即不再隐藏。
- 怪物回合末：数字轨 -1；若本回合没有任何英雄受到伤害，则额外 -1。若数字轨到 0，英雄胜利。
- 若怪物回合末数字轨未到 0，所有英雄设置 aside 自己的 Hidden token，隐藏状态清除。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 黎明倒计时 |
| Werewolf | 1 | 房间、击晕状态、攻击限制 |
| Hidden token | 英雄数量 | 持有人、是否因移动 / 回合末清除 |
| 伤害标记读模型 | 1 | 本回合是否有英雄受伤，用于黎明额外推进 |

狼人属性：力量 7、速度 4、神志 2、知识 3。

## 9. UI 承接

- 主目标条显示数字轨、预计怪物回合末下降 1 还是 2，并说明原因。
- 隐藏英雄必须在目标选择和障碍物判定中退场，不能只显示一个图标。
- 狼人视线会阻止 Hide，UI 必须在按钮禁用原因里直接说明。
