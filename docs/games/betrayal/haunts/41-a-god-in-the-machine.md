# 作祟 41 交互子账本：A God in the Machine

> 状态：`contract-ready`。这是电气附身作祟，核心是发电机 ON/OFF、陷阱、电子设备破坏、房屋怪物远程攻击和走廊扭曲。

## 2. 公开步骤

- 公开房屋已经被电气实体控制，ON 发电机会让房屋攻击附近英雄。
- 公开英雄通过破坏电子设备和拆除陷阱提高数字轨，再用数字轨掷骰关闭发电机。
- 公开陷阱触发时造成 2 骰一般伤害且不会自动移除。

## 3. 私密可见性

- 英雄可见：发电机 ON/OFF、陷阱位置、电子设备房间、已破坏房间和数字轨。
- 叛徒可见：房屋怪物行动、放置陷阱、扭曲走廊、重新启动发电机。
- 所有陷阱与发电机位置均为公开地图状态；不能把陷阱当隐藏信息处理。

## 4. setup 队列

英雄侧：
1. 数字轨设为 0。
2. 将 5 个 Searched token 放在数字轨旁，代表已破坏电子设备。
3. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 叛徒保留探索者并成为叛徒。
2. Monster Card 放在叛徒左侧；房屋怪物在叛徒回合后行动。
3. 在叛徒所在房间放 1 个 Trap token，剩余 Trap token 放旁边。
4. 取 3/3/4/5 个 ON/OFF token 作为发电机；先在叛徒房间放 1 个，再在叛徒选择的物品 / 预兆符号房间各放 1 个，剩余放登陆板。

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 拆除陷阱 | 英雄 | 在陷阱同房间或相邻房间；每回合 1 次 | 速度检定；同房间 +2；6+ 移除陷阱交给叛徒，数字轨 +1；0-5 无事 | 陷阱对象动作 + 风险提示 |
| 破坏电子设备 | 英雄 | 在电子设备房间；该房间未被破坏；每回合 1 次 | 知识或力量检定；5+ 数字轨 +1 并放 Searched token；0-4 无事 | 房间动作 + 数字轨进度 |
| 过载发电机 | 英雄 | 在任意发电机房间；每回合 1 次 | 按数字轨数值掷骰；5+ 该发电机转 OFF，若全部 OFF 则英雄胜利；0-4 当前英雄回合结束 | 发电机对象动作 + 过载骰盘 |
| 重启发电机 | 叛徒 | 在 OFF 发电机房间；每回合 1 次 | 知识检定；4+ 翻回 ON；0-3 无事 | 发电机对象动作 |
| 电子附身 | 房屋怪物 | 房屋怪物回合；目标房间没有英雄和陷阱，且不在发电机同房间或相邻 | 放置 1 个 Trap token | 地图目标选择 |
| 扭曲走廊 | 房屋怪物 | 房屋怪物回合；每回合 1 次 | 掷 2 骰；移动任一探索者最多该点数房间；若触发陷阱立即停止 | 探索者目标 + 路径预览 |

电子设备房间：Panic Room、Vault、Kitchen、Laboratory、Game Room。

## 7. 持续 / 触发规则

- 英雄进入带 Trap token 的房间时，受到 2 骰一般伤害；陷阱保留在房间。
- 房屋怪物不能被攻击、不能被击晕、不能移动。
- 房屋怪物可用力量攻击位于 ON 发电机同房间或相邻房间的英雄；OFF 发电机不提供攻击范围。
- 已放 Searched token 的电子设备房间不能再次破坏。
- 数字轨是英雄准备度，不是回合倒计时；拆陷阱和破坏电子设备都能推进。

## 9. UI 承接

- 主目标条显示 `发电机 OFF 数 / 总数`、数字轨当前值、下一次过载掷骰数。
- 地图必须区分 ON 发电机攻击范围、OFF 发电机、陷阱威胁和已破坏电子设备。
- 扭曲走廊必须显示路径和是否会触发陷阱，不能只在日志里移动探索者。
