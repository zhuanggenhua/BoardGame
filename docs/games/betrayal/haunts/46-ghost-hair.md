# 作祟 46 交互子账本：Ghost Hair

> 状态：`contract-ready`。这是头发怪作祟，核心是真解药编号、面朝下解药研究、英雄死亡变小怪物、巨型头发怪穿越预兆房和携带真解药击败巨怪。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p55 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p55 |
| 剧本卡 / 触发预兆 | Cursed! / Skull |
| 叛徒 | 作祟揭秘者 |
| 类型 | 叛徒变巨型怪物 + 小头发怪 + 隐藏编号解药 |

## 2. 公开步骤

- 公开数字 token “1”是真解药，其余为假解药。
- 公开英雄可在 Library 研究翻开解药，也可在解药所在房间发现并检查。
- 公开英雄携带真解药成功攻击巨型头发怪即可获胜。

## 3. 私密可见性

- 英雄可见：解药 token 的位置、正反面状态、是否已经确认真解药。
- 叛徒可见：解药洗混后的放置结果、大小头发怪行动顺序和换位能力。
- 真解药编号是规则公开知识，但具体 token 身份在翻开前属于隐藏状态。

## 4. setup 队列

英雄侧：
1. 英雄无额外 setup。
2. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 叛徒被头发吞噬：用 Giant Hair Monster token 替换叛徒棋子，并掩埋叛徒全部物品和预兆。
2. Monster Card 放在叛徒左侧；怪物回合替代叛徒回合。
3. 找出编号 1 到 4/6/8/10 的 Number token，作为 Antidotes；洗混后由叛徒面朝下放置在房屋中。
4. 在 Entrance Hall 放 1 个 Small Hair Monster。
5. 额外留出 1/2/3/4 个 Small Hair Monster token。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 持有真解药时成功攻击巨型头发怪 |
| 叛徒 | 所有英雄都变成头发怪 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 研究诅咒 | 英雄 | 在 Library；每回合 1 次 | 知识检定；5+ 翻开 1 个面朝下 Antidote token；0-4 无事 | Library 动作 + token 选择 |
| 发现解药 | 英雄 | 在有 Antidote token 的房间；每回合 1 次 | 翻开该 token；若为编号 1，可选择拾取 | token 本体动作 |
| 解药攻击 | 持有真解药的英雄 | 攻击 Giant Hair Monster | 攻击结果 +3；若攻击成功，英雄胜利 | 攻击面板 + 解药加值 |
| 头发换位 | Giant Hair Monster | 在预兆符号房间；每个巨怪回合 1 次 | 与 1 个 Small Hair Monster 交换位置 | 怪物目标选择 |

## 7. 持续 / 触发规则

- 真解药可按正常交易规则在英雄之间交易。
- 英雄死亡时，用 Small Hair Monster 替换其探索者。
- 叛徒没有普通探索者回合；先让 Small Hair Monsters 行动，再让 Giant Hair Monster 行动。
- Giant Hair Monster 可以把所有预兆符号房间视为相邻来移动。
- Giant Hair Monster 只能受到力量攻击造成的伤害；其他攻击成功不能伤害它。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Antidote token | 4/6/8/10 | 房间、正反面、编号、是否被拾取 |
| 真解药 | 1 | 编号 1，当前房间 / 持有人 |
| Small Hair Monster | 起始 1，额外 1/2/3/4 | 房间、是否由英雄死亡生成 |
| Giant Hair Monster | 1 | 房间、预兆房相邻移动、换位能力 |

Small Hair Monster 属性：力量 5、速度 7、神志 2、知识 3。Giant Hair Monster 属性：力量 7、速度 1、神志 6、知识 4。

## 9. UI 承接

- 解药 token 必须显示“未知 / 已翻开编号 / 真解药已拿走”状态。
- 攻击巨型头发怪时，若攻击者没有真解药，应提前提示无法获胜或无法造成有效伤害的限制。
- 预兆房间相邻移动和换位必须在地图上高亮目标，不让玩家猜哪些房间相连。

## 10. 验证

- 单测：解药数量和编号；Library 翻开；发现真解药可拾取；真解药交易；攻击 +3 和胜利；英雄死亡变小怪；巨怪仅受力量伤害；预兆房相邻移动；头发换位。
- 页面测试：解药隐藏 / 翻开、真解药持有人、巨怪攻击限制、怪物行动顺序。
- E2E：覆盖英雄找到真解药并击败巨型头发怪胜利。
