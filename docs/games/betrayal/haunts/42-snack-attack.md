# 作祟 42 交互子账本：Snack Attack

> 状态：`contract-ready`。这是恶魔狗作祟，核心是四个闹鬼房间驱灵、食物 token、防御时喂狗降骰和狗力量随食物增强。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p51 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p51 |
| 剧本卡 / 触发预兆 | Paranormal Investigators / Dog |
| 叛徒 | 作祟揭秘者 |
| 类型 | 一名叛徒 + 不可击晕恶魔狗 + 闹鬼房间进度 + 食物资源 |

## 2. 公开步骤

- 公开四个闹鬼房间及其对应检定属性。
- 公开英雄需要驱灵达到人数阈值后，用神志成功攻击恶魔狗才能获胜。
- 公开 Food token 可在被恶魔狗攻击时交出，使狗本次掷骰结果 -4。

## 3. 私密可见性

- 英雄可见：已驱灵房间、食物剩余、英雄持有 Food token、获胜阈值。
- 叛徒可见：狗当前 Food token 数量、恶魔狗力量加值、叛徒在帮派常去地点回血动作。
- 食物在 Monster Card 上的数量是公开威胁，不能只藏在叛徒剧本书。

## 4. setup 队列

英雄侧：
1. 若 Larder 未发现，从房间堆找出并放在地下室。
2. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 叛徒保留探索者并成为叛徒。
2. 叛徒治疗全部属性。
3. Monster Card 放在叛徒左侧；恶魔狗在叛徒回合后行动。
4. 掩埋 Dog 预兆，在叛徒房间放 Demon Dog token。
5. 将 0/1/1/2 个 Food token 放在 Monster Card 上，剩余放旁边。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 驱灵达到 2/3/4/4 个后，用神志成功攻击恶魔狗 |
| 叛徒 | 所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 驱灵 | 英雄 | 在闹鬼房间，且该房间没有 Searched token；每回合 1 次 | 对应属性检定；4+ 在该房间放 Searched token；0-3 无事 | 房间动作 + 驱灵进度 |
| 神志攻击恶魔狗 | 英雄 | 攻击恶魔狗 | 可选择神志攻击；若攻击成功且驱灵数达到阈值，英雄胜利 | 攻击面板显示阈值是否满足 |
| 喂狗防御 | 被攻击英雄 | 被恶魔狗攻击且自己有 Food token | 可交出 1 个 Food token，使狗本次掷骰结果 -4 | 受击反应窗口 |
| 从 Larder 偷食物 | 英雄 | 在 Larder；每回合 1 次 | 速度检定；4+ 若食物池仍有 Food token，拿 1 个；0-3 无效 | Larder 房间动作 |
| 参观帮派常去地点 | 叛徒 | 在 Larder / Library / Gymnasium / Chapel；每回合 1 次 | 治疗叛徒全部属性 | 房间动作 |
| 进食 | 恶魔狗 | 在 Larder；每个恶魔狗回合 1 次 | 若有剩余 Food token，拿 1 个放到 Monster Card | 怪物动作 + 力量刷新 |

闹鬼房间：Library 知识、Larder 力量、Gymnasium 速度、Chapel 神志。

## 7. 持续 / 触发规则

- 恶魔狗不能被击晕。
- 恶魔狗力量 = 基础力量 4 + Monster Card 上 Food token 数。
- 英雄喂狗减少的是恶魔狗本次掷骰结果，不改变 Monster Card 上的食物数量，除非实现裁定 token 交到指定池并可回查。
- 已驱灵房间用 Searched token 标记，不能重复驱灵。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Searched token | 最多 4 | 闹鬼房间是否已驱灵 |
| Food token | 5 | 旁边储备 / 英雄持有 / Monster Card |
| Demon Dog | 1 | 房间、当前力量加值、不可击晕 |

恶魔狗属性：力量 4+食物数、速度 4、神志 5、知识 4。

## 9. UI 承接

- 主目标条显示 `已驱灵 N / 阈值 2/3/4/4`，并提示是否已可通过攻击取胜。
- 恶魔狗卡显示 Food token 数和当前力量，不让玩家自己心算。
- 被恶魔狗攻击时，持有 Food token 的英雄必须出现喂狗反应入口和 -4 预览。

## 10. 验证

- 单测：Larder 搜索放置；闹鬼房间属性映射；驱灵不可重复；阈值按人数；Food token 防御 -4；狗力量随 Monster Card 食物增加；恶魔狗不可击晕。
- 页面测试：驱灵进度、食物持有与狗力量、喂狗反应窗口。
- E2E：覆盖英雄完成足够驱灵后用神志击败恶魔狗胜利。
