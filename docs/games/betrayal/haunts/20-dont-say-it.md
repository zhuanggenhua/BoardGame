# 作祟 20 交互子账本：Don't Say It

> 状态：`contract-ready`。这是房间顺序猜名作祟，核心是叛徒秘密房间列表、提示规则和无脸人可杀条件。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p28 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p21 |
| 剧本卡 / 触发预兆 | Cursed! / Dog |
| 叛徒 | 年龄最大角色 |
| 类型 | 叛徒 + 秘密顺序 + 线索反馈 + 条件击杀 |

## 2. 公开步骤

- 公开叛徒是年龄最大角色。
- 公开英雄要按顺序找到无脸人名字的音节房间。
- 公开全部音节找到后，击败无脸人才能摧毁它并胜利。

## 3. 私密可见性

- 叛徒秘密选择并编号 2/3/4/5 个房间，代表音节顺序，可跨区域。
- 英雄每次询问只得到当前最低未划掉编号房间是否正确的反馈。
- 错误时，叛徒只按规则给区域和距离提示，不公开房间名。

## 4. setup 队列

英雄侧：
1. 若屋内非登陆板房间少于 5 个，从房间堆抽放直到有 5 个。
2. 按人数准备 2/3/4/5 个 Rune token 作为音节。
3. 叛徒左侧玩家先行动。

叛徒侧：
1. 叛徒保留探索者，治疗全部属性。
2. Monster Card 放在叛徒左侧。
3. 秘密选择并编号 2/3/4/5 个房间。
4. 将 Faceless Man token 放在叛徒房间。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 找到全部音节后，攻击并击败 Faceless Man |
| 叛徒 | 所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 找音节 | 英雄 | 自己所在房间 | 询问叛徒下一个音节是否在此房间；正确则放 Rune token，最后一个放下后已知真名；错误则叛徒给提示并让无脸人伏击 | 房间动作 + 叛徒反馈面板 |

## 7. 持续 / 触发规则

- 正确：叛徒确认并划掉该房间，英雄在该房间放 Rune token。
- 错误：叛徒先说明英雄是否在正确区域；若在正确区域，再说明到正确房间需要多少移动点，不计算 Mystic Elevator 等特殊移动或 Skeleton Key 等物品效果；随后将无脸人放到该英雄房间并进行力量攻击。
- 叛徒回合后，无脸人行动。
- 无脸人不能被击晕。
- 只有在全部音节已找到后，英雄攻击并击败无脸人才能摧毁它。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| Rune token 音节 | 2/3/4/5 | 已找到顺序、房间、是否已全部找到 |
| 秘密房间列表 | 2/3/4/5 | 叛徒私密编号、已划掉状态 |
| Faceless Man | 1 | 房间、不可击晕、是否可被摧毁 |

Faceless Man 属性：力量 5、速度 2、神志 5、知识 5。

## 9. UI 承接

- 英雄界面显示已找到音节进度，不显示未找到房间名。
- 叛徒界面提供“正确 / 错误提示”结构化输入，不能让自由文本替代规则提示。
- 距离提示必须使用普通移动路径，不叠加特殊房间和物品。

## 10. 验证

- 单测：非登陆板房间不足时补房；秘密列表人数规则；正确音节推进；错误提示区域和距离；错误后无脸人攻击；真名未全知时无脸人不可摧毁。
- 页面测试：英雄找音节、叛徒提示面板、Rune token 进度。
- E2E：覆盖错误提示、找到全部音节、击败无脸人胜利。
