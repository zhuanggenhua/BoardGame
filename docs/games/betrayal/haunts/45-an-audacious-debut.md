# 作祟 45 交互子账本：An Audacious Debut

> 状态：`contract-ready`。这是真人秀剧本作祟，核心是 Book 剧本持有、偷剧本、改写剧本、叛徒假死复活和武器不能降到临界。

## 1. 源段锁定

| 项 | 内容 |
| --- | --- |
| 英雄书 | `betrayal-3e-secrets-of-survival-en.md` p54 |
| 叛徒书 | `betrayal-3e-traitors-tome-en.md` p54 |
| 剧本卡 / 触发预兆 | A Mysterious Invitation / Book |
| 叛徒 | 作祟揭秘者 |
| 类型 | 一名叛徒 + 数字轨复活次数 + Book 控制 + 武器限制 |

## 2. 公开步骤

- 公开英雄需要杀死叛徒，并把数字轨降到 0，确保叛徒不再“演死”。
- 公开 Book 可被英雄偷走，并在可写房间改写剧本降低数字轨。
- 公开叛徒死亡时，如果数字轨未到 0，会移动到指定房间、数字轨 -1 并继续游戏。

## 3. 私密可见性

- 英雄可见：数字轨、Book 当前持有人、可写房间、叛徒死亡后是否真正失败。
- 叛徒可见：武器抽取、Armory 复活点、事件房间加骰和武器不能致临界。
- Book 当前持有人是公开规则状态；不能只靠卡牌物理归属隐藏。

## 4. setup 队列

英雄侧：
1. 英雄无额外 setup。
2. 作祟后首回合由叛徒左侧玩家开始。

叛徒侧：
1. 叛徒保留探索者并成为叛徒。
2. 叛徒治疗全部属性。
3. 若 Armory 未发现，从房间堆找出并放在一楼。
4. 从物品牌堆抽牌直到抽到 2 张武器；叛徒拿走这 2 张武器，其余已抽牌放回物品牌堆底；若牌堆中没有武器则跳过。
5. 数字轨设为 2/3/4/5。

## 5. 目标模型

| 阵营 | 胜利条件 |
| --- | --- |
| 英雄 | 数字轨为 0 时杀死叛徒 |
| 叛徒 | 所有英雄死亡 |

## 6. 特殊行动

| 行动 | 使用者 | 条件 | 检定 / 结果 | UI 承接 |
| --- | --- | --- | --- | --- |
| 偷剧本 | 英雄 | 与叛徒同房间，且叛徒持有 Book；每回合 1 次 | 速度检定；4+ 拿走 Book；0-3 无事 | 叛徒对象动作 + Book 状态 |
| 改写剧本 | 持有 Book 的英雄 | 在可写房间；每回合 1 次 | 知识检定；6+ 数字轨 -1；0-5 无事 | 房间动作 + 数字轨预览 |
| 假死复活 | 叛徒 | 叛徒死亡且数字轨未到 0 | 叛徒移动到指定房间，数字轨 -1，继续游戏 | 死亡结算替代流程 |

可写房间：Library、Ballroom、Gallery、Guest Quarters。

## 7. 持续 / 触发规则

- 叛徒死亡时若数字轨为 0，英雄立即胜利。
- 叛徒死亡时若数字轨不为 0，叛徒放到 Armory，治疗全部属性，并获得下一回合；随后从叛徒左侧玩家继续顺时针。
- 叛徒在事件符号房间且该房间有英雄时，所有掷骰额外 +1 骰。
- 武器造成伤害时，不能把任何人的属性降到临界以下；该限制同时保护叛徒和英雄。
- 触发预兆 Book 默认进入普通持有物模型，Book 持有人决定能否改写剧本。

## 8. token / 怪物合同

| 对象 | 数量 | 状态真相 |
| --- | ---: | --- |
| 数字轨 | 1 | 叛徒剩余假死 / 剧本进度 |
| Book | 1 | 当前持有人、是否可用于改写 |
| 武器 | 最多 2 张起始给叛徒 | 是否受 Prop Weapons 限制 |
| Armory | 1 | 复活点，必要时搜索放置 |

## 9. UI 承接

- 主目标条显示数字轨和“下次杀死叛徒会胜利 / 会触发假死”。
- 攻击结算必须在使用武器时预览“不能降到临界以下”的封顶效果。
- 叛徒假死不是普通死亡动画；必须有短阶段提示并立即更新回合顺序。

## 10. 验证

- 单测：Armory 搜索；叛徒抽 2 武器；偷 Book；改写降轨；数字轨不为 0 时死亡复活并降轨；数字轨为 0 时英雄胜利；事件房间加骰；武器不能致临界。
- 页面测试：Book 持有人、改写剧本、叛徒假死提示、武器伤害封顶。
- E2E：覆盖英雄偷 Book、改写到 0、再杀死叛徒胜利。
