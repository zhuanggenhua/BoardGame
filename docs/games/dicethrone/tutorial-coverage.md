# Dice Throne 双人教程覆盖账

本文件记录本游戏实际选进教程的内容、取舍及证据；通用设计流程唯一来源是 [tutorial-design](../../../.spec/knowledge/standards/tutorial-design.md)，项目入口是 [tutorial-workflow](../../../.spec/skills/tutorial-workflow/SKILL.md)。

## 范围

主线从正式双人开局出发，用僧侣示范一条能走完的攻防循环。目标是让玩家看懂当前牌面、知道当下为什么能出牌、亲自完成骰子与响应，再看到对局回到可操作阶段；教程不是规则书摘要。

只把本流程需要的双人规则放入主线。其它规则仍留在规则源和帮助页，不因规则书有记载就搬进提示。手牌上限无法在这条自然牌序中触发，保留单独的选学练习；它不伪装成主线的连续后果。

主线版本为 revision 19；旧教程进度失效，不迁移旧步骤。独立手牌上限练习为 revision 5。

## 主线的学习目标与动作理由

| 节点 | 玩家学到并亲自做的事 | 当前理由与结果 |
| --- | --- | --- |
| 开局 → 加倍 | 胜负看体力；先手首回合跳过收入。手机首次读牌时长按放大；左上 1 是费用，红色 ! 表示双方任意阶段可用，正文给出抽 2 张的效果。 | 起始 2 CP；打出加倍后剩 1 CP，并抽到冲拳 II。 |
| 发现费用不足 → 一掷千金 → 升级 | 冲拳 II 需要 2 CP，先看到差 1；蓝色 M 表示一掷千金只限自己的主要阶段，免费掷 1 骰并按点数一半向上取整获得 CP。升级牌同样限自己的主要阶段，覆盖原技能并永久提高伤害。 | 固定掷出 1，CP 从 1 → 2；支付 2 升级冲拳 II，CP 归 0。 |
| 进攻掷骰 → 选能力 | 先教 5 骰和最多 2 次重掷；首次掷出四拳后，再提示保留四拳、重掷剩下的骰。亮起的技能表示满足当前骰面条件。 | 留 4 拳、重掷 1 骰，选择四拳对应的冲拳，造成 8 点普通伤害；普通攻击可以防御。 |
| 对手防御 → 主要阶段 2 出售 | 防御先于剩余伤害扣体力；主要阶段可以出售手牌，每张换 1 CP。 | 0 CP 时出售掌击，获得 1 CP，正好支付之后的抬一手。 |
| 响应设置 → 对手掷骰 | 手动响应会在伤害结算前停下，交由玩家出牌或略过。抬一手的橙色边框 / 骰子图标表示掷骰阶段且要求非投掷者；青色外框只是正式 UI 提示这张牌此刻可响应。 | 开启手动响应后，对手确认骰面，玩家花 1 CP 重掷对手 1 骰并确认目标；新骰面重新决定对手合法能力。 |
| 自己防御 → 太极响应 | 防御骰和能力效果先结算；攻击者先响应，之后防御者可减伤。每枚太极减少 1 点伤害。 | 冥想产生 4 太极；攻击者略过增伤，玩家花 1 枚减伤，再略过剩余响应，结算伤害。 |
| 收入 → 退出教程 | 收入阶段得到 1 CP 并抽 1 张；先手首回合例外已在开局说明。 | 对手回合结束后，收入改变资源与手牌；教程退出后继续同一牌桌。 |

CP 链闭合：开局 2 → 加倍 -1 → 一掷千金 +1 → 冲拳 II -2 → 出售掌击 +1 → 抬一手 -1 → 下次收入 +1。所有支付对象和后续使用对象都由同一合法牌序产生。

## 明确排除

| 暂不进主线 | 原因 / 处理 |
| --- | --- |
| 平局与同时归零、治疗与 CP 上限、资源偷取 | 本次不产生这些决策；保留在规则帮助，不在对局开场讲完整术语。 |
| 维持效果排序与阶段末伤害 / 治疗结算 | 代表对局没有维持效果；不凭空注入效果来讲规则。 |
| 全部骰面组合、大小顺分支、被动、终极、攻击修正与伤害类型大全 | 首次学习只需当前合法的冲拳 IV、普通攻击和防御；其余留作规则帮助 / 后续教程。 |
| 其它英雄状态、伙伴、多人数与团战 | 超出本轮确认的双人通用范围。太极仅作为本次真实防御例子，不代表全英雄 Token 规则。 |
| 回合末手牌上限与空牌库重洗 | 主线不会自然超过 6 张。选学练习只从 7 张手牌开始，亲自出售到 6 张；不重复解释出售得 CP，也不追加回合交接和重洗。 |
| 普通关闭按钮与一般阶段按钮逐项讲解 | 显然控件直接操作即可；只教隐藏长按和本流程中需判断时机 / 目标的操作。 |
