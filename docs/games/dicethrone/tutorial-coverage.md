# Dice Throne 交互式教程内容总账

本文件记录单游戏来源、局面、覆盖与证据；通用流程的唯一正文是 [tutorial-design](../../../.spec/knowledge/standards/tutorial-design.md)，项目适配入口是 [tutorial-workflow](../../../.spec/skills/tutorial-workflow/SKILL.md)。

## 用户目标与范围

用户原话：“我的核心是交互式教程，是代替视频、文本规则，所以要全面，并且响应这类新增的功能也需要解释到”；“规则有的都要出现……弃牌、放大都要通过流程自然教学……每个操作是有理由的”。本轮先覆盖双人通用规则与操作，采用僧侣作为实际操作对象；其它英雄完整专属机制、伙伴、多人及团战不纳入。

本轮同时重构全项目多游戏的教程生产流程，Dice Throne 是回代案例，不是通用规范的范围。主线从双人正式开局进入，50 体力、2 CP、4 张手牌，学习者固定座位 0。仅固定合法牌序与随机；不在中途补牌、补资源或注入标记。

## 实际参考及取舍

| 实际读取对象与位置 | 读到的教学行为 | 本次采用 / 舍弃 |
| --- | --- | --- |
| [Dominion 官方第二版规则书](https://www.riograndegames.com/wp-content/uploads/2016/09/Dominion2nd.pdf)，第 4、6 页 | 卡名、正文、类型、分隔线、费用有图面标注；类型又与可用阶段关联。它是纸面规则图解。 | 先解释字段的含义，再用实际费用与时机做决定；不把整页图例复念成提示。 |
| D. R. Johnson，[Every Board Game Rulebook Is Awful](https://boardgametextbook.com/EBGRIA.pdf)，第 75 页，图 75.1–75.2（作者观察 Dominion App） | 从手牌和市场引出购买，并在使用宝物后补充“不会失去宝物”的易错规则。 | 规则贴着首次决策，操作后承接真实结果；不以章节目录证明已研究具体教学。 |
| 同书第 76 页，图 76.1（作者观察 Wingspan App） | 放鸟前先说明蛋费，先取蛋，再回来支付；后续取资源只增加重掷、替代支付等新差异。 | 用资源准备连接后续出牌；同一含义只教一次。舍弃作者指出的开场信息过多和无新增意义的重复。 |
| 同书第 77 页（作者观察 Spirit Island App） | 先教放大，之后玩家可以随时读牌理解当前行动；数轮实际行动后继续普通游戏。 | 把隐藏长按放在第一次读卡处，不教点叉；教学结束后保留可继续的真实对局。 |

以上应用观察来自作者文字与图注，不冒称本轮亲自运行这些商业应用。已下载并实际提取原书第 75–77 页；外部材料只证明教学设计观察，不作为 Dice Throne 规则依据。营销介绍与视频章节索引只作定位，本轮不据此声称看过完整演示。

## 规则与正式交互来源

- [王权骰铸规则](../../../src/games/dicethrone/rule/王权骰铸规则.md)：§1–8、§10–11 的双人通用条款；§3.5、§9 多人条款不纳入。
- [僧侣卡牌](../../../src/games/dicethrone/heroes/monk/cards.ts)：顿悟为蓝框、0 CP；莲花获得 2 太极、1 闪避、1 净化，否则抽牌；清修 II 升级费 2 CP。
- [通用卡牌](../../../src/games/dicethrone/domain/commonCards.ts)：加倍为红框即时牌、1 CP 抽 2；抬一手为橙框、1 CP，在对手确认掷骰后重掷其 1 骰。
- [时机与电子交互](card-timing-terms.md)、正式手牌、骰盘、响应条及 Token：长按、拖动出售、奖励骰确认、目标选择、响应偏好与弃牌堆撤回。

## 实现前的因果链与资源复演

主线固定四张起手：顿悟、加倍、抬一手、掌击。牌库顶为清修 II、静心，供加倍抽取；后续收入按剩余合法牌库抽牌。

| 节点 | 玩家理由与正式输入 | CP 前 → 后 | 新对象 / 状态来源 |
| --- | --- | --- | --- |
| 开局读卡 | 长按顿悟，识别费用、时机、正文 | 2 → 2 | 4 张正式起手，检视不出牌 |
| 主要阶段打顿悟 | 蓝框限定自己主要阶段，准备防守标记 | 2 → 2 | 真实奖励骰固定莲花，确认后获得太极 / 闪避 / 净化 |
| 第一次进攻 | 锁骰、重掷，比较小顺 / 大顺，亲自选能力 | 2 → 2 | 同一局的真实攻击与对方防御 |
| 主要阶段 2 打加倍 | 红框即时牌补牌，备好升级与后续手牌 | 2 → 1 | 从正式牌库抽清修 II、静心 |
| 出售 / 撤回 | 拖到弃牌堆，抽到 2 CP 升级牌后，补足升级与响应的费用；非推荐出售留在同一决策，可点弃牌堆正式撤回 | 1 → 2 | 掌击进入弃牌堆；之后收入还会给 1 CP |
| 对手回合打抬一手 | 花预留费用重掷对方骰，缩小其合法能力集合 | 2 → 1 | 橙框掷骰时机、真实目标选择与确认 |
| 自己防御与响应 | 防御骰、太极减伤、闪避奖励骰或合法放弃 | 1 → 1 | 标记来自顿悟，不能凭空使用；清修也可获得太极 |
| 收入 | 正式回合交接后 +1 CP、抽 1 张牌 | 1 → 2 | 已有清修 II 保留在手中 |
| 净化击倒 | 用已有净化，保留 CP 用于升级 | 2 → 2 | 对手此前正式打掌击施加击倒 |
| 升级 | 花预算永久升级清修 | 2 → 0 | 清修 II 留在技能槽，回到真实可操作阶段 |

## 覆盖矩阵

下表教学深度与浏览器结论分开；本轮改写后旧图不证明新链路。当前新链行为与图面结果在验证完成后回填。

| 来源 / 内容 | 首次教学与实际入口 | 深度与边界 |
| --- | --- | --- |
| §1 胜负、同时归零 | intro；实际攻击后读取体力 | 规则说明 + 实际伤害；不模拟终局 |
| §2 起手、CP、治疗与上限 | stats、phases；出售 / 支付 / 收入 | 规则说明 + 资源实操；CP 上限在独立练习实际触发 |
| §2 空牌库重洗 | 手牌上限练习回合交接后的收入 | 实际重洗并抽牌 |
| §3 全部双人阶段 | phases → advance → 攻防 → end-turn → opponent-end-turn → income-result | 主要阶段、攻防、响应与收入实操；无维持效果时只解释排序 / 末尾同时结算，不声称玩家排序过 |
| §3.3 主要行动 | main-actions-rule；卖掌击、打顿悟、后续升级 | 次数不限与顺序自选，出售每张 1 CP；实际操作 |
| §4 骰面、次数、锁骰、能力 | dice-roll → dice-lock → dice-reroll → ability-rule → abilities | 实操小顺与大顺两条合法路径；不发动能力经正式阶段推进，再恢复同一骰面继续首次攻防 |
| §4 被动、防御与终极 | ability-rule、attack-rule、defense-rule | 规则说明；常规进攻、防御实操，特殊伤害不冒称实操 |
| §5 卡面字段与蓝框 | hand-inspect、main-actions-rule、enlightenment-play | 读 CP 费用 / 彩框 / 正文，再实际使用蓝框牌 |
| §5 红框 | double-play → draw-result | 即时牌时机与费用，真实抽牌承接 |
| §5 橙框 | ai-turn → interference-play → target → confirm → result → response-finish | 任一方掷骰阶段；牌面额外条件仍要满足，实际改对方骰并按新结果选技能 |
| §5.1 升级类型、时机、差价、跳级 | draw-result 基础识别；upgrade-rule → meditation-2 → upgrade-result | 实际 II 级升级；差价与跳级说明，未再次升级 |
| §6 状态来源、立即生效、永久 / 消耗 / 独特与默认时机 | 顿悟奖励骰后 status-tokens；防御后与响应 | 标记通过实际牌效获得；由持有者依限制使用；太极、闪避、净化实际操作，不外推所有英雄标记 |
| §6.2 叠加上限与超出截断 | defense-resolve | 清修四个太极符号实际只补到持有上限 5；不是少结算 |
| §6 击倒选择 | knockdown-explain → purify-rule → purify-use → purify-result | 付 2 CP / 跳进攻的规则说明；实际净化保留进攻权与升级预算 |
| §7 伤害类型、攻击修正 | attack-rule、attack-token-pass、defense-start、interference-confirm；真实攻击、防御与减伤 | 类别与修正时机说明，普通攻击实操；附属伤害的多人目标不纳入 |
| §8、§11 规则用语 | enlightenment-play / confirm：指定颗数与“出现”；defense-rule：倍数；abilities：“或”；resolveAttack：“然后 / 此外”；stats：盗取；main2-return：掷骰阶段结束；opponent-end-turn：阶段末 | 当前对象读法与规则说明；倍数按清修实际计数承接，“然后”在顺子效果正文出现；“此外 / 盗取”只作相关结算 / 资源的短对照，不冒称实操 |
| §10 减伤顺序、干扰、同时结算 | 攻击方响应规则、defense-resolve、token-response-rule、opponent-end-turn | 当前真实响应链 + 相应规则说明；不以一次减伤覆盖所有乘除分支 |
| 电子检视、出售与撤回 | hand-inspect、sell-card-intro | 桌面 / 原生触屏长按、关详情无状态变化；非推荐牌真实出售、点弃牌堆撤回、再出售预算牌；连续出售缺前提时完整检查点恢复 |
| 电子响应偏好、介入 / 放弃 | response-control；牌响应与伤害响应 | 真实切手动，介入与合法不介入均继续到下一状态 |
| 退出 / 完成 / 恢复 | 当前真实教程入口、目录与普通房间 | 独立验证，不能用主线完走代替退出清理与首次初始化 |
| 伙伴、其它英雄完整机制、多人数 | 用户范围外 | 不声称全游戏已覆盖 |

## 独立练习与入口

只保留 [手牌上限练习](../../../src/games/dicethrone/tutorialPractices.ts)：首帧前声明代表态，弃牌阶段有 7 张合法手牌、14 CP、空牌库和其余弃牌。玩家自行选出售对象到 6 张，然后真实交接、收入、重洗。

主线用牌后要积到 7 张需额外保留手牌多个完整回合，重复既有攻防，无法合理服务当前出牌与响应目标，因此保留独立入口；它不是主线的连续后果。目录只有完整主线与此练习。
