## 兼容性口径
- 七张梭哈和香蕉分牌不兼容：不速之客、漫长收尾、粗暴开场、入门、迂回。
- 叠加挑战必须按注册表上限裁剪；当前实现对不速之客、漫长收尾、粗暴开场、入门限制最多 2 次。
- 规则配置只能在第一场抢劫、第一轮、尚未选择筹码、尚无历史记录时修改；开始游戏后必须锁定。
- 开局前修改扩展配置时，只有游戏模式、奥马哈、两副手牌、特殊牌堆或发牌/公共牌结构变化才重新发牌；撤离筹码、自动模式、提醒类 UI 和纯牌型评估开关只更新配置，不洗牌重发。
- 两副手牌仅在德州扑克模式可用，并按 TTS 限制最多 5 人；每名玩家获得上手/下手两幅隐藏手牌，摊牌时分别评估，取更强一手参与筹码排序。

## 当前未完成边界
- 专家牌单卡效果未实现；当前 TTS Lua 证据只支持专家牌抽取/持有状态，没有发现单张专家牌效果脚本。
- 未绑定脚本效果的工具牌只作为可抽到的工具牌对象记录，不脑补额外规则。
- 保险柜 AssetBundle 主要是模型和动画，不是本次规则脚本还原的阻塞项。
- 特殊牌当前使用程序化牌面；后续若找到稳定素材，可再走素材准入流程替换。
