# 旧延迟交互 D 分卷

本文件不再承载可执行审计正文。它保留路径，是为了让旧 evidence、旧任务记录和旧链接不悬空。

当前 deferred、finalize、后续选择链、恢复态和阶段收口审计应回到：

- [`description-to-implementation-audit.md`](description-to-implementation-audit.md)：确认延迟语义、消费宿主、最终权威状态和清理。
- [`rule-driven-interaction-design.md`](rule-driven-interaction-design.md)：交互权限、Choice Request、响应窗口和自动推进。
- [`e2e-verification.md`](e2e-verification.md)：真实入口、截图和端到端证据。
- [`audit-evidence-template.md`](audit-evidence-template.md)：记录范围、证据、缺口分类和旧结论回写。

旧 D 编号只允许作为历史证据里的定位语言；新审计不得继续按旧编号清单机械填表。若旧分卷中某条方法仍有价值，先抽象成“要回答什么现实问题”，再迁入对应主源；具体游戏案例下沉到 `evidence/` 或 `docs/games/<gameId>/...`。
