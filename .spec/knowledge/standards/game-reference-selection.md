# 游戏参考准入

游戏参考须来自玩法同类的实际产品，且观察到的状态须直接对应本轮玩家任务。先写清想研究的决定和所需信息，再比较胜负目标、核心循环、行动者与行动来源、对象关系和反馈。用可回查的规则或实玩说明哪些环节相同、哪些差异会改变设计。题材、画风、同平台或同属桌游不足以认定同类。

整条玩法或教程的参考按主循环判断。局部游戏 UI 仍须满足玩法同类性，再核对该操作的对象、输入、信息层级、空间约束和结果反馈。记录产品、模式、实际看过的入口或时间点、同类依据、可迁移范围及影响迁移的差异。用户点名的来源仍按原对象读取，并据实记录符合哪些范围。

从参考推导通用做法时，对照多个独立的适用产品，记录重复出现的做法与反例。单个产品、多段同源画面或同产品的多个教程只证明该产品的做法。跨类型材料、平台教程指南和通用设计清单可作为背景资料。合格样本不足时，记录查找范围与缺口，把仍需验证的设计依据写清楚。

教程时序与开场证据见[教程设计](tutorial-design.md)，画面与交互状态证据见[UI 改动门禁](ui-change-gates.md)。
