# 旧状态管线 D 分卷

本文件不再承载可执行审计正文。它保留路径，是为了让旧 evidence、旧任务记录和旧链接不悬空。

当前状态流、pipeline、重复副作用、共享消费者和 AI / 自动推进审计应回到：

- [`description-to-implementation-audit.md`](description-to-implementation-audit.md)：确认写入、消费、最终权威状态和共享影响。
- [`engine-systems.md`](engine-systems.md)：共享引擎原语、事件、FX、AI 和状态边界。
- [`regression-closeout.md`](regression-closeout.md)：回归、同类扩审和漏审归因。
- [`audit-evidence-template.md`](audit-evidence-template.md)：记录范围、证据、缺口分类和旧结论回写。

旧 D 编号只允许作为历史证据里的定位语言；新审计不得继续按旧编号清单机械填表。若旧分卷中某条方法仍有价值，先抽象成“要回答什么现实问题”，再迁入对应主源；具体游戏案例下沉到 `evidence/` 或 `docs/games/<gameId>/...`。
