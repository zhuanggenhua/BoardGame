# 旧力量修正主语 D 分卷

本文件不再承载可执行审计正文。它保留路径，是为了让旧 evidence、旧任务记录和旧链接不悬空。

当前力量、战力、伤害、资源或其它数值修正审计应回到 [`description-to-implementation-audit.md`](description-to-implementation-audit.md)：先拆“谁获得 / 谁消费 / 作用于哪个最终权威状态”，再追实现消费点和玩家可见结果。

旧 D 编号只允许作为历史证据里的定位语言；新审计不得继续按旧编号清单机械填表。具体游戏里的数值裁定、卡牌主语、等级差异和历史错误应落到对应 `evidence/` 或 `docs/games/<gameId>/...`。
