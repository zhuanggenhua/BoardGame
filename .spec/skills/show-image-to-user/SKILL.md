# 图片与录屏交付

本入口负责交付方式，不另定义视觉通过标准。原始图片读取见 [safe-image-reading](../safe-image-reading/SKILL.md)，图面裁决见 [ui-audit-loop](../ui-audit-loop/SKILL.md)，证据范围、整屏和原图核查合同见 [e2e-verification](../../knowledge/standards/e2e-verification.md)。读取失败或输出截断时按 `.spec/AGENTS.md` 补读。

## 先分清交付对象

- **最终验收媒体**：先按本轮完整目标完成适用的行为、真实截图和视觉审查；`PASS` 只证明已覆盖范围。未完成或 `REVISE` 的图片不得称为最终通过。
- **用户点名的原图或失败证据**：按 [用户点名原图核查](../../knowledge/standards/e2e-verification.md#用户点名原图核查) 提供同一原图，标明来源和实际结论，不将核查称为产品通过。用户要求圈出问题时，另提供标注诊断副本和未修改原图，说明对象、层级、玩家任务与判定依据；副本不能冒充原图。
- **内部过程图**：用于定位、重拍和审图，不主动包装为最终交付。用户明确要求查看时按诊断证据提供。
- 用户要求完整流程、某个状态或特定视口时，对应交付物必须直接覆盖它；不以相邻状态或旧图补位。多图写明顺序及每张证明什么。

展示或查看器成功只说明媒体有查看入口；用户未明确表示看过或接受时，不称用户已验收。用户要求的查看方式和宿主展示能力优先于本项目默认；不重复索要已给的授权。

## 展示通道

- 用户要求网页查看器链接或只要链接时，使用下面的项目查看器入口；只要链接不打开窗口。用户明确要求打开查看器时才打开或复用。
- Codex 桌面应用支持图片内联时，用户要看图或截图可用本地绝对路径展示，例如 `![说明](D:/absolute/path/image.png)`；文件路径含空格时用尖括号。录屏、GIF 或视频优先使用宿主支持的原生预览。内联图仍须遵守对应证据合同。
- 用户指定系统查看器、PureRef 或其他可用方式时按其要求执行。一次交付不重复打开同一媒体；失败时记录实际错误，再按用户允许和宿主能力选择可行通道，不把路径、链接或私下审图说成用户已经看过。
- 用户要看最终验收图时，若该图尚未通过，继续完成授权的修复和验证或说明实际缺口；用户点名查看失败图则按诊断模式提供。

## 项目网页查看器

`scripts/verify/open-verified-image.mjs` 负责清单 / 路径校验及网页查看器目录注册。最终游戏 E2E 图组按 [证据主源](../../knowledge/standards/e2e-verification.md) 生成索引和 PASS 清单；单游戏及证据类别不混装。最终媒体与清单逐项匹配，确认来源、状态、视口、视觉裁决和内容哈希。未通过的游戏 E2E 跑次不能覆盖稳定证据；实时查看器的定点更新与 staging 边界以证据主源为准。

```powershell
# 预检清单及待展示的媒体，先处理报告中的缺口；多张图可依次列在 --paths 后
node scripts/verify/open-verified-image.mjs --pass-manifest "<PASS清单.json>" --path "<媒体文件>" --dry-run

# 只注册并返回链接；原样使用脚本输出的 VIEWER_URL
node scripts/verify/open-verified-image.mjs --dir "<最终媒体目录>" --no-open

# 用户明确要求打开查看器时
node scripts/verify/open-verified-image.mjs --dir "<最终媒体目录>"
```

按目录身份复用已有结果，不手工拼接 key、focus 或 files 参数；筛选交由脚本。目录内离线入口或查看器注册不证明用户已查看。若用户点名原图核查，用 `--dir "<原图核查目录>" --source-review --no-open` 和 `source-review-manifest.json`；该校验只证明原图来源一致，标注副本单独交付，不加入原图一致性清单。

用户明确要求上传服务器或手机可访问相册时，才使用对应发布流程；本地看图不自动上传。整理目录前先核对对象及引用，不因注册失败直接删除其他证据。

## 失败与汇报

路径不存在先核对实际文件；空文件、错误图片、未通过审查或清单不匹配不得宣称最终通过。查看器失败时查看命令输出和 `logs/e2e-image-viewer.log`，说明实际后果、原因和可用的最小补救。最终回复按请求给出当前媒体或链接、入口和状态、直接观察与未覆盖范围；不能用文件存在、链接生成或测试绿灯代替视觉结论。
