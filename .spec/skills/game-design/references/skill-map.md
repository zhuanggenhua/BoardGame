# Game Design Topic Map

`game-design` 是唯一触发入口。主题正文已合并到 [`topic-cards.md`](topic-cards.md)；本文件只保留导航。

## 主题组

- 立项和框架：pillars、problem statement、80/20、资源三角。
- 核心循环和迭代：verbs、玩家动作反馈、prototype loop。
- 机制和平衡：flow、动态难度、奖惩反馈、min/max、倍增 / 减半。
- 关卡、谜题和引导：能力类型、affordance、环境叙事、节奏结构。
- UI、控制和错误：UCD、Hick、Fitts、错误分类和恢复。
- 玩家心理和测试：认知偏差、归因偏差、playtest 方法。
- 团队和主题：决策权、共同愿景、主题协同、比例 / 张力。

具体执行时直接读 `topic-cards.md` 的对应主题卡，不读取旧讲义副本。
