# 教程验收

这是验收入口。先读 [教程设计规范的首玩审查](../../knowledge/standards/tutorial-design.md#首玩审查) 和其所在第六节。涉及参考游戏或确认稿时，回读同一标准的来源与范围。教学改稿与实施由 [教程制作流程](../tutorial-workflow/SKILL.md) 承接。

1. 从对应游戏的覆盖文档定位正式教程入口、确认稿、参考观察和当前证据。交给独立审查者的首玩材料按主源限定，作者对照资料在记录实际观察后使用。
2. 在同一份验收记录里关联首个理解断点、对应提示和画面、当时输入与实际结果。按主源给出内容判定，再接 [图面审计](../ui-audit-loop/SKILL.md) 与 [端到端证据](../../knowledge/standards/e2e-verification.md)。
3. 返工后回到相同入口，更新同一验收记录中的受影响节点。展示通过的媒体时转 [看图流程](../show-image-to-user/SKILL.md)。
