# 游戏 UI 参考案例

本文件记录可回查的参考和设计观察，不作为规则正文或固定版式。引用前需打开对应原图与当前任务状态核对；动态行为不能仅凭静态图推断。项目级设计要求见 [`ui-ux`](../../../knowledge/standards/ui-ux.md) 和 [`ui-change-gates`](../../../knowledge/standards/ui-change-gates.md)。

## 杀戮尖塔：战后选择卡牌

- 来源：[玩家指南中的选牌截图](https://images.steamusercontent.com/ugc/957481092836729609/B9E28A64F2A7481684562684F4E09FA8E7F88970/)，[原指南](https://steamcommunity.com/sharedfiles/filedetails/?id=1613845715)；另见[卡牌奖励界面示例与说明](https://dspace.cuni.cz/bitstream/handle/20.500.11956/192911/130401300.pdf?isAllowed=y&sequence=1)。
- 玩家任务：从少量候选中选一张加入牌组，或跳过。
- 参考可见状态：提示选择卡牌、三张带规则内容的候选和独立跳过入口。静态图只证明画面，不证明悬浮、点击、取消或提交后的行为。
- 可迁移观察：以候选卡本身承载比较与选择，卡面保留阅读尺度；提示只指出当前决策，跳过入口与选牌分开。由此减少玩家在说明、候选和额外按钮之间寻找关系的成本；这是一种设计判断，不是可量化的用户测试结论。
- 适用边界：这是少量候选的奖励选择，不能推断几十张候选如何搜索、筛选、滚动或分页，也不能推断是否保留原手牌可见。规则要求可比较手牌或不可跳过时，以目标游戏规则和真实决策需要为准，不复制固定三张、跳过动作或视觉皮肤。
- 当前素材访问记录：原始图片在本环境浏览器访问超时；截图内容可由上面的独立页面说明交叉核对。未实际打开原图时不得声称已做完整视觉检查，应先恢复访问并向用户展示同一参考图。
