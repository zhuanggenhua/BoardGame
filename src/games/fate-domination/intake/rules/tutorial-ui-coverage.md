## 本课程内能实际操作的对象

| 对象 | 正式操作及可见变化 | 证明边界 |
| --- | --- | --- |
| 前哨部署 | 选择具体印刷点位、取消/改选、明确确认、落位后停留 | 不把选点当成已经部署；同值最高空位按 slot 区分 |
| 地图 | 拖动、缩放、复位；原位置、移动目的地、取消与确认 | 部署与移动分别保留正式命令 owner |
| 玩家摘要 | 当前公开合计威力在一级显示；悬停对方头像出现无框单排已打出牌 | 暗置保持牌背；进入牌排暂停收起，移开有 2.5 秒宽限 |
| 玩家详情与检视 | 自选打开本人、隐藏/已揭示对手详情及原卡；关闭回到任务 | 查看时教学浮层退场；详情不显示临时合计威力，紧凑牌距、红色淘汰 |
| 牌堆与弃牌 | 数量开关、弃牌横向浏览及原卡检视 | 不为同构数字再扩一套课程和截图 |

| 令咒 | 未选禁用确认；选恢复、强化或移动，取消/确认 | 费用与耗尽由领域和网络测试证明，不依赖截图读数字 |
| 普通草稿 | 明/暗置、普通与技能混选、撤回、确认 | 选择/撤回只在客户端；原子提交 cardIds/faceDownIds/round；错误/离线保留、过期/重复由独立测试证明 |
| 骑乘 | 独立零至三张选择、取消/重开、三张确认 | 正费用、第四张拒绝及普通草稿隔离由已有骑乘 E2E 和真实网络验证 |

| 教程生命周期 | 刷新恢复、随机回退重做、合法偏离重练、中途退出、完成后新决定 | 回退释放已取消的 AI 执行记录；同一步重同步不重复执行 |
| 正式选角 | 完成教程后进入普通新局；候选、当前原卡、关联资料和确认同页 | 选角不是首课。御主资料是可变集合，查看卡面/牌背不提交选择 |

## 角色资料容量与职责

十三名御主共 49 项正面资料及两张关联牌背；宝石、四道具、追加技能攻击、关联攻击、独立牌库、身份变化与升华分别保留类别。六张月灵髓液的三种图面不等于总量三张；死之艺术及宝石牌背不算新能力。中文原图关系见[资源合同](../catalog/master-reference-artwork-contract-2026-10-25.md)，具体商业参考借用位置见[职责总账](../../../../../artifacts/fate-domination-identity-selection/element-ledger.md)。

资料目录只供阅读，不写入当前持有、手牌、已激活能力或技能区，也不为未实现效果伪造发动按钮。凛、肯尼斯与时臣分别覆盖资源/关联攻击、独立牌库及最多关联图面；受限桌面要求末项可滚动阅读，确认仍可到达。
