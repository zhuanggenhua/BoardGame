## 命名与 atlas 契约

- 正式角色 ID 使用 `vampire_lord`；用户素材目录保持 `xixuegui`，通过运行时目录映射连接。
- 固定素材名使用 `ability-cards`、`player-board`、`tip`、`dice`、`status-icons-atlas`，与 DiceThrone 现有英雄一致。
- 卡牌 atlas 使用 `ability-cards-vampire_lord.atlas.json`，尺寸 `900x2048`，5 列 x 7 行，真实可读卡牌为 `slot-00` 至 `slot-32`。
- `slot-17` 至 `slot-32` 为吸血鬼专属 / 升级牌；`slot-32` 图面为“血石！”，不得当成公共牌“出乎意料！”。
- 2026-08-29 裁定：公共卡运行时仍注入现有通用卡定义，但吸血鬼 atlas 映射排除 `card-unexpected`；`card-vampire-lord-bloodstone` 独占 `slot-32`，`card-unexpected` 在吸血鬼牌库中不绑定吸血鬼专属 atlas 预览。
- 2026-08-29 裁定：`slot-23/24/25/27/28` 的下区不是第二张手牌；它们进入升级后基础技能的 `variants`，打出升级牌只替换基础技能。
