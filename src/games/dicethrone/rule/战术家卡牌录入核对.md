## 对照与疑点

| 对象 | 结论 |
| --- | --- |
| 复合升级 | slot 25/26/28/29 是单张物理升级牌内的上下复合子区，运行时仍应按“一张升级卡替换一个基础技能，内部 variants 同类取最高”建模；不得拆成多张 runtime card |
| 通用牌索引 | 战术家“意不意外?!”在 slot 32，不是树精/忍者旧映射 slot 37；已在 `cards.ts` 使用战术家专属映射 |
| 机制状态 | 当前仅完成 L1 静态录入与少量简单行动效果；升级替换、复杂响应窗、目标选择、复合升级 variants 仍待 L2 |
