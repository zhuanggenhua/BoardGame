## 玩家板面合同

| 字段 | 结论 |
| --- | --- |
| 当前正式玩家板素材 | `player-board.png` 为咒缚面，`human-player-board.png` 为人类/normal 面；运行时按 `HeroState.playerBoardFace` 选图 |
| 运行时字段 | `HeroState.playerBoardFace` |
| 初始值 | `cursed_pirate` 初始化为 `normal` |
| 开局附加状态 | `initialStatusEffects[STATUS_IDS.CURSED_COIN] = 3` |
| 当前使用方 | `CenterBoard`、攻击特写裁切、`PLAYER_BOARD_FACE_CHANGED` 后能力集切换与 `card-cursed-pirate-pirates-life` 都已消费 `playerBoardFace`；咒缚面分支治疗 3，normal 面分支获得 1 诅咒金币 |
| 当前布局合同 | normal 面继续复用现有 `v2` 技能槽布局，不新增第二套 `abilitySlotLayout` / `abilitySlotMapping` |
| 当前 normal 面对象接入状态 | runtime 已按 `getCursedPirateAbilitiesForFace('normal')` 接入 `弯刀突刺 / 做好标记 / 咒缚 / 走跳板 / 点燃炸药 / 判决指令 / 惊魂动魄 / 嘿，老兄 / 无情劫掠` 9 个对象；其中 `human-cursed / cutlass-stab / make-your-mark / walk-the-plank / astonishing / human-still-wet-behind-ears` 已有 L2 测试，`light-the-fuse / verdict-command / merciless-plunder` 仍待对象级补证 |
| 已确认差异 | normal 面图面出现 `弯刀突刺 / 做好标记 / 点燃炸药 / 判决指令 / 走跳板 / 惊魂动魄` 等对象，且被动 `咒缚` 也改成“回合结束移除 1 个诅咒金币；若没有可移除金币则翻面”。这与当前 runtime 仍在使用的咒缚面对象 `灵魂突刺 / 死亡印记 / 死亡吐息 / 灵魂指令 / 深海潜行 / 亡灵之爪` 明显不同。 |
| 未纳入范围 | normal 面对象级彻底审计、`light-the-fuse / verdict-command / merciless-plunder` 的独立 L2-L4 补证，以及基于真实双面合同的对象级重审计仍未完成，不能把“已接入 9 个对象”外推成官方双面机制已完整收口 |
