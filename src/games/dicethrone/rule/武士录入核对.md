## Addendum（2026-03-27）：Honor 完整规则已落地

- `honor / 荣誉` 现已完整支持 `1 -> +1` 与 `2 -> +3`。
- 这次不是做武士专属特判，而是把非线性 token 消耗沉到通用领域层：
  - `allowedConsumeAmounts`
  - `valueByAmount`
  - `pendingDamage.tokenUsageTotals`
- 当前 UI 仍保持单按钮；同一响应窗口里连续两次各消耗 `1` 层 `honor` 时，第二次会只补差值 `+2`，总计仍为 `+3`。
- 同一响应窗口累计已用到 `2` 层后，即使角色身上还有更多 `honor`，它也不会继续出现在可用 token 列表里，命令校验同样会拒绝第三次使用。
