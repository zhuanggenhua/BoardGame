## 当前口径

- 这份表只记录**图片可直接判定的录入合同**，不替代实现审计。
- 以 2026-05-17 当前工作区计，Treant 的基础技能与被动主效果已经全部对齐到 L2。
- 当前剩下的录入层重点不在基础技能本体，而在：
  - 树灵共享通则与神性树灵防负面已有代表性真实 UI/L3；
  - 玩家板槽位与高亮消费链已有真实 UI/L3 证据，仍需作为回归证据长期保留，避免被动槽/防御槽再次被旧共享语义带偏；
  - 15 张专属卡已补逐卡真实手牌入口 L3；后续残余是全分支 L4 审计，不是录入层缺口。

## 当前结论

- Treant 基础技能与被动本体目前已经不是主要录入风险点。
- 5 张升级卡描述当前**已经**按图片重录到 `game-dicethrone.json`，不再是录入层残余。
- 当前录入层没有已知残余：
  - token 共享提示板合同已有 L2 与代表性真实 UI/L3；
  - 玩家板槽位合同已在 `abilitySlotMapping.ts` / `AbilityOverlays.tsx` 修正，并已有真实 UI 证据；后续必须持续保留这类证据，防止被动槽与防御槽再次错绑；
  - 15 张专属卡已完成逐卡真实手牌入口 L3。
- 仍需继续追踪的不是录入缺口，而是审计层残余：本轮已补四批 L4 分支，包括 `quiet-cultivation` 养成选择与伪造不可能养成、`wild-growth` 基础版直测与 `wild-growth-2` 可选/否定、`shattering-fist` 跳过/伪造移除 2 与 `shattering-fist-3` 非三同点/伪造不可能养成、`tend-care-2` 4 人目标归属/生命源泉与刺藤目标满栈/座位表外索引、`forest-awakens` 无队友/生命源泉与刺藤满栈/伪造不可能养成结果、`rooted-2` 双触发与 4 人生命源泉目标全集、`nature-touch` 基础版与伪造不可能养成、`drink-deep` 4 人目标全集与目标生命源泉满栈、`harvest` 4 人边界/移除 3/最多 2 目标/CP 与生命源泉接近上限、`downpour` 禁止部分升级/跳过/无可升级、通用养成动作卡伪造不可能养成、`mother-tree` 非树灵与树灵满栈、`soulfire` 纯树灵/纯三树枝/纯三树叶/生命源泉满栈/树灵满栈/4 人敌我归属、`trample` 阈值与刺藤满栈、`life-sap` 1/6 与 `MAX_HEALTH` 治疗边界、`treant-divine` 同回合限次与错误玩家/错误数量/错误时机/错误代跳拒绝、`treant-seedling` 缺失/越界/锁定目标骰拒绝、树灵主动动作非法 `actionIndex` 与未知 passive 拒绝；但基础技能/token/卡牌的所有目标数量、所有骰面排列、所有多人/队友组合仍尚未逐一达到 L4。
- 本轮另补一批审计层防线：`rooted-2` 拒绝座位表外生命源泉目标索引，`wild-growth-2` 拒绝伪造移除 3 个树灵，`harvest` 拒绝座位表外生命源泉目标 mask，`drink-deep` 拒绝负数/座位表外目标索引，`shattering-fist` 拒绝伪造移除 2 个树灵且允许合法跳过，`tend-care-2` 拒绝座位表外生命源泉/刺藤目标索引，`forest-awakens`/`quiet-cultivation`/`shattering-fist-3`/`nature-touch`/通用养成动作卡拒绝伪造不可能养成结果，`harvest` 无树灵时只能移除 0 且不改写 CP/生命源泉，`rooted` 过量防伤不出负伤害也不治疗防守方，且 `rooted` choice value 现在携带强语义标记，伪造保持当前树灵/跳过生命源泉目标会被拒绝，`treant-seedling` 拒绝缺失/越界/锁定目标骰，`treant-divine` 拒绝错误玩家/错误数量/错误响应时机/错误代跳，`CHOICE_RESOLVED` 通用 token/status 增量也只接受有限整数，字符串与 `NaN` 不再污染堆叠状态。这些属于实现/审计层非法值与边界门禁，不是新的录入残余。
