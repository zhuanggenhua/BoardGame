## 对照与疑点

| 对象 | 结论 |
| --- | --- |
| 通用牌索引 | 工匠与战术家同规格：slot 00-16 为通用牌，`card-unexpected` 在 slot 32 |
| 空白槽 | slot 33-34 为黑色空槽，不接运行时对象 |
| 复合升级 | slot 21、23、24 存在上下子区，默认按“一张升级卡替换一个基础技能，内部 variants / 子效果同类取最高”处理；不得拆成多张 runtime card |
| slot 19 | 图面像攻击/防御反应牌，但用户未要求完整机制实现；L1 先作为工匠专属卡保留，后续 L2 需要回到单卡图裁定名称、目标技能与结算时机 |
