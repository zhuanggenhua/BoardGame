## 残余范围

| 条目 | 现实缺口 | 当前状态 | 最小补救 |
|---|---|---|---|
| `blood_power` 主动消费增强 | 只有获得 / 堆叠证据，缺玩家消费入口、可消耗数量、跳过语义、伤害增加和 token 扣减清理 | blocked | 先从提示卡 / 规则合同建立权限矩阵，再实现正式 token 使用入口和最终状态测试 |
| `mesmerize` 强迫重掷 | 只有获得证据，缺目标骰选择、对手骰区权限、5-6 重掷语义、消耗和关闭条件 | blocked | 建立骰子选择 / 重掷交互合同，再实现命令、清理和真实入口证据 |
| 复合升级下区 | 多张升级牌含“升级技能 + 下区技能/效果”，当前只落升级壳 | blocked | 回单卡裁图和成熟角色复合升级合同，裁定下区进入 ability variants 还是独立效果 |
| `slot-32` 通用牌预览 | 图面是“血石！”，但公共 `card-unexpected` 暂复用同 slot | disputed | 裁定公共牌预览来源，避免用专属牌图替代公共牌 |

## 门禁结论

- 当前实现中状态标记为 `implementation_in_progress`，用于阻止用户误认为派系完整完成。
- 静态资源、角色注册、基础技能、获得类专属行动牌、普通升级壳和一批 II 级上区效果已经有本地结果级测试证据。
- 完整血力、催眠、复合升级牌、公共 `slot-32` 预览和真实双玩家 E2E 仍未收口，不能用本轮领域测试通过替代。
