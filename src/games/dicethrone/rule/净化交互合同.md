# 王权骰铸：攻击后续净化交互合同

本文件承接原反馈收口流程中的王权骰铸专项合同；它记录项目现行交互要求，不冒充官方规则原文。改动前仍须核对本游戏规则真相源、实际入口及用户授权范围。

- 进入净化预处理链的可净化负面状态 / Token，在施加前向受影响玩家提供“使用净化”和“不使用”两个选项；不得把第二项写成“承受状态”，也不得把弹窗延迟到状态的立即后果即将开始时。
- 使用净化只抵消对应状态的施加，再按原顺序结算攻击的其余效果；只有被抵消状态所触发的后续效果才随之消失。
- 验证选择发生时状态尚未施加、资源 / 伤害尚未提前变化，以及选择后的净化消耗、状态结果、其余攻击效果和状态触发效果。共享判定命中的可净化状态 / Token 逐项核对；其它施加来源未核对并接入前，不得声称全游戏覆盖。

当前实现参考 [`deferredAttackDebuff.ts`](../domain/deferredAttackDebuff.ts)，现有领域测试参考 [`interaction-chain-conditional.test.ts`](../__tests__/interaction-chain-conditional.test.ts)；它们只能证明实际覆盖的代码行为，不能替代规则来源或真实入口证据。
