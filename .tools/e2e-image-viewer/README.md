# E2E Image Viewer

本工具给 AI / 开发者快速查看端到端截图目录，也作为 PASS 后默认用户看图通道。它按目录复用同一个本地 Web 查看器，提供类似 PureRef 的图片画布：截图按画布位置铺开，但只加载视口附近的图片；远处图片先保留为轻量占位，放大或拖过去再加载。

## 使用

```powershell
node scripts/verify/open-e2e-image-viewer.mjs --dir "test-results/evidence-screenshots/<game>/<test>/<case>"
```

常用参数：

- `--dir <目录>`：要查看的证据目录，必须在当前仓库内；如果传入证据根目录、游戏目录或测试目录，工具会自动定位最新的具体截图目录，避免混入其它游戏。
- `--focus <文件>`：打开或复用目录后定位到指定图片 / 视频；目录已打开时只更新焦点，不重复开窗口。
- `--no-open`：只启动 / 注册目录，不打开浏览器。
- `--reopen`：目录已经打开过时仍强制再打开浏览器。
- `--port <端口>`：指定本地查看器端口，默认从 `4867` 起。

`npm run verify:e2e-images -- <目录>` 可作无选项快捷入口；带 `--no-open`、`--reopen`、`--port` 时优先直接调用上面的 `node` 入口，避免 npm 把参数当成自己的配置解析。

查看器打开后的地址栏只使用短 `key`，真实本地目录保存在工具状态文件里；这不影响按目录复用窗口。目录已打开时，后续打开同目录会返回 `ALREADY_OPEN=true`，并通过自动刷新同步新的焦点图。

## 中文索引

查看器会优先复用现有图组说明，而不是让 AI 每次重新描述图片。支持的索引文件名：

- `.e2e-image-index.json`
- `image-index.json`
- `label-source-manifest.json`

查找范围是当前截图目录和同一游戏的证据目录。只有索引项指向当前正在展示的具体截图目录时才会显示；其它游戏、其它流程或已经失效的路径会跳过，不会拖垮整个目录。文件名轻微变化时，查看器会在同一目录内用开头序号辅助匹配，例如 `05A-...`。

页面左侧显示可收起的中文索引；画布右侧保留完整操作空间。页面只显示中文标题和承接说明；地址栏、图片标题和 hover 不显示完整本地路径。需要原始路径时，双击图片复制。

## 画布操作

- 拖拽画布或图片：平移画布。
- 滚轮：以鼠标位置为中心缩放。
- `适配`：把当前目录的图片铺到窗口可见区。
- `重置`：回到默认缩放和位置。
- 单击图片：选中图片。
- 双击图片：复制原始本地路径；画布上只显示短标题，不直接显示完整路径。

## 边界

- 这是项目默认网页看图工具，但不是绕过验收的入口。
- 候选图、失败图和过程图可以在这里诊断，但不能因此变成最终验收图。
- 最终用户展示仍要先创建 PASS 清单，再走 `scripts/verify/open-verified-image.mjs`；该脚本默认调用本工具，不再默认调用 PureRef。
