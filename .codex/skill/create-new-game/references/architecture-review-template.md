## 1. 规则对象 -> 工程对象映射

| 规则对象 | 规则作用 | 工程对象类型 | 单对象 / 可聚合资源 | 稳定 id | 正式真相落点 | 备注 |

| 例：步兵木块 | 可移动、承伤、降级、离场 | `Piece` | 单对象 | `piece.id` | `core.pieces[]` | `level` 表示士气 |

| 对象类型 | 位置 | 朝向/翻面 | 等级/士气/耐久 | 控制/拥有/宿主 | 是否允许聚合 | 结论 | 理由 |
