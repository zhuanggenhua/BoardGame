# 基础玩法截图链示例

> 用途：当用户要“一个新游戏最基本的端到端流程”，并要求每步都有真实截图、能指出下一步点哪里时，直接照这个结构交付。
> 这是一份**交付模板与示例**，不是固定文案。实际交付时必须替换成当前游戏、当前截图和当前真实操作。

## 适用范围

- 适用于“让第一次看的人看懂这款游戏怎么运作”的基础流程。
- 不适用于只验证单个 bug、单个控件、单个 prompt 的局部验收。
- 如果当前只证明到中段，不得把这份模板包装成“整局流程”；必须明确写出截止边界。

## 交付物清单

至少同时交这两样：

1. 真实截图目录：`test-results/evidence-screenshots/_shared/<gameId>-基础玩法流程/`
2. 逐步说明文档：`evidence/<gameId>/<gameId>-basic-flow-e2e-<date>.md`

## 填写示例

```md
## <gameId> 基础玩法截图链

### 流程边界
- 视角约束：固定同一联机 viewer/seat。本例全程只看 `<seatName>` 自己的页面，不切去别的私有页冒充单玩家流程。
- 开始点：`<真实开始状态>`
- 结束点：`<真实结束状态>`
- 当前未覆盖：`<本条链未覆盖的规则或分支>`

### Step 1 - 进入第一次可操作状态
- 截图：`D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/_shared/<gameId>-基础玩法流程/01-<阶段>-<动作对象>-<状态>.png`

- 下一步点击哪里：`点击 <现实对象名>，再点击 <现实对象名>`
- 点击后结果：`<玩家肉眼会看到的变化>`
- 肉眼确认：`<为什么第一次看的人也知道从哪里开始>`

### Step 2 - 进入第一个正式主行动
- 截图：`D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/_shared/<gameId>-基础玩法流程/02-<阶段>-<主行动入口>-<状态>.png`
- 这一步玩家现在要做什么：`<先进入当前回合的正式主行动>`
- 下一步点击哪里：`点击 <主行动控件 / 卡牌 / 地图目标 / 横幅按钮>`
- 点击后结果：`<进入目标选择 / 资源支付 / 行动结算>`

### Step 3 - 完成第一次资源支付或目标确认

- 这一步玩家现在要做什么：`<为当前行动支付成本 / 选定目标 / 确认执行>`
- 下一步点击哪里：`点击 <资源对象或目标对象>，再点击 <确认入口>`
- 点击后结果：`<动作正式落地后的结果>`
- 肉眼确认：`<资源、目标与确认入口为什么没有断链>`

### Step 4 - 看到第一次结果反馈
- 截图：`D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/_shared/<gameId>-基础玩法流程/04-<阶段>-<结果对象>-<状态>.png`
- 这一步玩家现在要做什么：`<先读懂刚才动作带来的分数 / 伤害 / 控制权 / 资源变化>`
- 下一步点击哪里：`点击 <下一段正式入口>` 或 `这一步无需代替别人操作，只等待 <谁> 在他自己的页面完成动作`
- 点击后结果：`<流程如何继续>`
- 肉眼确认：`<结果反馈为什么已经能看出这游戏怎么运作>`

### Step 5 - 补完整条核心链

- 这一步玩家现在要做什么：`<例如打一场战斗 / 完成一次计分 / 触发一次季节结算>`
- 下一步点击哪里：`点击 <现实对象名>`
- 点击后结果：`<这条链如何收口并回到主流程>`
- 肉眼确认：`<为什么这一张能证明玩家已经看到游戏核心运作>`
```

## 写法约束

- `下一步点击哪里` 必须先写现实对象名，不要先写 `locator`、`test id`、字段名。
- `点击后结果` 必须写玩家肉眼会看到的变化，不要只写“触发 command”或“状态更新成功”。
- `肉眼确认` 必须回答“为什么第一次看的人也知道该怎么继续”，不能只复述断言通过。

## 交付前自查清单

- [ ] 已写明开始点、结束点、当前未覆盖范围
- [ ] 至少 5 步，且步骤顺序可回放
- [ ] 每步都有真实截图绝对路径
- [ ] 每步都有“下一步点击哪里”
- [ ] “点击哪里”使用的是现实对象名，不是内部字段名
- [ ] 每步都有“点击后结果”
- [ ] 至少有 1 步真实展示了这款游戏的核心特色，不只是“按钮能点”
- [ ] 若用了局部辅助图，已明确标注它来自哪张真实截图，且没有替代原图
- [ ] 最终汇报里至少附了 1 条说明文档路径和 2 张关键截图绝对路径
