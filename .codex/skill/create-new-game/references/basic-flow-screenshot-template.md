# 基础玩法截图链示例

> 用途：当用户要“一个新游戏最基本的端到端流程”，并要求每步都有真实截图、能指出下一步点哪里时，直接照这个结构交付。
> 这是一份**交付模板与示例**，不是固定文案。实际交付时必须替换成当前游戏、当前截图和当前真实操作。

## 适用范围

- 适用于“让第一次看的人看懂这款游戏怎么运作”的基础流程。
- 不适用于只验证单个 bug、单个控件、单个 prompt 的局部验收。
- 如果当前只证明到中段，不得把这份模板包装成“整局流程”；必须明确写出截止边界。

## 交付物清单

至少同时交这两样：

1. 真实截图目录：`test-results/evidence-screenshots/_shared/<gameId>-基础玩法流程/`
2. 逐步说明文档：`evidence/<gameId>/<gameId>-basic-flow-e2e-<date>.md`

```md
- 肉眼确认：截图里被选中的剧本卡和“确认投票”按钮都在同一屏，第一次看的人能直接知道从哪里开始

- 这一步玩家现在要做什么：先从顶部绿色横幅里选轮盘行动，再决定本轮要执行哪项主行动

- 点击后结果：会进入这项行动的弃牌支付步骤

- 这一步玩家现在要做什么：为当前行动支付弃牌成本
- 下一步点击哪里：点击底部手牌区里要弃掉的牌，再点手牌上方的“确认执行”
- 点击后结果：支付完成后，这个行动会结算完成并把回合推进给下一位势力
- 肉眼确认：截图里同时看得到手牌、支付条和确认按钮，不会像卡死页一样不知道下一步点哪

### Step 4 - 别的势力行动时，大明视角继续观察流程
- 截图：D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/qidahen/online-full-round-second-round/七大恨-完整首轮-03-大明视角-蒙古行动中仍显示大明手牌.png
- 这一步玩家现在要做什么：等待蒙古行动完成，但仍从大明自己的 viewer 页观察局面推进
- 下一步点击哪里：这一步大明页不用代替别人操作；等待蒙古玩家在他自己的页面完成行动
- 点击后结果：蒙古回合结束后，主流程会自动推进到后金，再推进到第 2 轮大明

### Step 5 - 第 2 轮回到大明，开始攻打链
- 截图：D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/qidahen/online-full-round-second-round/七大恨-完整首轮-05-第2轮开始-回到大明行动窗口.png

- 下一步点击哪里：先点顶部绿色横幅里的轮盘选项；轮盘推进后，点地图上的“锦州”
- 点击后结果：锦州会成为当前选中的进攻目标，右侧行动列里会出现可执行的攻打行动

- 点击后结果：页面会进入突袭作战的弃牌支付步骤
- 肉眼确认：地图上的目标区已经被高亮选中，右侧“突袭作战”按钮也同时可见

### Step 7 - 为攻打支付弃牌
- 截图：D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/qidahen/online-full-round-second-round/七大恨-完整首轮-07-第2轮大明-点击突袭作战后进入弃牌确认.png
- 这一步玩家现在要做什么：为这次攻打支付 1 张手牌
- 下一步点击哪里：点击底部手牌区里要弃掉的牌，再点中间支付条上的“确认执行”
- 点击后结果：支付完成后，会进入这次攻打的待结算状态
- 肉眼确认：截图里既能看到地图目标，也能看到支付条和确认按钮，流程没有断

### Step 8 - 进入攻打待结算
- 截图：D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/qidahen/online-full-round-second-round/七大恨-完整首轮-08-第2轮大明-弃牌后进入攻打待结算.png
- 这一步玩家现在要做什么：为这次攻打选择待结算结果
- 下一步点击哪里：点击右侧红色待结算面板底部的“断后”
- 点击后结果：本次待结算会被真实执行，待结算面板关闭，主流程继续推进
- 肉眼确认：截图里攻打箭头、目标高亮和“断后/溃退”按钮同时存在，能看懂这一步已经进入战斗收口

### Step 9 - 攻打收口后回到主流程
- 截图：D:/gongzuo/webgame/BoardGame/test-results/evidence-screenshots/qidahen/online-full-round-second-round/七大恨-完整首轮-09-第2轮大明-点击断后后返回主流程.png
- 这一步玩家现在要做什么：确认刚才的攻打待结算已经结束，并继续下一段轮盘流程
- 下一步点击哪里：点击顶部绿色横幅中的下一项轮盘行动
- 点击后结果：会继续执行大明本轮剩余的轮盘推进
- 肉眼确认：待结算面板已经消失，顶部横幅重新成为唯一主提示，说明攻打链已经真实收口
```

## 写法约束

- `下一步点击哪里` 必须先写现实对象名，不要先写 `locator`、`test id`、字段名。
- `点击后结果` 必须写玩家肉眼会看到的变化，不要只写“触发 command”或“状态更新成功”。
- `肉眼确认` 必须回答“为什么第一次看的人也知道该怎么继续”，不能只复述断言通过。

## 交付前自查清单

- [ ] 已写明开始点、结束点、当前未覆盖范围
- [ ] 至少 5 步，且步骤顺序可回放

- [ ] 每步都有“下一步点击哪里”
- [ ] “点击哪里”使用的是现实对象名，不是内部字段名
- [ ] 每步都有“点击后结果”
- [ ] 至少有 1 步真实展示了这款游戏的核心特色，不只是“按钮能点”
- [ ] 若用了局部辅助图，已明确标注它来自哪张真实截图，且没有替代原图
- [ ] 最终汇报里至少附了 1 条说明文档路径和 2 张关键截图绝对路径
