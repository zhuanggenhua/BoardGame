## ADDED Requirements

### Requirement: Preload The Action Heroes POD Atlas

The Smash Up critical image resolver SHALL include the Action Heroes POD card atlas before the board renders when that faction is selected.

#### Scenario: Enter a match with Action Heroes POD

- **WHEN** any player has selected Action Heroes POD
- **THEN** the resolver SHALL include the Action Heroes POD compressed card atlas in the critical image set
- **AND** it SHALL include the reused Excellent Movies, Dudes! base atlas
