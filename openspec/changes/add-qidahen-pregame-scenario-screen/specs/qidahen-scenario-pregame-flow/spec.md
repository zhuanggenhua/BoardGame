## ADDED Requirements
### Requirement: 七大恨剧本待决项 MUST 在进入正式棋盘前完成
《七大恨》系统 MUST 在进入正式棋盘前完成当前剧本要求的待选人物与待选军备，而不是把这些待决项留到地图主界面内处理。

#### Scenario: 直进入口缺少剧本待决项时先显示前置选择页
- **GIVEN** 用户从教程或其他直进入口进入《七大恨》对局
- **AND** 当前入口还没有完整的剧本待决项结果
- **WHEN** 对局准备渲染正式棋盘
- **THEN** 系统 MUST 先展示独立的剧本前置选择页
- **AND** 正式棋盘 MUST 在待决项完成后才可进入

#### Scenario: 建房阶段已提供完整剧本待决项时直接进局
- **GIVEN** 联机房间的 `setupSelections` 已包含当前剧本要求的待选人物与待选军备结果
- **WHEN** 玩家进入《七大恨》对局
- **THEN** 系统 MUST 直接进入正式棋盘
- **AND** 不得再次要求玩家重复选择同一批剧本待决项

### Requirement: 七大恨正式棋盘 MUST 不再重复显示剧本配置面板
《七大恨》正式棋盘 MUST 不再重复显示剧本摘要、待选人物、待选军备这类剧本配置面板；剧本前置页是唯一的默认配置入口。

#### Scenario: 进入正式棋盘后不再显示重复剧本面板
- **GIVEN** 玩家已经完成当前剧本的全部前置选择
- **WHEN** 正式棋盘渲染
- **THEN** 地图主视图 MUST 不再显示剧本摘要、待选人物或待选军备面板
- **AND** 不得为了“提示当前剧本”在棋盘主视图重复占据一块常驻 HUD

#### Scenario: 剧本待决项异常残留时只允许现有动作区提示阻断
- **GIVEN** 当前剧本仍有未完成的待决项
- **WHEN** 用户尚未完成前置选择页
- **THEN** 系统 MUST 阻止进入正式棋盘主操作
- **AND** 若需要提示，只能复用现有动作区或等价非主地图承载区给出阻断说明
- **AND** 不得通过在局内 HUD 堆叠剧本待决项面板作为默认替代方案
