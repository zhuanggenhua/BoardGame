# Change: 外链游戏试玩与个人创作中心

## Why
当前上传入口能保存外部网址、封面和介绍并送审，但未形成公开目录到外链试玩的完整链路。个人中心只有资料、对局记录和统计，用户无法在同一处区分自己的投稿与有权管理的作品。

## What Changes
- 外链游戏优先在本站 iframe 中打开，由包含 iframe 与悬浮菜单的共同容器请求全屏，提供结束游玩和返回原入口。
- 记录外链容器的前台停留时长，与原生桌游的对局记录分开呈现；跳转到外站后停止本站计时。
- 个人中心增加概览、我的投稿、我的作品、作者认证四个分区；收藏库继续承担玩家收藏语义。
- 打通投稿审核、公开外链目录、作者认领和认领后的资料管理。投稿人、展示作者和实际管理者保持不同语义。
- 作者通过主页链接、截图及控制权证据申请认领，管理员审核目标作品与作者的关系后授予站内管理权。通过后作者可直接修改作品公开资料。
- 以 `https://yuanyigames.top/` 为首个真实收录候选，作者为鸢一桑，介绍必须包含其 B 站主页链接。

## Scope and Approval
- 2026-10-27 用户已明确选择 iframe 优先，并要求尝试加入指定网址；同时要求考虑作者认证、我的投稿、我的游戏与个人中心重构。
- 2026-10-27 用户批准本方案实施，原话：“可以，按这个方案实施，那个网站先收录，iframe受限就提示并提供外站打开。最后要所有新ui截图”。指定站点解除嵌入限制不再阻塞本站功能交付，但该站 iframe 实际可玩仍不得记为通过。
- 本轮交付为本地完整实现、真实测试环境收录与新 UI 双端截图。上线和真实作者管理权授予未获本轮授权。
- 不创建新游戏领域引擎或复制外站代码；这是一项外链目录能力，不是本站 `betrayal` 游戏重做。
- 原生 WebView、团队协作权限、商业支付、外部游戏实际开局/结束事件接入暂不纳入第一版。

## Impact
- Affected specs: external-game-launch、creator-ownership、user-profile。
- 现有 UGC 投稿模块继续拥有投稿审核职责；外链目录拥有公开游戏和管理权，试玩页拥有容器生命周期，时长服务拥有会话计量。
- 首页继续使用当前 `refactor-home-platform-interface` 的视觉基线，不在本 change 改写该 change 的既有完成结论。
- 当前首页、个人页和上传页存在其他未提交工作。后续实施必须保留这些改动，并以实施时文件为准。

## Current Blocker
2026-10-27 本轮请求指定站点首页，返回 HTTP 200、标题“山中小屋”、`X-Frame-Options: DENY`，浏览器会拒绝嵌入。本站增加 iframe 属性无法解除此限制。作者需要调整站点的嵌入策略，允许实际本站来源；调整后还需验证游戏加载、登录、缩放与全屏。

该候选当前只能记为“嵌入被阻止”，可以保留明确的外站打开动作，不能作为 iframe 成功案例。具体信息和未知字段见 [intake.md](intake.md)。

## Review Points
1. 个人中心采用“概览 / 我的投稿 / 我的作品 / 作者认证”，收藏库与作品管理分离。
2. 截图作为认证材料，配合主页临时验证码或后台控制证据，由管理员审核后认领；不凭公开截图自动夺取已有作品。
3. 认领者可直接修改名称、介绍、规则、封面、游戏网址及展示状态；管理者身份、审核结论和统计不能由普通编辑接口修改。

## Validation
实施前先通过 OpenSpec 严格校验。实施后按 tasks.md 分别验权限、投稿和认领生命周期、iframe 与前台计时、PC/手机真实 UI。文档校验不证明运行时或视觉完成。
