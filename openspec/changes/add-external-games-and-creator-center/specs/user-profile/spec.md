## ADDED Requirements

### Requirement: 个人中心的投稿与作品分区
系统 SHALL 在个人中心提供概览、我的投稿、我的作品和作者认证分区，复用原有资料编辑和对局历史，收藏库继续表示玩家收藏。

#### Scenario: 查看我上传的游戏
- **WHEN** 用户进入我的投稿
- **THEN** 只查询本人提交记录，可按草稿/待审核/已收录/已驳回浏览，看到可执行操作和审核意见
- **AND** 已收录的非作者投稿不会自动显示为本人可管理作品

#### Scenario: 查看我的作品
- **WHEN** 用户进入我的作品
- **THEN** 显示服务端确认本人拥有管理权限的作品，能进入编辑、预览和展示状态操作
- **AND** 其他作者的收藏游戏不混入作品管理列表

#### Scenario: 移动端编辑后返回
- **WHEN** 手机用户从投稿或作品列表进入共享编辑器并返回
- **THEN** 原分区、筛选和可达的列表位置保留，必要操作可滚动到达，触控与关闭路径可用

### Requirement: 个人中心状态与真实数据
系统 SHALL 在各分区显示真实的登录、空、加载、错误、无权限和审核状态，不用示例数据填补统计或权限缺口。

#### Scenario: 没有作品的新用户
- **WHEN** 登录用户没有投稿或没有作品
- **THEN** 对应分区给出提交游戏或申请认领的实际入口，不生成虚构作品和认证标记

#### Scenario: 查看外链游玩历史
- **WHEN** 用户在概览查看外链游玩记录
- **THEN** 明确显示估算前台停留口径，与原有胜负对局列表区分，并可返回对应外链详情

#### Scenario: 登录取消或读取失败
- **WHEN** 未登录用户取消登录，或分区请求失败
- **THEN** 保留原访问目标，失败状态可重试，不静默显示空列表或假成功
