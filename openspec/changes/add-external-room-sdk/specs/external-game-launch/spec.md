## ADDED Requirements

### Requirement: 托管网页游戏通过 SDK 接入平台房间
系统 SHALL 根据已公开的托管网页 ZIP 版本自动识别房间 SDK，并允许支持该协议的游戏从详情页创建平台房间。未接入的游戏保留「开始游戏」。

#### Scenario: 刚收录或已经收录的网页包
- **WHEN** 玩家打开携带房间 SDK 的已发布网页游戏详情
- **THEN** 自动显示「创建房间」，作者无需在后台另行配置

#### Scenario: 好友通过邀请加入并开局
- **WHEN** 房主创建房间，已登录的玩家通过邀请加入，所有座位的连接已就绪
- **THEN** 房主可以开始对局，所有玩家从房间直接进入该局，游戏收到平台昵称和各自座位

#### Scenario: 房间固定资源版本
- **WHEN** 房间创建后游戏上传了更新
- **THEN** 该房间继续使用创建时的入口。参与者只接收发给自己的对局连接信令
