## ADDED Requirements

### Requirement: 平台目录展示托管网页游戏的原版房间
系统 SHALL 支持已适配的托管网页游戏从详情页进入游戏自己的建房流程。游戏在平台内创建的房间可在详情页被发现和加入，房间参数及开局由游戏管理。

#### Scenario: 刚收录或已经收录的网页包
- **WHEN** 玩家打开携带房间 SDK 的已发布网页游戏详情
- **THEN** 已适配的游戏显示「创建房间」，点击后打开游戏原有的建房界面

#### Scenario: 好友通过邀请加入并开局
- **WHEN** 房主在游戏内建房，访客在易桌游游戏详情找到该房间并加入
- **THEN** 访客可以直接连接游戏房间，无需另登录易桌游或手工交换连接码，房主在游戏内开局

#### Scenario: 房间固定资源版本
- **WHEN** 房间创建后游戏上传了更新
- **THEN** 该房间继续使用创建时的入口。参与者只接收发给自己的对局连接信令
