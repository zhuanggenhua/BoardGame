## ADDED Requirements

### Requirement: 兽人持续力量与保护效果必须明确宿主和生命周期

兽人的持续力量、基地保护和附着行动保护 MUST 通过统一 authoring / protection surface 表达作用宿主、控制者、触发来源、起效范围与清理时机，不得使用全局布尔值或重复 UI 文案替代领域状态。

#### Scenario: 兽人保护效果只过滤允许的行动影响

- **WHEN** 呆瓜兽人、太难了、洗手间或坑洞命中其它玩家打出的行动
- **THEN** 保护 MUST 只阻止规则要求的本次行动影响
- **AND** 保护 MUST NOT 阻止基地效果、怪物效果、非行动效果或保护控制者自己的行动
- **AND** 宿主离开基地或附着行动被移除后 MUST 清理保护范围。
