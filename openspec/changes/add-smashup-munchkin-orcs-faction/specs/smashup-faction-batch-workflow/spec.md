## ADDED Requirements

### Requirement: 兽人派系玩法必须逐对象接入并保留显式选择

Smash Up 兽人派系的运行时实现 MUST 覆盖 12 张卡牌和 2 个基地的已锁定规则子句，并 MUST 将玩家需要决定的目标、模式、顺序与是否发动交给显式交互；合法候选只有一个时也不得自动代选。

#### Scenario: 兽人对象级实现收口

- **WHEN** 兽人派系被标记为对象级完成
- **THEN** 每张卡牌和每个基地 MUST 有独立的 L2 领域行为结论
- **AND** 涉及真实交互或流程态的对象 MUST 有 L3/L4 真实入口或明确的阻塞记录
- **AND** 代表性链路不得替代未覆盖对象的完成结论。

#### Scenario: 单候选仍需手动选择

- **WHEN** 兽人能力只有一个合法目标、模式、支付物或是否发动候选
- **THEN** 系统 MUST 保留选择态并等待玩家点击 / 确认
- **AND** 领域状态 MUST 在玩家提交该选择前保持不变。
