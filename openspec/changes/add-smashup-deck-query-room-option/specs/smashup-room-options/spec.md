## ADDED Requirements

### Requirement: 大杀四方房间 SHALL 支持余牌查询开关

大杀四方创建房间时 MUST 提供名为 `余牌查询` 的房间设置项，并将其与 `泰坦`、`DIY` 放在同一组多选配置里，默认开启。

#### Scenario: 创建房间时默认开启余牌查询

- **WHEN** 用户打开大杀四方的创建房间面板且未主动修改该选项
- **THEN** 提交的 setup 数据 MUST 将 `余牌查询` 视为开启
- **AND** 对局运行时 MUST 以开启状态初始化对应能力

#### Scenario: 创建房间时显式开启余牌查询

- **WHEN** 用户在创建房间时开启 `余牌查询`
- **THEN** 提交的 setup 数据 MUST 保留该开启状态
- **AND** 对局运行时 MUST 允许牌库查看能力按开启状态工作

### Requirement: 大杀四方牌库查看 SHALL 服从余牌查询开关

大杀四方牌库区 MUST 根据房间的 `余牌查询` 开关决定是否允许展开剩余牌详情。

#### Scenario: 余牌查询关闭时禁止打开剩余牌详情

- **GIVEN** 当前房间的 `余牌查询` 为关闭
- **WHEN** 玩家查看游戏内牌库区
- **THEN** 牌库区 MUST 继续显示当前剩余数量
- **AND** 点击牌堆 MUST 不打开剩余牌详情面板

#### Scenario: 余牌查询开启时允许查看剩余牌详情

- **GIVEN** 当前房间的 `余牌查询` 为开启
- **WHEN** 玩家点击牌堆
- **THEN** 系统 MUST 打开剩余牌详情面板
- **AND** 面板 MUST 继续展示牌库剩余总数与按卡名聚合后的条目

#### Scenario: 余牌查询开启时对手视角也能查看当前视角玩家的余牌

- **GIVEN** 当前房间的 `余牌查询` 为开启
- **AND** 玩家已经切换到另一位玩家的对手视角
- **WHEN** 玩家在该视角下点击牌堆
- **THEN** 系统 MUST 打开当前视角玩家的剩余牌详情面板
- **AND** 面板 MUST 展示该视角玩家的牌库剩余总数与聚合条目
