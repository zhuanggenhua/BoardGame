### Requirement: Betrayal Tutorial Must Depend On Authoritative Runtime

The tutorial system MUST only attach `betrayal` tutorial steps to runtime states that are already backed by authoritative domain topology and rule flow.

- **WHEN** a `betrayal` tutorial chapter teaches pre-haunt movement or exploration

- **AND** it MUST NOT rely on temporary folded room links, synthetic one-slot exploration helpers, or direct endgame injection as its primary runtime path
