## ADDED Requirements
### Requirement: 《七大恨》联机局内剧本介绍与投票
《七大恨》在线房间 SHALL 在进入 match 后先展示独立的局内剧本介绍与投票 setup 页；全部席位完成投票并结算出剧本前，不得直接进入剧本前置或正式棋盘主操作。

#### Scenario: 在线房间先进入剧本介绍与投票
- **GIVEN** 房主创建了一个启用《七大恨》局内剧本投票模式的在线房间
- **WHEN** 任一席位进入该房间对应的 match 页面
- **THEN** 系统先显示独立的局内剧本介绍与投票 setup 页
- **AND** 每个候选剧本都展示可阅读的介绍或摘要
- **AND** 在投票尚未结算前，不得直接暴露剧本前置或正式棋盘主操作
- **AND** 该阶段不得同时渲染正式棋盘的轮盘、手牌、牌库、弃牌或行动栏

#### Scenario: 全部席位投票后结算出本局剧本
- **GIVEN** 一个启用局内剧本投票的《七大恨》在线房间中所有席位都已提交投票
- **WHEN** 系统完成投票结算
- **THEN** 系统按当前票型结算出本局最终剧本
- **AND** 同票时按既定裁定规则处理
- **AND** 结算完成后才进入该剧本对应的人物/军备前置或正式棋盘

### Requirement: 《七大恨》局内 Setup 壳层
《七大恨》系统 SHALL 在 local 与 online 的 match 内使用统一的 setup 壳层承接剧本待决人物与军备；只要当前对局仍有未完成的剧本待决项，正式棋盘主操作就不得暴露为可继续状态。

#### Scenario: 投票结算后待决项存在时进入 setup 页
- **GIVEN** 玩家已经进入《七大恨》对局
- **AND** 当前局内剧本介绍与投票已经结算完成，或当前对局本就不需要经过剧本投票层
- **AND** 当前 `pendingScenarioCharacterChoices` 或 `pendingScenarioArmamentChoices` 仍非空
- **WHEN** 页面准备渲染正式棋盘
- **THEN** 系统先显示专用 setup 页面或等价独立壳层
- **AND** 玩家可以在该壳层内完成当前待决项
- **AND** 正式棋盘不得只剩“被阻断提示”而没有对应操作入口

#### Scenario: 待决项完成后不再重复 setup
- **GIVEN** 当前《七大恨》对局的剧本待决人物与军备都已确认
- **WHEN** 玩家刷新页面或重新进入该对局
- **THEN** 系统直接进入正式棋盘
- **AND** 不得再次要求同一批待决项重复选择

### Requirement: 《七大恨》联机视角隔离
《七大恨》系统 SHALL 按当前座位提供联机私有视图；底部手牌、支付候选与其它私有卡面只能展示给对应座位，不能随着当前行动势力切到其他玩家视角。

#### Scenario: 联机玩家只看到自己的私有手牌
- **GIVEN** 一个《七大恨》联机房间中存在至少两个不同势力
- **WHEN** 某位玩家进入正式棋盘
- **THEN** 底部手牌区只显示该玩家所属势力的手牌
- **AND** 其他势力的私有手牌不会以完整卡面或可操作对象形式出现在该玩家视图中

#### Scenario: 当前行动势力变化时不串视角
- **GIVEN** 当前回合控制权从一个势力切换到另一个势力
- **WHEN** 非当前势力玩家继续停留在自己的联机页面
- **THEN** 页面仍保持该玩家自己的私有视图
- **AND** 不得因为 `currentPlayer` 变化直接把底部手牌和可操作对象切成别人的内容

### Requirement: 《七大恨》一级到二级行动壳
《七大恨》正式棋盘 SHALL 先让玩家锁定当前一级行动，再在固定槽位展示对应的二级步骤、确认入口与取消/返回语义；未成为当前主交互对象的地图点击或旁路按钮不得继续抢焦点。

#### Scenario: 一级行动先锁定再进入二级步骤
- **GIVEN** 玩家已进入《七大恨》正式棋盘的行动窗口
- **WHEN** 玩家准备执行一个势力行动
- **THEN** 页面先清晰展示当前可选的一级行动列表
- **AND** 只有在玩家锁定其中一个一级行动后，才显示该行动的支付、目标选择或后续步骤
- **AND** 二级步骤的确认入口与取消/返回入口都停留在固定交互槽位

#### Scenario: 非当前步骤对象不会继续到处可点
- **GIVEN** 玩家已经进入某个一级行动的二级步骤
- **WHEN** 当前步骤只允许支付手牌、选择按钮候选或点击指定地图目标
- **THEN** 与当前步骤无关的地图区域、旁路按钮或其它一级行动不得继续表现为同级可操作入口
- **AND** 首屏必须能直接看出当前唯一下一步点哪里

### Requirement: 《七大恨》高风险战斗链必须具备端到端证据
《七大恨》在派兵攻城、战后处理等高风险流程上的验收 SHALL 以真实端到端链路和关键前后态截图证明，不得只靠局部 UI 存在或单步断言收口。

#### Scenario: 首回合核心动作具备关键前后态证据
- **GIVEN** 开发者宣称《七大恨》首回合核心流程已经可跑通
- **WHEN** 查看该轮 E2E 证据
- **THEN** 证据中至少包含入口后、一级行动锁定后、关键二级步骤中、关键步骤执行后的真实页面截图
- **AND** 每张关键前图都能直接看出下一步主操作落在哪里
