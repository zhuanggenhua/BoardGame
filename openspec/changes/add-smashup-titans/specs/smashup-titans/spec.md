## ADDED Requirements

### Requirement: 泰坦必须作为大杀四方的一等公民牌种被建模
系统 MUST 把泰坦建模为区别于随从、行动、融合和基地的正式牌种，并为其维护 owner、controller、位置、指示物与每回合状态。

#### Scenario: 选择带泰坦的派系后初始化 set-aside 泰坦
- **GIVEN** 玩家选择了一个带官方泰坦的派系
- **WHEN** 阵营选择完成并初始化对局
- **THEN** 对应泰坦必须出现在该玩家的 set-aside 区
- **AND** 该泰坦不能进入玩家的牌库、手牌或弃牌堆

#### Scenario: 泰坦离场后回到牌库旁
- **GIVEN** 一个泰坦当前在某个基地上
- **AND** 它因为 destroy、return、place、基地离场或计分清场而离场
- **WHEN** 离场结算完成
- **THEN** 该泰坦必须回到其 owner 的 set-aside 区
- **AND** 该泰坦上的力量指示物必须被清空

### Requirement: 泰坦只能在规则允许时被打出并立即完成
系统 MUST 只允许在卡牌或泰坦自身明确授权时打出泰坦；打出泰坦始终是可选的，并且一旦选择打出就必须立即完成。

#### Scenario: 没有授权时不能打出泰坦
- **GIVEN** 某玩家拥有一个处于 set-aside 的泰坦
- **AND** 当前没有任何能力允许其打出该泰坦
- **WHEN** 玩家尝试打出该泰坦
- **THEN** 系统必须拒绝该操作

#### Scenario: 已控制泰坦时不能再打出第二个泰坦
- **GIVEN** 某玩家已经控制一个在场泰坦
- **WHEN** 另一个效果允许该玩家打出另一个泰坦
- **THEN** 系统必须阻止该玩家打出第二个泰坦

#### Scenario: 以“代替常规随从或行动打出”时只消耗常规额
- **GIVEN** 某泰坦的授权文本要求“代替你的常规随从打出”或“代替你的常规行动打出”
- **WHEN** 玩家按该授权打出泰坦
- **THEN** 系统必须只消耗对应的常规出牌额
- **AND** 不能把这次打出记为额外出牌

#### Scenario: 可按随从方式打出的泰坦可以进入“打出一个随从”候选
- **GIVEN** 某泰坦声明自己可以按随从方式被打出
- **AND** 一个效果要求玩家选择一个可打出的随从
- **WHEN** 系统计算该效果的合法候选
- **THEN** 该泰坦必须可以作为合法候选被展示与选择

#### Scenario: 按随从方式打出不会改变泰坦牌种
- **GIVEN** 某泰坦刚刚通过“按随从方式打出”的规则进入基地
- **WHEN** 后续效果检查它的运行时牌种
- **THEN** 系统仍必须把它视为 `titan`
- **AND** 不能因此让“仅能选择 minion 或 action 的目标效果”错误命中它

### Requirement: 泰坦打出与移动必须遵守控制权和 clash 规则
系统 MUST 支持泰坦的打出、移动和控制权规则，并在标准基地上于双泰坦同基地时触发 clash。

#### Scenario: 打出别人的泰坦会改变控制权但不改变 owner
- **GIVEN** 一个效果允许玩家打出一个不属于自己的泰坦
- **WHEN** 该玩家成功打出该泰坦
- **THEN** 该玩家必须成为该泰坦当前的 controller
- **AND** 该泰坦的 owner 必须保持为原持有该派系的玩家

#### Scenario: 移动别人的泰坦不会改变控制权
- **GIVEN** 某玩家通过效果移动了另一名玩家已在场的泰坦
- **WHEN** 移动完成
- **THEN** 该泰坦的位置必须改变
- **AND** 其 controller 不能因为这次移动而改变

#### Scenario: 标准基地上双泰坦必须 clash
- **GIVEN** 一个标准基地上已有一个泰坦
- **WHEN** 另一个泰坦被打出或移动到该基地
- **THEN** 系统必须比较双方在该基地的总力量
- **AND** 总力量较低一方的泰坦必须离场回到其 owner 的 set-aside 区
- **AND** 若总力量相同，则先在场的泰坦必须保留

#### Scenario: 允许多泰坦的基地可以显式跳过 clash
- **GIVEN** 某基地显式声明允许多个泰坦共存
- **WHEN** 第二个泰坦进入该基地
- **THEN** 系统必须保留两个泰坦
- **AND** 不能触发默认 clash

### Requirement: 泰坦必须正确参与计分资格与清场
系统 MUST 将泰坦纳入力量与计分规则，但不能把泰坦误当作随从。

#### Scenario: 泰坦本体不算随从
- **GIVEN** 某玩家在一个基地上只有泰坦、没有随从
- **AND** 该泰坦没有提供任何总力量
- **WHEN** 该基地计分
- **THEN** 该玩家不能仅凭该泰坦获得该基地的 VP

#### Scenario: 泰坦的力量指示物或能力可提供计分资格
- **GIVEN** 某玩家在一个基地上没有随从
- **AND** 该玩家的泰坦通过指示物或能力提供了至少 1 点总力量
- **WHEN** 该基地计分
- **THEN** 该玩家必须被视为满足“至少 1 点总力量”的得分资格

#### Scenario: 计分清场时泰坦不进入弃牌堆
- **GIVEN** 某基地完成计分并开始执行清场
- **WHEN** 系统清理该基地上的卡牌
- **THEN** 随从与行动必须按原规则进入各自拥有者的弃牌堆
- **AND** 在该基地上的泰坦必须回到其 owner 的 set-aside 区

### Requirement: 泰坦必须被正确纳入目标选择与 UI 展示
系统 MUST 在需要时把泰坦暴露为可选择对象，并在 UI 中展示其 set-aside/在场状态。

#### Scenario: 只能影响 card 的效果可以选择泰坦
- **GIVEN** 一个效果明确可以选择任意 card
- **AND** 场上存在一个合法泰坦目标
- **WHEN** 玩家打开该效果的选择界面
- **THEN** UI 必须把该泰坦显示为合法可选项

#### Scenario: 只能影响 minion 或 action 的效果不能误选泰坦
- **GIVEN** 一个效果只能选择 minion 或 action
- **AND** 场上存在泰坦
- **WHEN** 玩家打开该效果的选择界面
- **THEN** UI 不能把泰坦显示为合法可选项

#### Scenario: 玩家能看到自己 set-aside 和在场的泰坦状态
- **GIVEN** 一场包含泰坦的对局已经开始
- **WHEN** 玩家查看大杀四方界面
- **THEN** 玩家必须能看到自己哪些泰坦处于 set-aside
- **AND** 也必须能看到当前在各基地上的泰坦及其控制者与指示物数量

#### Scenario: 可用泰坦必须显示在牌库右侧
- **GIVEN** 当前视角玩家有至少一个处于 set-aside 的泰坦
- **WHEN** 玩家查看自己的牌库与弃牌堆区域
- **THEN** 这些可用泰坦必须排列在牌库右侧
- **AND** 它们不能混入手牌区或弃牌堆展示

#### Scenario: 有持续行动时泰坦显示在持续行动上方一排
- **GIVEN** 某基地上有持续行动牌
- **AND** 该基地上有一个或多个泰坦
- **WHEN** UI 渲染该基地
- **THEN** 泰坦必须显示在持续行动牌上方的一排独立区域

#### Scenario: 没有持续行动时泰坦显示在基地上方
- **GIVEN** 某基地上没有持续行动牌
- **AND** 该基地上有一个或多个泰坦
- **WHEN** UI 渲染该基地
- **THEN** 泰坦必须显示在基地卡正上方的独立区域
