# 执行设计与来源

## 正常行动链先行

正式萨尔浒后开局，顺位蒙古→后金→大明，轮盘从新年位置开始但不先执行一次新年。每回合先检查超限并移动轮盘，再自由安排手牌行动与落点行动。普通成对格开放两项，季节格择一，跨季节必须停。初始纪年为Card1301，其余十二张真实普通纪年洗牌；教程仅固定一次合法洗牌与骰序，不在中途改部队、资源、顺位或卡面。

正式管线、真实浏览器与视觉验收均已完成；具体牌序、节点、范围和证据以[当前作者总账](../../../docs/games/qidahen/records/qidahen-annual-tutorial-design-20261030.md)及[验收记录](../../../docs/games/qidahen/records/qidahen-annual-tutorial-acceptance-20261031.md)为准。以下保留提案层流程概览。

| 正常局面 | 正式动作与用途 | 教学落点 |
|---|---|---|
| 蒙古、后金先行动 | 各移动一格并完成真实回合；保持首年顺位 | 首张可见卡前可用合法自动命令建立大明回合，不伪造大明首动 |
| 大明首次到开垦/军屯 | 在辽北征召6支正规军，完成军屯获取手牌和1支部队 | 手牌资源、势力行动、区域本土资格、人口与军队；只教当前输入 |
| 轮盘推进至年中 | 到达者选格内合法动作，再全体税赋、江南漕运、符合条件的人物判定 | 人口大于兵力才收税；实际补牌后才解释超限 |
| 大明从辽北出兵 | 支付轮盘调度费，先来源、具体部队、再叶赫目标；用实际鸳鸯阵与权威骰序战斗 | 河流宽度2、炮兵不占宽度、战术骰级、炮/骑/步的真实先后及损伤 |
| 战后占领或撤退 | 依真实结果提交战后选择；保留未出动部队 | 领土控制与实际移动结果，不用同局继续作为课程 |
| 大明进入外交/雇佣 | 影响实际相邻目标，支付并选择雇佣军建立区域 | 友好/附庸两面和雇佣军来源；普通格两项独立 |
| 轮盘停在新年 | 格内动作后，朝贡、五项维护、各区域耗损、纪年领取、新卡顺位与人物 | 全部由真实归属玩家选择；按所选新纪年条件、旧顺位打破平局，可拒付顺延 |
| 新年度的大明训练 | 自然走到征兵/训练，实际弃牌、选部队升级、结束行动 | 一回合每支部队仅训练一次；解释当下可见炮兵科技上限 |

规则源和争议字段分别在 `test-results/qidahen-annual-card-source-review.md`、`qidahen-annual-maintenance-source-review.md`、`qidahen-character-errata-source-review.md`。普通纪年的人物统一择一，孙元化/袁崇焕先检查东林前提；魏忠贤额外人物另行真实选择。卡面阿敏3重叠、9/10缺项等局部未决不能用默认无效果掩盖。

## Owner

- 来源选择扩展现有regionFocusState.lockedSourceRegionId；候选与确认共用pendingTargetActionBuilder正式合法性，不再由兵力排序代选。
- 轮盘移动只提交移动和对手抽牌；`TimingOpportunitySystem`创建共享`ResolutionFrame`，恢复点在frame元数据，不另存core年度cursor。`turnResolutionSystem`投影同一ChoiceRequest并发领域事实，`turnResolutionFacts`只在正式reducer结算。UI、校验和自动玩家消费相同候选。
- 年度维护、耗损、纪年费用均处理真实手牌实体；Korea回独立弃牌。旧直接季节结算与预选人物owner必须退出后才可收口。
- 共享 `TutorialSystem` 的 `AI_CONSUMED` 回执按 `stepId` 对齐当前教程步骤；迟到的旧步骤回执不会清除新步骤尚未执行的AI动作。
- 地图所有合法区域继续按真实边界高亮；教程只强调这次推荐的目标。部队逐实体选择，候选绿、已选金；手牌沿用半露、悬停抬起和共享放大镜。新行动面板复用原右侧槽，不能复制地图事实或规则摘要墙。
- 战斗物理骰子复用lib/dice-physics/DiceBoxPhysicsSource，游戏侧窄组件只编排阶段与权威骰值。教程复用已有waitForAnimation/animationComplete，不新建教程动画门禁。

## 共享骰子扩展护栏

旧语义：d6/d12权威指定结果、物理投掷、材质与停稳回调保持。消费者：Betrayal使用d6及牌面皮肤，公共测试覆盖d6/d12默认与恢复/重掷；七大恨新增d8/d10数字骰。只扩展骰种联合及缺少preset时的面数，不改变旧骰种时序/皮肤/fallback顺序。保护：公共引擎与PhysicsSource现有测试、新增多面骰面值边界测试，以及七大恨真实页面投掷中、停稳与伤害连续证据。
