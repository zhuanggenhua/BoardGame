# Change: update qidahen board interaction shell

## Why
当前《七大恨》虽然已经把剧本待决项移到前置页，但正式棋盘里的交互壳层仍然不够稳定：右侧行动区、底部手牌交互区、轮盘推进入口和关键截图证据之间缺少统一约束，导致用户仍可能遇到“下一步不明显”“支付/弃牌与主棋盘混屏”“关键交互截图看不出是哪一步”的问题。

## What Changes
- 为《七大恨》建立棋盘交互壳层规范，明确右侧行动区与底部手牌交互区的固定职责与固定槽位。
- 要求轮盘阶段的唯一下一步必须提供明文按钮入口，而不是只靠点击左侧轮盘盘面。
- 要求支付/弃牌类交互通过底部手牌区承接，必须保留确认与取消语义，不得静默消耗成本。
- 要求关键交互证据截图使用中文语义命名，能直接表达当前阶段、动作对象和交互状态。

## Impact
- Affected specs: `qidahen-board-ui`
- Affected code: `src/games/qidahen/Board.tsx`, `e2e/qidahen*.e2e.ts`, 七大恨截图证据目录
