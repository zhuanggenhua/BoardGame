## ADDED Requirements

### Requirement: 牧师持续效果必须有独立生命周期和作用宿主

牧师附着行动、基地行动和回合临时力量效果 MUST 明确作用宿主、起效时机、清理时机与离场行为，不得用常驻全局加成或重复 UI 文案代替领域状态。

#### Scenario: 回合临时力量清理

- **WHEN** 好习惯或加入团队结算本回合力量加成
- **THEN** 加成 MUST 影响规则要求的仆从范围
- **AND** 回合结束后 MUST 自动清理
- **AND** 新进入仆从是否受影响 MUST 按已锁定牌面语义验证，不得默认外推

#### Scenario: 附着行动移除

- **WHEN** 监禁诅咒或无用诅咒被摧毁、移动或宿主离场
- **THEN** 对应能力压制或力量排除 MUST 从最终权威状态中移除
- **AND** 不得残留到其他仆从或其他基地
