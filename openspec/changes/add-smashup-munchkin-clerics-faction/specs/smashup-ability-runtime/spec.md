## ADDED Requirements

### Requirement: 牧师能力必须消费现有 Smash Up 领域合同

牧师能力实现 MUST 复用现有 Smash Up 的交互、事件、触发器、持续修正、牌库和计分清场消费点；若共享合同无法表达牌面语义，MUST 先补共享合同或登记明确阻塞，不得用静态标签冒充玩法实现。

#### Scenario: 弃牌堆随机回收

- **WHEN** 牧师卡牌从己方弃牌堆随机回收牌
- **THEN** 被回收牌 MUST 从原弃牌堆移除并进入当前玩家手牌或牌库
- **AND** 数量不足、弃牌堆为空或玩家跳过时 MUST 有明确的最终状态

#### Scenario: 跨玩家临时行动

- **WHEN** 回忆祷词从其他玩家弃牌堆各随机展示一张行动
- **THEN** 未被打出的行动 MUST 返回原拥有者弃牌堆
- **AND** 被打出的行动 MUST 作为当前玩家的额外行动结算
- **AND** 不得把原拥有者的牌静默转移到当前玩家弃牌堆
