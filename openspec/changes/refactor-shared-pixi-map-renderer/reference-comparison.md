## 证据及边界

- 代码基线：2026-10-13 从 `origin/main` fetch 核对的 `b8098ee12e389e54e01eb5a22a41eef82a94e44f`。云端新工作区 `BoardGame`，分支 `feat/reference-interaction-plan`；原审查工作区保留不动。当前采用 sparse checkout，尚未安装运行时依赖或验收本项目页面。
- B：此前实际操作 [山中小屋第三版](https://yuanyigames.top/) 单人模式，到第 9 轮、第 27 回合、作祟 20「不要说出来」、叛徒胜利；覆盖探索、放房间、事件骰子、可选重掷、伤害分配、跨楼层、作祟、战斗、死亡与结局后查看棋盘。此处记录实玩结果，不把它冒充本项目的截图验收。
- C：此前在用户授权的内置浏览器实际操作 [Old King’s Crown](https://oldkingscrown.fly.dev/)，自己的对局 （测试房间地址省略）。完成第一年，第二年第三场冲突后连接中断，未确认整局结局。覆盖竞价、部署、拖动调兵、战术、胜负、奖励、跨年补牌与日志。该游戏是参考，不是我方七大恨。
- U：用户已锁定逐格 hop、每格脚步、路径线、reach、门口呼吸灯、落地 ripple、镜头跟随。`0.3s / 16px` 是用户提供的参考参数，未独立逐帧测量；材质脚步声也未独立听音验收。落地参数须在我方正常缩放和真实页面验证，不宣称数值复刻等于体验通过。
- 未测项：我方当前运行时 FPS、输入延迟、GPU 内存、两站逐帧成本；C 的惯性细节和结局。以下静态代码风险不等于已经复现的运行时 bug。

## 直接补进提案的 12 条增量

已锁定的直选、`?` 入口和回合 skip 不再列作新功能。

1. **P0 / M1**：普通相邻移动从 560ms 平移改为可调一次 hop；起跳、途中、落地、实体接管可见，跨层/传送不伪装普通步行。0.3s/16px 仅作首轮候选。
2. **P0 / M2**：脚步按正式材质配置，绑定每步落脚而非点击；开门、房间入场音绑定对应阶段，不重复播放同一事件。
3. **P0 / M3**：选中移动对象时显示正式合法路径及成本，门口呼吸仅装饰已合法的候选；不伪造多格可达性。
4. **P0 / M4**：落地 ripple 与目标接管同阶段；取消/拒绝/回滚能释放占用，不能出现双棋子或永久等待。
5. **P0 / M5**：相机跟随服务于看清当前对象，保留玩家 pan/zoom；手动操作优先，不因投骰/详情关闭回中。
6. **P0 / M6**：Pixi 与保留的 DOM 地图对象消费同一显示变换；单一输入 owner，拖动后不误点、缩放锚点不漂，性能按同入口 A/B 实测。
7. **P1 / D1**：探索、朝向选择、放置、房间入场、进入和触发结果按现有规则顺序承接；没有决策不加“继续”，有声明不自动跳过。
8. **P1 / D2**：光雾只营造层次，交互层不拦截；按事件/视窗生命周期启停，卸载清理，降低动态偏好时保留必要结果。
9. **P2 / I1**：当前决策的候选、已选、确认与结果处于同一稳定阅读区，选项持续可见且可用态同源；不增加解释实现的文案。
10. **P2 / I2**：提交前的可逆分配从结果所在位置撤回，重新选择能恢复；属性轨道/资源变化贴所属对象表达。
11. **P2 / I3**：满载部署和窄屏选择态中，固定 HUD 与地图目标均可读可点；优化保护槽位，不靠强制隐藏主信息实现“清爽”。
12. **P2 / I4**：检视关闭、结果收口与已有结局回看保留合法局面及镜头；需要的原因写入共享日志，不新建常驻重复摘要。

## 分期、边界和评审

1. 用户已批准实玩增量，最新要求小黑屋统一 Pixi 并先完整做好，保留当前美术。七大恨实施暂停；不建立第三套框架。
2. P0 统一在 Betrayal：复用已有 Pixi，完成地图/对象/相机与事件→hop→声音→落地。七大恨仅作为兼容消费者回归，不继续其迁移。
3. P1 再接发现场景与光雾；P2 按实测缺口补选择、部署和回看，不重做已合格组件。
4. 可复用能力只从已通过的实际消费者抽取；本轮按用户明确要求把 Betrayal 地图场景迁到 Pixi，不重写 DomainCore、Pipeline、socket 或 AudioManager。
5. 每段实施后做代码 review 和最窄回归，再从真实入口看实际过程。旧 r8/r9 图、测试绿灯和代码静态推断不作为本轮 UI 通过证据。

拒绝：高频按钮复杂进出动画（增加等待）；照搬墨水皮肤（不属于能力）；统一全屏等待遮罩（抢操作）；为了结局回看新增第二套日志（已有 owner）；为所有游戏预建 PresentationDirector（没有当前消费者证据）。
