## ADDED Requirements

### Requirement: 管理员可在任意线上对局使用调试面板

生产环境 SHALL 仅允许当前角色经服务端确认的 `admin` 账号在任意线上对局使用现有 `GameDebugPanel`；管理员无需占用对局座位。面板发起的调试操作 SHALL 通过服务端管理员授权通道执行。

#### Scenario: 管理员调试未占座的线上对局
- **GIVEN** 用户已登录且服务端确认当前角色为 `admin`
- **WHEN** 用户打开任意生产线上对局，即使没有该对局的座位凭据
- **THEN** 系统显示现有对局调试面板并允许使用受支持的调试操作
- **AND** 调试操作由游戏服务器执行并广播权威结果

#### Scenario: 普通用户或开发者访问线上调试面板
- **GIVEN** 用户角色为 `user` 或 `developer`，或其管理员角色无法由服务端确认
- **WHEN** 用户打开生产线上对局或伪造调试请求
- **THEN** 系统不向其开放调试面板
- **AND** 游戏服务器拒绝管理员调试操作

#### Scenario: 管理员创建新房间并离开当前对局
- **GIVEN** 管理员在生产线上对局使用会销毁当前房间的新建房间操作
- **WHEN** 系统准备离开并销毁当前对局
- **THEN** 系统必须先要求管理员明确确认

#### Scenario: 开发和教程调试
- **GIVEN** 对局处于开发 / E2E 调试环境或教程流程
- **WHEN** 现有测试或教程执行调试状态注入
- **THEN** 系统保留原有行为，不要求管理员身份
