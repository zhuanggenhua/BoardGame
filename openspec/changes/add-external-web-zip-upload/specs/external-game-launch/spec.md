## ADDED Requirements

### Requirement: 上传独立静态网页游戏
系统 SHALL 通过外部游戏投稿接收静态网页 ZIP，并保持入口与资源的相对目录及原始文件内容。IP 直连部署沿用平台公网 IP，上传网页在隔离的浏览器沙盒中运行，平台按游戏保存网页存档。收录与更新沿用正式审核。

#### Scenario: 先选择投稿类型
- **WHEN** 投稿者新建外部游戏投稿
- **THEN** 同时显示两个初始未选的投稿类型，选择游戏链接后显示网址输入框，选择网页 ZIP 后显示文件上传入口

#### Scenario: 上传并收录
- **WHEN** 投稿者上传一个具有唯一入口的静态网页 ZIP 并通过审核
- **THEN** 目录显示一款游戏，玩家可从开始游戏进入包内网页

#### Scenario: 更新时已有会话继续
- **WHEN** 已收录网页游戏的替换 ZIP 通过审核
- **THEN** 之后打开的页面使用审核通过的入口，已打开的会话继续使用原入口及其资源
