# Change: 外部网页游戏 ZIP 投稿

## Why
已有完整静态网页的投稿者需要直接上传原包，并能在不干扰已有会话的情况下提交更新。

## What Changes
- 在现有外部游戏投稿中接受带 `index.html` 的静态网页 ZIP，沿用封面、草稿及审核流程。
- 游戏包按投稿分配独立网页来源，同一投稿使用稳定来源。每次上传的文件通过内容摘要定位，审核通过后切换当前入口。
- 现有内嵌会话继续使用打开时的地址，更新验证使用本地《永恒之谷》原包。

## Impact
- Affected specs: external-game-launch。
- 用户已授权本地实现、测试及截图。游戏源文件按输入原样托管。
