## ADDED Requirements

### Requirement: 《七大恨》教程 MUST 从正式开局教会一个完整主循环
《七大恨》教程 SHALL 从正式开局出发，真实示范一个完整主循环：手牌上限、轮盘推进、一次手牌行动、一次轮盘行动，并让玩家看清每一步真实点击落在哪个对象上。

#### Scenario: 基础章从正式开局进入完整回合
- **GIVEN** 玩家从《七大恨》教程目录进入基础章
- **WHEN** 教程开始
- **THEN** 教程必须从正式开局进入
- **AND** 玩家必须真实看到并完成手牌上限、轮盘推进、一次手牌行动和一次轮盘行动
- **AND** 每一步截图证据都必须能指出真实点击对象，而不是只看横幅或说明文字

#### Scenario: 横幅只做提示不冒充交互入口
- **GIVEN** 基础章或后续章节出现顶部横幅、右侧步骤卡或地图提示条
- **WHEN** 当前真实点击对象落在轮盘、手牌、地图目标或按钮本体
- **THEN** 教程文案必须直接指向那个真实对象
- **AND** 不得把横幅、摘要或说明卡写成交互入口本身

### Requirement: 《七大恨》教程 MUST 覆盖关键规则面而不是只跑代表链
《七大恨》教程 SHALL 以玩家主章节或明确子章节的形式覆盖关键规则面，至少包括：进攻与野战、战败撤退、攻城与围城、轮盘发展分支、年中与新年、朝鲜与地图特例；对于中立入侵、水路移动、战术牌、避战/劫掠、守城宣告或骑兵城战减值、朝鲜朝贡或朝鲜耗损，必须至少补齐一条真实章节链或真实截图证据。

#### Scenario: 战斗章节覆盖战术或特殊移动分支
- **GIVEN** 玩家进入《七大恨》战斗相关教程
- **WHEN** 教程讲解野战与调度
- **THEN** 教程除了基础进攻链外，还必须至少真实覆盖以下之一：中立入侵、水路移动、战术牌、避战、劫掠
- **AND** 对应章节或截图必须来自真实可操作链路

#### Scenario: 攻城与地图特例覆盖剩余关键规则
- **GIVEN** 玩家进入攻城、跨年或朝鲜相关教程
- **WHEN** 教程讲解城战、维护或地图特例
- **THEN** 教程必须至少真实覆盖以下之一：守城宣告、骑兵城战减值、朝鲜朝贡、朝鲜耗损
- **AND** 不得只用摘要文案代替真实流程证据

### Requirement: 《七大恨》教程文案 MUST 只解释游戏事实
《七大恨》教程文案 SHALL 只解释规则动作、对象、成本、限制和结果；不得解释“这段教程为什么这样编排”、不得使用作者旁白腔，也不得在主 UI 常驻说明里重复画面已经表达的东西。

#### Scenario: 教程不会解释编排理由
- **GIVEN** 玩家正在阅读某一步教程说明
- **WHEN** 该说明解释当前为什么要做某个动作
- **THEN** 文案必须落在游戏规则事实上
- **AND** 不得出现“这道示范题先这样做”“这不是通用规则”“为了教学方便”之类的编排解释

#### Scenario: 教程不会把主 UI 写成说明书
- **GIVEN** 正式棋盘处于教程模式
- **WHEN** 玩家观看常驻 UI 上的标题、步骤卡、横幅或摘要
- **THEN** 这些文字只能承担对象名、状态、成本、结果或单步动作提示
- **AND** 不得长期显示“这一步做什么”“现在看哪里”“画面已经高亮了还再说一次”的描述性正文

### Requirement: 《七大恨》教程验收 MUST 以真实截图和步骤点击说明收口
《七大恨》教程的验收 SHALL 使用真实章节截图收口。每张关键截图必须能同时回答：当前处于哪条规则链、下一步真实点哪里、点完后规则上会发生什么。

#### Scenario: 关键截图具备可读步骤语义
- **GIVEN** 开发者提交《七大恨》教程章节验收结果
- **WHEN** 审查关键截图
- **THEN** 每张关键截图都必须能用中文语义文件名或配套说明表达当前规则阶段
- **AND** 必须说明真实点击对象落在轮盘、手牌、地图目标或按钮中的哪一个
- **AND** 不得只给截图路径而没有点击对象说明
