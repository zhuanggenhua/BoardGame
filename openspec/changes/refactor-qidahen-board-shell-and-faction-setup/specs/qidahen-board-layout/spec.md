## ADDED Requirements
### Requirement: 《七大恨》地图 Scene 与 HUD 独立适配
《七大恨》正式棋盘 SHALL 使用铺满真实 viewport 的单一交互地图 Scene，并使用独立 HUD 层承载玩家状态、轮盘、手牌和动作控件；`1920x1080` 只能作为内部设计尺寸，不能成为页面最大宽度或固定视觉边界。

#### Scenario: 宽屏地图铺满且 HUD 完整
- **GIVEN** 玩家使用宽于 `1920x1080` 比例的桌面视口进入《七大恨》棋盘
- **WHEN** 页面完成布局
- **THEN** 交互地图 Scene 铺满真实 viewport
- **AND** 页面左右不得出现固定舞台外的纯色边块、黑条或额外补图拼接边
- **AND** 玩家状态、轮盘、手牌和动作控件完整可读可点

#### Scenario: 地图缩放与 HUD 互不带动
- **GIVEN** 玩家已经进入《七大恨》正式棋盘
- **WHEN** 玩家缩放或平移地图
- **THEN** 地图图像、地图 token 和地图命中区域使用同一变换
- **AND** HUD 的位置和尺寸不随地图缩放或平移改变
