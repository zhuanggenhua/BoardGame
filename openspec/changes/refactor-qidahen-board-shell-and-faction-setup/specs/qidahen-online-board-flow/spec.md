## ADDED Requirements
### Requirement: 《七大恨》局内阵营确认
《七大恨》在线房间 SHALL 在剧本确定后、人物与军备前置前显示阵营确认页；每个玩家必须确认一个当前剧本可用且未被其他玩家占用的阵营，全部确认前不得进入正式棋盘。

#### Scenario: 玩家确认唯一阵营
- **GIVEN** 房主已经确定本局剧本
- **AND** 当前仍有玩家未确认阵营
- **WHEN** 玩家打开阵营确认页
- **THEN** 页面展示当前剧本可用阵营及其占用状态
- **AND** 玩家只能选择未被其他玩家占用的阵营
- **AND** 正式棋盘、人物前置和军备前置均不显示

#### Scenario: 全部阵营确认后进入各自前置
- **GIVEN** 每个玩家都已选择互不重复的合法阵营
- **WHEN** 最后一位玩家提交有效选择
- **THEN** 系统按选择结果更新玩家与阵营归属
- **AND** 当前行动玩家同步为开局阵营的所属玩家
- **AND** 页面进入人物与军备前置
- **AND** 每位玩家只看到自己阵营的私有前置内容
