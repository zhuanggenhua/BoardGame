## 目标与验收矩阵

1. 修前使用真实服务生成多间可加入房间，在375×812和360×702复现列表窗口；对照改前压力图，锁定尺寸、摘要占用、首屏可见行和末项可达性后修复。保留正常空态/少量房间及长介绍/完整动作压力态。
2. 头像统一提供默认、项目内置预设、自行上传裁剪。账户设置与现代个人资料入口共用同一选择owner，验证保存、刷新、重新登录和账户隔离；默认恢复不残留上传图。
3. 关于移除重复支付二维码，支持作者入口仍承载二维码。保留关于自身信息和赞助名单职责，不借机改经典首页。
4. 所有受影响PC与手机界面逐项列出同状态对照，不把少拍数字变化或重复返回当成免除PC。行为与视觉分别记录；只交当前发生UI变化的整屏图。

## 已定位与实现

- 修前真实单房间：375与360的抽屉都只有407px，房间窗口73px。八房间夹具反而撑出640/561.6px，旧压力图掩盖了常态塌缩。现代手机抽屉改为既有尺寸的稳定高度；PC继续按内容自然增长，不强行套用手机固定高度合同。
- `AvatarUpdateModal`成为默认、六款预设与上传裁剪的唯一选择入口；账户设置与现代个人资料共用，继续使用既有update-avatar/upload-avatar接口。恢复默认保存项目默认资源，不增加后端影子状态。
- 关于删除重复的支持作者内容；项目链接、联系及赞助名单保留。支付二维码继续由支持作者入口承担。
- 实际核图又发现反馈自动预览丢失封面。新增浏览器图像内容断言先红：王权封面区域100个采样中彩色像素为0。页面使用的blob/外部图片不能由导出的foreignObject SVG继续读取；修复仅在截图副本内嵌可见图片，不修改原页面素材、隐藏错误或移除校验。桌面、手机及宽屏修后断言均通过，当前三张反馈原图均已实际核对封面。
- 触控扩审加入光标变体的实际横向滚动。滚后关闭失败没有靠修改产品或改成鼠标规避：隔离对照中，同一手势保留CDP会话时触摸及click完整、面板关闭；提前detach时只有触摸、没有click，面板仍在。修正测试会话生命周期、使用有时间间隔的真实触摸move；手机滚动、末列可达、关闭、随后反馈预览整条链已通过。诊断脚本留在临时区，未留下必定失败的正式测试。
