# 首页全部退回后的交叉复审

> 后续状态：用户在2026-10-25进一步否决头像上传及无来源设计，要求所有功能逐项匹配PC和移动参考。本文旧96图的整体最终资格已撤回，观察与行为日志留作历史；当前来源查证见 [逐功能双端参考](reference-reacceptance-20261025.md)。

本记录承接用户的“全部打回重新验收”，不是新增 AI 规范。对象是被退回的现代首页双端界面，以及补漏的登录、注册、找回密码状态。经典首页组合不改；不提交、推送或部署。行为与图面结论分账，用户最终验收尚未完成。

## 原始问题与商业真相来源

手机头像上传写“拖拽”是实际设备文案错误，不能拿桌面合法拖放或上传接口成功替代手机可用性。旧测试直接给隐藏文件输入设置文件，没有证明普通用户能从可见按钮开始上传。

本轮实际读取 [官方手机入门中的头像流程](https://support.discord.com/hc/en-us/articles/360046618751-Getting-Started-on-Mobile) 及其[原始手机动图](https://support.discord.com/hc/article_attachments/22330093411095)，逐张查看第零、二十五、六十、九十五帧的完整画面。借鉴点击上传、选择图片、裁剪后确认；不照搬颜色或原生底部面板。项目仍保留默认、预设、自行上传三来源和既有浮窗。

系统照片选择器界面不在浏览器截图里；测试只证明真实按钮唤起文件选择事件，然后由自动化提供文件。没有把浏览器仿真的触控和聚焦说成原生手机软键盘验收。
