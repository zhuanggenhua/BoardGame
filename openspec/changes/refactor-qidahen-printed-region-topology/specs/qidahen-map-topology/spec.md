## ADDED Requirements
### Requirement: 七大恨印刷正式区单一真相
系统 SHALL 让 `qidahen` 的正式地图区域直接来源于印刷原图上的闭合命名区，而不是来源于运行时逻辑区的借位 id、名称覆盖或历史合并结果。

#### Scenario: 根据手绘边界生成正式区
- **WHEN** 开发者在七大恨地图工具中使用已保存边界生成正式区域
- **THEN** 系统 MUST 以自动填充后的闭合区作为正式区候选
- **AND** 每个存在地区名的独立闭合区 MUST 能被表示为独立正式区

#### Scenario: 存在逻辑区借位命名
- **GIVEN** 某个运行时逻辑区当前复用了其他印刷区 id 或名称
- **WHEN** 地图工具生成或审计正式区
- **THEN** 系统 MUST 不得因为该逻辑区借位而吞并独立印刷闭合区

### Requirement: 七大恨逻辑区显式映射印刷正式区
系统 SHALL 为 `qidahen` 运行时逻辑区提供显式映射关系，用来声明逻辑区与印刷正式区之间的一对一或一对多关系，而不是继续依赖隐式名称覆盖。

#### Scenario: 逻辑区读取地图拓扑
- **WHEN** 运行时需要加载七大恨区域配置
- **THEN** 系统 MUST 先读取印刷正式区拓扑
- **AND** 再通过显式映射得到规则层使用的逻辑区视图

#### Scenario: 逻辑区沿用历史聚合
- **GIVEN** 某个规则逻辑区短期内仍需覆盖多个印刷正式区
- **WHEN** 运行时派生逻辑区
- **THEN** 系统 MUST 通过映射表明确声明该聚合关系
- **AND** MUST 不得通过修改印刷正式区名称来伪装聚合

### Requirement: 七大恨正式区审计区分真相缺口类型
系统 SHALL 在七大恨地图工具的审计和调试输出中区分“印刷正式区缺失”和“逻辑区映射缺失”，避免把两类问题混为同一种漏填。

#### Scenario: 原图上存在独立命名闭合区但正式区表没有对应项
- **WHEN** 审计工具检查七大恨正式区域
- **THEN** 它 MUST 报告该问题属于印刷正式区缺失

#### Scenario: 正式区已存在但逻辑区尚未映射
- **WHEN** 审计工具检查七大恨区域分层
- **THEN** 它 MUST 报告该问题属于逻辑区映射缺失
- **AND** MUST 不得把该正式区重新并回相邻区域
