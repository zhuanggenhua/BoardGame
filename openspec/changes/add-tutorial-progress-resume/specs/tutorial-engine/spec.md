## ADDED Requirements
### Requirement: 教程进度恢复
系统 MUST 对教程模式保存可恢复进度，并在刷新后让玩家选择继续或重头开始。

#### Scenario: 刷新后提示恢复
- **GIVEN** 玩家在某个教程章节中已推进到首步之后
- **WHEN** 玩家刷新并重新进入同一教程章节
- **THEN** 系统 MUST 显示继续或重头开始的确认弹窗
- **AND** 选择继续 MUST 恢复保存的局面与教程步骤
- **AND** 选择重头开始 MUST 清除该章节保存进度并从第一步重新启动

#### Scenario: 多章节进度隔离
- **GIVEN** 同一游戏包含多个教程章节
- **WHEN** 玩家分别进入不同章节
- **THEN** 系统 MUST 按游戏与章节独立保存教程进度
- **AND** 一个章节的保存进度 MUST NOT 覆盖或触发另一个章节的恢复提示

#### Scenario: 完成后清理进度
- **GIVEN** 玩家完成某个教程章节
- **WHEN** 系统执行教程完成收口
- **THEN** 系统 MUST 清理该章节的保存进度
- **AND** 玩家再次进入该章节时 MUST NOT 因已完成快照而提示继续
