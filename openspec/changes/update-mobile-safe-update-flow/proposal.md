# Change: 移动端更新不中断对局且可以取消

## 问题与目标

用户要求对局中的玩家不被更新打断；下载失败或卡住时能取消；每次进入应用只自动检查一次，取消后不连续重新触发；自动下载后下次启动生效，只有手动点右下角才立即更新，并完成此前外部游戏原生浏览器的发布。当前 OTA 在 `forceUpdate` 时立即切换，原生更新可以阻塞界面并启动安装器，关闭弹窗不保证取消在途动作。

## 变更

- OTA 与 Android 原生更新均按一次应用会话管理自动检查和取消；用户可主动再次检查。
- 对局期间不切换 bundle、不拉起安装器、不以更新遮挡对局；异步检查、下载完成时重新核对对局状态。
- 显示明确的取消入口；取消后本次操作不能再安装、排队激活或重启，下载是否可中止以实际插件能力验证，不将隐藏弹窗称为取消下载。
- 区分普通更新和确需版本兼容限制的情况；下载或检查失败时保留明确错误及取消、重试，不产生自动循环。
- 评估并调整现行“所有 OTA 强制立即切换”的发布合同，保证旧客户端升级过渡不使正在对局的玩家中断。

## 边界和风险

- 新客户端保护不能追溯改变已经运行的旧客户端；发布第一版前必须先验证旧客户端真实行为并制定不打断对局的过渡方案，不能仅凭新代码测试直接推送强制 OTA。
- 不授予外部游戏作者管理权，不改变已有正式游戏的对局规则或服务端版本兼容合同。
- 本次不将页面关闭、进程后台或网络失败等价为用户主动取消；不承诺插件底层能取消下载，直到核实并实测。
- 本 change 替代 `add-android-embedded-live-updates` 中与新用户要求冲突的“所有 OTA 强制立即切换”行为；项目发布 skill 涉及规范治理时另走治理流程，不能保留冲突正文。
