# Change: 添加现代与经典首页风格切换

## Why
当前生产首页固定为现代平台首页，先前经典大厅入口已被移除；旧书本首页偏好仍可能留在本地存储。用户需要在设置中切换现有现代与经典首页，并在刷新后保留选择。

## What Changes
- 复用现有现代平台首页和基线中的经典大厅组合，在首页设置中提供现代 / 经典两个选项。
- 沿用 `bg_home_entry_style` 本地偏好，切换后立即生效并跨刷新保留。
- 将已保存的 `book` 风格迁移为现代风格；不改动其它本地设置。
- 书本首页从生产首页入口退出，内部开发预览保留。

## Impact
- Affected capability: `manage-user-settings`。
- 仅改首页风格选择、首页渲染入口、移动端首页方向判断和对应行为测试。
- 不新增首页主题，不改对局规则，不做整套视觉验收。
