## ADDED Requirements
### Requirement: 灰烬派系接入
系统 SHALL 将灰烬作为召唤师战争可选派系接入，覆盖派系选择、预构筑牌组、卡池、图集渲染、关键图片预加载、资源 manifest、中文/英文可见文案，以及当前交付范围内已实现的卡牌能力。

#### Scenario: 选择灰烬并进入对局
- **GIVEN** 玩家位于召唤师战争派系选择阶段
- **WHEN** 玩家选择灰烬并开始游戏
- **THEN** 游戏使用灰烬召唤师、起始城门、起始单位与预构筑牌组初始化
- **AND** 灰烬召唤师、提示图、卡牌图集通过正式资源链加载

#### Scenario: 灰烬卡池可用于自定义牌组
- **GIVEN** 玩家打开召唤师战争自定义牌组构建
- **WHEN** 玩家选择灰烬派系
- **THEN** 卡池展示灰烬召唤师、冠军、士兵、普通事件和传奇事件
- **AND** 卡池不包含副本后缀 ID 或起始单位副本 ID

#### Scenario: 未完成机制显式冻结
- **GIVEN** 灰烬某张卡的规则子句尚未实现或尚未验证
- **WHEN** 形成交付证据
- **THEN** 该子句 MUST 被标记为 `blocked` 或 `scoped-debt`
- **AND** 不得把静态接入或代表性验证声明为灰烬派系完整完成
