# Design: 萌奇金勇士派系

## 真相源与职责边界

- 规则真相源：`evidence/smashup/munchkin-new-faction-flow-audit-2026-08-01.md` 的勇士规则合同，以及用户指定素材目录中的勇士卡图 / 基地图。
- 静态 owner：`src/games/smashup/data/factions/munchkin.ts`；本 change 补能力标签，不另造卡牌定义。
- 卡牌能力 owner：新增 `src/games/smashup/abilities/munchkin_warriors.ts`，由 `munchkin.ts` 统一注册。
- 跨派系机制 owner：怪物摧毁触发上下文落在 `ongoingEffects` / `domain/index.ts`；持续力量落在 `ongoing_modifiers.ts`；事件字段与归约落在 `types.ts` / `reduce.ts`。

## 实现决策

1. 所有选择使用现有 `createSimpleChoice` / `queueInteraction` 合同，并显式设置 `autoResolveIfSingle: false`。
2. 普通击败怪物只提供未被控制的怪物作为目标；控制中的怪物不通过普通击败命令处理。
3. 斩杀把击败事件产生的每张宝藏以 `specificCardUid` 发放为独立即时额外出牌机会，玩家可逐张打出或跳过，允许只使用部分奖励。
4. 骚乱的全怪物摧毁事件携带 `suppressTreasureReward`，由 Munchkin 怪物归约器禁止该事件产生奖励，不伪装成普通击败。
5. 怪物摧毁后触发统一使用 `onMonsterDestroyed`，上下文包含被摧毁怪物 UID、定义、力量、基地和消灭者；明星勇士、堡垒、锦标赛通过基地范围与实例触发。
6. 永恒的英雄通过 `MINION_RETURNED` 的可选附着行动 UID 列表把宿主和本行动放回同一所有者手牌，其它附着行动仍按原规则进入各自弃牌堆。

## 交互与验收矩阵

| 对象组 | 关键玩家决定 | 最小真实证据 |
| --- | --- | --- |
| 大英雄 / 地牢诱饵 | 先手动选择“摧毁怪物”或“打出怪物”模式 | 单模式也停在模式选择，随后目标 / 基地可见并可点击 |
| 狂战士 / 斩杀 / 战争怒吼 | 手动选择怪物；战争怒吼再选同基地随从；斩杀逐张决定奖励宝藏是否打出 | 目标怪物本体高亮，结算后奖励 / 力量 / 指示物落在真实对象上 |
| 嘲讽者 / 骚乱 | 可选发动；选择基地和模式 | 跳过与发动两条状态均有明确收口 |
| 哑铃 / 永恒的英雄 / 无处不在之盾 | 手动选择宿主；持续效果随附着、移动、离场更新 | 附着卡只显示一次，宿主力量变化可直接读出 |
| 明星勇士 / 堡垒 / 锦标赛 | 怪物被谁摧毁、在哪个基地、是否仍有怪物牌库 | 跨玩家摧毁与同基地触发对照，避免跨基地误触发 |
| 领导运动 | 执行后按有怪物基地筛选力量，回合结束清理 | 有怪物 / 无怪物基地和己方 / 对手随从对照 |

## 风险与回退

- 若新增怪物触发时机无法在现有 reaction queue 中保留基地与怪物快照，先补共享触发上下文和领域测试，不在勇士文件中私造并行队列。
- 若附着行动回手会破坏现有清场或返回手牌触发顺序，先按 UID 精确限定回手集合，禁止全量吞掉其它附着行动。
- 若截图中目标被源卡、泰坦、行动列或基地信息遮挡，视为 UI 未通过，继续调整现有承载层后重拍。
