## ADDED Requirements

### Requirement: 勇士持续效果必须明确宿主、基地和生命周期

勇士的附着力量、怪物数量力量和回合临时力量 MUST 通过统一持续效果 / modifier surface 表达宿主、基地、控制者和清理边界，不得用全局布尔值或重复显示源卡替代领域状态。

#### Scenario: 无处不在之盾随怪物数量动态重算

- **WHEN** 宿主所在基地的怪物数量发生变化，或宿主移动 / 行动被移除
- **THEN** 宿主的力量 MUST 按当前同基地怪物数量实时重算
- **AND** 其它基地、其它玩家和已移除附着不得继续得到该加成

#### Scenario: 永恒的英雄只替代宿主与本行动的离场去向

- **WHEN** 带有永恒的英雄的宿主将进入弃牌堆
- **THEN** 宿主和永恒的英雄 MUST 进入该行动拥有者的手牌
- **AND** 宿主身上的其它附着行动 MUST 仍按各自原有去向处理
