## 本轮变更

- 去掉顶栏与右上角 `+`。
- 中央冬木市地图保持源图 1927×1179 比例，可拖拽平移、滚轮缩放；棋子与地点事件堆挂在同一地图内容父容器。
- 棋子按印刷白框圆心落位（`translate(-50%,-50%)`，Python 测圆心）：士郎工房 +2 `59.99/14.03`、慎二深山 +3 `70.52/46.14`、绮礼新都 +3 `70.47/78.03`、凛侦察 `11.05/81.26`。
- 地图铺满视口，自由平移缩放；HUD 浮在地图上，不为手牌收缩地图舞台。牌堆挂在地图内容父容器负 x，竖向对齐事件/深山/新都行，跟随 pan/zoom。事件卡落在地点印刷白格里。
- 手牌左右分栏：左攻击、右技能。攻击区在攻击手牌上方；点手牌打出、点已打出撤回，实时合计威力。
- 左下头像上方叠放三张令咒卡，点击后选择效果，确认时消耗一张。令咒上方是自己的抽牌堆与弃牌堆。
- 其他玩家改到右侧一列：御主圆形 token + 从者圆形头像（真名隐藏裁金背圆）；名字放在圆形右侧，战果、魔力、手牌数同一排。右侧多出来的宽度给这排身份读数。已打出的攻击牌/技能牌只在选中头像后的席位抽屉显示，点击头像才打开详情；详情及其旁边不显示已打出牌。详情只看御主牌、从者牌、三张技能、令咒。真名隐藏时技能为三张红背；真名解放后展示概览正面与全部技能正面。
- 攻击手牌、技能手牌、已打出攻击共用同一套平铺：每张露出完整牌面，牌间小间距，打出或撤回后自动收拢。令咒仍层叠。两区保持左攻击、右技能，不得收成窄条牌堆，也不得把两区挤成左侧一排。
- 牌堆（事件背）挂在地图左侧 gutter，竖向对齐事件/深山/新都行。命运之战、圣地等事件卡落进地图印刷的白色半透明格子，不放地图左边。
- 下一阶段按钮保持原 v5/v6 右下：`right: 0; bottom: -2px`，文案「下一阶段」，球内「行动 / PHASE 04」。右列对手停在按钮上方。
- 悬浮卡牌或自己头像时，在对手列左侧钉一张大图；点击同一对象隐藏，移出后再悬浮才会再出现。不使用中央遮罩作为主检视。
- 浑身の一撃去掉假数字 overlay。卡面印刷为消耗 0、威力 4；先前 18 / 03M 是占位，不是录入错误。

## 查漏：用户未点名但规则需要的界面

本稿已带上、用户没单独说的：

- 回合与阶段条、右下阶段球
- 攻击手牌上方的出牌区与合计威力
- 自己戳上的魔力 / 战果
- 棋盘印刷的战果轨、移动费用、工房格
- 局势牌叠在事件区印刷框；地点事件卡叠在白色半透明格子
- 地图缩放读数与复位
- 令咒三选一（移动深山或新都 / 加四魔力 / 合计威力加二且获胜再加二战果）

同一工作稿仍未覆盖的规则场景：

- 战斗合计威力，贴在交战地点附近，不进边栏
- 前哨部署：把棋子从工房派到地点
- 响应窗口与结束阶段：其他玩家插入的时机
- 新都事件在行动阶段前暗置
- 工房人数上限提示
- 地点可点选移动，并预告费用
- 同地点对战双方的站位
- 战果轨上的玩家颜色标记
- 高潮回合九到十一的视觉区分
- 淘汰后失去全部魔力、继续游戏的状态
- 从者已装备技能与手牌技能的区分
- 公开事件 / 局势的检视入口
- 令咒用尽空态
- 操作日志、设置入口（右上加号已按你的要求去掉）

## 商业桌游图面复核（2026-10-18）

主助手直接查看了开发商公开的《沙丘：帝国》数字版界面截图，来源 https://www.direwolfdigital.com/dune-imperium-digital/ ，原图 https://d19y2ttatozxjp.cloudfront.net/assets/dune/digital/di_ss_05.webp ，文件哈希 `4f07404d85cf99609db3c244db999365c845e474724529e56d3322a73b2d718e`。这是图面参考，不宣称实玩过该商业游戏或确认其点击行为。

吸收的是信息层次：玩家摘要固定在侧边，手牌集中在底部，战场主体保留中央操作空间，次要信息另占独立区域。当前工作稿因此维持右侧席位摘要、选中席位就近的已打出抽屉、独立的大图详情，以及稳定相邻的两个手牌分区。

不照搬其底部压缩手牌：参考图以图标为主且部分牌面重叠，命运支配牌上有较长规则文字，用户也已明确否决窄条密叠；因此保留完整牌面及侧边放大检视。亦不复制配色、字体、星空背景、图标或商业素材。已有做法能够满足当前阅读任务的部分保留，而不是为了看起来不同而全换皮。
