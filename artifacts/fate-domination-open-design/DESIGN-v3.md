# Fate/Domination OpenDesign 沉浸式牌桌候选稿 v3

## 状态

- `open-design-artifact-candidate`
- 人工设计验收：`not-approved`
- 本稿为 v2 的彻底重构，保留 v2 仅作历史对照，不把 v2 的面板布局继续带入。

## 参考方向

- 用户提供参考图：`reference-image-not-committed`
- 关键结论：沉浸式牌桌空间、中央大棋盘、四周玩家席位、顶部牌库与工具、底部弧形手牌、右下阶段推进。
- 手牌区参考 DiceThrone 的悬浮弧形编排：卡牌为实体对象，选中卡上浮，检查入口附着在卡牌外沿。

## 本轮重构决策

1. 删除 v2 的顶部大信息栏、右侧后台式玩家栏和底部多列 dock，改为牌桌空间内的低侵入 HUD。
2. 冬木市棋盘成为唯一中央主视觉，玩家席位贴在左右边缘，避免棋盘被面板切碎。
3. 手牌使用 5 张真实卡图做弧形浮起排列；阶段推进脱离手牌组，固定在右下角，保留稳定点击区。
4. 魔力、VP、指令咒收敛到左下 YOU 面板；局势/事件由顶部牌库与棋盘本体承担，不再做常驻说明卡墙。

## 区域职责

| 区域 | 责任 | 禁止 |
|---|---|---|
| 中央棋盘 | 冬木市地图、四个区域锚点、当前部署 | 不放大段规则说明 |
| 左右玩家席位 | 对手/竞争者姓名、位置、VP | 不做厚重侧栏 |
| 顶部 HUD | 局名、回合、牌库、供应/记录/菜单入口 | 不堆叠资源面板 |
| 底部手牌 | 私有牌面、选择、检查 | 不遮挡阶段按钮 |
| 左下 YOU | 当前玩家、身份、资源 | 不重复整个玩家 rail |
| 右下阶段控件 | 当前阶段、下一阶段 | 不贴屏幕边缘，不放到手牌之间 |

## 素材账本

- `assets/fuyuki-city.webp`：真实冬木市棋盘主视觉。
- `assets/event-back.webp`：真实事件牌背，用于顶部牌库叠牌。
- `assets/master-emiya.webp`、`assets/master-slot-b.webp`：真实 Master 席位头像。
- `assets/attack-magic-low.webp`、`assets/attack-strength-high.webp`、`assets/skill-luck.webp`、`assets/skill-moment.webp`：真实手牌。
- 未使用 CSS 卡牌占位图，也未生成新媒体素材。

## 互动合同

- 点击手牌切换选中态，选中牌上浮。
- 点击卡牌外沿检查按钮打开牌面检查弹层，不改变局面。
- 点击地图区域切换当前高亮位置，并显示短 toast。
- 点击顶部工具显示对应短 toast。
- 点击右下阶段按钮切换“等待对手响应”示意态。

## 验收尺寸

- PC 主基线：1920×1080，无页面滚动，中央棋盘、底部手牌和右下阶段控件同屏。
- 移动参考：390×844，中央棋盘先出现，手牌随后单独进入纵向层级，阶段按钮仍为触控友好区。
