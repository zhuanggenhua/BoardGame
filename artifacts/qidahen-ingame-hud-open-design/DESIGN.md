# 七大恨局内钉边 HUD Open Design

设计候选，未获人工批准。未写入 `Board.tsx`。

## 规则

- 每回合：手牌行动 + 轮盘行动，顺序自定。
- 轮盘：免费走 1 格 / 指定对手抽 2 走 2 / 所有对手抽 2 走 3；落到扇区再执行该扇区行动。
- 手牌行动四选一：事件 / 军备 / 势力行动（弃牌）。
- 大明势力行动：突袭作战、征召军队、赐印招安、驱虎吞狼。
- 地图可平移缩放；印刷在地图上的轮盘、朝鲜槽、纪年槽随场景移动，不能当唯一热区。

## 成熟对照

| 参考 | 采用 |
| --- | --- |
| 数字 Twilight Struggle / War of the Ring | 轨道、牌库钉屏幕边；棋盘自由查看 |
| Memoir '44 Online | 手牌本体在底边重叠，牌库/弃牌夹在两侧 |
| 本仓派系选择稿 | 墨色/朱砂/纸；势力行动名称 + hover 效果；印刷卡不套第二层框 |

## 本页

1. 左：印刷轮盘本体（点合法扇区走格）+ 两张纪年卡本体。
2. 顶：三势力 chip（当前 / VP / 手牌）。
3. 右：朝鲜牌库、弃牌本体。
4. 底：抽牌、重叠手牌、弃牌；手牌行动 + 轮盘行动状态；势力行动名称 hover。
5. 中：辽东战场视窗，可拖可缩放；棋子跟地图走。

## 不做

- 常驻行动记录、AP、科技树。
- 印刷卡再套 CSS 外框。
