# 纸牌帮 Open Design 当前 UI 基线稿 v0.4

## 本轮纠偏结论

- v0.1 是方向稿，不是当前 UI 基线，已废弃。
- v0.2 虽然回到了当前 UI 家族，但仍犯了低级交互几何错误：主按钮贴底、手牌筹码可能遮挡牌面、右上角外层 HUD 归属不清。
- v0.4 只修这三类硬错误，不改真实 `src/games/the-gang/Board.tsx`。

## 当前真相源

- 当前 UI 截图：`test-results/evidence-screenshots/the-gang/the-gang-runtime.e2e/桌面端当前玩家使用可见-UI、其它座位用代表态完成四轮抢劫并显示摊牌结果/桌面首轮可操作状态.jpg`
- 当前 UI 对照：`test-results/evidence-screenshots/the-gang/the-gang-runtime.e2e/桌面端当前玩家使用可见-UI、其它座位用代表态完成四轮抢劫并显示摊牌结果/桌面首轮全员筹码已选.jpg`
- 当前实现入口：`src/games/the-gang/Board.tsx`
- 设计合同：`design-system/games/the-gang.md`

## v0.4 硬修正

- 主操作：`下一轮` 不再贴底边，改为右侧操作带内的稳定可点锚点，避免被底部安全区/屏幕边缘吞掉，也避免和底部手牌争抢点击区。
- 手牌筹码：筹码挂到手牌组外侧右上角的预留空间，不再压进卡面、点数、主要图案或点击区。
- 右上 HUD：进度和 toast 已从 `main.frame` 牌桌根结构拆出，放到 `.outer-hud` 外层覆盖层；它们不参与牌桌内部布局，也不画成桌面对象。

## 必须保留的当前 UI 骨架

- 顶部：玩家名分散在牌桌上方，右上只放短进度和 toast，不做厚玩家卡。
- 右上：抢劫进度必须保持在右上自然锚点；toast 默认隐藏或按真实状态短暂出现，禁止为了“能看到”而把常驻 HUD 下移到不合理位置。
- 中央：牌桌保持大面积留白，筹码和公共牌是桌面对象，不包成大面板。
- 左下：牌型速查、扩展、工具保持低侵入，允许展开但不抢主牌桌。
- 底部：我的手牌贴近底边，牌型短标签跟随手牌；状态筹码在手牌外侧，不遮挡卡面。
- 右侧：高频主按钮必须可点、可读、稳定，不能为了贴近截图贴到画面底边，也不能远离当前决策对象。
- 视觉：绿色毡布斜纹、轻微中心光、对象投影可以微调，但不能改变当前构图家族。

## v0.1 / v0.2 废弃点

- 废弃 v0.1 厚玩家卡片、金库/警报大面板、椭圆桌框、独立大筹码池。
- 废弃 v0.2 底边贴死的主按钮。
- 废弃 v0.2 绝对定位压进手牌内部的筹码；后续只允许放在手牌外侧右上角或不遮挡的外侧 gutter。
- 废弃 v0.2 未明确外层/内层归属的右上 HUD；后续右上应用级 HUD 必须在牌桌根节点之外，不能只靠 z-index 伪装。
