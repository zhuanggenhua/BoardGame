# 小黑屋选择探索者 Open Design 候选稿

设计候选，未获人工批准，不进入 `characterSelectSurface.tsx`。

## 规则读取

- `src/games/betrayal/rule/山屋惊魂小黑屋第三版规则汉化整理.md` 第 5 节设置、第 7 节属性。
- 每位玩家选择一个角色，拿角色面板、立牌和底座。
- 起始属性是角色面板上的绿色数字，四项属性公开。
- 队伍翻阅五张剧本卡，选一张作为本局剧本。

## 规则到画面

| 规则结论 | 画面 |
| --- | --- |
| 角色面板是选择对象 | 12 张正式五角角色板直接点选，不另画属性条 |
| 起始属性印在板上 | 左侧放大同一张板供阅读，网格负责浏览 |
| 角色不能重复 | 已占用的板压暗，并写占用玩家名 |
| 准备是提交，不是浏览 | 放大板下方只有「随机」「确认」 |
| 五张剧本卡是下一步 | 全员准备后另开一屏纸条；没有官卡图，不用假卡面 |

## 饱和态

- 4 人。你选了米歇尔·梦露，尚未准备。周衡已准备梁沃伦。阿凯选了奥利弗，待确认。苏麦空位。

## 结构合同

刚性：五角板本体、占用压暗、放大阅读、确认贴在正在看的板上、剧本选择独立成屏且只有 5 张。

可降级：墙纸渐变、发光强度、纸条纸色。
