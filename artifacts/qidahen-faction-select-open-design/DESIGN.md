# 七大恨开局重构 Open Design

设计候选，未获人工批准。

## 规则

- 玩家开局任务是选择势力：大明 / 蒙古 / 后金。
- 势力差异在规则正文：手牌上限（大明 15，蒙古与后金 10）、势力行动、本剧本起始手牌。
- 起始剧本设置卡 3 张由房主选用，约束人数与可玩势力。不是每位玩家的主任务。
- `aids/player-aid-*` 是军备进度表，不是帮助卡，不拿来当派系介绍。

## 不做

- 牌背当认领主语。
- 自造口号、入座、待锁定、坐到一边。
- 把剧本卡做成和派系同级的主舞台。
- 复制第二张预览图。

## 成熟对照

| 参考 | 采用 |
| --- | --- |
| Spirit Island / Root | 主屏认领势力；剧本/对手是创建者选项 |
| 召唤师战争 / Smash Up | 点势力本体，介绍贴在该势力上 |
| Memoir '44 | 剧本是简报文件，放进房主菜单里打开 |

## 本页

1. 主舞台：三个势力。介绍用规则《游戏简介》里对该势力的原文，加上手牌上限 / 牌库 / 水路（仅大明）。
2. 势力行动只显示名称；悬浮读规则里的效果正文（Smash Up / 召唤师战争 hover 检视）。
3. 房主右上「剧本」打开起始设置卡。印刷卡不套 CSS 外框，选中用抬升和贴合阴影。
4. 确认阵营。
