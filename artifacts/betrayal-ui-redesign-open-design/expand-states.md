# OpenDesign 续作：补足《山屋惊魂》整局 UI 状态

继续项目 `81d767ee-4be6-468f-9cbd-285f8b949b3e` 的可编辑设计源。当前已有 PC/手机主态、角色属性/物品/能力、书页、过程、剧本选择/确认。用户要求“整个游戏 UI”重做，现有包仍缺移动选目标、骰盘/结果、房间发现卡、作祟状态、终局等核心流程，不能只凭主态交付。

先读取当前项目 `brand-spec.md`、`asset-ledger.md`、`ui-audit.md` 及 repo 的 `design-system/games/betrayal.md`、`docs/games/betrayal/user-stories/board-ui-trait-haunt-status-contract-2026-07-31.md`、相关真实素材/当前实现。基于已有同一设计系统，补至少以下各状态的 PC 1920×1080 和手机 796×360 成对可编辑页面及实际导出 PNG：

1. 移动/探索选目标：地图房间本体高亮，玩家 token、当前/合法目标、剩余移动和取消/确认语义清楚；明确平移后聚焦 token 的目标视觉位置，设计图不冒充行为修复。
2. 骰盘与结果：真实骰子素材、加值/总点数清楚，骰子漂在主地图上层，不画深色托盘；关键按钮不出屏。
3. 房间发现与物品/事件/预兆卡展示：正式卡面为主，可检视；当前房间、卡名、需要确认者/等待状态有明确锚点；不要重复说明墙。
4. 作祟后的牌桌：玩家、预兆 0–9 轨、剧本入口和队友状态同屏；不要把作祟 setup 常驻在右侧。
5. 终局/胜负与返回：真实结果及玩家后续动作，PC/手机均可读。
