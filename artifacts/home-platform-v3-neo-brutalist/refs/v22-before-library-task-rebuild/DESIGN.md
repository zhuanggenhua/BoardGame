4. 编辑个人资料在右侧栏顶部。
5. 右侧栏只有游玩时长 / 局数 / 收藏数量。没有排行，没有评分，没有当前正在游戏。
6. 主列「最新动态」标题右侧写这段时间的小时数。
7. 动态行是横版胶囊：左横图、中游戏名和局数 / 该游戏排行 / 该游戏分数（三位小数），右时长与上次游玩。

## 2026-10-16 移动端返工

用户否定旧移动 PASS，并明确选择「按此方向重构移动端」。本次授权只覆盖该 artifact；整稿仍待人工设计批准。

- 当前源：`index.html` 负责同源 DOM 和交互；`mobile.css` 独占窄屏样式；`capture.mjs` 执行 PC 链路，`mobile-capture.mjs` 执行移动链路与末项命中断言。
- 四个根因：收藏卡被受限网格压缩、房间/好友的 flex-basis 截断内容、发现长文挤在半宽封面、详情简介及操作挤在窄列。
- 移动页各有一个纵向滚动窗口。底栏有独立安全区，对局条继续覆盖内容；内容末尾提供滚动余量，使最后一个对象能滚到对局条上方。
- 对局条在 375×812 为约 66px；收藏、发现、房间、好友、上传提交和动态末项分别留整屏证据。
- 375×540 仅验证缩短可视高度的填写压力，不代表真机软键盘验收。
- PC 1920×1080 重新验证，保持三导航、左侧列表、六列发现、个人页左右背景和叠底对局条。
- 返工前源与证据保留于 `refs/v22-before-mobile-rebuild/`；旧 PASS 仅供历史追溯，不能替代本轮结论。
