## 弹窗壳

所有 overlay 共用同一套关闭件 `closeX` 和确认件 `sheetConfirm`。落地 `src/` 时抽成可复用 ModalChrome，本稿只保留这两个 helper。

- 关闭：右上角 36 正方形，线段光学居中。没有「取消」文字。
- 确认：底部独立 `sheet-foot`，按钮水平居中，宽度 72% 且 240–320。销毁、创建都走这套。
- 详情、作者、创建、销毁四类弹窗同一套叉号。

## 个人中心

组织对齐点名文件 `C:\Users\zhuagenbao\Desktop\个人主页.png`（Steam 资料页），不抄深色皮肤，也不用库页封面墙。排行和分数对齐 BGG 游戏榜：排行是游戏位次，分数是用于排名的分。

1. 整页左右留给资料背景（当前用最常玩游戏封面铺底）。中间内容井限宽，约 1280，两侧各露出不少于 160。
2. 两列：左主列身份 + 最新动态，右侧栏独立。
3. 身份：120 头像 + 名字 / 在线。
4. 编辑个人资料在右侧栏顶部。
5. 右侧栏只有游玩时长 / 局数 / 收藏数量。没有排行，没有评分，没有当前正在游戏。
6. 主列「最新动态」标题右侧写这段时间的小时数。
7. 动态行是横版胶囊：左横图、中游戏名和局数 / 该游戏排行 / 该游戏分数（三位小数），右时长与上次游玩。

页眉和内容共用 `--profile-inset: 24px`。不要求封面墙填满剩余高度。
