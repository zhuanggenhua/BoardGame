# 身份选择与角色组件：元素职责总账

状态：职责与中文原卡关系已重新锁定，正式 UI 已回代；当前对应浏览器和逐图复核通过；只认定资料选择承载，不恢复全游戏或全部角色 PASS。本文不是玩家教程正文，也不是第二份规则定义。

## 来源与本轮裁定

- 中文规则：`src/games/fate-domination/intake/rules/chm-进行一场圣杯战争.md` 的“选择御主”“召唤从者”“选取完成后处理御主游戏开始时”。自由选择与推荐 3X 是不同方式，附图不能擅自把当前方式改成 3X。
- 原卡：本轮直接查看第一批 13 名御主的身份原图；另直接查看凛的宝石能力卡及肯尼斯的月灵髓液攻击卡。其它附属逐项以 `first-batch-master-aux-ocr.md` 的原图和状态核对，不能以 demo-data 的 skills 数组长度认定物件数量。
- 物件原始范围：13 名御主、51 条附属截图记录；截图记录包含重复引用、令咒、不同状态、资源和升华，不等于 51 张独立技能牌。49 locked 与 2 partial 沿用来源状态，不能通过新 UI 补齐未核规则。
- 被退回的 `FateIdentitySetup` 只消费从者 skillAssetPaths，省略御主关联组件。当前已改为独立的御主原卡资料集合；从者技能不再充当御主资料。

## 御主差异覆盖

| 御主 | 已核身份原图带来的对象/时机差异 | 选择时必须能了解 | 对局设计约束 |
| --- | --- | --- | --- |
| 间桐雁夜 | 宿敌指向右侧玩家；工房额外魔力，常规移动额外消耗 | 身份能力、宿敌及其附属 | 对手关系与资源修正不能假装成三张攻击技能 |
| 间桐慎二 | 开局取得伪臣之书；战败失去令咒 | 书的关联状态及能力 | 状态变化和令咒归属独立于从者技能 |
| 卫宫士郎 | 初始魔力 2；干将·莫邪加入技能区；首次淘汰例外 | 身份、追加技能攻击及必胜黄金之剑关联原卡 | 追加牌进入技能区；不能占掉原三张从者技能。无限剑制属于从者卫宫的另一对象，不得并入此御主 |
| 雨生龙之介 | 开局取得死之艺术；部署/胜利激活；工房不获魔力 | 身份、死之艺术及其它关联卡面 | 激活状态、来源能力和地利放弃是不同对象；partial 卡不推断效果 |
| 远坂时臣 | 火炎弹加入技能区；四件道具加入游戏，顺位倒数两位使用 | 火炎弹、四道具及其它关联原卡 | 道具作用于多人权限，不能全归为本人三技能或手牌 |
| 伊莉雅斯菲尔 | 初始魔力 6；第八回合开始激活天之衣；暗置回合收益 | 身份、天之衣及关联原卡 | 后续激活能力不能在开局当作已持有并激活的技能 |
| 间桐樱 | 排名条件激活黑泥；第八回合结束可能激活被污染的圣杯 | 两种条件能力及其它关联卡 | 区分未来资料和当前已激活能力，不提前给行动入口 |
| 韦伯 | 鉴识眼、前哨抽牌与调查；另有升华卡 | 原身份能力与关联资料 | 原身份能力不是三张独立从者技能；执行按钮仍由正式能力注册表决定 |
| 言峰绮礼 | 从者真名是否隐藏决定监督者/执行者身份 | 两种状态及对应卡面 | 同一身份的替换状态不能画成两张同时有效的技能 |
| 肯尼斯 | 六张月灵髓液洗成独立牌库；行动阶段从该库抽牌 | 独立牌库的构成、攻击卡面及关联资料 | 独立牌库、抽出的手牌、从者技能三者分开；三种图面不等于总计三张牌 |
| 间桐脏砚 | 初始魔力 10、上限 16；创造者及五百年的执念 | 创造者/执念等关联卡面 | 不把身份/目标归为攻击技能；令咒来源缺口不得自行补图 |
| 卫宫切嗣 | 开局以起源弹替换牌库一张牌；有暗置打出/关闭与激活能力 | 替换攻击卡及关联资料 | 替换关系、暗置信息、激活时机分别消费正式状态 |
| 远坂凛 | 十枚宝石；宝石能力可引出游戏外攻击牌；高潮重复限制 | 宝石能力、宝石物件、关联攻击及升华卡面 | 资源数量、能力选择、游戏外牌与入场后攻击不能混成固定技能槽 |

本表只锁对象职责，不宣称上述全部效果已有 reducer、AI 或联网实现。选角查看的是角色资料集合；对局只能展示正式状态中实际产生/持有/激活的物件。不得把资料目录直接灌进手牌或技能区。

## 元素裁决与复验口径

| 元素 | 唯一职责 | 当前裁决 | 缺失会损失什么 / 复验 |
| --- | --- | --- | --- |
| 御主/从者候选 | 在本局合法集合中选身份 | 保留正式选角主任务；候选范围消费当前规则 owner | 不能用图鉴的全部对象伪造本局合法候选；选择、换选、占用和确认分别验 |
| 当前角色完整资料 | 读清当前候选会带来什么 | 重新设计；按当前御主或从者切换，不让另一身份固定三技能抢主语 | 凛、时臣、肯尼斯三个不同组件家族必须逐项看懂并可查看原卡 |
| 关联组件集合 | 阅读本角色的身份外物件及关联规则 | 可变长度、保留原图、提供完整浏览；不设固定三槽 | 必须验最多记录、最少记录、不同类型/重复物件和溢出；不以截图数冒充物件数 |
| 已选另一身份 | 保留本局组合上下文 | 降为可切回的已选摘要，不把它当当前主阅读对象 | 切换身份类型后选择不丢失，放大/浏览不改变已选结果 |
| 对局手牌/技能/能力/资源 | 执行当前真正可用的动作 | 不由选角资料目录生成假状态；另按正式领域对象承接 | 御主追加攻击牌、能力卡、独立牌库与从者三技能分别归属；未实现效果不伪造按钮 |
| 开局确认 | 将本局选择交给正式准备流程 | 保留真实 owner，禁用/等待/成功可辨 | 未准备不提前部署；教程固定身份不重新出现选角首课 |

当前回代：13 名御主共 49 项正面资料，死之艺术及宝石的两张牌背分别关联原卡；肯尼斯的三种图面不冒称三张总量。选择、阅读和对局执行分属原 owner，资料目录不写入权威持有区。常规凛/时臣、受限肯尼斯末项阅读由正式浏览器复验；最终图面结论另记，不由功能通过代替。
