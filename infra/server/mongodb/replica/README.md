# BoardGame 云主到 Acer 备机同步

这套配置采用“云端唯一写主 + Acer 被动备机”的快照同步：

- 云端每 15 分钟生成一份只保留最新版本的 `mongodump` 归档；
- Acer 通过专用 SSH 密钥拉取归档，校验 SHA-256 和 gzip 完整性后才恢复；恢复成功后才替换本地已知快照；
- 新快照恢复失败时，使用上一份已验证快照回滚；回滚也失败时，预览 Web / 游戏服务保持停止，避免对外提供部分恢复的数据；
- Acer 恢复时只停止备机 Web/游戏容器，不影响云端生产；
- Acer 不参与生产写入，不与云端做双写，也不假装是 MongoDB 自动选主副本集。

这是 RPO 约 15 分钟的被动备份链路。自动故障切换仍需要先验证 Acer 应用版本、公网入口和会话恢复，再配置 Cloudflare Load Balancing。
