# A3 / B3 scope

A new independent art-direction candidate based on the B2.1 source archive. The original game, old abstract candidate, B2 and B2.1 are preserved. A3 introduces paper-theatre geometry; B3 changes the cabinet form and adds domestic drapery, portraits and localized aging. It is not game-rule integration or deployment.

Only CPU geometry/source checks, type checking and bundling were performed. No browser, GPU window, screenshot, actual UI interaction, measured performance or visual acceptance. Do not use a different browser, renderer or environment to evade an existing access restriction.
