# 暮色餐厅 · A3 / B3 双方向美术候选

本轮做了美术与造型变化，不是 B2.1 的技术优化重复。它仍是独立餐厅样板，未接游戏规则，未发布到原版站点。原版、旧抽象版、B2 与 B2.1 均未覆盖。

## 直接打开

解压后打开 `preview/dining-room-A3-B3-standalone.html`。需要支持 WebGL 2 的现代浏览器，代码、材质和模型均内嵌，不需要账号、网络或在线素材服务。这个入口已经构建，但本轮没有实际运行浏览器。

左侧切换两种美术方向，保留当前相机位置以便直接对照。底部可切换整体／桌面／俯视、中性／暖光、切面／完整／仅地面。重置只恢复视角、灯光与墙体，不更换已选美术方向。拖动旋转，滚轮缩放，右键平移。

## 两个方向

### A3 · 纸上剧场

不是写实版的低细节模式，而是一套独立几何：

- 四层切纸底座与墨色夹层、低墙和印刷护墙板。
- 椅背使用带真实镂空的刀模剪影，座面以折纸片表达。
- 椭圆桌保留纸边轮廓，烛台变为平面剪影，餐盘使用印刷圆环。
- 木地板、地毯与纸面采用受限的墨绿、旧纸、暗金配色。
- 保留与 B3 相同的六席、桌面长宽、斜向地毯和房间占地。

### B3 · 旧宅微缩

沿用 B2.1 的整体布局，重点补足旧宅语汇：

- 方盒餐边柜改为弧形前脸、薄顶板、曲腿、环形拉手和弧形抽屉线。
- 增加带窗棂、窗台和模糊树影的装饰窗，配真正有深度的褶皱帷幔、绑带与流苏。
- 增加两幅带细框的原创匿名人物剪影画。不是原作卡图或现成肖像复制。
- 局部细裂纹、封蜡信件和烛蜡滴落用于表现久置的餐厅，没有加入石砖、宝箱、奇幻火盆等地牢道具。
- 门洞和原桌椅布局保留。窗景属于表面表达，不是可穿透窗洞或完整外部场景。

## 已验证与尚未验证

**已通过：43 项 CPU 检查、TypeScript 类型检查、Vite 生产构建。**

检查包含原有 13 项几何检查、17 项重置／页面生命周期／合批回归和新增 13 项美术结构检查。新增检查覆盖纸椅背真实镂空、帷幔褶皱及法线、墙饰不侵入门位、两方向的相同布局、材质确定性、有限坐标、墙体独立显隐及视口水平投影边界。

- A3：6,348 个三角形，159 个源网格，合批后 20 个网格。
- B3：78,086 个三角形，790 个源网格，合批后 58 个网格。
- 网格数是 CPU 结构统计，不是实际 draw calls 或帧率。
- 主脚本约 581 kB，仍有 Vite 大于 500 kB 的体积提示。

**未运行图形窗口、浏览器、实际控件点击、手机视觉布局或截图；未完成美术验收。** 这份候选不应被称为“画面已经更好”或“视觉通过”。几何与源码测试不证明配色、阴影、画面构图和 UI 遮挡合格。已有图形访问限制没有被绕过。

下一轮验收应在可正常运行的环境中，固定同一相机对比 A3 与 B3 的整体、俯视、桌椅近景和两种灯光；再检查手机竖屏／横屏、切墙、拖动后重置和页面返回。

## 开发

进入 `source/`，运行：

```sh
npm ci
npm run check
npm run typecheck
npm run build
```

`source/checks/` 和 `evidence/` 保存本轮验证结果。`ART-DIRECTION.md` 说明两条路线的设计边界与验收标准。`evidence/provenance.json` 记录输入包及校验和。
