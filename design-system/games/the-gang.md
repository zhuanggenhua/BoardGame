# The Gang UI 设计合同

## 视觉方向

- The Gang 使用“绿色牌桌 + 金库/警报 + 扑克协作推理”的游戏专属风格。
- BGG 电子版只提供结构参考：顶部玩家板、中部筹码池/牌河、底部警报金库/手牌、结算 reveal/final 态。
- TTS/Workshop 只提供素材和对象参考，不提供 UI 风格目标。
- 独立风格关键词：`地下金库牌桌`、`协作抢劫指挥台`、`赌场筹码与保险箱`、`低噪声绿色毡布`。
- 不能长成其它游戏的通用卡片面板：The Gang 的首屏第一视觉必须是扑克、筹码、牌河和金库/警报，而不是层层容器、说明卡或通用 HUD。
- BGG 的 `.top_zone / .middle_zone / .bottom_zone` 是开放牌桌关系，不是三层外框；实现上应保留空气感和对象本体优先级。

## 主界面规则

- 主 UI 只常驻对象名、数值、短状态和按钮标签；禁止常驻规则解释、结构说明和长段策略文案。
- 新房间进入后默认是开局配置状态；只有房主点击 `开始抢劫` 后，本次抢劫才正式开始，AI 和玩家都不得在开始前拿筹码或推进轮次。
- 抢劫正式开始后，扩展、模式、挑战和开局开关必须锁定；不能依赖 AI 先手或某个玩家先拿筹码来“顺便锁规则”。
- 规则、扩展、工具牌、开始按钮和筹码这类玩家点得见但当前无权限/未满足条件的入口，必须给 toast 反馈；禁止只用静默 disabled 让玩家以为点不动或坏了。
- 顶部玩家板显示玩家、当前筹码和手牌可见/隐藏状态。
- 中央区优先展示当前轮筹码池和公共牌河，不被帮助说明、日志或参考内容挤占。
- 底部区承接金库/警报、我的手牌、当前牌型和单一主操作。
- 帮助/参考默认折叠或低侵入展示，不得变成主 HUD。
- 容器只用于真实语义边界：玩家板、牌槽、手牌、结算；普通分区不得再额外叠一层“卡片壳”。
- 桌面基线先验收：桌面首轮、桌面摊牌/结算的截图和 AI 复看通过前，不得开始以手机横屏为主修目标。
- 手机适配只能在桌面合同上降级，不能反向改变桌面构图、整体比例或对象主次。

## 响应式约束

- `mobileLayoutPreset: board-shell` 下 Board 根容器必须使用 `h-full` / `min-h-0`，禁止 `100vh`、`100dvh`、`min-h-screen` 作为内部高度真相源。
- 手机横屏截图必须能同时看到顶部玩家板、中部筹码/牌河和底部手牌/操作区；若底部裁切，则 UI 未完成。
- 手机横屏的左下 `牌型 / 扩展 / 工具` 和扩展/工具弹窗必须沿用 PC 承载结构，只允许压缩尺寸、间距和安全区；禁止改成移动端专用大按钮、单列工具面板或另一套视觉皮肤。
- 结算态应使用 compact reveal/final 面板，不得把玩家结果列表撑爆底部安全区。

## 验收门槛

- 定向单测断言 BGG 结构标记和结算标记存在。
- 真实页面 E2E 重新生成桌面首轮、桌面摊牌/结算、手机横屏截图。
- 最新截图必须打开给用户看，并单独做 AI 复看；旧 TTS 截图不能作为完成证据。
