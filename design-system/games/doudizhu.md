# 斗地主 UI 实现合同

日期：2026-07-25

## spec

- 目标用户：第一次进入本项目斗地主的玩家，以及用它评估 Phaser 接入价值的开发者。
- 现实任务：在真实 `/play/doudizhu` 页面完成叫分和基础出牌流程，并能从截图一眼看懂当前轮到谁、能点什么、点完发生什么。
- 主路径：进入对局 -> 叫分 -> 地主确定 -> 地主出第一手牌 -> 下一位玩家响应。
- 必须覆盖状态：叫分态、地主确定态、出牌态、不出态、终局态、等待别人行动态。
- 验收标准：真实页面 E2E + 至少 5 步基础玩法截图链 + AI 肉眼判定达到商业斗地主基线。

## domain

| 规则对象 | UI 承接 | 必须可见状态 |
| --- | --- | --- |
| 玩家座位 | 头像座位徽章 | 昵称、身份、手牌数、当前行动、叫分 |
| 地主牌 | 中央上方三张牌槽 | 未翻开、已归属地主 |
| 自己手牌 | 底部大牌列 | 可点、选中、已出后减少 |
| 对手手牌 | 牌背堆 | 只显示数量，不泄露牌面 |
| 上一手牌 | 中央牌局舞台 | 玩家、牌型、具体牌 |
| 叫分动作 | 中央下方按钮组 | 不叫、1 分、2 分、3 分 |
| 出牌动作 | 底部操作区 | 出牌、不出、提示 |
| 胜负结果 | 主舞台覆盖层 | 地主/农民获胜 |

禁止混用：

- 不用调试文字替代玩家状态。
- 不用代理列表替代手牌对象选择。
- 不用 E2E 状态标签替代玩家 UI。

## design

- 视觉气质：红金 + 深绿牌桌 + 暖色舞台光，偏商业休闲棋牌，不走严肃桌游模拟。
- 主视觉：三人座位、底部手牌、中央地主牌/上一手牌，形成稳定三角构图。
- 桌面：开放式桌面，最多保留轻量金线和光晕，不允许整屏硬边框围栏。
- 牌面：高对比白色实体牌，左上/右下角标，花色用红黑明确区分；大小王独立样式。
- 牌背：深红金纹，中心“斗”字或菱形纹样。
- 按钮：金红实体按钮，强 bevel、内阴影、按压反馈；3 分/出牌是强主按钮。
- 字体：中文用 Microsoft YaHei / Noto Sans CJK；牌面点数用更粗的数字字重；不使用解释性长句。
- 动效：优先 transform/opacity/tween；叫分、选牌、出牌、当前玩家切换必须有反馈。

## components

| 信息/动作 | 现实语义 | 承载 | 禁止替代 |
| --- | --- | --- | --- |
| 当前轮到谁 | 行动权 | 座位外圈光效 + 顶部短状态 | 只写在标题里 |
| 叫分 | 当前主决策 | 中央下方 4 个实体按钮 | 小文本链接 |
| 出牌 | 当前主动作 | 底部稳定按钮组 | 跟着牌漂移的小按钮 |
| 选牌 | 对象选择 | 点击牌本体，上移 + 外发光 | 文字候选列表 |
| 对手信息 | 隐藏信息摘要 | 头像 + 牌背堆 + 手牌数 | 展示对手手牌 |
| 地主身份 | 阵营状态 | 座位身份章 + 地主牌归属 | 仅日志 |

## craft

- 少框：所有容器必须对应真实游戏对象；不能解释用途的框删除。
- 少正文：主界面只保留对象名、数值、短状态、按钮标签、单步短提示。
- 对象优先：牌、头像、桌面光效承担视觉，不靠大面板填充。
- 可点性：按钮有 bevel / shadow / hover；牌有 hover lift；当前可操作对象有发光。
- 截图第一眼：3 秒内看出自己是谁、轮到谁、下一步点哪里。

## template

- 顶部：轻量局信息条，不能压过牌桌。
- 左上 / 右上：两个对手座位，头像 + 牌背堆 + 身份。
- 中央上：三张地主牌。
- 中央：上一手牌或等待首家出牌的舞台。
- 中央下：叫分按钮或出牌响应按钮。
- 底部：自己的座位和手牌，手牌是最大交互区。
- 移动端：后续在桌面通过后按等比缩放和安全区让位；桌面未过不做手机完成口径。

## evaluator

阻塞项：

- 截图第一眼不像斗地主商业游戏。
- 当前行动只靠标题文字，座位无高光。
- 自己手牌不可读、不可点或选中反馈弱。
- 对手没有头像座位关系，只是文本。
- 主桌面出现大硬框、调试面板或网页卡片感。
- 叫分 / 出牌按钮不显眼或不像游戏按钮。
- E2E 只证明 canvas 能点，没有基础玩法截图链。

通过口径：

- 无阻塞项。
- 技术 E2E 跑通。
- 基础玩法截图链覆盖至少 5 步。
- AI 肉眼复看通过后才能给用户打开最终图。

## React / Phaser 分工

- 现有引擎、DomainCore、dispatch、playerView 继续是权威状态。
- React 负责 Provider、路由、外层 test id、全局 HUD、i18n 和非 canvas 壳层。
- Phaser 负责牌桌主视觉、牌对象生命周期、输入命中、选中/发牌/出牌 tween。
- Phaser scene 不保存权威状态；只保存渲染缓存、选中态和短暂动画态。
