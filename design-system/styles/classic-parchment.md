# 经典羊皮纸风格

定位：复古、温暖、实体桌游 / 规则书质感。适合经典桌游、文字叙事、规则书风格页面和需要卡牌实体感的界面。

## 视觉语法

- 暖色纸面：米色、棕色、金色作为主层级。
- 印刷感：文字、边框和留白模拟规则书，而不是现代 HUD。
- 低对比装饰：角落线、细边框和轻阴影可用，但不能抢内容。
- 实体感克制：卡牌像纸牌，面板像纸页，不做厚重 3D。

## 组件规则

| 组件 | 默认形态 |
| --- | --- |
| 主要按钮 | 黄 / 金色底、深棕文字、轻边框、短 hover 色阶 |
| 次要按钮 | 米色底、棕色边框、深棕文字 |
| 卡片 | 近白纸面、细棕边框、小圆角、轻阴影 |
| 装饰卡片 | 只在角落使用短线装饰，不做满框花纹 |
| 信息面板 | 米色底、弱边框、轻阴影 |
| 模态窗 | 纸面底、深棕文字、弱遮罩；内容优先于纹理 |
| 状态标签 | 使用深绿 / 深红 / 金色，保持低饱和 |

## 字体

| 用途 | 字体 |
| --- | --- |
| 标题 | `Crimson Text`, `Playfair Display`, `Georgia`, serif |
| 正文 | `Crimson Text`, `Georgia`, serif |
| UI 控件 | `Inter`, system-ui, sans-serif |

外部字体不是强依赖；不可用时按 fallback 渲染。

## 动效

| 场景 | 时长 |
| --- | --- |
| Hover | 200ms |
| 卡片翻转 | 400ms |
| 面板展开 | 300ms |

动效要像实体物品轻微移动；避免科技感毛玻璃、强弹簧和夸张缩放。

## 禁止项

- 不用冷灰色当主背景。
- 不做重度渐变、霓虹高光或玻璃拟态。
- 不把整页变成低可读纹理背景。
- 不用过多装饰角、花边和印章压住信息。
