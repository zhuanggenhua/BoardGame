# 战术简洁风格

定位：专业、清晰、信息密度高。适合策略对战、卡牌对战、棋类、军事模拟和需要快速扫描状态的界面。

## 视觉语法

- 扁平层级：用边框、阴影和底色区分结构，不靠装饰。
- 信息优先：棋盘、卡牌、单位和合法目标比背景更显眼。
- 冷色主调：深蓝灰背景，蓝色主操作，红 / 绿 / 黄只表达状态。
- 网格对齐：间距稳定，数字和状态标签易比较。

## 组件规则

| 组件 | 默认形态 |
| --- | --- |
| 主要按钮 | 蓝底、白字、`rounded-md`、短 hover / active 色阶 |
| 次要按钮 | slate 面板色、边框、白灰字 |
| 危险按钮 | 红色半透明底 + 红色边框，不能和主操作同权重 |
| 面板 | `bg-surface`、细边框、`rounded-lg`、适度内边距 |
| 悬浮面板 | 比基础面板更强边框和阴影，但不使用毛玻璃大面积遮罩 |
| 卡牌 | 深色底、清晰边框、hover 只强化边框 / 阴影 |
| 选中对象 | 蓝色边框或 ring，必要时加弱蓝阴影 |
| 状态标签 | 小字号、短文本、颜色只表达状态类型 |
| 棋盘格 | 固定比例，合法目标用蓝色半透明底和边框 |

## 动效

| 场景 | 时长 |
| --- | --- |
| Hover / focus | 150ms |
| 状态切换 | 200ms |
| 面板展开 | 250ms |
| 单位移动 | 300-400ms |

动效使用 `ease-out` 或线性过渡；避免弹跳、过度缩放和长时间闪烁。

## 排版

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 面板标题 | `text-lg` | `font-semibold` |
| 正文 / 描述 | `text-sm` | `font-normal` |
| 标签 | `text-xs` | `font-medium` |
| 关键数值 | `text-base` | `font-bold` |

组件内间距 `p-2` 到 `p-4`；组件间距 `gap-2` 到 `gap-4`；大区块 `gap-4` 到 `gap-6`。

## 禁止项

- 不使用大面积暖色、厚重纹理或装饰边框。
- 不用彩虹色表达普通状态；颜色必须绑定语义。
- 不让 hover 改变布局尺寸。
- 不用弹跳按钮、夸张 3D 厚边和儿童化动效。
