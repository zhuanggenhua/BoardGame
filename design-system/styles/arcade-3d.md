# 街机立体风格

定位：活泼、直接、物理反馈强。适合派对、骰子、轻策略、收集和儿童向界面。

## 视觉语法

- 立体按钮：底部阴影表达厚度，点击时下沉。
- 高饱和主色：主操作醒目，但功能色必须稳定。
- 粗体文字：按钮和关键数值使用 bold / black，避免细字。
- 圆角克制：常用 `rounded-lg` 到 `rounded-xl`，不要变成胶囊堆叠。
- 反馈明确：hover、press、选中和禁用状态必须一眼可见。

## 颜色 token

主色可按游戏替换，但必须保持 light / from / to / shadow 四级层次。

| 用途 | token | 默认值 |
| --- | --- | --- |
| 主色高光 | `--primary-light` | `#fcd34d` |
| 主色渐变起点 | `--primary-from` | `#fbbf24` |
| 主色渐变终点 | `--primary-to` | `#d97706` |
| 主色底部阴影 | `--primary-shadow` | `#b45309` |
| 危险高光 | `--danger-light` | `#f87171` |
| 危险起点 | `--danger-from` | `#ef4444` |
| 危险终点 | `--danger-to` | `#b91c1c` |
| 危险阴影 | `--danger-shadow` | `#991b1b` |
| 次要背景 | `--secondary-bg` | `#334155` |
| 次要阴影 | `--secondary-shadow` | `#1e293b` |
| 次要边框 | `--secondary-border` | `#64748b` |
| 次要文字 | `--secondary-text` | `#f1f5f9` |

可替换主色组：翡翠绿、宝石蓝、紫罗兰等；只替换 token，不改变组件语法。

## 组件规则

| 组件 | 默认形态 |
| --- | --- |
| 主要按钮 | 垂直渐变、浅色边框、4px 左右底部阴影、点击下沉 |
| 次要按钮 | slate 深色底、同样厚度阴影，权重低于主按钮 |
| 危险按钮 | 红色渐变和红色阴影，不和主按钮共用主色 |
| 信息面板 | 深色半透明底、细边框、轻阴影 |
| 激活面板 | 主色渐变、白字、弱发光 |
| 数字徽章 | 小圆角、粗体、最小宽度稳定 |
| 状态点 | 2-3px 级别圆点；只在在线 / 警告等需要时 pulse |
| 资源条 | 固定尺寸格子；填充态发光，空态低饱和 |

## 尺寸

| 尺寸 | 内边距 | 字号 | 阴影 |
| --- | --- | --- | --- |
| sm | `py-2 px-3` | `text-xs` | 3px |
| md | `py-2.5 px-5` | `text-sm` | 4px |
| lg | `py-3 px-6` | `text-base` | 5px |

## 动效

- Hover：轻微放大或亮度提升，不能改变布局。
- Press：按钮下沉并减弱阴影。
- 常规过渡 150-200ms。
- 可用短弹簧，但阻尼要足，不能连续晃动。

## 禁止项

- 不使用大面积单色霓虹背景。
- 不把所有控件都做成同权重的彩色大按钮。
- 不让文字因 uppercase、描边或阴影变难读。
- 不在高密度策略界面滥用厚按钮和强动效。
