# Mage Wars current-scope 入口合同 + 综合候选链 E2E 证据

> 文件名保留 `golden-flow` 是历史引用兼容；按现行规范，本证据归类为 `入口合同链 + current-scope 综合候选链`，不能登记为 `stable / pre-push` 主黄金链。

## 本轮目标

- 参考 DiceThrone 黄金链，反推 Mage Wars 应按“核心机制族”而不是“用户刚指出的常见操作”建立覆盖矩阵。
- 补齐本次发现的严重漏点：完整流程展示必须先覆盖选择法师 / 法术书入口，再进入牌桌候选链；牌桌计划阶段只能作为牌桌段第一张。
- 为标准竞技场 4x3、兽王 / 女祭司两派系标准起始书中已实现代表机制保留一条真实浏览器综合候选链。
- 明确区分：候选链覆盖了哪些当前代表机制；哪些只是分段 / 低层覆盖；哪些核心机制仍 deferred，不能被外推成完整实体版 Mage Wars。
- 标准书范围已切到规则书第 40 页四本标准起始法术书；墙体牌 `2500` 烈火之墙和 `25700` 荆棘之墙已纳入配置对象池，本地正式 runtime atlas/frame 已接入。当前候选链已纳入 `25700` 荆棘之墙边界施放 / 墙牌落位；墙体局部链覆盖墙前 / 墙后视线阻挡和穿墙通行伤害；`2500` 已通过共享流程判等覆盖，只有出现独有规则、入口差异、证据冲突或用户点名时才补直接浏览器链。服务器资源发布和完整无注入主黄金链仍未完成。

## 自动核验结论

- 入口选择：玩家先在选择页选中绑定法师的标准法术书，确认后进入对应法师牌桌；新建法术书必须先选绑定法师，命名副本能保存、编辑、删除并进入计划态。
