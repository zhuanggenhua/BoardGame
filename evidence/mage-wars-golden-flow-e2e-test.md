> 文件名保留 `golden-flow` 是历史引用兼容；按现行规范，本证据归类为 `current-scope 综合候选链`，不能登记为 `stable / pre-push` 主黄金链。

## 本轮目标

- 参考 DiceThrone 黄金链，反推 Mage Wars 应按“核心机制族”而不是“用户刚指出的常见操作”建立覆盖矩阵。
- 为标准竞技场 4x3、兽王 / 女祭司两派系标准起始书中已实现代表机制保留一条真实浏览器综合候选链。
- 明确区分：候选链覆盖了哪些当前代表机制；哪些只是分段 / 低层覆盖；哪些核心机制仍 deferred，不能被外推成完整实体版 Mage Wars。
- 标准书范围已切到规则书第 40 页四本标准起始法术书；墙体牌 `2500` 烈火之墙和 `25700` 荆棘之墙已纳入配置对象池，本地正式 runtime atlas/frame 已接入，公共墙体机制已有局部 E2E 证据；两张墙体牌的数据按现有录入基线使用，只有 Wiki、玩家反馈或新主真相源冲突时才复审。主黄金链整合和服务器资源发布尚未完成；`2500` 已通过共享流程判等覆盖，只有出现独有规则、入口差异、证据冲突或用户点名时才补直接浏览器链。

## 自动核验结论

- 正式入口：用例从正式双人联机房间进入标准竞技场，双方占座 / 加入后通过页面动作推进。
- 计划与隐藏信息：双方计划法术后，对手计划仍按牌背隐藏；图组第一张就是计划阶段，链尾也能回到下一轮计划。
- 召唤与部署：兽王和女祭司各自从正式页面召唤生物，并在截图前等待召唤过程帧和实体落场。
- 移动与目标：候选链复用已打绿的真实对象移动段，为后续攻击和代表态桥接建立状态；场上对象本体用于守卫、攻击和能力来源。
- 装备 / 结界：巨熊皮甲、风龙皮甲、公牛耐力和巨熊力量均先进入目标选择态，绿色合法目标由玩家点击后才结算为附件卡，并断言不会作为主场地单位出现。
- 魔物 / 攻击：缠绕藤蔓锚定目标对象；间歇喷泉通过正式页面触发攻击掷骰事件，并捕捉来源、飞行、命中过程帧。
- 守卫：阿希拉牧师通过正式页面执行守卫，服务端断言守卫标记存在；随后被近战攻击清除并记录守卫移除事件。
- 对象能力：阿希拉牧师治疗之光通过场上对象能力按钮发动，点击目标前高亮受伤野性山猫，点击后捕捉治疗光效和恢复数字过程帧，并由服务端断言对象能力事件、治疗掷骰事件和目标伤害降低。
- 法师能力：女祭司复原术通过法师能力入口发动，服务端断言法师能力事件、状态移除事件和燃烧状态消失。
- 终局：近终局代表态中基础攻击触发 `sys.gameover`，页面显示终局遮罩。

## 口径

- 允许说：Mage Wars 当前标准竞技场两派系已实现核心代表链已有一条单条 Playwright current-scope 综合候选链，并且更名后本地定向通过。
- 允许说：这条候选链复用了现有正式联机 fixture、页面操作 helper、代表态桥接 helper、召唤 / 攻击 / 治疗过程帧捕捉 helper、附件目标选择断言、附件 UI 断言和能力事件断言；它不是把低层散件测试改名冒充黄金链。
- 允许说：候选链覆盖当前范围的多项核心机制代表，并通过核心机制覆盖矩阵列明已覆盖、分段覆盖、低层覆盖和 deferred 边界。
- 允许说：墙体正式卡面接线、公共机制、浏览器墙前 / 墙后视线阻挡对照和穿墙通行伤害已有独立局部 E2E 和截图证据，可作为后续主黄金链整合的已打绿散件。
- 允许说：给用户看当前候选链截图时，应打开完整 24 张有序图组；第 1 张必须是计划阶段，单张终局图只能作为链尾证据。
- 禁止说：它已经是 `stable / pre-push` 主黄金链。
- 禁止说：完整实体版 Mage Wars、全 322 张法术、墙体主链整合、服务器资源发布、自由构筑、自然整局、完整 AI、教程、行动日志 UI、撤回 UI 或刷新恢复已经完成；也不能把共享流程判等改写成每张墙体牌都已有独立完整浏览器链。
