## 本轮锁定

- 问题对象：灰尘剧本下，当前三张攻击武器（砍刀、匕首、指环）从真实页面声明武器攻击、点击地图目标、分配伤害，并在永久叛徒死亡后触发狂热病患化和叛徒终局。
- 真相来源：`docs/games/betrayal/haunts/03-the-dust.md` 的死亡叛徒狂热病患化 / 掩埋 / 叛徒终局合同，当前 23 张运行持有牌中的攻击武器分类，以及真实入口 Playwright 用例 `e2e/betrayal/the-dust-attack-weapon-death.e2e.ts`。
- 目标入口 / 环境：`D:\gongzuo\webgame\BoardGame`，Playwright chromium，1600x900 真实牌桌页面 `/play/betrayal?players=3&seat0=human&seat1=human&seat2=human`，通过测试 helper 注入灰尘 + 攻击武器 + 临界死亡代表态。
- 验收口径：三张当前攻击武器逐张覆盖；玩家必须在真实页面选择武器并点击地图上的同房目标 token；受伤方必须在真实伤害分配面板分配对应物理 / 精神伤害；确认后核心状态进入灰尘叛徒终局，并在结果报告显示剧本“灰尘”和“叛徒得逞”。

## 自动断言覆盖

- 初始状态处于灰尘作祟阶段，攻击者和受伤方同房，第三名玩家已死亡，尚未进入终局。
- 三张当前攻击武器都在武器选择区可用，并分别写入 `usedCardIdsThisTurn`。
- 点击攻击入口后，地图上的受伤方 token 必须进入可点目标状态，并显示贴合 token 的五边形目标高亮。
- 砍刀和匕首进入物理伤害分配，允许力量 / 速度；指环进入精神伤害分配，允许知识 / 神志。
- 受伤方视角的伤害分配面板必须显示来源“攻击”和对应伤害数；未分配足额前确认按钮禁用。
- 确认分配后先出现灰尘 If You Win 结局朗读幕；点击“查看结果报告”后进入结果报告。
- 核心状态必须满足：阶段为 `endgame`，剧本为 `the-dust`，结果为叛徒胜利，胜者为攻击者，受伤方死亡并生成对应狂热病患，受伤方持有物被清空。

## 不外推边界

- 本证据只证明当前三张攻击武器（砍刀、匕首、指环）的真实页面完整致死链。
- 本证据不证明未来新增武器、远程武器、全部攻击变体、全部兔脚 / 头骨回滚组合、全部持有牌 UI、完整交易 / 搜尸 / 掩埋组合，或灰尘全部规则完成。
- 领域层逐武器死亡、掩埋、头骨失败后兔脚成功 / 仍失败矩阵仍以 `src/games/betrayal/__tests__/firstScenarioRuntime.test.ts` 的定向用例为主证据。
