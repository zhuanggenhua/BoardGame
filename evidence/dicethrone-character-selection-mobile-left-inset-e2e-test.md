# DiceThrone 移动端选角左侧 inset 结论作废说明

## 作废原因

- 该文档对应的是一次错误定位：把“左侧英雄列表上下太挤”误判成“整层左 inset 不够”。
- 当时通过修改 overlay / 左侧整栏 inset 去解释问题，方向不对，且后续已经确认这会把验收目标带偏。

## 失效结论

- “需要给左侧英雄栏额外补一条安全/视觉留白”这一结论失效。
- “把左侧贴边当成主问题处理”这一结论失效。

## 当前有效口径

- 当前有效证据改为：`evidence/dicethrone-character-selection-mobile-hero-list-spacing-e2e-test.md`
- 当前有效问题定义：左侧英雄列表是滚动列表，本轮只应微调列表项上下间距，不应为了首屏多露几项去改整层 inset、缩头像或挤压主内容区。
