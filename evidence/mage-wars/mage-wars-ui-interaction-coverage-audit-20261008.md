> 日期：2026-10-08，补证 2026-10-09 / 2026-10-10  
> 范围：`mage-wars` 当前工作树的玩家可见 UI 与 independent E2E 入口；golden 与 tutorial 分别管理，不并入 independent。  
> 2026-10-08 结论：法师魔杖新 UI 有直接真实入口 E2E；当时 independent 截图总览已复核。整款游戏全部 UI 的逐用例重跑不在该日通过声明内。

## 锚点扫描

- Mage Wars 非测试 TS/TSX 中静态 `data-testid`：125 个。
- 四个 independent E2E 文件逐字引用：123 个。
- 未被引用的 2 个锚点均来自未注册的普通移动 FX renderer，已有单测证明该 cue 不进入运行时；不是玩家可见 UI 漏洞。
- 该扫描不替代逐个检查动作、正式状态变化和截图。视口、选书、组书、取消/响应、墙体、撤回和终局等用例仍按各自真实合同判断，不能因 `123/125` 直接宣称“全 UI 全分支通过”。

## 裁决

- 用户点名的法师魔杖新 UI 已有真实双人牌桌 E2E、对象专属候选牌截图、绑定结果和快速重绑资源变化；此前候选浮层图面问题已有 2026-10-01 / 10-02 同源重构逐图审计记录。9/30 的旧 `REVISE` 清单已被后续记录取代，不能继续作为当前结论。
- 当前 independent 截图总览为 `PASS`：12 组、64 个媒体。`20261009` 与 `20261008-r2` 是历史包。
- 该结论只覆盖此总览与上述直接 E2E 证据，不表示本轮重新运行了所有 Mage Wars E2E 文件。独立复核服务曾返回 503，记录为不可用，没有计作代理通过。

### 产品修复（已有单测）

- 己方 / 对方车道格子去掉 rose / sky 测试色块。
- 魔杖绑定后，绑定法术名叠在杖前；整组可点。
- 选中后动作按钮无外框，停在全屏中下 `middle-lower-action-dock`。
- 检视放大层展示附件，可在该层点附件；动作条仍在屏幕中下。
- 法师魔杖 / 元素魔杖绑定法术可未准备施放，施放后不弃牌。
- 群兽法杖为 OR：治疗 或 近战 +2 至回合结束；近战加成后显示 `mage-wars-melee-bonus-marker`。
- 推斥 / 移动改为 `MageWarsEntitySlide`，不再发炮弹。
- 召唤 FX 挂在卡牌底图层，略大于卡面。

### 产品修复

- 中下动作条停在法术书上方，按钮 `h-9` / `min-w-[6.75rem]` / `nowrap`，发动、模式选择、绑定施放共用同一套尺寸。
- 放大层检视棋盘单位棋子（法师肖像或场上生物），不是 HUD 角色介绍卡。
- 放大镜统一为大杀四方手牌无十字实心样式，尺寸 `clamp(22px, 2vw, 38px)` / `clamp(12px, 1.1vw, 21px)`。
- 附加卡宽度约为宿主卡宽三分之一，场上条和放大层同时成立。
- 推斥克隆真实棋子从源滑到目标，活棋用 `relocatingAnchorIds` 隐藏；传送仍走闪现。
- 召唤沿用现有 `SummonHybridEffect` 光柱，`pillarWidthRatio=1` 等宽贴卡；去掉另做的光圈叠加。Summoner Wars 默认细柱不变。
