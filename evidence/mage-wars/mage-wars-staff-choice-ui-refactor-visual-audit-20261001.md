# Mage Wars 魔杖选择 UI 重构后逐图验收

> 审计日期：2026-10-01  
> 状态：`PASS`  
> 范围：法师魔杖、元素魔杖的真实施放、绑定选择、快速重绑和结算。

## 本轮硬要求

1. 候选对象必须以正式法术牌本体呈现。
2. 卡牌已有的名称、费用、类型、射程、效果不得在卡外重复渲染。
3. 选择弹层必须保护竞技场、法术书牌列、己方 HUD 和取消入口。
4. 玩家可见界面不得泄漏内部 `mageId`、测试标签或调试 ID。
5. 结算态必须显示真实绑定结果和法力变化。

## 重构结论

- 新增共享框架组件：`src/components/game/framework/CardChoiceOverlay.tsx`。
- 组件只负责卡面、选中 / 禁用状态、无障碍名称和取消入口；默认不渲染卡外牌名、费用、类型或效果。
- Mage Wars 的施放选择和快速重绑选择共用同一组件。
- 取消了会导致截图首帧空弹层的入场透明动画，确保真实截图时牌面立即可见。
