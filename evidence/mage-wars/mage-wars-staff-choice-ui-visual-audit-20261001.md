> 目标：证明法师魔杖与元素魔杖的真实施放、选择、快速重绑链路有清晰可用的玩家 UI。

## 本轮要求

1. 两个魔杖对象都必须有真实页面端到端入口。
2. 绑定和快速重绑选择态必须显示正式候选法术牌本体，而不是文字行。
3. 选择弹层不得遮挡竞技场、底部法术书牌列、己方 HUD 和取消入口。
4. 玩家可见界面不得泄漏内部 `mageId` 或其它测试 / 调试 ID。
5. 结算态必须能看见新绑定法术和法力消耗结果。

- 法师魔杖：`e2e/mage-wars/online-runtime.e2e.ts`，真实页面选择来源卡 -> 己方法师 -> 候选法术 -> 再次快速重绑；结果 `1 passed`。
- 元素魔杖：`e2e/mage-wars/online-runtime.e2e.ts`，真实页面选择来源卡 -> 己方法师 -> 候选法术 -> 取消 / 快速重绑；结果 `1 passed`。
- 组件回归：`Board.fx.test.tsx`，结果 `68 passed / 68`。
