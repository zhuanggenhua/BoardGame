# 《法师战争》单局教程文案工作稿

开场接手第 5 回合的兽王。兽王、丛林灰狼和敌方高地独角兽在同一区域。灰狼已有 3 点伤害，双方法师本轮普通行动已用，兽王还留着快速施法，已准备次级治疗。此局面由正式开局向前复演取得。女祭司带有一张精华汲取，法术书按项目构筑校验为 118 点。教程只载入这一次，后面沿用同一盘的资源、伤害、牌和行动状态。

| 时机 | 玩家看到的提示 | 触发与分支 |
| --- | --- | --- |
| 入场 | 独角兽已经冲到你面前。灰狼刚挨了一击，但还站得住。先让它护住兽王。 | 镜头能直接点到灰狼就保持原位。 |
| 选中灰狼 | 让灰狼守卫。只要它还守着这个区域，对手的近战就得先对付它。 | 玩家亲自选灰狼并提交守卫。 |
| 守卫已就位 | 灰狼站稳了。趁对手还没进攻，用准备好的次级治疗给它处理伤口。 | 这里使用独立的快速施法标记。 |
| 选中治疗 | 点受伤的灰狼。掷出的点数越多，能治的伤越多，最多治到没有伤。 | 不预写结果。 |
| 治疗掷骰结束 | 骰子给的是治疗点数，灰狼身边显示实际治好了多少。它只有 3 点伤，掷得再高也只会治 3 点。 | 全空时显示「这次没掷出治疗点。灰狼仍然守在原地。」数字按实时结果。 |
| 对手近战 | 独角兽得先撞上灰狼。看看防守方的护甲抵掉了多少普通伤害。致命伤害会穿过护甲。 | 展示正式攻击事件和实得伤害。全空仍展示掷骰。 |
| 玩家回应 | 灰狼还站着，可以咬回去。你也可以放弃反击。选完以后，这次守卫就结束了。 | 玩家自主反击或放弃，保留结果。 |
| 回合交替 | 新回合到了。行动标记会重新就绪，法师会聚魔，持续在场的效果也会结算。轮到你决定这回合准备什么。 | 本局若独角兽有伤再提示「独角兽有重生，刚回了一些生命」。 |
| 计划 | 这一轮准备丛林灰狼和兽性觉醒。两张牌各占一个计划槽。还没确认时，你可以把选错的牌拿下来。 | 对手只看到计划数量。用过、已绑定或在场的牌不能作为同一副本再次准备。 |
| 部署 | 部署时只有已经准备好法术的再生点能出手。你的两张牌继续留在准备区。 | 第一次经过时解释。没有再生点行动时略过重复说明。 |
| 优先快速施法 | 可以现在用快速施法，也可以留到生物行动。兽性觉醒得等新灰狼进场再用。 | 明确为何暂留额度，不误导在部署施放。 |
| 独角兽退到邻区 | 独角兽退了一格。这回轮到你进攻。让原来的灰狼跟进。 | 该目标在移动及攻击前必须仍有效。 |
| 灰狼移动后 | 灰狼已经追到同一区域，还能做一个快速行动。选噬咬，攻击独角兽。 | 玩家提交主动近战。 |
| 近战结果 | 击败分支「独角兽倒下了。这张生物牌进了弃牌堆。」存活分支「独角兽还站着。它身上的伤会保留，除非之后被治疗或重生移除。」 | 不把存活写成必然击败。 |
| 兽王行动 | 现在兽王有完整行动。打出准备好的丛林灰狼，在兽王所在区域召唤。 | 正式施法消耗 9 法力。 |
| 灰狼入场 | 新灰狼已经到了。它这一回合还不能行动，除非被唤醒。选兽性觉醒，再选刚来的那一只。 | 花费等于目标等级。本局为 2。上回合入场的灰狼不能成为目标。 |
| 觉醒后 | 它的行动标记翻回来了。等轮到它，再把它移到旁边。 | 玩家亲自移动。若仍有活动生物，不直接进入最终快速施法。 |
| 准备墙与推斥 | 对手的法师在往中间靠。准备荆棘之墙和原力推斥，先给她下一步留个陷阱。 | 两张均在本局实际法术书内。 |
| 施放墙体 | 点在两个区域之间的边界上。荆棘会遮挡视线，穿过它还可能挨打。 | 指向真实边界，不用某个区域点击冒充选墙边。 |
| 再计划推斥 | 上回合没有用掉的推斥回到法术书里了。这次准备它，等对手到了墙边再动手。 | 不重复展示已经教学的整套空窗。 |
| 选择推斥方向 | 选靠墙的女祭司，再选墙对面的区域。这一推原本花 3 法力，穿过会攻击的墙还要多付 3。 | 保持玩家当前缩放和视角，只在目标不可操作时引导找回。 |
| 荆棘攻击结算 | 女祭司是 6 级生物，这道墙会对她攻击五次，每次两颗骰。1 级生物通过这道墙时不会挨打。 | 玩家看到独立的实际骰面与最终伤害。 |
| 计划伏下结界 | 对手可以用咒语对付你受过伤的灰狼。准备法力失效，先给它留一道保护。 | 提前规划与后面的实际对手施法相连。 |
| 伏下法力失效 | 花 2 点法力，把它伏在灰狼身上。对手看得见结界已经伏下，但看不到是什么。 | 此时结界不生效，不扣展示费。 |
| 对手向灰狼施法 | 女祭司想让灰狼睡过去，触发了法力失效。支付 2 点法力展示，能把这道法术反制。你也可以不付，让结界弃置。 | 足额且支付才反制。不付或不足时让原法术继续。 |
| 反制或放弃后 | 已反制「灰狼没睡着。女祭司已经支付的施法费用不会退回。」未反制「结界已弃置，灰狼陷入沉睡。现在它不能照常行动。」 | 两句由状态与事件择一。 |
| 装备皮甲 | 对手正在调来更多生物。让兽王先穿上巨熊皮甲。以后兽王挨打时，它能抵掉一些普通伤害。 | 装备留在法师身上，移动时一起移动。 |
| 缩短施法距离 | 女祭司身边来了一个牧师。兽王前进一格，下一回合就能用间歇喷泉打到它。 | 对范围外目标应说明距离，不给笼统的「不可操作」。 |
| 攻击法术 | 点间歇喷泉，再点牧师。黄色效果骰决定是否出现附带效果，攻击骰决定能打出多少伤害。 | 全空、眩晕与击败各由正式结果触发。 |
| 对手复原 | 牧师中了眩晕。女祭司用复原术驱掉了它，只付了这个状态的移除费。 | 只在牧师存活且实际施放复原术时显示。若已击败牧师，沿结果直接继续。 |
| 魔杖绑定 | 法师魔杖可以夹住一张咒语。先选要绑定的单体治疗。之后施放时仍然要付费，也要满足范围和时机。 | 学习正式绑定目标入口。 |
| 下轮改绑 | 现在给魔杖换成次级治疗。支付改绑费，原先那张会回到法术书。 | 读实际法术书副本，改绑 3 法力。 |
| 对手附上精华汲取 | 女祭司把精华汲取用在第二只灰狼身上。下回合要交 2 点法力，才能让它继续留在场上。 | 早先守卫的灰狼保持原状。 |
| 维持付费 | 现在轮到你决定。花 2 点保住这只灰狼，还是省下法力、放弃它？ | 保留两个正式选项。法力不足时按实际规则结算。 |
| 维持结果 | 付费时「灰狼留下了。只要精华汲取还在，下回合还要再决定。」放弃时「这只灰狼离场了。它和附着的结界分别回到双方的弃牌堆。」 | 第一次决策后接建巢。后续付费或放弃都能继续，原先那只灰狼还在。 |
| 施放巢穴 | 兽王只能准备自己的法术。建一座巢穴，它也能准备一张动物生物牌，并在部署时替你施放。 | 第 14 回合快速施放，花费 15 法力。 |
| 为巢穴计划 | 巢穴这回合聚了 4 点。把苦木林狐分给它，留出兽王自己的计划位。 | 从真实棋盘选择巢穴，再从法术书选牌。 |
| 由巢穴部署 | 茂林里的帮手已经准备好了。苦木林狐花 5 点，巢穴出 4 点，兽王补 1 点。它会出现在巢穴所在的区域。 | 核对同一回合资源和落点。 |
| 使用魔杖 | 灰狼还有伤时，就从魔杖里施放次级治疗。施放后，牌留在魔杖里，下回合还能用。 | 点实际魔杖进入该卡的合法对象列表。若狼已无伤，则按场上其他实际受伤单位承接，未选中合法目标就不提交。 |
| 对手拿出弓 | 女祭司拿出了野银长弓，灰狼已经在她的射程内。给灰狼施放灵蛇反射，让它有机会躲开这一箭。 | 本段讲可用的立即展示方式。女祭司通过正式装备攻击命令射击灰狼。 |
| 防御响应 | 箭来了。你可以用灵蛇反射试着躲开，也可以留着这次防御。选用它，就掷黄色的十二面骰，看能不能达到牌上的点数。 | 防御和放弃分别保留；实际防御门槛读取卡牌。 |
| 防御结果 | 成功时「躲开了，这一箭不会造成伤害。」未成功时「没能躲开。接着算箭造成的伤害。」放弃时「这次不用防御。看看这支箭造成多少伤害。」 | 只有玩家实际使用防御时才有防御骰。未回避时继续真实攻击流程。 |
| 法师追击 | 女祭司就在前面。让兽王靠近她。下一次轮到兽王行动时，就能亲自攻击。 | 本段不承诺走到后立刻攻击，接到实际可用动作。守卫存在时须先解决守卫。 |
| 法师攻击 | 现在兽王和女祭司在同一个区域。选兽王，再指向女祭司，用兽王自己的近战攻击。 | 读取真实攻击候选。击败、存活和玩家战败均允许成为真实终局。 |
| 对方法师仍在场 | 女祭司还站着。看她还剩多少生命，再决定继续追击、用法术，还是先保护自己的法师。 | 移交同局自由对战。继续使用现有牌、法力与动作。 |
| 对局结束 | 胜利时「女祭司倒下了，这场决斗结束。是你亲手守住阵地、找到机会，再让兽王打出了最后一击。」失败时「兽王倒下了，这场决斗结束。下次留意对手的射程，给自己留一次防御或脱身的机会。」 | 胜利文案最后一句只有法师直接近战击败时使用。其他胜利改为「你击败了对手的法师。」 |

回合阶段提示随真实阶段出现，悬浮可查当前阶段和能做的事。对应文案为「重置：刷新行动标记；仍满足条件的守卫会保留。」「聚魔：法师与有聚魔数值的牌获得法力。」「维持：选择是否保留须付费的效果，结算场上持续状态。」「计划：双方各自选择要准备的牌。」「部署：依次处理再生点已经准备好的法术。」「优先快速施法：可以现在施放，也可以保留标记。」「生物行动：双方轮流激活一个就绪生物，法师也在其中。」「最终快速施法：还有快速施法标记的一方可以用掉，再进入新回合。」

操作说明放在首次真正用到的位置。桌面选牌时用「想细看这张牌？鼠标移到牌上，再点放大镜。」关闭放大时用「把鼠标移到放大的牌上，点关闭。」触控文案用「长按卡牌放大，点关闭返回。」查看弃牌时用「点弃牌堆，看看用过的咒语和被击败的生物。」核对对手时用「点对手头像可以看公开信息，点自己的头像回来。」反制分支适合用「双方刚做了什么，可以在对局记录里回看。」这些交互实际发生后才计入覆盖。

### 随局打开的规则释义

这些短文供玩家在遇到对应卡牌、状态或问题时回查。正文保留当前这一步要做的事。

| 在哪里看 | 玩家看到的说明 |
| --- | --- |
| 初次看法师和棋盘 | 你控制一名 6 级法师。你的法师倒下，你就输掉这场决斗。棋盘分为区域，墙在区域之间。生物、墙、魔物、结界和装备都是对象。拥有者是牌原来所属的玩家，控制方负责使用它。对战时，另一方是敌方。 |
| 第一次换回合 | 每轮交换先手，先手标记告诉你现在归谁。正面朝上的行动标记表示生物能被激活。激活后，它可以移动、攻击、施法、守卫或不做动作，选择取决于种类和时机。卡上的记号另有用途，例如写明能力已使用或还剩几次。 |
| 看完整行动 | 生物可以留在原地做标准行动，也可以移动后做一个快速行动。第二次普通移动本身也是快速行动。法师还有一枚独立的快速施法标记，可在快速施法窗口及合适的己方生物行动前后使用。 |
| 看移动限制 | 区域有能阻碍你的敌方生物时，通常就不能连走两格。迟缓再限制移动后的行动。迅捷增加移动机会，不会让你无视阻碍。遁逸可以无视敌方阻碍和守卫，小型生物不能拦路。束缚阻止普通移动和守卫，瘫痪还会阻止攻击、施法、反击和通常的防御。 |
| 看墙边和跨越 | 会阻挡视线的墙会断开目标视线。会阻挡通行的墙不能正常穿过。带通行伤害的墙会在穿越时攻击；攀爬要花标准行动，也可能挨墙的攻击。推斥撞上阻挡通行的墙或竞技场边缘时，会挨一次无法回避的三骰攻击。传送直接换区域，绕过中间的墙和生物。延伸会多花法力，用法术书里另一张同名墙接出一段。 |
| 看卡的使用限制 | 等级和法系关系到学习代价，也会限制目标或来源。初级牌每张只花 1 点收录，史诗牌在法术书最多放一张。传奇牌限制同名对象在场数量，独有限制你自己的同名对象。一个区域只能有一个带区域独占的魔物。法师专用法术要由法师施放。法师绑定会提高以法师为目标时的展示费用。 |
| 看魔杖与施法生物 | 魔杖绑定的牌留在装备上，每轮可按规则施放一次。法师要为自己准备法术。魔宠可以另外准备，并用合适的行动施放；再生点在部署行动，先用自己的法力，差额由控制它的法师补足。 |
| 看布置结界 | 结界可以先伏在目标上。你知道它是什么，对手只知道这里有一张伏牌。展示时再付牌上的展示费用。写有强制触发的结界在指定时机展示，触发时付不起就会失去这张结界。反制截断还没结算的法术，已放在场上的对象被摧毁时才离场。 |
| 看守卫与攻击目标 | 普通近战打同区，远程看卡上的最短、最远距离和视线。守卫会迫使能被它拦截的近战先打守卫；小型守卫和遁逸有例外。飞行有自己的目标限制，带远触的近战可以打同区的飞行生物。区域攻击分别打目标区域内的对象，边界上的墙不在这批目标里。 |
| 看攻击骰 | 庇护先减攻击骰，只用最高一份，至少还留一颗。近战、远程和冲锋上的加骰看自己的触发条件。普通伤害先经过护甲，穿刺会削弱护甲；致命伤害穿过护甲。直接伤害不用攻击骰，也不从护甲里扣。 |
| 看防御和多次攻击 | 防御在命中前尝试回避，无法回避的攻击会跳过这一步。攻击命中可以掷出零伤害。反伤屏障在对应时机还击，和近战反击分别结算。两连击、三连击和横扫各有自己的目标规则，按次结算。首次攻击才享受的加成不重复计算。一个攻击或法术被取消时，停止后续效果。 |
| 看生物属性 | 活体通常可以治疗，也可能受毒素和精神效果影响。非活体具有毒素免疫和有限生命，有限生命会挡住治疗和重生。虚体通常只计攻击骰上的 1，以太攻击可以正常结算伤害和附带效果。带不羁的生物不会被束缚。 |
| 看伤害附带效果 | 黄色十二面骰也用于检查附带状态和逃逸。维持时每枚燃烧标记掷一颗攻击骰，掷到零就移除该标记，腐化会直接造成伤害。虚弱影响攻击，眩晕可能让攻击落空。昏迷和沉睡会限制行动，睡着的生物受伤会醒来并变为眩晕。残废会束缚生物，行动结束时能尝试逃逸。牌写着无法燃烧，就不会获得燃烧状态。 |
| 看其他能力 | 嘲讽可能指定下一次近战的目标；有嗜血的生物遇到同区受伤的活体敌人时可能必须进攻。狂怒随受伤累积进攻加成，治疗时会减退。吸血把满足条件的近战伤害转为治疗。陷阱在牌写明的时机触发，法力流失和法力传输会在满足攻击条件后改变法力。 |
| 看维持 | 有维持费用时，先看哪一方需要支付、放弃的对象是什么。不付就按能力写的方式移除。治疗移除现有伤害，重生通常在维持阶段自动发生。想提前移除状态，先看你的法术或能力能移除哪些状态、要花多少法力。 |
