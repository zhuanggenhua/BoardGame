# 山屋惊魂作祟3「灰尘」主动持有牌玩家可见代表链

## 验收对象

- 本证据只覆盖当前 8 张主动持有牌在作祟3「灰尘」阶段的玩家可见入口和真实页面使用链：急救包、奇怪的药品、地图、笔记本、日记、手稿、书本、面具。
- 本证据修正并验证的缺口是：灰尘作祟阶段存在“攻击灰尘”等主动作时，玩家选中主动持有牌后，底部“使用”按钮必须切回持有牌使用语义，而不能继续执行作祟主动作。
- 本证据不代表全部持有牌 UI / E2E、全部交易 / 搜尸 / 兔脚 / 掩埋组合、全部攻击武器 UI 或灰尘全部规则完成。

- `npx eslint e2e\betrayal\the-dust-active-possession-ui.e2e.ts e2e\betrayal\betrayalTestHelpers.ts`：0 errors。
