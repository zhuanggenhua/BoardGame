# 召唤师战争网页 / 手机发布版本核对

日期：2026-07-13

## 用户现象

- 电脑网页端不显示新派系。
- 手机端可以显示新派系。

本轮锁定的新派系为莫古（`mogu`）。

## 真相源与结论

### 本机源码

- 莫古由提交 `18a097f97a70f22cdb7316c784843f1f875385ad` 于 2026-07-12 19:11 +08:00 加入。
- 当前派系列表中莫古 `selectable=true`，同时保留 `under_construction` 用户可见状态。

### 生产服务器容器

- `boardgame-web` 与 `boardgame-game-server` 镜像 revision 均为 `f565de178019148e196b5d0c4e49f4b90b4264a0`。
- `18a097f9` 是 `f565de17` 的祖先，且 `f565de17` 中的召唤师战争派系列表包含莫古。
- 因此生产容器镜像本身不是“没有莫古的旧服务器版本”。

### 公网网页入口

- `https://easyboardgame.top/` 当前由 Cloudflare Pages 返回。
- 公网页面实际 JavaScript 包内产品版本为 `0.6.4`。
- 公网召唤师战争相关代码块不包含 `mogu / 莫古`。
- 结论：电脑网页不显示莫古，是 Pages 网页入口仍在旧前端包，不是浏览器仅隐藏了卡片。

### Android stable

- stable OTA `latest.json` 标记 `productVersion=0.6.5`，发布时间晚于莫古提交，因此已安装该 OTA 的手机可以显示莫古。
- 召唤师战争独立素材包仍为 `0.6.4`；这不阻止莫古入口代码出现，因为游戏模块代码来自 OTA，素材包只承载独立资源。
- 发布完整性异常：stable OTA `latest.json` 当前引用的 `6.0.0-ota-2026-07-12T13-28-04-101Z.zip` 返回 404；已安装手机可继续使用本地版本，但新安装或重新下载无法用该 URL 取得同一 OTA。
