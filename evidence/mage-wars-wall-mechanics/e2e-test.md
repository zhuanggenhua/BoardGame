# Mage Wars 墙体机制局部 E2E 证据

> 本文件记录标准起始书内墙体的局部可玩链路和对象级判等；它不是 Mage Wars 主黄金链完成证据，也不证明全卡表或完整实体版 Mage Wars 已经闭合。

## 范围

- 代表牌：兽王标准起始书 `25700` 荆棘之墙。
- 同机制覆盖：邪术师标准起始书 `2500` 烈火之墙复用同一公共墙体边界、墙体状态、视线阻挡和通行伤害实现；`2500` 与 `25700` 的正式 runtime atlas/frame 已接入本地资源链。数据按当前录入基线使用，只有 Wiki、玩家反馈或新主真相源冲突时才复审。
- 玩家链路：墙前远程攻击目标可选、选择已准备墙体法术、点击 A3-B3 区域边界、生成可见源墙牌的墙体对象、墙后同一远程目标不可选、场上生物穿越该边界并受到通行伤害。
- 不覆盖：主黄金链整合、完整实体版 Mage Wars、服务器真实资源上传和全卡表。若后续用户点名要求 `2500` 烈火之墙“直接浏览器完整端到端”，再补该对象直接链；当前不是默认阻塞项。

## 验证命令

```powershell
node scripts/infra/run-e2e-single.mjs ci e2e/mage-wars/online-runtime.e2e.ts "正式页面墙体法术可选择边界并在穿越时触发通行伤害"
```

结果：2026-08-24 重跑 `1 passed (19.0s)`，`.last-run.json` 为 `passed`。

## 自动断言

- 正式页面墙前选择皇家箭手后，A3 到 B3 的阿希拉牧师目标可选且可点击。
- 正式页面从准备区选择 `25700` 荆棘之墙后，A3-B3 边界暴露为合法墙体目标。
- 点击边界后，服务端权威状态写入 `core.walls['a3-b3']`，并记录 `MW_WALL_SUMMONED`。
- 墙体生成后，A3-B3 边界上的可见对象包含 `data-wall-visual="spell-card"`，并保留 `data-source-card-id="25700"` 的源墙牌预览。
- 施法结算事件 `MW_SPELL_CAST_RESOLVED` 保留 `targetWallEdgeId='a3-b3'`，能回查玩家选择的真实边界。
- 墙体生成后再次选择皇家箭手，B3 的阿希拉牧师不再作为远程攻击合法目标，页面目标状态为不可用。
- 野性山猫从 A3 穿越到 B3 后，服务端记录 `MW_WALL_PASSAGE_DAMAGE_TRIGGERED` 和真实 `DAMAGE_DEALT`，对象伤害大于 0。

## 口径

- 可以说：`2500` 和 `25700` 的本地正式 runtime atlas/frame 已接入；墙体公共领域行为、边界目标 UI、源墙牌可见、浏览器墙前 / 墙后视线阻挡对照和一条真实页面穿墙伤害链已经跑通；`2500` 通过共享流程判等和领域证据覆盖，不是未审计对象。
- 可以说：`2500` 和 `25700` 不再是“完全没有墙体运行机制”或“缺正式卡面接线”；数据仅在出现 Wiki、玩家反馈或新主真相源冲突时复审。
- 不能说：Mage Wars 主黄金链已完成、服务器资源已发布、全卡表已完成或完整实体版 Mage Wars 已完成。
