# Mage Wars 墙体机制局部 E2E 证据

> 本文件记录标准起始书内墙体的局部可玩链路；它不是 Mage Wars 主黄金链完成证据，也不证明正式 runtime atlas、精确牌面数值或全卡表已经闭合。

## 范围

- 代表牌：兽王标准起始书 `25700` 荆棘之墙。
- 同机制覆盖：邪术师标准起始书 `2500` 烈火之墙复用同一公共墙体边界、墙体状态、视线阻挡和通行伤害实现；正式牌面精确数值仍待审计。
- 玩家链路：选择已准备墙体法术、点击 A3-B3 区域边界、生成墙体对象、场上生物穿越该边界并受到通行伤害。
- 不覆盖：正式墙体卡图 atlas、全墙体逐牌精确数值、浏览器内攻击前后视线阻挡对照、主黄金链整合和完整实体版 Mage Wars。

## 验证命令

```powershell
node scripts/infra/run-e2e-single.mjs ci e2e/mage-wars/online-runtime.e2e.ts "正式页面墙体法术可选择边界并在穿越时触发通行伤害"
```

结果：`1 passed (16.5s)`，`.last-run.json` 为 `passed`。

## 自动断言

- 正式页面从准备区选择 `25700` 荆棘之墙后，A3-B3 边界暴露为合法墙体目标。
- 点击边界后，服务端权威状态写入 `core.walls['a3-b3']`，并记录 `MW_WALL_SUMMONED`。
- 施法结算事件 `MW_SPELL_CAST_RESOLVED` 保留 `targetWallEdgeId='a3-b3'`，能回查玩家选择的真实边界。
- 野性山猫从 A3 穿越到 B3 后，服务端记录 `MW_WALL_PASSAGE_DAMAGE_TRIGGERED` 和真实 `DAMAGE_DEALT`，对象伤害大于 0。

## 口径

- 可以说：墙体公共领域行为、边界目标 UI 和一条真实页面穿墙伤害链已经跑通。
- 可以说：`2500` 和 `25700` 不再是“完全没有墙体运行机制”，但仍是 `正式 atlas / 精确牌面审计未闭合`。
- 不能说：Mage Wars 主黄金链已完成、墙体正式素材已完成、全墙体逐牌已完成、浏览器视线阻挡对照已完成或完整实体版 Mage Wars 已完成。
