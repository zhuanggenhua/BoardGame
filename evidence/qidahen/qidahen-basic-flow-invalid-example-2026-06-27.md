# 七大恨基础玩法截图链失效说明

## 结论

`2026-06-27` 这一轮曾尝试整理一套“七大恨基础玩法截图链”，但该版本**不得作为正式交付物、正式模板或真相源复用**。

## 失效原因

### 1. 使用了教程态 / 本地测试入口，不是联机固定玩家视角

- 对应 E2E 入口是 `e2e/qidahen-basic-flow.e2e.ts` 中的 `/play/qidahen/tutorial`
- 这条链路服务的是教程/测试态，不是联机房间中某个固定 viewer 页的连续体验
- 因此它不能直接回答“联机玩家自己从头到尾看到什么”

### 2. 截图链跨到了下一位势力视角

- 旧版本把 `大明` 行动结束后切到 `蒙古` 行动窗口也写进了同一条“基础流程”
- 这违反了固定玩家视角的联机截图要求
- 在联机语义下，这种链路只能算“多势力演示”或“本地教程演示”，不能冒充“单玩家基础流程”

### 3. 文档说明默认化了不应常驻的描述性正文

- 旧版本用“这一步玩家现在要做什么”等整句描述去解释截图
- 这会反向鼓励把 `这一步做什么 / 现在执行 / 下一步点击哪里` 这类正文塞回玩家主 UI
- 该写法与项目“主 UI 禁止描述性正文”的口径不一致

### 4. 把右侧区域默认写成主提示承载位

- 旧版本多次把“右侧行动区/右侧红色提示框”写成当前唯一主提示入口
- 但用户已经明确指出：这类主提示应优先作为上方横幅或正式主槽位承接，而不是默认落在右侧说明区

## 现状态

- 旧的 `qidahen-basic-flow-e2e-2026-06-27.md` 已删除，避免继续误导后续协作者
- 现有截图目录 `test-results/evidence-screenshots/_shared/qidahen-基础玩法流程/` 目前只能视为**候选素材目录**，不能直接当正式联机基础流程证据

## 后续正确做法

- 若要做正式“联机玩家基础流程”，必须先锁定固定 viewer/seat
- 流程链不得跨到别的势力页面
- 玩家主提示必须服从正式 UI 槽位，不得靠右侧说明区常驻正文承接
- 若当前 UI 仍需要靠长句解释“这一步做什么”，应先判 UI 本身未收口，再谈截图链
