# 山屋惊魂作祟 3「灰尘」：灰尘冲动 + 头骨死亡保护代表链

## 结论等级

- 结论：代表性玩法已验证，仍有残余范围。
- 范围：只证明「灰尘冲动」一般伤害在玩家分配到骷髅后，会触发头骨死亡保护；成功时阻止死亡并等待玩家确认后交接，失败时才死亡并生成狂热病患。
- 非范围：不等于灰尘完整作祟完成，不覆盖其它死亡保护组合、其它伤害来源、全员感染全排列、完整英雄治愈胜利或死亡叛徒怪物化全排列。

## 规则合同

- 作祟 3「灰尘」中，回合内未交换疾病标记的探索者在结束回合时承受「2 骰一般伤害」。
- 头骨死亡保护属于「将要死亡」时触发的死亡保护，不能只限定在物理 / 精神 / 攻击伤害；一般伤害分配到骷髅同样应触发。
- 受伤玩家必须先完成伤害分配，系统才能判断是否触达骷髅；如果触发头骨，死亡保护骰盘必须先展示并等待确认，不能立刻跳到下一名玩家。

## 实现覆盖

- 伤害分配事件现在允许一般伤害触发头骨死亡保护，`deathPrevention.damageKind` 可记录 `general`。
- 灰尘冲动若带有回合交接信息，会在头骨死亡保护骰盘确认前保持当前玩家；点击「返回牌桌」后才执行下一玩家交接。
- E2E 夹具覆盖成功 / 失败两支：
  - 成功：投出 6，阻止死亡，不生成狂热病患，确认后交给下一名玩家。
  - 失败：投出 0，正常死亡，死亡玩家生成狂热病患，确认后交给下一名玩家。

## 残余范围

- 灰尘仍缺其它死亡保护组合、其它伤害来源和死亡叛徒怪物化路径全排列。
- 灰尘仍缺全员感染 / 死亡触发叛徒胜利的更多排列，以及完整英雄治愈胜利全路径回归。
- 这条代表链只覆盖「灰尘冲动一般伤害」与「头骨」组合，不外推到所有作祟、所有死亡保护物品或所有怪物攻击。
