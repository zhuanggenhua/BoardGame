# 聊天窗口比例修正

本轮只修正现有聊天窗的频道、成员与底部控件占位，保留玩家／房间频道行为。

- 频道改为自然文字宽度、二十八像素高的下划线标签，取消整行大色块。
- 成员入口并入频道行，房间号与可见范围合为一条辅助信息。
- 输入高三十二像素，表情／发送只显示小图标；外围透明命中区补足四十四像素且不侵入输入框。
- 本轮真实联机端到端：`npm run test:e2e:file -- e2e/dicethrone/chat-channels.e2e.ts`，一项通过，总时长二十六秒。
- 同一测试验证桌面与手机横屏消息区高度占面板超过六成、频道高度不超过三十像素、频道宽度小于面板三成；同时覆盖发送、切换、未读、草稿、观众私有消息隔离和表情面板展开关闭。
- 目标组件与端到端文件 ESLint 及空白检查通过。
- 服务端与聊天 hook 本轮未改；行为单测沿用上轮四十二项通过记录，不作为本轮视觉合格证据。
- 旧视觉结论因用户指出占位问题撤销；新图逐张审查见本日视觉报告。
- 未验证竖屏、软键盘和长消息压力态。未提交、推送或部署。
