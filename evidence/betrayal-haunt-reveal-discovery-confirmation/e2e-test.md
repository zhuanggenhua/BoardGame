# 山屋惊魂普通预兆翻牌确认 E2E 证据

## 验收对象

- 本证据覆盖普通预兆触发作祟后，作祟揭示横幅和翻牌发现确认队列的真实页面承接。
- 本证据也覆盖普通预兆未触发作祟时，真实页面必须把预兆牌和作祟检定同屏展示，并等待所有玩家完成同一个确认步骤后回到作祟前牌桌。
- 规则含义：关闭作祟揭示横幅只代表收起“作祟开始”提示，不等于确认刚翻出的预兆；获得预兆和作祟检定可以保留两条结果事实，但玩家可见层只保留一个 `确认 x/y` 步骤，所有玩家确认后才关闭。
- 本证据不代表通用发现结算队列全部完成，也不代表灰尘剧本或全部作祟完成。

## 自动断言覆盖

- 普通预兆通过真实领域命令触发作祟，核心状态进入作祟阶段并保留一条 `pendingCardResolutionQueue`，同时保留“获得预兆 / 作祟检定”两条结果事实。
- 作祟横幅显示期间，发现面板不与横幅同时抢占前景。
- 关闭作祟横幅后，真实页面必须显示发现面板，按钮带有 `data-pending-card-resolution-step="1/1"`。
- 点击本人确认后，核心队列仍保留，页面按钮变为 `已确认 1/3`。
- 其余玩家确认后，核心确认队列为空，发现面板关闭，页面回到作祟牌桌。
- 普通预兆未触发作祟时，核心状态保持作祟前，页面不显示作祟揭示横幅，但同屏显示预兆、骰盘和 `确认 0/3`；本人确认后显示 `已确认 1/3`，所有玩家确认后才关闭。
- 未触发作祟的全员确认完成后，核心确认队列为空，持有区保留“狗”，最近结算记录保留获得预兆和作祟检定两条事实。
- 当前 9 张预兆牌池逐张覆盖：书本、狗、面具、头骨、圣符、盔甲、雕像、指环、匕首均在未触发作祟分支显示 `确认 0/3` 和 `已确认 1/3`，确认后回到作祟前牌桌，并通过核心状态断言对应牌名和基础 id 已进入当前探索者持有区。
- 当前 9 张预兆牌池逐张覆盖触发作祟分支：书本、狗、面具、头骨、圣符、盔甲、雕像、指环、匕首均先显示作祟揭示横幅，关闭后显示 `确认 0/3` 和 `已确认 1/3`，确认后回到作祟牌桌，并通过核心状态断言对应牌名和基础 id 已进入作祟揭示者持有区。

## 不外推边界

- 本证据只证明“普通预兆触发作祟 + 关闭作祟揭示横幅 + 一个全员确认步骤”的真实页面代表链。
- 本证据额外证明当前 9 张预兆在“未触发作祟 + 一个全员确认步骤 + 回作祟前牌桌 + 入持有区”分支上的真实页面矩阵。
- 本证据额外证明当前 9 张预兆在“触发作祟 + 作祟揭示横幅 + 一个全员确认步骤 + 回作祟牌桌 + 入作祟揭示者持有区”分支上的真实页面矩阵。
- 本证据不证明所有事件牌、房间效果、物品牌、兔脚重掷、死亡保护、作祟 setup、灰尘终局组合、预兆牌能力全排列或完整通用发现结算队列都已完成。
