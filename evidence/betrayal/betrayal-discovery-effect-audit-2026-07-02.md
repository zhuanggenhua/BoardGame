# 山屋惊魂发现池效果实现审计（2026-07-02）

## 结论

当前山屋惊魂可以进入审计阶段，但第一批审计结论必须写成：**发现池对象真相已成型，具体效果实现未收口**。本轮审计发现，当前代码已经建立 43 间房、11 张物品、9 张预兆、8 张事件的发现池；但房间效果没有独立字段或结算入口，物品/预兆效果只有通用数值增减模型，事件效果也只有通用移动/属性增减模型，不能判为房间效果或卡牌具体效果已审计完成。

## 代码证据

- 房间模板当前只有 `name / hint / tags / visualId / doorways`，没有房间效果字段；43 间房全部缺 `effect` 字段。
- 探索房间结算会更新房间基础数据、消耗牌堆、写入最近发现，并在事件牌场景下套用 `eventEffect` 的通用移动/属性增减。
- 物品/预兆使用共用 `USE_EFFECTS`，效果类型只支持 `move` 或 `trait`。
- `USE_POSSESSION` 有基本门禁：当前探索者必须持有该牌、同回合不能重复使用、本回合新获得不能立刻使用。
