> 2026-07-29 接续边界：本文件只审「木乃伊横行」进入作祟后的中段运行链，消费 `docs/games/betrayal/haunts/01-mummy-rampage.md`、当前实现、测试和既有 evidence。它不重新录入图包，不替代 74 张发现牌、42 个房间、全部作祟或完整自然长链 E2E。「女孩」版本边界已由当前总账裁定：它是旧版木乃伊剧本 token / 触发标签，不是当前 9 张预兆牌。

## 审计范围

本文件覆盖第 1 剧本「木乃伊横行」作祟开始后的中段规则消费：

- setup：叛徒、木乃伊、石棺、女孩、知识标记、公开 token。
- 英雄线：寻找木乃伊真名、学习驱逐法术、驱逐木乃伊。
- 叛徒线：拾起女孩、交女孩给木乃伊、交圣符或指环给木乃伊、木乃伊回石棺胜利。
- 木乃伊规则：强制关键预兆、0/1 移动骰瞬移、同房必须先攻击、2 点以上伤害后偷取或造成伤害。
- 终局读模型：英雄胜利与叛徒胜利的 If You Win 正文承接。

本文件不审整牌库效果、房间效果、事件牌「怪异的镜子」7 号作祟完整链、圣符/指环自身牌效完整链，也不新增玩法实现。

### 审计口径修订（2026-07-31）

本文件的审计核心是“规则子句是否被当前实现正确消费”：规则子句、实现入口、状态写入 / 清理、玩家可见入口和必要负向断言是否闭合。审计不是穷举所有房间、伤害、死亡保护、重掷和特殊状态组合；只有能直接改变规则结果、让玩家无法完成流程、或证明共享消费者不一致的组合，才升级为实现正确性缺口。

2026-07-31 补充：规则要求放置 token / 标记 / 怪物标记时，审计必须同时拆成“运行态对象存在”和“正式资源图面存在”。本文件此前只证明木乃伊运行态和地图交互存在，没有核对 `tokenAsset` / `portraitAsset` 对应资源文件是否真实存在；因此旧“公开 token”相关表述在木乃伊图面层失效，必须降级。

后续残余统一分三类：

- `实现正确性阻塞`：规则子句未实现、UI 无入口、状态未写入 / 未清理、合法动作无法完成、已锁合同与实现冲突。
- `验证层级缺口`：实现和代表证据已经存在，但还缺自然整局、真实截图、负向 UI 或发布级完整链证明。
- `非阻塞扩展`：更多房间特殊状态、更多伤害来源、更多减伤 / 死亡保护 / 兔脚叠加、全部组合排列；这些只能作为专项扩展或回归命中后处理，不能作为木乃伊中段当前完成门槛。

含义：木乃伊横行中段规则已经有合同、命令、校验、事件、reducer、目标条/token、领域代表测试和 Board 主动作代表测试；剧本阅读与终局朗读已有真实入口 E2E。本轮已补木乃伊怪物行动真实入口的 1 点移动骰、移动模式非法未发现房间提示、带女孩和圣符回石棺胜利、同房攻击目标过滤、已攻击后移动恢复、攻击奖励偷圣符/偷女孩和造成伤害分支：木乃伊移动骰为 0 或 1 时，真实页面均可从怪物动作槽进入移动模式并瞬移到女孩房间自动拾起女孩；移动模式会提示“只限已发现房间，不能探索新房间”，且未发现房间不会生成怪物移动目标框；木乃伊已持女孩并携带圣符时，可从真实怪物移动入口选择石棺房间，点击后进入叛徒终局朗读；木乃伊同房攻击目标过滤已补，叛徒和已死亡英雄即使与木乃伊同房，也不会被高亮为攻击目标，只有同房且存活的英雄可被点选；木乃伊同房攻击并结算偷取奖励后，真实页面会恢复「移动木乃伊」入口，并可瞬移离开当前房间；木乃伊真实攻击后可点击偷走地图、偷走圣符或夺走女孩，其中圣符会从英雄持有区移除并写入木乃伊携带预兆，女孩会改为木乃伊持有；木乃伊真实攻击后点击「造成伤害」会进入受伤英雄的「木乃伊攻击」物理伤害分配页，受伤英雄确认强制速度/力量伤害后会扣属性轨道格，并回到真实牌桌/投骰复盘界面；若受伤英雄持有头骨且木乃伊攻击造成致死伤害，真实页面会进入头骨死亡保护骰盘，成功后阻止死亡并回到牌桌，失败时显示「正常死亡」、目标英雄死亡，但因仍有另一名英雄存活不会直接进入终局；若目标英雄同时持有兔脚，头骨失败后真实页面会显示兔脚重掷入口，重掷成功后改为阻止死亡；若受伤英雄持有胸针，木乃伊强制伤害分配页仍只显示力量/速度，不显示胸针开关，不开放通用伤害属性，结算后胸针不记为已用；若目标英雄没有可偷物品、预兆或女孩，领域与 Board 代表链证明不会生成空的偷取奖励，而是直接进入木乃伊攻击强制物理伤害分配；若奖励 pending 后旧偷取目标失效，领域会拒绝偷取旧目标，Board 会显示偷取目标已失效并保留「造成伤害」选择。

此前已补强制关键预兆真实探索 E2E / 截图链：英雄作祟后探索预兆房会强制从预兆堆找出「书本」，叛徒作祟后探索预兆房会强制从预兆堆找出「圣符」或「指环」，并在发现面板显示木乃伊横行强制找牌提示。此前已补叛徒行动真实入口 E2E / 截图链：叛徒从真实牌桌主动作拾起女孩、交女孩给木乃伊、交出圣符进入叛徒终局，并覆盖木乃伊已持女孩时交出指环进入叛徒终局；此前已补英雄行动真实入口 E2E / 截图链：寻找木乃伊真名取得第 1 枚知识标记、学习驱逐法术取得第 2 枚知识标记、驱逐木乃伊进入英雄终局朗读和结果报告；此前已补木乃伊怪物行动真实入口 E2E / 截图链：移动骰 0 瞬移女孩房间并拾起女孩、同房必须先攻击、攻击后返回牌桌选择偷走地图。

当前仍不能宣称“山屋整游戏端到端完成”“全牌库完成”或“全部房间完成”；也不能把木乃伊中段的代表链外推成无残余发布结论。但按规则正确性审计口径，更多房间特殊状态组合、更多伤害来源减伤 / 死亡保护 / 兔脚组合、同一整局自然跨回合链和大量卡牌 / 房间交叉组合应分别归入验证层级缺口或非阻塞扩展，不能继续写成当前必须优先补完的实现阻塞。
