# 山屋惊魂木乃伊怪物行动真实入口 E2E

## 结论

- `e2e/betrayal/mummy-rampage-monster-actions.e2e.ts` 已通过，14 passed。
- 木乃伊移动骰为 0 或 1 时，真实页面可从怪物动作槽开回合、投移动骰、进入移动模式，并瞬移到女孩房间后自动拾起女孩；移动模式会提示“只限已发现房间，不能探索新房间”，未发现房间不会生成怪物移动目标框。
- 木乃伊与英雄同房时，真实页面不显示移动入口，必须先从木乃伊攻击入口选择木乃伊和同房英雄。
- 木乃伊已持有女孩并携带圣符时，真实页面可从怪物移动入口选择石棺房间，木乃伊回到石棺后触发叛徒终局。
- 同一真实入口已补攻击目标过滤：叛徒和已死亡英雄即使与木乃伊同房，也不会出现攻击目标高亮；只有同房且存活的英雄可被点选。
- 木乃伊与英雄同房完成攻击并结算偷取奖励后，真实页面会恢复「移动木乃伊」入口，并可从当前房间瞬移离开。
- 木乃伊攻击造成 2 点以上伤害后，真实页面会回到牌桌奖励选择，可选择偷走地图、偷走圣符、偷走指环、夺走被英雄持有的女孩，也可选择造成伤害并进入受伤英雄的伤害分配页。
- 受伤英雄视角可在「木乃伊攻击」伤害分配页确认强制速度/力量伤害；若受伤英雄持有盔甲，真实页面会显示原始物理伤害、盔甲减免 1 点和实际分配点数；结算后会扣除减免后的属性轨道格并回到真实牌桌/投骰复盘界面。
- 木乃伊攻击造成致死伤害且受伤英雄持有头骨时，真实页面会在伤害分配后进入头骨死亡保护骰盘；头骨掷出成功后阻止死亡，并回到真实牌桌而不是进入终局。
- 木乃伊攻击造成致死伤害且受伤英雄持有头骨时，头骨失败分支也已从真实页面覆盖：骰盘显示「正常死亡」，目标英雄死亡，但因为仍有另一名英雄存活，所以不会直接外推成终局。
- 木乃伊攻击造成致死伤害且受伤英雄持有头骨和兔脚时，真实页面覆盖头骨失败后的兔脚介入：受伤英雄持有区显示兔脚可重掷入口，选择骰子重掷后可把死亡保护结果改为「阻止死亡」，并回到真实牌桌而不是进入终局。
- 木乃伊攻击造成强制速度/力量伤害且受伤英雄持有胸针时，真实页面覆盖胸针不适用：受伤英雄持有区可见胸针，但伤害分配页不显示胸针开关，不开放知识/神志通用伤害入口，结算后胸针未记为本回合已用。
- 本证据只证明木乃伊怪物行动的真实页面入口、0/1 点瞬移、移动模式“只限已发现房间 / 不能探索新房间”提示与未发现房间不生成目标框、已持女孩和圣符时从怪物移动入口回石棺触发叛徒终局、同房先攻击、同房攻击目标过滤、攻击后移动恢复、偷取地图分支、偷取圣符分支、偷取指环分支、夺走女孩分支、造成伤害分配页入口、木乃伊攻击这一条的盔甲减伤、非致死伤害结算回牌桌、木乃伊攻击致死伤害触发头骨后的成功阻止死亡与失败正常死亡、木乃伊攻击头骨失败后的兔脚重掷阻止死亡，以及木乃伊强制伤害下胸针不适用；不证明胸针在其它伤害来源/非强制伤害真实入口、其它伤害来源的减伤/死亡保护/兔脚组合、更多楼层/房间目标组合或同一整局自然跨回合长链完成。
