# 山屋惊魂木乃伊怪物行动真实入口 E2E

## 结论

- `e2e/betrayal/mummy-rampage-monster-actions.e2e.ts` 已通过，4 passed。
- 木乃伊移动骰为 0 或 1 时，真实页面可从怪物动作槽开回合、投移动骰、进入移动模式，并瞬移到女孩房间后自动拾起女孩。
