# 小黑屋选角 UI 重构图面验收

## 本轮要求

1. 选角页减少多层边框，角色本体成为第一视觉主体。
2. 角色确认完成后只需一次点击，页面进入剧本卡确认阶段。

## 负面检查

- 未发现页面级横向溢出、角色卡裁切、底部主按钮出屏或选中态遮挡角色本体。
- 未把剧本候选弹层纳入最终交付组：900px 高度下候选列表需要滚动，避免将裁切状态包装为 PASS。

## 证据边界

- 本组只证明桌面 1600x900 选角入口的视觉和一次点击确认结果。
- 移动端、多人真实同步和完整剧本开局仍由对应 E2E / 组件测试覆盖，不由这两张图代替。
