## 固定局面与衔接

正式开局事先配置韦伯与伊斯坎达尔，玩家开始时尚未部署，不出现选角步骤。以下借鉴现有固定种子对局：先手占工房 +2，学员可选三个 +1 点位；部署、战略部署、前往深山町、补魔、明置出牌、骑乘追加、急行、战斗结算和下一回合依次由真实命令产生。来源：[教程计划](../../src/games/fate-domination/tutorial.ts)和[历史行为记录](direct-input-20261103-media/tutorial-real-entry/Fate-正式教程：真实开局、所有学员命令、自动他席、恢复与终局/e2e-1794185447579-ardiea/behavior-trace.json)。历史记录不是当前版复验。

示范目的是解释为什么此时这样做，不把示范选择写成唯一规则。正式合法点位全部显示并可操作；若其它合法选择改变后续状态，必须沿真实结果续接或回到完整检查点，不能伪造禁用或静默改写状态。

## 玩家可见文案与动作

每行代表一个教学意图；有些行动可在同一条提示下完成，不代表必须出现 23 张提示卡。卡面能够清楚表达的效果优先读原卡；带「条件」的行只在该局面真实发生时出现。

| 顺序 | 当前局面 → 玩家文案 | 玩家动作与下一步 |
| --- | --- | --- |
| 01 开场 | **原文**：圣杯战争将持续11天【回合】。每个夜晚【战力结算】，玩家将有机会与其他玩家战斗，以便在冬木市各地占领不同的目标，从而获得超越对手的优势。 | 进入同一局；身份已在场，不解释对手由谁控制。来源：CHM「如何进行游戏」。 |
| 02 胜负和整体流程 | **原文摘句**：他们在战斗中的取胜以及其他增加他们在圣杯战争中获胜机会的行动，如进行侦察，将具体地转化为战果点数（VP）用以衡量。**说明**：每回合依次经历准备、前哨、行动和战斗；先经历一回合，看看如何获得战果。 | 开始准备阶段。最终第 11 天胜负与淘汰在首次涉及排名或相关回合时交代，不用它取代开场目标。来源：CHM「如何进行游戏」「游戏流程」。 |
| 03 准备 | **原文**：按回合顺位，所有玩家从他们的牌堆中抽牌，将他们的手牌补充到上限（通常为3，此时已经有3张以上则不抽）。 | 看到补牌结果并完成本席准备；接前哨部署。 |
| 04 前哨部署 | **原文**：按回合顺位，玩家们将自己的御主立牌部署于魔术工房或战场（不可部署于侦查）。**说明**：这次先到魔术工房补充魔力，选择一个可用点位。 | 点具体点位或拖入直接部署；不是选整片区域。所有合法点位可见，工房按规则高位优先；进入工房后立即看到所得魔力。 |
| 05 御主能力 | **原文**：玩家可以于自己的前哨阶段的任意时候（包括部署前和部署后）使用自己的“前哨阶段”能力。**说明**：使用「战略部署」补充手牌，为接下来的出牌做准备。 | 在角色旁实际发动；读当前能力真实卡文「支付1魔力来抽2张牌」，看到扣魔与抽牌。悬浮详情不遮掉教程。 |
| 06 进入行动 | **说明**：手牌已经准备好。接下来前往战场争夺事件战果。**原文**：然后，按回合顺位，玩家们必须以如下顺序进行行动：1.进行常规移动。2.进行常规出牌。 | 完成前哨并等待其他席位，进入行动阶段。 |
| 07 常规移动 | **原文**：常规移动不可拆分，需一次决定起点与终点且一次性花费魔力。**说明**：点击自己的棋子，再点深山町；也可以直接拖过去。 | 按当前地图可达性行动，支付实际路线费用；展示到达的战场和事件。无法移动时给出真实原因，不用无意义遮罩。 |
| 08 交战（条件） | **原文**：若你与至少一名对手（包括玩家和NPC）一起位于一处会发生战斗的战场，则你处于“交战状态”，此时你无法进行常规移动。 | 只在确实与对手同处战场时出现；随后出牌。效果移动另按对应卡文解释。 |
| 09 看牌 | **原文**：攻击牌有魔力消耗和基本威力。**说明**：检视「骑乘」，看看费用、威力与它的效果。 | 通过放大镜、长按或右键检视真实牌面，再回到当前行动；不在详情中显示临时合计威力。 |
| 10 令咒补魔（条件） | **原文**：通常你必须在出牌前拥有8点及以上的魔力才可以从技能区打出攻击。**说明**：当前魔力不足；使用令咒恢复魔力，为打出「骑乘」做准备。 | 选择恢复并确认，按真实数值决定是否还需一枚；不足时不能假装已经达标。 |
| 11 常规出牌 | **原文**：打出正好两张攻击牌作为你本回合的常规出牌。它们可以是你手中的普通攻击牌……或是你技能区的技能攻击…… **说明**：这次明置选择「翻弄」与「骑乘」，选好后确认；再点已选牌可以撤回。 | 选择、撤回只影响草稿；确认后实际支付并提交，正式区域显示攻击和合计威力。牌实例和费用须随当前复演校对。 |
| 12 骑乘 | **说明**：骑乘已打出，可以使用牌上的「坐骑召唤」追加攻击。 | 发动真实牌上能力，依据实际候选和费用选择，最多三张；确认后观察实付与威力变化。卡面是规则源。 |
| 13 效果移动 | **说明**：刚追加的「急行」可以让你沿箭头前往下一地点；按牌面发动它。 | 只在急行实际打出且可发动时出现；观察抵达后的战场。效果移动的费用及交战例外按中文原文和牌面，不能说成常规移动。 |
| 14 查看对手 | **说明**：悬停对手头像查看已打出的牌；触控时点玩家摘要。 | 玩家比较当前战场公开威力与公开牌；暗置牌维持隐藏。牌排可移入检视，详情只承载静态资料。 |
| 15 战斗与结算 | **原文**：在所有玩家的战斗阶段结束后开始进行战力结算。**说明**：比较当前战场各玩家的威力，看看谁获得事件战果。 | 玩家完成自己的战斗阶段；其他席行动后观察实际结算。首次结算时提供原文中的攻击威力、地利及能力/局势/天气影响；有地利时才指向实际地利。 |
| 16 回合收牌 | **原文**：回合结束时，令技能牌明置返回其技能区并令非技能牌暗置进入其弃牌堆。你可以于任何时候查看自己的弃牌堆。 | 第一轮确实清理后查看；进入下一轮准备，不把“查看弃牌”写成卡牌效果。 |
| 17 战场部署与地利（条件） | **原文**：若部署于战场且位于地利位置，战力结算时，若该玩家仍位于此位置，获得等同于该地利位置标注的地利数的合计威力。 | 玩家实际在战场选择合法点位并在结算时观察，不把工房收益说成战场地利。 |
| 18 暗置（条件） | **原文**：若你位于战场，则你的常规出牌中必须要有一张明置牌。暗置牌处于未被激活的状态，它们不消耗魔力，不计算威力，也不属于攻击……通常而言，技能牌不能被暗置打出。 | 在确有两张可用牌且有保留魔力的目的时，切换暗置选一张普通牌并确认。非战场两张暗置是另一规则，不冒充本次战场示范。 |
| 19 战后选择（条件） | **卡面原文**：此战场的胜者可以恢复1枚令咒。**说明**：选择是否恢复。 | 仅当真实事件 E12、玩家获胜且存在选择时出现；玩家亲自选择并看到结果。来源：中文事件卡面录入。 |
| 补充：真名解放（条件） | **原文**：有些卡牌会拥有【真名解放】词条，当你使用这些卡牌后，立即展示你的从者概览卡与所有技能牌并处于【真名解放】状态。 | 仅在真实揭示时对准对应玩家；查看新公开的资料，不泄露未揭示的内容。 |
| 补充：令咒战斗与移动（条件） | **说明**：令咒还有强化战斗或移动的效果；查看可用效果后，选择本次要使用的效果并确认。 | 必须有实际令咒、合法时机和相应对局目的；具体收益、目标与移动规则来自中文令咒原文，不能编造效果。若主线没有自然前因，记作未覆盖而非插入虚构局面。 |
| 20 排名与淘汰（条件） | **原文摘句**：在第8天【回合结束时】，除VP前4名的玩家外，所有玩家都被淘汰出局；第9天保留前3名，第10天保留前2名。**说明**：分数相同等并列情况按规则处理。 | 在实际首次相关时机显示；淘汰标记直接落在头像上。人数不足对应名次时不凭空制造淘汰。平局规则须以中文原文完整处理。 |
| 21 终局 | **原文**：在第11天【回合结束时】，拥有最多VP的玩家将获得圣杯并赢得游戏。 | 实际结局后显示结果；若并列，按中文规则依次处理深山町胜者与仍平局的结果。 |
