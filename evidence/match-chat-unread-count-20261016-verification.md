# 统一未读数字角标

本轮仅统一 MatchChatPanel 的未读展示：玩家与观战席使用同一数字角标，超过九十九显示 99+，未读为零不显示。频道、消息、权限和未读状态源均不变。

- 真实联机端到端：`npm run test:e2e:file -- e2e/dicethrone/chat-channels.e2e.ts`，一项通过，总时长二十四点一秒。
- 观战席未读从一累积到二并显示数字，切入观战席后清除；玩家停留观战席收到玩家频道消息时显示数字一，切入玩家频道后清除。上述均为真实消息产生并断言，不注入未读状态。
- 同一用例保留草稿、观众私有历史隔离、表情展开关闭及桌面／横屏紧凑比例验证。
- 目标 ESLint、差异空白检查、OpenSpec 严格校验通过。
- 第四张展示观战席数字二，第七张展示玩家数字一，第八张展示切入后清除。
- 99+是原有展示逻辑，本轮保留，未发送百条真实消息作边界压力验证。
