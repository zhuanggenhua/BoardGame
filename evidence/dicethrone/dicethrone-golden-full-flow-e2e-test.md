## 修复与保护

- 响应窗口位置：`src/games/dicethrone/ui/GameHints.tsx` 将响应条固定在 `data-placement="fixed-hand-lift-slot"`，底部偏移为 `clamp(10rem, 42vh, 26rem)`，视觉位置在抬起手牌上方而非屏幕中部。
- 响应窗口 E2E：`e2e/dicethrone/dicethrone-ai-ultimate-response.e2e.ts` 断言响应条为 `fixed`、锚定视口、位于手牌上方、与抬起手牌留出空隙，并验证手牌 hover 后响应条不漂移。
- 相关回归用例已同步新槽位断言：`dicethrone-bonus-dice-e2e-screenshots.e2e.ts`、`dicethrone-die-modification.e2e.ts`、`ui-scope-regression.e2e.ts`。
- 手牌空白问题：黄金链夹具不再从裸通用牌定义取牌，改为按角色牌组取带正式 `previewRef` 的 `MOON_ELF_CARDS` / `BARBARIAN_CARDS`；缺正面图集会直接失败。
- 截图前置：`screenshotStep()` 每次落图前等待当前玩家手牌翻正、图集图片加载完成且无 shimmer / 牌背 / 空白占位。
- 规范落点：独立 UI 的规则已在 `.spec/knowledge/standards/ui-ux.md` 里明确，绝对/固定定位 UI 必须挂 overlay/rail 层，不能参与主内容 flex/grid 布局；本轮没有新增平行规则。
