# 本聊天全部改动的旧 UI 复用复查

> 本文为历史复查记录，原30图总通过结论已撤销。当前全部新交互以[重新逐图验收](doctor-strange-full-ui-reaudit-20261101.md)及其真实新媒体为准；本文的旧测试、旧图审和旧查看器记录不证明当前已通过。

用户要求：“反思所有修改，非必要不要旧的ui，而是直接复用啊”。按上下文解释为“非必要不要改旧 UI，直接复用”。范围为本聊天奇异博士实施及共享消费者的改动，不撤销其它聊天的工作。

基线按模块取实际历史，不整文件回滚：旧提示外观使用 `22790d2c7^` 的 `GameHints`；旧卡池统一尺寸、原取消控件使用 `90b7dba67^` 与 `22790d2c7^` 的对应组件。`git log -S` 还确认卡池入口早在2026-09-10已经存在、普通选骰提示入口命中2026-03-04历史，均早于本聊天实施，不能以“没有旧组件”为理由重造。用户明确要求的新行为和缺陷修复优先于旧源码。复查期间不修改规则结果、候选权限或卡牌来源来迁就界面。

## 逐项裁决

| 修改对象 | 旧入口 / 历史核对 | 必要性与处理 |
| --- | --- | --- |
| 普通重投/改骰提示 | 原 `GameHints.DiceInteractionHint` | 撤掉擅改的深棕窄面板、左对齐、字号、去动画及额外说明行；恢复原琥珀色单行、原尺寸/边距/动画/层级和左侧居中。提示挂载及真实重投进度保留。 |
| 卡池少量候选放大 | 原 `InteractionOverlay` 统一 `CARD_POOL_CARD_WIDTH` | 没有用户要求单独放大的依据，删除 focused 尺寸分支，恢复统一尺寸。 |
| 选中后其它牌压暗 | 原卡池直接比较所有候选 | 删除新增压暗，其它候选保持可见；保留真实选中标记。 |
| 卡池承载底框及浅色套框 | 原透明卡池与正式卡面 | 已按用户否决移除，恢复原满宽透明承载；不恢复违反当前明确要求的额外卡框。 |
| 取消/跳过按钮 | 原 `ChoiceModal` 的 secondary 样式 | 撤掉擅改的透明 ghost 样式，恢复旧控件；不改变点击语义和命令。 |
| 三分支选项布局/样式 | 复用 `ChoiceModal` 和 `GameButton` | 用户明确要求平面、单列、对比清楚，保留该改动；确认/取消仍使用原按钮。 |
| 玩家及状态选择 | `ChoiceObjectSelection` 适配既有 `InteractionOverlay` | 保留必要的规则候选映射，复用原玩家头像、状态素材、选中和确认；不另造第二套对象选择器。 |
| 手牌/牌库/弃牌/准备区选择 | 既有卡池、卡图和预览来源解析 | 仅扩展新英雄真实卡区候选；保留正式来源和权限，不新增影子牌库。 |
| 清空/取消入口 | 旧 `InteractionOverlay` 已有该控件 | 不作为新交互增加；根据原入口继续承接取消或清除，保留原本允许/禁止条件。 |
| 单持有人弹窗 compact | 默认仍为原 `GameModal normal` | 用户明确否决09占满窗口，仅单个状态持有人保留紧凑参数；撤回对玩家和多人选择的额外压缩，恢复原xl/normal、内边距和标题间隔。 |
| 状态说明位置 | 原 `InfoTooltip`，仅单持有人传边界 | 07/09真实遮住候选或确认的修复必要，保留最窄定位参数，不重画 tooltip；多人持有人保持原定位。 |
| 手牌区域高度/布局常量 | 历史高度本来就是22个壳层单位 | 保留同值常量复用，未缩改旧手牌区；修复实际裁切，保持已有手牌组件。 |
| 骰盘选择、进度与提交 | 原 `DiceTray` / `DiceActions` | 复用原骰子与确认/取消；必要修复包括选满仍清楚可见、同骰重复选择排队不提前执行。不开第二个骰盘。 |
| 提示/合法动作合同 | 原交互owner、单一展示面 | 保留必要的操作者/骰子owner/合法候选投影，避免左右重复提示；不以合同重构为由改变旧组件外观。 |
| 技能选择与效果分支 | 原 `AbilityChoiceModal`、`ChoiceModal` | 保留原技能选择入口，候选由规则提供；对象型选择接已有完整选择器，不增加先选角色再选唯一效果的重复步骤。 |
| 来源卡特写 | 原 `CardSpotlightOverlay` / `CardPreview` | 保留来源卡自动显示和关闭；去掉用户否决的外框，并按真实frame算高度，修掉写死0.61造成的比例问题。 |
| 小卡正文阅读 | 原 `CardInspectButton`、原 `Board.setMagnifiedCard`、原 `BoardOverlays/MagnifyOverlay` | 图审确认缩略正文太小，不能只因旧尺寸就通过；最窄补齐是接入已有阅读控件与长按hook，不新造阅读状态。检视不选择、不提交，关闭后回原选择。单卡按真实帧比计算高度，并受既有容器可用高度约束，防裁切；未改多卡阅读外观或共享MagnifyOverlay。 |
| 新角色素材、物理槽、准备区 | 武士v2参考、奇异博士独立素材合同 | 新内容必要，接入原玩家板、卡图、状态和预览；不替换旧英雄的素材和布局。 |
| 角色状态与排序 | 原角色目录及选角组件 | 用户明确要求保留实施中并后置，保留状态派生排序；未创设新选角页面。 |
| 规则、AI、日志、撤回、资源链 | 原领域owner与已有支撑能力 | 原实施范围所需，保留规则与候选正确性修复；这轮不把UI反思扩大成改游戏规则或全仓重构。 |
| E2E、源码身份、图片查看器 | 已有项目工具 | 只支撑当前源码和实际媒体验收，不作为重画产品UI的依据；不降低校验或用历史PASS否定用户反馈。 |

其它聊天当前在 `statusEffects.tsx` 的 token 涟漪修改不属于本聊天恢复范围，不覆盖。已把本次共享提示的用户裁定同步给此前已获用户授权协调的雷神聊天，防止再依据旧顶部记录改写。
