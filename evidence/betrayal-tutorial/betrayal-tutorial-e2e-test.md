# 山屋惊魂教程 E2E 截图验收

## 当前自然流程

本轮真实桌面教程从正式牌桌开始，按玩家因果链完成：移动到相邻房间 -> 进入探索 -> 放置并确认新房间 -> 触发事件牌 -> 点击“投掷事件” -> 事件骰和结果公开 -> 查看书本牌面 -> 关闭牌面并使用书本本体 -> 神志 -1，事件检定改用知识重新投骰 -> 选择兔脚要重掷的骰子 -> 确认使用兔脚并重投 -> 查看重投后的正常骰盘 -> 没有新选择时自动进入伤害分配 -> 选择承受伤害的属性并确认。

书本不在事件触发前单独教学；它只在事件已经触发、玩家点击“投掷事件”、事件骰出现后进入教学。先用放大按钮查看书本牌面，读完关闭，再点击书本本体生效。兔脚选中骰子必须有玩家一眼能看见的选中态；兔脚重投后的截图必须保留正常尺寸骰盘。事件牌和骰面已经在公开投掷、书本改骰和兔脚重掷过程中展示；没有新的玩家响应、选择或授权时，不再要求逐人确认事件骰，运行时自动进入伤害分配。物品确认和事件确认复用同一套确认按钮样式。
