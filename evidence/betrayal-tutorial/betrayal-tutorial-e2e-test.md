# 山屋惊魂教程 E2E 截图验收

## 当前自然流程

本轮真实桌面教程从正式牌桌开始，按玩家因果链完成：移动到相邻房间 -> 进入探索 -> 放置并确认新房间 -> 触发事件牌 -> 点击“投掷事件” -> 事件牌、骰面和结果展示给所有玩家 -> 直接点击书本把检定改为知识 -> 查看书本牌面 -> 选择兔脚要重掷的骰子 -> 确认兔脚并重投 -> 看清最终骰面和事件结果后确认 -> 进入伤害分配。

书本不在事件触发前单独教学或确认；它只在事件骰已经出现后作为当前投骰的即时改骰入口。书本点击后立即生效，不弹二次确认。事件结果会展示给所有玩家；确认按钮的职责是让玩家确认大家已经看清这次事件和最终骰面，确认完成后才进入后续结算。物品确认和事件确认复用同一套按钮样式。
