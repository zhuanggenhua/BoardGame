# 阿南西之网首次标准行动修复

- 规则来源：发行商规则页 https://smashup-rulebook.alderac.com/wiki/Anansi_Tales ，Anansi's Web；每回合玩家首次打出标准行动后，在该基地有随从时可把该牌交给他人并抽两张。规则页明确牌面指定自己去向的牌不触发该替代。
- 原因：旧代码只在执行转交后记录基地已用，选择让过或牌自身规定去向时未记录“第一次行动已经发生”。
- 实现：标准行动事件记录当前回合每位玩家首次出牌的身份；触发条件核对该事件，并根据牌面定义排除已指定转交去向的行动。去除以基地是否执行转交作为第一次出牌依据的状态。
- 验证：`anansi-web-first-action.test.ts` 的首次让过、牌自身指定去向、新回合、第一次出牌后才进入基地、先打非标准行动、同牌回手重打等七个命令链通过；`anansi-tales.test.ts` 中阿南西之网目标交互和转交抽牌测试通过。同类搜索补录了已找到的强制回牌库行动；可选替代去向及所有对象组合尚未全面审计。规则测试与状态预置不等于浏览器实战验收。
